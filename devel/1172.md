# 1172 French 数学快捷键迁移到 lang 插件

## What

将 `TeXmacs/progs/math/math-kbd.scm` 中 `in-math-french?` 的 kbd-map 迁移
到 lang 插件 `TeXmacs/plugins/lang/progs/lang/french-kbd.scm`，并在
`TeXmacs/packages/customize/language/french.ts` 中
`<use-module|(lang french-kbd)>` 加载。

迁移 20 条有效绑定（外加原块中注释掉的历史绑定一并搬移），内容逐行
不变。绑定全部为纯 ASCII，无 cork 编码问题（与 1157 spanish 不同）。

## Why

语言相关快捷键收敛到 lang 插件统一管理，与 spanish-kbd / esperanto-kbd /
chinese-kbd 的结构保持一致（见 1156、1157）。

## How

- 新增 `plugins/lang/progs/lang/french-kbd.scm`：
  `(texmacs-module (lang french-kbd) (:use (math math-kbd)))`，
  内含原 `in-math-french?` kbd-map 全部 20 条绑定。
- `math-kbd.scm` 删除整个 `in-math-french?` kbd-map 块
  （该文件为 UTF-8，可正常 `gf fmt`）。
- `french.ts` 增加 `<use-module|(lang french-kbd)>`，文档切换为
  French 语言时加载快捷键。

主要绑定（法语数学模式，`var` 即 `Tab` 键）：

| 按键序列 | 效果 |
|----------|------|
| `空格 e t` | 插入 `∧`（infix-and，"et"） |
| `空格 o u` | 插入 `∨`（infix-or，"ou"） |
| `空格 s s i` | 插入 `⇔`（infix-iff，"ssi"） |
| `p o u r 空格 t o u t` | 插入 `∀`（prefix-for-all，"pour tout"） |
| `空格 e var…` | ε 系列变体（varepsilon / mathe / epsilon / backepsilon） |
| `空格 o var` | ο（omicron） |
| `空格 s var[ var]` | σ / ς（sigma / varsigma） |

## 如何测试

迁移后行为应与迁移前完全一致。

前置：启动 Mogan，新建文档，通过菜单「文档 → 语言 → French」将文档语言
切换为法语，进入数学模式（`$`），输入 `p o u r space t o u t` 验证
快捷键生效。

回归：把文档语言切回 English，重复该序列，确认不再触发（快捷键已从
全局 math-kbd 移除，仅随 French 语言包加载）。

## 涉及文件

- `TeXmacs/plugins/lang/progs/lang/french-kbd.scm`（新增）
- `TeXmacs/progs/math/math-kbd.scm`（删除 in-math-french? kbd-map）
- `TeXmacs/packages/customize/language/french.ts`（加载模块）
