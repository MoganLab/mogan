## What
将 chat-tab-session.scm 中自主拼接的输入输出格式，改为使用 TeXmacs 标准的 `session` + `unfolded-io-text` 结构。

1. 修改 `chat-tab-append-round!`，将当前手动拼接的 `(with "font-series" "bold" "User:")` / `(with "font-series" "bold" "Assistant:")` + `output` 节点，替换为标准的 `unfolded-io-text` 节点。
2. `unfolded-io-text` 的子节点依次为：prompt（`document`）、input（`document`）、output（`document`）。
3. prompt 默认使用模型简称（如 `"V4> "`）。
4. message-buffer 的顶层结构从 `document` 改为 `session`，以便与标准 session 机制保持一致。

规范格式示例：
```scheme
(session "llm" "DeepSeek-V4-Pro:225510-2"
  (document
    (unfolded-io-text
      (document "V4> ") (document "hello")
      (document "Hello! How can I help you today? "))
    (unfolded-io-text
      (document "V4> ") (document "world")
      (document "Hello! If you have any questions..."))
  )
)
```

## Why
当前 chat-tab-session 采用自主拼接的 document 结构（手动插入 bold "User:"、bold "Assistant:" 和 output 节点），这导致：
- 格式与 TeXmacs 原生 session 机制不兼容；
- 无法复用 session-edit.scm 中已有的字段折叠、prompt 管理、输出处理等基础设施；
- 未来若需支持导出或渲染自定义样式，维护成本高。

通过迁移到标准的 `unfolded-io-text`，可以复用现有的 session 框架，降低维护成本，并确保格式一致性。

## How
参考 `session-edit.scm` 中 `field-create` 和 `make-session` 的实现思路，在 `chat-tab-session.scm` 中进行如下改造：

1. **简化前提**：chat-tab-session 已调用 `session-enable-text-input`，因此 `session-text-input?` 在该会话中恒为 `#t`，可直接使用 `input-text` / `unfolded-io-text` 分支，无需判断。

2. **修改 `chat-tab-append-round!`**：
   - 构建 `unfolded-io-text` 节点，三个子节点分别为 prompt、input、output 的 `document`。
   - prompt 可从模型名称提取前缀（如 `DeepSeek-V4-Pro` 取 `"V4> "`），或使用 `plugin-prompt` 机制获取。
   - 将 `unfolded-io-text` 插入到 message-buffer 的 document 中。
   - 返回值仍为 output 对应的 document 树节点，供后续 `chat-tab-output` 写入使用。

3. **调整 message-buffer 初始化**（如有必要）：
   - 若需要将顶层改为 `session` 节点，可在 `chat-tab-ensure-session!` 中首次初始化时，将 buffer body 设为 `(session "llm" ses (document))`。
   - 或在 `chat-tab-adapter.scm` 的 `open-llm-chat-tab` 中创建 buffer 时直接插入 `session` 节点。

4. **保持现有回调机制不变**：
   - `chat-tab-session-do`、`chat-tab-session-next`、`chat-tab-session-notify`、`chat-tab-session-cancel` 的回调逻辑无需改动。
   - `chat-tab-output` 仍负责将模型返回内容追加到 output document 中。
