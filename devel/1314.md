# 1314 命令行导出 PDF 幻灯片多页展开

## 问题

执行命令行转换命令：
```bash
xmake r stem -c TeXmacs/tests/tmu/1314.tmu /tmp/1314.pdf
```
导出的 `/tmp/1314.pdf` 只有 1 页，未能将包含 `<screens>` 的幻灯片展示文稿全部屏幕展开为多页 PDF。

## 根因

1. 命令行参数 `-c` 在 `src/System/Boot/init_texmacs.cpp` 中默认拼接执行 `(load-buffer <in> :strict)` 和 `(export-buffer <out>)`；
2. `export-buffer` 走 `buffer-export`（C++），直接调用 `vw->ed->print_to_file (dest)`，未对幻灯片文档（`<screens>`）执行 `dynamic-make-slides` 展开；
3. 此外，Scheme 端展开幻灯片存在未绑定的变量依赖：
   - `screens-buffer?` 未注册到 `init-research.scm` 的 `lazy-define (dynamic fold-edit)`，且 `tm-print.scm` 未 `:use (dynamic fold-edit)`；
   - `fold-edit.scm` 中调用了 `converter-context?`，但未在模块中定义或导入，导致 `dynamic-make-slides` 报错中断；
   - `wrapped-print-to-file` 末尾调用了 GUI 确认弹窗 `user-confirm-open-pdf`，在 headless/命令行导出时不应弹出。

## 修复

1. **命令行特殊处理**：在 `src/System/Boot/init_texmacs.cpp` 的 `-c` 选项处理中，针对 `out_suffix == "pdf"`，调用 `(export-buffer-to-pdf <out>)`；
2. **提取 `export-buffer-to-pdf`**：在 `TeXmacs/progs/texmacs/texmacs/tm-print.scm` 中定义 `export-buffer-to-pdf`：
   - 复制当前 buffer 到临时 buffer，避免污染原文档；
   - 若为 `screens-buffer?` 则执行 `dynamic-make-slides` 将多屏幕展开为多页幻灯片；
   - 若包含 `dark` 样式包则移除；
   - 调用 `print-to-file` 导出；
   - 关闭临时 buffer 并切换回原 buffer；
   - `wrapped-print-to-file`、`wrapped-print-to-pdf-embeded-with-tm`、`wrapped-print-to-pdf-embeded-with-tmu` 复用该函数；
3. **修复符号依赖与 headless 守卫**：
   - 在 `fold-edit.scm` 中补充 `converter-context?` 定义；
   - 在 `init-research.scm` 的 `(lazy-define (dynamic fold-edit) ...)` 中补充 `screens-buffer?`；
   - 在 `tm-print.scm` 的模块定义中加入 `(:use (dynamic fold-edit))`；
   - `user-confirm-open-pdf` 增加 `(and (x-gui?) (not (headless?)))` 守卫；
4. **集成测试**：
   - 添加 `TeXmacs/tests/1314.scm` 测试用例，验证幻灯片导出为 PDF 时为 2 页。

## 简化调整（/simplify 复查后）

1. **`converter-context?` 改为导入而非重复定义**：`scripts-edit.scm:489` 已有完全相同的定义，
   在 `fold-edit.scm` 重复定义会造成两处漂移。删除新定义，`fold-edit.scm` 的 `:use`
   加入 `(dynamic scripts-edit)`（无循环依赖，scripts-edit 不依赖 fold-edit）；
2. **headless 守卫简化**：`(and (x-gui?) (not (headless?)))` 中 `x-gui?` 在 Qt 构建下
   恒为 `#f`（`gui_is_x()` 在 `QTTEXMACS` 下返回 false），导致 GUI 下确认弹窗也永远不弹。
   改为 `(not (headless?))`，恢复 GUI 行为、仅抑制 headless；
3. **删除冗余 `screens-buffer?` lazy-define 注册**：`tm-print.scm` 与 `fold-menu.scm`
   均通过 `:use (dynamic fold-edit)` 模块导入解析该符号，无需注册到顶层；
4. **合并两个 embeded 包装函数**：`wrapped-print-to-pdf-embeded-with-tm/-tmu` 提取后
   仅剩字符串差异，抽出 `(wrapped-print-to-pdf-embeded fname kind)` 公共函数，
   两个 `tm-define` 各剩后缀校验加一行转调；
5. **`wrapped-print-to-file` 去掉冗余 `let`**：`export-buffer-to-pdf` 返回前已切回原
   buffer，直接 `(save-buffer-save (current-buffer) ...)`，与两个兄弟函数保持一致；
6. **C++ `-c` 分支去重**：`load-buffer` 前缀在 pdf 与默认分支重复，合并为共享的
   else 分支内按 `out_suffix == "pdf"` 选择导出命令。

验证：`xmake r 1314` 通过（2 correct, 0 failed）；命令行
`xmake r stem -c TeXmacs/tests/tmu/1314.tmu /tmp/1314.pdf` 导出 2 页 PDF。
