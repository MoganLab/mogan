## 2026/04/03 session input 块改为可分页的悬挂缩进结构

### What
将 session 和 program 中 `generic-input` 的实现，从基于 `tabular/tformat/table` 的两列表格结构，改为基于 `alt-prefixed-line` 的悬挂缩进结构。
这样 prompt 仍然保持在左侧，正文保持原有的视觉对齐方式，但整个 input 不再被排版器视为不可拆分的大块。

### Why
此前 `generic-input` 使用表格来排版 prompt 和 body。
表格在分页时通常会被当作一个整体处理，所以当单个 input 块内容过长、接近或超过页高时，排版器会尽量整体移动该块，而不是在页尾断开正文继续排到下一页。
这会导致 session 中的长 input 无法自然分页，与 output 块的分页行为也不一致。

### How
TeXmacs/packages/compute/session.ts :79 将 `generic-input` 从两列表格改为 `alt-prefixed-line`
TeXmacs/packages/compute/program.ts :77 将 `generic-input` 从两列表格改为 `alt-prefixed-line`
