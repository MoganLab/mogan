## 2026/08/04 PDF 目录跳转

### What
实现点击 PDF 大纲（书签）条目跳转到对应页码的功能。

### Why
仅有侧边栏展示还不够，需要支持点击导航才能发挥大纲目录的价值，让用户能够快速定位到文档的指定位置。

### How

#### 1. 页码修正（0-based → 1-based）

`PdfOutlineItem::page` 由 `fz_resolve_link` 解析得到，是 **0-based** 页码；而 `PDFReaderWidget::goToPage()` 使用 **1-based** 页码。在 `buildTree(PdfOutlineItem)` 中转换：

```cpp
// PdfOutlineItem::page 是 0-based（fz_resolve_link），goToPage 需要 1-based
int pageOneBased= (item.page >= 0) ? item.page + 1 : -1;
treeItem->setData (0, Qt::UserRole, QString::number (pageOneBased));
```

#### 2. 信号连接（outlineActivated → goToPage）

在 `qt_tm_widget_rep::sync_startup_tab_mode()` 中，创建 `PDFReaderWidget` 后连接信号：

```cpp
PDFReaderWidget* viewer= pdfViewerWidget;
QObject::connect (pdfOutlineDock, &OutlineWidget::outlineActivated,
                  viewer, [viewer] (const QString& target) {
                    bool ok;
                    int  page= target.toInt (&ok);
                    if (ok && page >= 0) viewer->goToPage (page);
                  });
```

点击大纲条目时，`OutlineWidget` 发出 `outlineActivated(QString)` 信号，lambda 将字符串转为整数后调用 `goToPage(page)` 完成跳转。
