# [1311] 在领取会员左侧添加 Go 按钮并用 QML 实现 Go 菜单

## 1 任务背景
在 Mogan 标题栏（领取会员按钮左侧）新增一个导航/跳转入口按钮（Go），提供快速打开最近使用文档的功能。
- 移除光标历史跳转（后退、前进、保存位置）及冗余的打开文档列表；
- 专一、聚焦展示最近使用的文档列表（Recent），点击快速加载；
- 采用现代 QML 实现该下拉菜单浮层，并从主菜单栏中移除原本的「Go」菜单项。

## 3 下拉菜单展示改进
通过 Python 自动化测试脚本截取真实界面截图，进行以下精简与视觉体验提升：
1. **纯净聚焦最近使用**：移除前进、后退、保存位置三项操作，仅展示「最近使用」文档，去除冗余图标占位，文件名靠左完整对齐；
2. **初始高度自适应**：QML `Column.implicitHeight` 依赖延迟排版导致 `adjustSize()` 初始高度塌陷，通过依据条目数即时计算确定合理高度；
3. **中文文件名编码修复**：`GoMenuBridge.cpp` 中将 `cork_to_utf8` 替换为 `to_qstring`，自动保持 UTF-8 文件名保真，杜绝乱码；
4. **浮层右对齐**：右对齐至「转到」按钮右侧，自然向左展开，完全不遮挡「领取会员」等右侧按钮；
5. **视觉与滚动**：优化双层柔和阴影，超出最大高度时显示优雅细条滚动指示器；
6. **点击打开文档崩溃修复**：点击打开最近文档时，`load-buffer-open` 会自动关闭之前的未修改空白草稿缓冲区（`prev-buffer`），而 `delete_view` 在销毁旧视图时未重置全局指针 `the_view`，导致随后的光标移动通知触发 `get_current_view()` 时访问已释放内存崩溃（SIGSEGV）；修复为在 `delete_view` 中重置 `the_view = NULL`，并在 `get_current_view` 中安全回退到历史可用视图，同时在 `abstract_view` 中增加空指针保护；另外将 Scheme 侧 `load-buffer` 替换为更健壮的 `load-document`；
7. **新文档标签页选中状态修复**：
   - `concrete_window()` 在新视图刚生成未绑定窗口时抛出 "no window attached to view" 断言异常，导致后续 `window_set_view` 中断，增加回退到当前主窗口（`all_windows[0]`）；
   - `qt_tm_widget.cpp` 在 `SLOT_FILE` 和 `SLOT_TAB_PAGES` 中改用 `window_view_for_widget(this)` 取当前窗口实际视图，而非易受浮层焦点影响的全局焦点视图；
   - Scheme 侧 `go-menu-meta` 统一使用 `url->system` 与 `system->url`，并在打开后主动 `switch-to-buffer*`，保证标签页 URL 精准匹配并高亮选中。

## 5 代码精简（/simplify）

**What**：清除菜单收缩为「仅最近文档」后遗留的死代码与重复实现。

**Why**：QML 只消费 `label_recent`/`recent` 与 `loadBuffer`/`closeMenu`，但元数据契约、bridge 槽函数与测试仍保留前进/后退/保存位置/打开文档列表的完整链路，读者需追踪后才发现在何处终止。

**How**：
- `GoMenuBridge` 删除 `goBack`/`goForward`/`savePosition`/`switchToBuffer` 槽函数、`buffers` 等 7 个无用 meta 键及 `tmscm_to_cpp_bool`；`loadBuffer` 改用项目既有的 `exec_delayed (scheme_cmd ...)` 延迟求值惯例，去掉 `QTimer` 与遗留的 `converter.hpp` 引用；
- `go-menu-meta` 仅产出 `label_recent`/`recent`；删除分支完全相同的 `go-menu-switch-to-buffer`；
- 抽出 `(open-recent-entry u)` 统一最近条目的云文档 join/本地 load 分派，`go-menu-load-buffer` 与 `startup-tab-open-recent` 共用；
- `short-menu-name` 改为对 `short-file-name` 的 `utf8->herk` 包装，消除逐字节重复的 cond 分派；
- `showGoMenu` 复用 `qt_use_software_scene_graph()` 与 `qt_inject_theme_context()`，删除手抄的场景图初始化与主题注入；bridge 已以 popup 为父对象，删除冗余的 destroyed→deleteLater 连接；
- `QTMTabPageContainer::updateActiveTab` 合并 debug/release 两份循环为一份（仅日志行包 `#ifdef LIII_DEBUG`），并将 `as_string (currentView)` 提出循环；
- `GoMenu.qml` 删除从未渲染的 `subText`、恒为真的 `enabled` 属性及四处死分支；`actualContentHeight` 不再对 `childrenRect` 取 max，统一使用按条目数计算的 `calculatedHeight`；
- 三处测试（`go-menu-test.scm`、`go_menu_bridge_test.cpp`、`qml_load_test.cpp` 的 `GoMenuStubBridge`）同步收缩到现行契约；
- `1311.py` 删除指向开发者本机 `~/git/pynput/lib` 的导入回退。
