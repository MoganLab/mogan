# [1311] 在领取会员左侧添加 Go 按钮并用 QML 实现 Go 菜单

## 1 任务背景
在 Mogan 标题栏（领取会员按钮左侧）新增一个导航/跳转入口按钮（Go），提供原顶部菜单栏「Go」菜单的全部功能：
- 光标历史跳转：后退（Back）、前进（Forward）、保存位置（Save position）；
- 打开的文档列表（Open documents）：列出当前打开的 buffer，标记当前活动文档，点击平滑切换；
- 最近打开的文档（Recent）：列出历史最近打开且当前未加载的文档，点击快速打开。

同时采用现代 QML 实现该下拉菜单浮层，并从主菜单栏中移除原本的「Go」菜单项。

## 3 如何测试

### 3.1 QML 加载单元测试
```bash
xmake b qml_load_test && xmake r qml_load_test
```

### 3.2 手动测试
启动 Mogan STEM：
```bash
xmake b stem && xmake r stem
```
1. 观察主菜单栏（File, Edit, View, Document...），确认「Go」菜单项已被移除；
2. 观察窗口标题栏右上角（领取会员按钮左侧），可见「转到」/「Go」按钮；
3. 点击该按钮，下方弹出优雅的现代 QML 菜单浮层；
4. 菜单内展示：
   - 后退（若无历史置灰）、前进（若无未来置灰）、保存位置；
   - 打开的文档列表，当前文档前带勾号，点击可切换标签页；
   - 最近使用的文档列表，点击可打开文档；
5. 点击菜单外部或按 Esc 键，菜单自动关闭。
