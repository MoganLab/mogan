## 5 What

1. **TemplateCache 新增推荐 ID 缓存接口**：`saveRecommendIds()` / `loadRecommendIds()`，缓存文件为 `recommend_ids.json`
2. **TemplateManager 初始化时恢复推荐列表**：`initialize()` 在加载 `metadata.json` 后，额外从 `recommend_ids.json` 恢复 `recommendTemplateIds_`
3. **TemplateManager 获取推荐后持久化**：`onRemoteRecommendTemplatesLoaded()` 在 `saveMetadataCache()` 后调用 `saveRecommendIds()`
4. **推荐模板顺序保持**：缓存以 JSON 数组形式存储，load 时按数组顺序恢复

## 6 Why

1. **离线无法展示推荐模板**：1014 中 `recommendTemplateIds_` 仅存于内存，进程退出后丢失。下次离线启动时首页推荐区为空
2. **推荐顺序丢失**：后端返回的推荐排序（如运营策略）应该保持一致，即使离线也应按上次缓存的顺序展示

## 7 How

### 7.1 缓存文件结构

`$TEXMACS_HOME_PATH/system/template_cache/recommend_ids.json`：

```json
{
  "version": "1.0",
  "recommend_ids": [
    "thu-undergraduate-thesis",
    "nsfc-ysf-c",
    "elegantbook"
  ]
}
```

### 7.2 启动恢复流程

```
[TemplateManager::initialize]
  |
  +-- loadLocalTemplates()
  +-- loadCachedCategories()
  +-- cachedMetadata = cache_->loadMetadataCache()
  +-- mergeMetadata(cachedMetadata)              ← 恢复模板元数据
  +-- recommendTemplateIds_ = cache_->loadRecommendIds()  ← 新增：恢复推荐顺序
  +-- if (!recommendTemplateIds_.isEmpty()) {
        emit recommendTemplatesLoaded();          ← 立即显示缓存的推荐卡片
      }
  +-- refreshCategories()
  +-- refreshRecommendTemplates()                  ← 每次启动都请求更新
```

### 7.3 获取后持久化流程

```
[onRemoteRecommendTemplatesLoaded]
  |
  +-- recommendTemplateIds_.clear()
  +-- for (...) recommendTemplateIds_.append(id)   ← 按 API 顺序记录
  +-- mergeMetadata(metadata, true)
  +-- cache_->saveMetadataCache(templates_)        ← 保存模板元数据
  +-- cache_->saveRecommendIds(recommendTemplateIds_)  ← 新增：保存推荐顺序
  +-- emit recommendTemplatesLoaded()
```

### 7.4 启动场景矩阵

| 场景 | 首页显示 | 后台请求 | 请求回来后 |
|---|---|---|---|
| 有缓存，有网络 | 立即显示缓存卡片 | ✅ 发送 | 更新数据 + 刷新 UI |
| 有缓存，无网络 | 立即显示缓存卡片 | ✅ 发送（失败） | 保持缓存不变 |
| 无缓存，有网络 | 只显示 new/open | ✅ 发送 | 动态添加推荐卡片 |
| 无缓存，无网络 | 只显示 new/open | ✅ 发送（失败） | 不变 |

### 7.5 关键状态变化

| 场景 | `recommendTemplatesFetched_` | `recommendTemplateIds_` |
|---|---|---|
| 首次启动，无缓存 | `false` → `true`（联网后） | 从 API 填充 |
| 二次启动，有缓存 | `false` → `true`（联网后） | 先恢复缓存，再更新 |
| 进程退出后重启 | 重置为 `false` | 从 `recommend_ids.json` 恢复 |

| 文件 | 改动 |
