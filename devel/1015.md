## 5 What

1. **TemplateCache 新增推荐 ID 缓存接口**：`saveRecommendIds()` / `loadRecommendIds()`，缓存文件为 `recommend_ids.json`
2. **TemplateManager 初始化时恢复推荐列表**：`initialize()` 在加载 `metadata.json` 后，额外从 `recommend_ids.json` 恢复 `recommendTemplateIds_`，并**校验每个 ID 是否存在于已加载的 `templates_` 中**，剔除因缓存不一致产生的失效 ID
3. **TemplateManager 获取推荐后持久化**：`onRemoteRecommendTemplatesLoaded()` 在 `saveMetadataCache()` 后调用 `saveRecommendIds()`，且对 API 返回的 `templateKey` **去重**，避免重复卡片
4. **推荐模板顺序保持**：缓存以 JSON 数组形式存储，load 时按数组顺序恢复
5. **缓存文件原子写入**：`saveMetadataCache()`、`saveRecommendIds()`、`saveCacheIndex()` 均采用"临时文件 + `QFile::rename()`"模式，防止程序崩溃导致文件截断
6. **网络恢复竞态修复**：`onNetworkStateChanged()` 网络恢复时，若旧推荐请求仍在进行，先 `abortRecommendTemplatesRequest()` 终止旧请求，再发起新请求

## 6 Why

1. **离线无法展示推荐模板**：1014 中 `recommendTemplateIds_` 仅存于内存，进程退出后丢失。下次离线启动时首页推荐区为空
2. **推荐顺序丢失**：后端返回的推荐排序（如运营策略）应该保持一致，即使离线也应按上次缓存的顺序展示
3. **缓存不一致导致推荐区静默清空**：`recommend_ids.json` 与 `metadata.json` 是两次独立文件读取，若后者被清除而前者仍存在，`recommendTemplateIds_` 中的 ID 在 `templates_` 中全部找不到，UI 会移除所有推荐卡片
4. **API 重复 templateKey 导致布局异常**：后端偶发返回重复 `templateKey` 时，旧代码无去重，同一 `StyleCard*` 被多次加入布局，Qt 行为未定义
5. **非原子写入导致缓存损坏**：直接写入目标文件时程序崩溃，文件被截断，下次启动解析失败
6. **网络恢复竞态**：快速网络切换时旧请求仍在后台运行，完成后不会自动触发新刷新，用户看到过时的推荐数据

## 7 How

### 7.1 缓存文件结构

`$TEXMACS_HOME_PATH/system/template_cache/recommend_ids.json`：

```json
{
  "version": "1.0",
  "recommend_ids": [
    "thu-undergraduate-thesis",
    "nsfc-ysf-c",
    "elegantbook"
  ]
}
```

### 7.2 启动恢复流程

```
[TemplateManager::initialize]
  |
  +-- loadLocalTemplates()
  +-- loadCachedCategories()
  +-- cachedMetadata = cache_->loadMetadataCache()
  +-- mergeMetadata(cachedMetadata)              ← 恢复模板元数据
  +-- cachedRecommendIds = cache_->loadRecommendIds()
  +-- for (id in cachedRecommendIds) {           ← 新增：校验缓存一致性
        if (templates_.contains(id)) validIds.append(id);
      }
  +-- recommendTemplateIds_ = validIds;
  +-- if (!recommendTemplateIds_.isEmpty()) {
        emit recommendTemplatesLoaded();          ← 立即显示缓存的推荐卡片
      }
  +-- refreshCategories()
  +-- refreshRecommendTemplates()                  ← 每次启动都请求更新
```

### 7.3 获取后持久化流程

```
[onRemoteRecommendTemplatesLoaded]
  |
  +-- QSet<QString> seenIds;
  +-- for (tmpl in templates) {                    ← 新增：去重
        if (tmpl && !seenIds.contains(tmpl->id)) {
          seenIds.insert(tmpl->id);
          newRecommendIds.append(tmpl->id);
          metadata.insert(tmpl->id, tmpl);
        }
      }
  +-- recommendTemplateIds_ = newRecommendIds;
  +-- mergeMetadata(metadata, true)
  +-- cache_->saveMetadataCache(templates_)        ← 原子写入
  +-- cache_->saveRecommendIds(recommendTemplateIds_)  ← 原子写入
  +-- emit recommendTemplatesLoaded()
```

### 7.4 启动场景矩阵

| 场景 | 首页显示 | 后台请求 | 请求回来后 |
|---|---|---|---|
| 有缓存，有网络 | 立即显示缓存卡片 | ✅ 发送 | 更新数据 + 刷新 UI |
| 有缓存，无网络 | 立即显示缓存卡片 | ✅ 发送（失败） | 保持缓存不变 |
| 无缓存，有网络 | 只显示 new/open | ✅ 发送 | 动态添加推荐卡片 |
| 无缓存，无网络 | 只显示 new/open | ✅ 发送（失败） | 不变 |

### 7.5 关键状态变化

| 场景 | `recommendTemplatesFetched_` | `recommendTemplateIds_` |
|---|---|---|
| 首次启动，无缓存 | `false` → `true`（联网后） | 从 API 填充 |
| 二次启动，有缓存 | `false` → `true`（联网后） | 先恢复缓存并校验，再更新 |
| 进程退出后重启 | 重置为 `false` | 从 `recommend_ids.json` 恢复并校验 |

### 7.6 增量卡片更新

`QTMHomePage::refreshTemplateCards()` 由全量重建改为增量更新：

1. **收集现有卡片**：建立 `existingCards` 映射（ID → StyleCard 指针）
2. **计算差异**：遍历 `existingCards`，删除不在新列表中的卡片（`deleteLater`）
3. **按 API 顺序重建列表**：
   - 对于已有 ID：复用 `StyleCard` 对象（缩略图不重新下载），只更新 `loadThumbnail` 刷新 URL
   - 对于新 ID：创建新的 `StyleCard`
4. **`rearrangeStyleCards()`** 按新顺序重新布局

```cpp
StyleCard* card= existingCards.value (tmpl->id);
if (card) {
    newCards.append (card);
    card->loadThumbnail (tmpl->thumbnailUrl);
}
else {
    card= new StyleCard (style, cardsContainer_);
    ...
}
```

### 7.7 网络恢复后刷新

`TemplateManager::onNetworkStateChanged()` 在网络恢复时处理竞态：

```cpp
if (isOnline && initialized_) {
    refreshCategories ();
    if (isRefreshingRecommendTemplates_) {       ← 新增：终止旧请求
      api_->abortRecommendTemplatesRequest ();
      isRefreshingRecommendTemplates_= false;
    }
    recommendTemplatesFetched_= false;
    refreshRecommendTemplates ();                ← 获取最新推荐
}
```

### 7.8 原子写入实现

`TemplateCache` 中所有写入方法统一采用临时文件 + rename 模式：

```cpp
QString tmpPath= cachePath + ".tmp";
QFile file (tmpPath);
file.open (QIODevice::WriteOnly);
file.write (doc.toJson (QJsonDocument::Compact));
file.close ();
QFile::rename (tmpPath, cachePath);
```
