# [0837] 绘图区默认缩放与子单位格线步数自适应

## 1 相关文档
- [dddd.md](dddd.md) - 任务文档模板

## 2 任务相关的代码文件
- `TeXmacs/progs/graphics/graphics-utils.scm` — 普通新建画图区时自动执行 200% 缩放
- `TeXmacs/progs/generic/generic-edit.scm` — 带背景新建画图区时自动执行 200% 缩放
- `TeXmacs/progs/graphics/graphics-main.scm` — 缩放动作中自动计算并更新子单位网格步数

## 3 如何测试

### 3.1 确定性测试（单元测试）
```bash
xmake b stem
xmake r stem
```

### 3.2 非确定性测试（交互验证）
1. 插入 `绘图区`，现在应当自动为 200% 的缩放，方便用户绘图；
2. 鼠标悬浮在格线上，检查自动吸附网格功能是否有问题；
3. 使用 `+`/`-` 快捷键对绘图区进行缩放，检查是否自动调整子单位格线步数为 `1`、`2`、`5` 或 `10`，并且在不同缩放下，网格显示是否正常；
4. 用户仍然可以手动设置格线步数为任意值，位于 `网格设置`->`子单元步数`；

## 4 What
- 实现新建绘图区时自动以 200%（2.0倍）缩放比例初始化；
- 实现子单位格线步数的 `auto` 自适应逻辑，并将其作为缺省默认选项；
- 缩放时，依据画布倍率自动将子单位步数调节为 `1`、`2`、`5` 或 `10`。

## 5 How
- `graphics-utils.scm` — 在普通新建画图区的 `make-graphics` 函数末尾添加 `(graphics-zoom 2.0)`，通过模拟用户手动放大逻辑使新画布具有 2.0 倍率；
- `generic-edit.scm` — 在带背景新建画图区的 `make-graphics-over` 模板函数末尾添加 `(graphics-zoom 2.0)`；
- `graphics-main.scm` — 引入 `graphics-grid-aspect-autoupdate` 辅助函数。在画布比例缩放更新后调用，提取当前 `magnify`，在 `magn <= 0.5`（设置为 `1`）、`magn <= 1.25`（设置为 `2`）、`magn <= 2.5`（设置为 `5`）以及更大时（设置为 `10`）动态调整网格细分数属性。
