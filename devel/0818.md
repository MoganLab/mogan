# [0818] group-edit 模式左键选中/拖动/框选重构

## 1 相关文档
- [0817.md](0817.md) - 绘图后自动切换到移动模式（前置任务）

## 2 任务相关的代码文件
- `TeXmacs/progs/graphics/graphics-group.scm` — 重构 `edit_left-button`，新增 `edit_start-drag`/`edit_end-drag`，抽出 `start-multi-select`/`end-multi-select`；删除冗余的 edit-props/animate 左键变体
- `TeXmacs/progs/graphics/graphics-main.scm` — `graphics-set-mode` 去掉 `unselect-everything` 与光标判断，删除无用的 `hand-modes`
- `TeXmacs/progs/graphics/graphics-env.scm` — `set-sticky-point-false` 光标由 `openhand` 改为 `normal`

## 3 如何测试

### 3.1 确定性测试（单元测试）
```bash
xmake b stem
xmake r stem
```

### 3.2 非确定性测试（交互验证）
1. 在 `移动模式` 下单击一个图形，应**仅选中**该图形（不进入拖动态），光标保持 normal
2. 按住左键拖动一个已选中图形，拖动过程光标变 closehand，松开后回 normal，图形被移动
3. 在空白处按下并拖动，应拉出红色框选框；松开后框内图形全部被选中
4. 有选中时单击空白，应取消全选；无选中时单击空白无反应
5. 在 `属性编辑`/`移动工具`/`旋转工具`/`缩放工具` 中切换，已选中的图形集合应**保持不变**（不被取消选择）
6. 右键拖动功能已被禁用

## 4 What
- 重构 group-edit 模式的左键交互，让左键统一承担 `选中`/`拖动`/`框选`
- 切换变换工具时保留选中集合，保证不会被取消选择
- 光标改为只在拖动时显示抓手，其他情况为 normal 状态

## 5 How
### 5.1 重构 group-edit 左键交互
`edit_left-button`（`(eq? mode 'group-edit)`）改为按状态分派：点中对象仅选中（不拖动），点空白取消全选，已在拖动态则提交移动。新增 `edit_start-drag`/`edit_end-drag` 承载拖动与框选：拖对象 → 移动，空白拖拽 → 拉框选中。框选逻辑从 `any_toggle-select` 抽出为独立的 `start-multi-select`/`end-multi-select` 复用。

### 5.2 合并 edit-props/animate 左键变体
删除 `(in? (graphics-mode) '((group-edit edit-props) (group-edit animate)))` 这个 `edit_left-button` 变体，其守卫是 `(eq? mode 'group-edit)` 的子集，行为已被 5.1 覆盖。

### 5.3 切换工具不再清空选中
`graphics-set-mode` 切到 move/zoom/rotate 时不再调用 `(unselect-everything)`，选中集在变换工具间切换时保留；同时删除该函数里已失效的光标判断分支及变成死代码的 `hand-modes`（`graphics-env.scm` 中字符串版 `hand-modes` 仍被使用，未动）。

### 5.4 光标改为松手驱动
光标判断从 `graphics-set-mode` 移到 `set-sticky-point-false`：拖动中 `closehand`，松手回 `normal`（原 `openhand`）。`set-cursor-style-if-in-hand-modes` 守卫保证只影响 move/zoom/rotate。
