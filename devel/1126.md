# [1126] tbox 包定义迁移至 3rdparty，并清理失效构建配置

## 1 背景

- `xmake/packages/t/tbox/xmake.lua` 是从 xmake-repo 搬来的默认仓库包定义，
  通过 `set_sourcedir` 指向 `../../../../3rdparty/tbox`（四层相对路径）。
- 项目里 pdfhummus / doctest / libaesgm 已经统一采用「源码 `3rdparty/<name>` +
  包定义 `3rdparty/<name>.lua`，包名加 `liii-` 前缀」的本地包写法，由根
  `xmake.lua` 用 `includes("3rdparty/<name>.lua")` 显式加载。tbox 是唯一的例外。
- 另外 `moebius/xmake.lua` 仍残留对 `Data/String/**.cpp` 等的引用，但 PR #3831
  已把 `moebius/Data/String/` 整个迁到 `lolly/Data/String/`，moebius 侧目录为空，
  `xmake f` 时抛 `cannot match add_files(.../Data/String/**.cpp)` 警告。

## 2 What

1. 新建 `3rdparty/tbox.lua`，包名 `liii-tbox`，`set_sourcedir` 改为
   `path.join(os.scriptdir(), "tbox")`（同级相对路径），写法与
   `3rdparty/pdfhummus.lua` 一致。
2. 根 `xmake.lua`：`includes("3rdparty/tbox.lua")`；`add_requires/add_packages`
   由 `tbox` 改为 `liii-tbox`。
3. `lolly/xmake.lua`、`xmake/goldfish.lua`：`add_requires/add_packages("tbox")`
   改为 `liii-tbox`（共 5 处）。
4. 删除 `xmake/packages/t/tbox/`（及随之清空的 `xmake/packages/t/` 目录）。
5. 清理 `moebius/xmake.lua` 中失效的 `Data/String/**.cpp`、
   `Data/String` include dir、`Data/String/(*.hpp)` 三处死引用。
6. `CLAUDE.md`「构建命令」节补充：构建失败时执行 `xmake f -c --yes` 清理配置缓存。

## 3 Why

- **统一包定义写法**：tbox 是仅剩的非 `3rdparty/*.lua` 本地包，迁过去后所有本地
  三方包风格一致，`liii-` 前缀也避免与 xmake-repo 同名包冲突。
- **消除构建警告**：moebius 对 `Data/String` 的死引用会在每次 `xmake f` 报
  `cannot match add_files` 警告，干扰真实问题定位。
- **沉淀排错经验**：`xmake f -c --yes` 清配置缓存是构建失败的常见解法，写进
  CLAUDE.md 让后续开发者少走弯路。

## 4 How

- 包名加 `liii-` 前缀而非保留裸 `tbox`：与 `liii-pdfhummus` / `liii-doctest` /
  `liii-libaesgm` 完全对齐。已确认所有 lua 调用方（`xmake.lua`、
  `lolly/xmake.lua`、`xmake/goldfish.lua`）同步改名；C++ 源码里的
  `#include "tbox/..."` 是 include 路径，不受包名影响，无需改动。
- `tests/a_tbox_main.cpp` 文件名含 `tbox` 但只是文件名，非包引用，保留不动。
- s7 包本次不动（用户确认）。

## 5 涉及文件

- `3rdparty/tbox.lua`（新增）
- `xmake/packages/t/tbox/xmake.lua`（删除）
- `xmake.lua`（includes + 2 处包名）
- `lolly/xmake.lua`（1 处 add_requires + 4 处 add_packages）
- `xmake/goldfish.lua`（1 处 add_packages）
- `moebius/xmake.lua`（删 Data/String 三处死引用）
- `CLAUDE.md`（构建命令补充）

## 6 验证

```bash
xmake f -c --yes                       # 配置阶段 install liii-tbox latest .. ok，无 Data/String 警告
xmake b -r liblolly && xmake b lolly   # liblolly 全量重建成功
xmake b stem                           # stem + goldfish 链接成功
```
