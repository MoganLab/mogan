## 5 What

将首选项里需重启字段（look and feel / gui theme / keyboard shortcut style）的确认弹窗
从旧 `user-confirm`（两按钮 yes/no）迁移到项目 QML 弹窗体系，升级为三按钮
（重启 / 稍后 / 取消）。

1. 新建 `ConfirmRestart.qml`（DialogShell + 标题 + 正文 + DialogButtons 三按钮），exec 阻塞模态
2. 新增 C++ glue 入口 `cpp_confirm_restart`，走 `run_qml_dialog`，返回 `"restart"/"later"/"cancel"`
3. scm 侧新增 `confirm-restart-and-act` 辅助，统一三分支语义（重启=落定+存盘+重启 / 稍后=落定 / 取消=回滚）
4. 改造 `set-pretty-preference*` 接入新弹窗（取消回滚旧值，修复旧 bug）
5. 设计稿 `qml-dialog.html` 补 ConfirmRestart 面板，README 补 `translate` 翻译机制规则

## 6 Why

旧实现用 Scheme 端 `user-confirm`（两按钮 yes/no），与项目已有 QML 弹窗体系
（ConfirmClose / FormDialog / FontSelector / ParagraphFormat / Statistics）不统一，且
两按钮无法表达「稍后」（保留新值但不立即重启）的语义。迁移后：
- UI 风格统一（DialogShell + DialogButtons + Theme）
- 三按钮明确区分「立即重启 / 稍后 / 取消」，取消语义回滚旧值
- 顺带修复 `set-pretty-preference*` 点 no 不回滚的 bug

## 7 How

### 7.1 scm 接入层（`preferences-menu.scm`）
- `restart-effect-message`：产出陈述句正文（无问句，问句由按钮表达）
- `confirm-restart-and-act title apply-proc rollback-proc`：调 `cpp-confirm-restart`，
  按返回值分支——restart 走 apply + save-all-buffers + restart-TeXmacs；later 走 apply；
  cancel 走 rollback。`save-all-buffers` 未定义时惰性 `(use-modules (plugin autosave))`

### 7.2 scm 接入层（`preferences-widgets.scm`）
- `restart-preference-title`：字段名 → 翻译标题映射（look and feel / gui theme /
  keyboard shortcut style）
- `set-pretty-preference*`：值变化时调 `confirm-restart-and-act`，**取消回滚旧值**
  （修复旧 bug）

### 7.3 C++ glue
- `cpp_confirm_restart(title, message)`：仿 `cpp_confirm_close` 走 `run_qml_dialog`，
  固定三按钮 ["Restart","Later","Cancel"]，经 `translate_buttons` 翻译注入
- context property：`dialogTitle` / `dialogMessage` / `dialogButtons`（+ 共用
  closeBridge/dpScale/isDark）
- 按钮下标 1/2/3 → "restart"/"later"/"cancel"；0/-1（Esc/X/加载失败）→ "cancel"
- 测试钩子 `MOGAN_TEST_CONFIRM_RESTART=restart|later|cancel`

### 7.4 QML 界面
- `ConfirmRestart.qml`：`DialogShell` 根，Column 内含标题 Text（居中加粗）+ 正文 Text
  （左对齐，`Theme.muted`，英文换行更整齐）+ DialogButtons（三按钮，primaryIndex=0 即重启主按钮）
- `onActivate` 默认 Enter 选「重启」（choose 1）

### 7.5 字典整理
- 新增 `("restart" "重启")` / `("later" "稍后")` / `("switch ...)" ...)` ×3
  （look and feel / interface theme / keyboard shortcut style）/
  `("this change requires ...)" ...)` ×2 / `("keyboard shortcut style" "快捷键显示风格")`，
  全部**小写首字母登记**（靠 `translate` 首字母大写折叠命中代码里的大写 key）
- 按**字母序**插入 `zh_CN.scm` 对应字母段
