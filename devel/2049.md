## 5 What

1. `generic-edit.scm` 中新增 `clipboard-tree-image?`：统一判断剪贴板 tree 是否为图像，覆盖两种结构：
   - 裸 `(image ...)`：`(tree-is? (tree-ref data 0) 'image)`
   - `with` 包裹的 image：`(tree-is? data 'with)` 且子节点 2 为 `'image`
2. `ocr-paste`：使用 `clipboard-tree-image?` 替代原 `cond` 两个分支，并清理误导性的 `(not (null? (tree-ref data 2)))` 检查。
3. `paste-as-texmacs`：同样清理 `null?` 检查，保持与 `ocr-paste` 一致的判定风格。
4. `kbd-magic-paste`：
   - 在 `image*` 分支与 mode 分发之间新增 `texmacs-snippet` 前置分支
   - `texmacs-snippet` 分支内用 `clipboard-tree-image?` 判定：是 image 则 OCR；否则 `kbd-paste` 按内部格式粘贴
   - 为所有 `track-event` 调用恢复 `(defined? 'track-event)` 守卫，避免 telemetry 插件未加载时报错

## 6 Why

### 6.1 问题现象

软件内选中内容（`Ctrl+C`）后用魔法粘贴（默认 `Ctrl+Shift+V`）：

- 普通文字：什么都不会粘贴
- 公式：被当作 LaTeX 文本重新解析，结果错乱
- 代码：被当作 code 重新解析，结果错乱
- 居中图片：不触发 OCR

### 6.2 根因

软件内 `Ctrl+C` 写入剪贴板的 mime 类型是 `application/x-texmacs-clipboard`，对应 `qt-clipboard-format` 返回 `"texmacs-snippet"`。原 `kbd-magic-paste` 没有专门分支，会落到 mode 分发：

- 数学模式：`clipboard-paste-import "latex"` → 把内部 tree 当 latex 文本解析
- 代码模式：`clipboard-paste-import "code"` → 把内部 tree 当 code 文本解析
- 文本模式：`smart-format-paste` → `paste-as-texmacs`，但普通内容没有 else 分支，静默什么都不做

同时，原 `ocr-paste` 只检查 `(tree-ref data 0)`，对 `with` 包裹的 image 直接拒绝。

### 6.3 为什么不在 smart-format-paste / paste-as-texmacs 里修

软件内复制最自然的行为就是普通粘贴。在 `kbd-magic-paste` 入口层拦截 `texmacs-snippet`，直接 `kbd-paste`，可以跳过所有 mode 分发与云端魔法粘贴校验。

### 6.4 为什么 ocr-paste 需要区分 source-format

软件内复制的 image tree 已经在 `clipboard-get "primary"` 的子树里；外部截图需要 `parse-texmacs-snippet` reparse。两种取 tree 的路径不同，所以加参数区分。

### 6.5 为什么传整个 with tree 给 ocr-to-latex-by-cursor

`ocr-to-latex-by-cursor` 内部通过扫描子节点定位 image。如果直接传 image 节点本身，子节点里没有 image，定位失败。所以传包含 image 的容器。

### 6.6 为什么恢复 track-event 守卫

`track-event` 定义在 `plugins/telemetry/progs/plugin/telemetry-track.scm`，不是全局必然存在的函数。mogan 主分支在未加载 telemetry 插件时，直接调用会报错。上游 PR #26 为简洁删掉了守卫，移植到 mogan 时需要恢复。

## 7 How

### 7.1 新增统一图像判定 helper

```scheme
(define (clipboard-tree-image? data)
  (or (tree-is? (tree-ref data 0) 'image)
      (and (tree-is? data 'with)
           (tree-is? (tree-ref data 2) 'image))))
```

### 7.2 ocr-paste 使用 helper

```scheme
(tm-define (ocr-paste source-format)
  ...
  (with data
    (if (string=? source-format "texmacs-snippet")
        (tree-ref (clipboard-get "primary") 1)
        (parse-texmacs-snippet
          (tree->string (tree-ref (clipboard-get "primary") 1))))
    (when (clipboard-tree-image? data)
      (ocr-to-latex-by-cursor data))))
```

### 7.3 kbd-magic-paste 新增 texmacs-snippet 分支并恢复守卫

```scheme
(tm-define (kbd-magic-paste)
  (let ((source-format (qt-clipboard-format)))
    (cond ((string-starts? source-format "image")
           (ocr-paste "image")
           (when (defined? 'track-event)
             (track-event "OCR_RECOGNIZE" '(("mode" . "paste")))))
          ((string=? source-format "texmacs-snippet")
           (with data (tree-ref (clipboard-get "primary") 1)
             (if (clipboard-tree-image? data)
                 (begin
                   (ocr-paste "texmacs-snippet")
                   (when (defined? 'track-event)
                     (track-event "OCR_RECOGNIZE" '(("mode" . "paste")))))
                 (begin
                   (kbd-paste)
                   (when (defined? 'track-event)
                     (track-event "MAGIC_PASTE" '(("mode" . "internal"))))))))
          (else
            ;; 原 mode 分发逻辑，所有 track-event 调用均保留守卫
            ...))))
```
