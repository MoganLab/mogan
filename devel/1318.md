# [1318] 首选项存入 JSON 时统一使用 Unicode 并修复 Cork 转义

## 1 相关文档
- [0514.md](0514.md) — 首选项统一存放位置
- [0515.md](0515.md) — 首选项配置文件改为 JSON 格式
- [1313.md](1313.md) — 导出为PDF 对话框新增「在单页幻灯片中展开折叠环境」选项与悬浮提示

## 2 任务相关的代码文件
- `src/Plugins/Qt/PreferencesBridge.cpp` — 修复 `build_assoc_literal` 中错误使用 `qt_scheme_quote` 导致键名被转义为 Cork `<gtr>` 的问题，改用 `qt_scheme_quote_utf8`
- `src/Plugins/Qt/PreferencesBridge.hpp` — 同步注释说明
- `src/Plugins/Qt/QTMWindow.cpp` — 窗口位置/大小保存时窗口标题改用 `from_qstring_utf8`，防止中文标题被转为 Herk `<#XXXX>`
- `src/Plugins/Qt/qt_widget.cpp` — 窗口还原初始位置时窗口名称转为 UTF-8，与保存的 key 一致

## 3 如何测试

### 3.1 确定性测试（单元测试）
```bash
xmake b preferences_bridge_test && xmake r preferences_bridge_test
xmake b stem && xmake r preferences-widgets-test
```

### 3.2 非确定性测试（交互验证）
1. 打开 Mogan STEM：`xmake r stem`；
2. 打开「编辑」->「首选项」->「转换」->「PDF」，修改「在单页幻灯片中展开折叠环境」开关并保存；
3. 打开对话框（如「选择性粘贴」或「提示」弹窗），移动窗口并关闭；
4. 查看 `preferences.json`；
5. **预期结果**：
   - 写入的键为 `"texmacs->pdf:expand slides"`，不再出现 `"texmacs-<gtr>pdf:expand slides"`；
   - 窗口坐标保存为 `"abscissa 提示"` 等中文原生 UTF-8，不再出现 `"abscissa <#63D0><#793A>"`；
   - 重新打开该对话框，窗口能正确复原到上次移动后的坐标。

## 4 What
1. 阻断向首选项写入非 Unicode（Cork/Herk 编码）键名的源头，彻底消除 `<gtr>` 与 `<#XXXX>`；
2. 修复 `PreferencesBridge.cpp` 将修改提交给 Scheme 时使用 `qt_scheme_quote`（调用了 `from_qstring` -> `utf8_to_cork`）导致 `>` 变为 `<gtr>` 的 Bug，改用 `qt_scheme_quote_utf8`；
3. 修复 `QTMWindow.cpp` 保存窗口位置时使用 `from_qstring` 导致窗口中文标题被转为 `<#XXXX>` 的问题，改用 `from_qstring_utf8`；
4. 在 `qt_widget.cpp` 中打开窗口恢复位置时，将传入的窗口名称转为 UTF-8，确保与存储的 Unicode 键匹配；
5. 遵循 Mogan 规范，无需为旧版本残留错误键编写兼容迁移逻辑。

## 5 Why
1. JSON 格式本身是 UTF-8 编码的通用配置文本，在 JSON 键名中保存 TeXmacs 内部特有的 Cork/Herk 转义（如 `<gtr>` 代表 `>`、`<#63D0><#793A>` 代表汉字）破坏了配置文件的可读性与外部解析兼容性。
2. 之前由于 `PreferencesBridge` 使用了 `qt_scheme_quote`，用户在 QML 首选项界面中保存设置时，键名 `"texmacs->pdf:expand slides"` 会被编码为 `"texmacs-<gtr>pdf:expand slides"`。而在内核代码（如 `dynamic-make-slides`）中查询的是字面值 `"texmacs->pdf:expand slides"`，导致首选项文件中同时出现两套冲突的键，并且 UI 修改后的值在内核中无法生效。
3. 窗口移动/缩放位置使用 `from_qstring` 导致汉字被转义为 `<#XXXX>`，同样属于不合理的非 Unicode 存储。

## 6 How
1. `src/Plugins/Qt/PreferencesBridge.cpp`：
   - `build_assoc_literal` 中将 `qt_scheme_quote` 改为 `qt_scheme_quote_utf8`；
2. `src/Plugins/Qt/QTMWindow.cpp`：
   - `QTMPlainWindow::moveEvent` 和 `resizeEvent` 中将 `from_qstring (windowTitle ())` 改为 `from_qstring_utf8 (windowTitle ())`；
3. `src/Plugins/Qt/qt_widget.cpp`：
   - `plain_window_widget` 中调用 `get_preferred_position` / `get_preferred_size` 时使用 `cork_to_utf8 (name)`。
