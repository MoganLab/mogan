# [221_10] 为有序列表和无序列表新增结构化向上/向下插入与删除

## 如何测试

1. 运行集成测试：`xmake r 221_10`
2. 启动 Mogan，打开或新建一个正文文档。
3. 插入无序列表，输入至少两个条目。
4. 将光标放在第二个条目内部，执行结构化插入向上（默认快捷键前缀下的 `structured-insert-up`），确认在当前条目上方插入新的空条目，且光标进入新条目内容区。
5. 将光标放在第一个条目内部，执行结构化插入向下（`structured-insert-down`），确认在当前条目下方插入新的空条目，且光标进入新条目内容区。
6. 对有序列表重复步骤 3-5，确认编号列表同样可向上/向下插入。
7. 将光标放在列表条目内部，打开焦点菜单或菜单栏中的结构化插入菜单，确认能看到 **Insert above** 和 **Insert below**。
8. 构造嵌套列表：让当前条目后面带有一个同类型子列表。
9. 在该条目内部执行结构化插入向下，确认新条目插入在嵌套子列表之后，仍处于外层同级列表，而不是插入到子列表内部。
10. 构造结构 `(enumerate (document (item) (concat (item) " ddd")))`，将光标放在 `ddd` 中，确认结构化向上插入会在当前 `concat` 条目前插入空 `(item)`，结构化向下插入会在当前条目后插入空 `(item)`。
11. 构造结构 `(enumerate (document (item) (item) (concat (item) "ddd") "ddd" (item)))`，将光标放在第二个 `"ddd"` 中，确认它被识别为第三个 item 的正文续段，结构化向下插入会插到第二个 `"ddd"` 之后、最后一个 `(item)` 之前。
12. 在列表项内部执行结构化删除向上，确认删除当前 item 上方的同级逻辑 item。
13. 在列表项内部执行结构化删除向下，确认删除当前 item 下方的同级逻辑 item。
14. 在列表上下文的结构化插入菜单中，确认只显示上下方向的插入/删除，不显示左右方向的插入/删除。

## 2026/05/07 新增列表结构化向上/向下插入与删除

### What

为 `itemize` 和 `enumerate` 系列列表补上结构化向上/向下插入和删除行为。

修改点：

- 在 `TeXmacs/progs/generic/generic-edit.scm` 中新增列表专用的 `structured-insert-vertical` 分派。
- 扩展 `structured-vertical?`，让有序/无序列表项上下文显示结构化向上/向下插入和删除菜单。
- 调整 `focus-insert-menu`，列表上下文隐藏左右方向的插入/删除菜单项。
- 新增 `blank-list-item-stree`，统一生成空列表项 `(item)`，与现有空列表项结构保持一致。
- 新增 `list-item-end-index`，用于计算向下插入时的同级插入位置。
- 新增 `list-item-insert-index`，统一封装向上/向下的插入位置计算。
- 新增 `list-item-remove-range` 和 `remove-list-item-range`，统一封装向上/向下删除的逻辑 item 范围。
- 新增 `current-list-item-marker-from-nearest-left`，支持光标位于 item marker 后续同级正文节点时，向左找到所属逻辑 item。
- 新增 `TeXmacs/tests/221_10.scm`，覆盖裸 `(item)` 与 `(concat (item) "...")` 混合结构、item 后续同级正文、嵌套列表跳过逻辑、向上/向下插入与删除位置计算和空列表项结构。

### Why

已有结构化插入主要服务于表格、数学结构和一般结构化节点。列表项虽然也属于结构化内容，但在有序/无序列表中执行结构化向上或向下插入时，没有列表语义下的“插入同级条目”行为。

用户在编辑列表时，结构化向上/向下插入的合理预期是：

- 向上插入：在当前同级条目前插入一个空条目。
- 向下插入：在当前同级条目后插入一个空条目。
- 向上删除：删除当前条目上方的同级逻辑条目。
- 向下删除：删除当前条目下方的同级逻辑条目。
- 如果当前条目后面挂接了同类型嵌套子列表，向下插入应跳过该子列表，把新条目放回外层同级位置，避免误插到嵌套列表内部或打断当前条目的子结构。
- 列表没有左右方向的同级结构，因此菜单中不应该暴露左右插入/删除按钮。

### How

实现复用现有列表缩进逻辑中的结构识别能力：

- 使用 `current-list-item-marker` 找到当前逻辑列表项。
- 当光标不在 marker 或 marker wrapper 内部时，`current-list-item-marker` 会在同一 `document` 中向左查找最近的 item marker；这样 `(concat (item) "ddd")` 后面的同级字符串 `"ddd"` 仍属于该 item。
- 使用 `find-item-wrapper-and-list` 取得列表项外层 `concat` wrapper 和所在的 `document`。
- 使用 `list-family` / `same-list-family?` 判断 `itemize`、`itemize-dot`、`enumerate-numeric` 等变体是否属于同一类列表。
- 向上插入时直接使用当前 item 的同级索引。
- 向下插入时调用 `list-item-end-index`，跳过当前 item 后紧跟的同类子列表和正文续段，直到下一个 item marker 前再插入新的空 item。
- 向上删除时删除前一个 item marker 到当前 item marker 之前的逻辑范围。
- 向下删除时从当前 item 逻辑范围末尾开始，删除下一个 item marker 到其逻辑范围末尾。
- 插入后通过 `tree-go-to` 将光标移动到新条目的正文内容位置。
- `structured-vertical?` 在 `list-structured-insert-context?` 成立时返回真，使菜单栏和焦点菜单能够暴露 **Insert above** / **Insert below** / **Remove upwards** / **Remove downwards**。
- `focus-insert-menu` 在列表上下文中只渲染上下方向的菜单项，避免显示不可用的左右插入/删除按钮。
