# 1310 页码（page number）

## 现状梳理：仓库中已有的页码功能

### 1. 底层机制（C++ + 标准宏）

- **`page-nr` 环境变量**：排版引擎在分页时为每页赋值的当前物理页码。
  默认环境中 `page-the-page = (macro (page-nr))`（`src/Typeset/Env/env_default.cpp:25`）。
- **`page-the-page` 宏**：页码渲染的入口，页眉/页脚中插入它来显示页码；
  `page-the-total` 为总页数。
- **页面盒子 label**：`pager.cpp` 的 `page_box()` 给每页打上 `"page-<页码>"` label。
- **编辑器查询接口**（`src/Edit/Editor/edit_typeset.cpp`，经 `glue_editor.lua` 导出到 Scheme）：
  - `get-page-count` → `get_page_count()`：从页面盒子树取实际页数；
  - `get-page-number-text i` → `get_page_number_text(int)`：解析第 i 页盒子 label
    `"page-<页码>"`，返回该页实际显示的页码文本（含重编号后的值）；
  - `get-current-page` → 光标所在页。

### 2. 插入式页码标签（`TeXmacs/packages/standard/std-utils.stem`）

- **`set-page-number nr`**（`std-utils.stem:884`）：`(assign "page-nr" nr)`，
  给当前页重新编号；
- **`set-page-number-macro m`**（`std-utils.stem:894`）：`(assign "page-the-page" m)`，
  自定义页码渲染宏；
- 菜单入口：Insert → Page → Numbering → "Renumber this page" / "Page number text"
  （`TeXmacs/progs/generic/format-menu.scm:367` `page-numbering-menu`）。

### 3. 样式包开关（Document → Page → Layout）

- `no-page-numbers.ts` / `page-numbers.ts` 两个 style package；
- `toggle-no-page-numbers`（`TeXmacs/progs/generic/document-edit.scm:532`）在两者间切换，
  菜单项 "No page numbers"（`document-menu.scm:759`）。

### 4. 分层页码样式系统（`TeXmacs/progs/generic/document-widgets.scm:221-407`）

菜单入口：Document → Page number → "New page number style layer"
（`document-menu.scm:860`，压缩菜单也有直达项），打开辅助窗口
`page-number-style-editor`（注册为 `'page-number-style` 辅助组件）。

**交互**：选择应用范围（Whole document / 自定义 `ps~pe`）、数字样式
（`pn-style-alist`：arabic / roman / Roman / hanzi / blank），
"Page mapping" 栏用 `get-page-count` + `get-page-number-text` 逐页预览
`物理页 -> 显示页码`（空页码显示为 `o`）。Apply 时调用 `assign-page-number`。

**实现机制**（`assign-page-number`，`document-widgets.scm:248`）：每加一层就生成
三个宏并写入文档 initial：

| 宏 | 作用 |
|---|---|
| `pn-m<n>` | `(minus (value "page-nr") <ps-1>)`，计算层内相对页码 |
| `pn-l<n>` | 相对页码 < 1 显示空串，否则按样式 `(number ...)` 显示；blank 层恒为空 |
| `pn-g<n>` | 当前页在 `[ps,pe]` 内显示 `pn-l<n>`，否则 fallback 到 `pn-g<n-1>` |

- 底层 `pn-g0 = (macro (value "page-nr"))` 为默认行为；
- 每次把 `page-the-page` 重定向到顶层 `pn-g<n>`，`pn-next` 记录下一个层号；
- 层按 Apply 顺序叠加，后加的层在自己的范围内覆盖先前的层，范围外回退到下一层。

### 5. 单页设置对话框（`TeXmacs/progs/generic/format-widgets.scm`）

`page-formatter` 对话框提供 "This page number"（改当前页 `page-nr`）和
"Page number rendering"（改 `page-the-page`：normal/roman/Roman）两项，
通过 `collect-settings` / `change-setting` 读写当前页内的 `assign` 标签。

### 6. 相关但独立的功能

- **高级页眉/页脚**（`document-widgets.scm` Advanced Headers/Footers）：
  用 `page-nr` 做 `[start,end]` 范围条件判断，只控制页眉页脚内容，不改页码本身；
- **页眉页脚编辑器**中 Insert → "Page number"/"Total pages" 即插入
  `page-the-page` / `page-the-total` 标签（`document-widgets.scm:1030`、
  `format-tools.scm:939`）。

## 本次改动

### What

用 QML 弹窗重新实现「文档 → 页码」功能，替换原来的
`page-number-style-editor` 辅助面板（只能往上叠层、不能回读/删除已有规则、
需手输页码区间）。

### 交互设计（原型：/tmp/1310.html）

- 弹窗左侧为**纵向页面栏**（可滚动）：每行 = 页面缩略占位 + 物理页号 +
  该页实际显示的页码，随规则编辑实时重算；
- 规则**起点固定、依次衔接**：第 1 条从第 1 页开始，第 i+1 条紧跟第 i 条；
  拖动手柄（或点击某一行）只选结束页；未被规则覆盖的尾部自动接着连续编号；
- 样式芯片直选：1,2,3 / i,ii,iii / I,II,III / 一二三 / 不显示；
- 规则列表仅最后一条可删；
- **弹窗内纯预览，不即时写文档**；点「应用」才一次性把规则写入文档
  initial 并关窗。

### How

- **QML 弹窗**：沿用仓库 QML 弹窗体系（见 ai-docs/qml/README.md）：
  新增 `src/Plugins/Qt/qml/PageNumber.qml`（DialogShell + 自定义页面栏）+
  `PageNumberBridge.{hpp,cpp}`（无状态透传，eval_scheme 调 scheme facade）+
  `cpp_page_number_dialog`（QTMQmlDialog，走 `run_qml_dialog` exec 模态——
  不 live 写回文档，本地暂存 + OK 一次性提交，同 FormDialog/Preferences 模式），
  glue 登记在 `src/Scheme/L5/glue_qt.lua`；qmldir / moganqml.qrc 同步登记。
- **scheme facade**（`TeXmacs/progs/generic/document-widgets.scm`）：
  - `pn-qml-meta`：返回 `((total . "N") (rules . (("1" "3" "roman") ...))
    (labels . ...))`；规则由 `get-all-inits` 过滤 `pn-*` 回读——
    从 `pn-g<n>` 的 if 条件解析范围（pe 为 `(page-the-total)` 记 `"total"`），
    从 `pn-l<n>` 解析样式（`(macro "")` 为 blank）；
  - `pn-qml-submit`：先 `initial-default` 清掉旧 `pn-m*/pn-l*/pn-g*/pn-next`
    与 `page-the-page`（仅当文档被本系统管理过，即存在 `pn-next`），再按规则
    顺序用 `make-pn-m/l/g-stree` 重建宏链、重指 `page-the-page`、写 `pn-next`；
  - `open-document-page-number` 改为记录当前 buffer 后调
    `cpp-page-number-dialog`；删除旧的 editor widget / `get-pn-mapping` /
    `pn-style-alist` / `assign-page-number` 等废弃代码。
- **测试**：`qml_load_test.cpp` 加 PageNumber 加载用例；C++ 钩子
  `MOGAN_TEST_PAGE_NUMBER=ok|cancel`；scheme 纯逻辑测试覆盖
  规则→宏→回读 round-trip。

### 弹窗宽度与罗马数字标记优化

- **What**：
  1. 将页码设置弹窗宽度由 760 扩大至 920，保证 5 种页码样式选项在一行内整齐舒展排开；
  2. 罗马数字样式标记改为 `roman::page_number` 与 `Roman::page_number`，中文显示为「小写罗马」/「大写罗马」，英文显示为「roman」/「Roman」，显著精简字符并节省横向空间。
- **Why**：原宽度 760 下右侧可用宽度约 492px，在不同字体渲染或语言环境下第 5 个选项容易被折行到第二行，视觉不够整齐，且首行范围输入区域也略显局促；同时罗马数字原英文全称过长，调整后更紧凑。
- **How**：
  - 在 `PageNumber.qml` 与 `QTMQmlDialog.cpp` 中将逻辑宽度调整为 920，样式卡片加保底最小宽度；
  - 在 `TeXmacs/plugins/lang/dic/en_US/zh_CN.scm` 中登记 `("roman::page_number" "小写罗马")` 与 `("Roman::page_number" "大写罗马")`，并在 `document-widgets.scm` 和 `PageNumber.qml` 中引用。

### 调整页码样式选项顺序

- **What**：交换样式选项次序，将「隐藏页码」置于首位、「阿拉伯数字」置于末位（隐藏页码 → 小写罗马 → 大写罗马 → 汉字数字 → 阿拉伯数字）。
- **Why**：符合书籍与学术排版的成书顺序（封面/扉页隐藏页码 → 序言/目录罗马数字 → 正文阿拉伯数字），用户配置规则时更自然顺畅。
- **How**：在 `PageNumber.qml` 的 `styleDefs` 中将 `blank` 移动到最前，`arabic` 移至最后。
- **涉及文件**：
  - `src/Plugins/Qt/qml/PageNumber.qml`
  - `devel/1310.md`

### 修复未被规则覆盖页面的左侧预览计算

- **What**：修正未被任何规则覆盖的页面在左侧预览中的页码计算，由误算相对序号 `String(p - lastEnd)` 改为直接显示物理页码 `String(p)`。
- **Why**：底层实现中宏链的最终回退是 `pn-g0 = (macro (value "page-nr"))`（物理页号）。当用户未对后续页面设置阿拉伯数字重编号规则时（例如仅设置第 1~2 页为封面隐藏或罗马数字），第 9 页实际排版即为 9，弹窗预览应与底层排版完全一致。
- **How**：在 `PageNumber.qml` 的 `pageDisplay(p)` 中，未匹配任何规则时直接返回 `String(p)`。
- **涉及文件**：
  - `src/Plugins/Qt/qml/PageNumber.qml`
  - `devel/1310.md`

### 修复拖拽结束页码时误触发弹窗移动问题

- **What**：修复在左侧页面纵向栏中拖动滑块手柄或行以调整结束页码时，弹窗窗口被同时拖动的问题。
- **Why**：外层 `DialogShell.qml` 背景上的 `DragHandler` 默认会在鼠标拖拽位移超过阈值时从子组件抢夺（take over）鼠标抓取权，导致内部 `MouseArea` 的拖拽被外层 `DragHandler` 抢占并触发 `closeBridge.startMove()`。
- **How**：
  1. 在 `DialogShell.qml` 的 `DragHandler` 上设置 `grabPermissions: PointerHandler.TakeOverForbidden`，禁止从任何已接管交互事件的子组件/项目强行抢夺抓取权，仅在点击空白背景时允许拖动窗口；
  2. 在 `PageNumber.qml` 中的 `dragHandle` 和 `maRow` 的 `MouseArea` 显式设置 `preventStealing: true`，防止祖先 Handler 或 Flickable 窃取鼠标事件。
- **涉及文件**：
  - `src/Plugins/Qt/qml/atoms/DialogShell.qml`
  - `src/Plugins/Qt/qml/PageNumber.qml`
  - `devel/1310.md`

### 优化样式选择的默认覆盖范围

- **What**：点击「阿拉伯数字」样式自动全选覆盖至文末；点击阿拉伯数字之外的样式（隐藏页码、小写罗马、大写罗马、汉字数字）时取消全选，默认选择一页（`pendingEnd = pendingStart`）。
- **Why**：阿拉伯数字多用于正文重编号至文末，默认全选便于用户一键应用；但封面、序言或目录（隐藏页码/罗马数字）通常只作用于前几页局部范围，不应沿用全选状态，取消全选并默认选择当前一页，让用户可以快速单页设置（如封面隐藏页码），或通过步进器 `[+]` 轻松扩展页数。
- **How**：在 `PageNumber.qml` 的样式卡片 `onClicked` 中，选中 `arabic` 时 `pendingEnd = totalPages + 1000`，其他样式时直接设为 `pendingEnd = pendingStart`；同时在 `onPendingEndChanged` 中同步更新 `endInput.text`，保证界面状态精准一致。
- **涉及文件**：
  - `src/Plugins/Qt/qml/PageNumber.qml`
  - `devel/1310.md`

### /simplify 代码质量清理（复用 / 简化 / 效率 / 抽象层次四视角）

- **What**：对页码弹窗全栈（Scheme facade / C++ bridge / QML）做一轮质量清理，不改交互语义。
- **Why**：初版实现存在跨层重复（JS 重实现数字格式化、bridge 重复 closeBridge 职责）、魔法数哨兵（`totalPages + 1000` 泄漏进用户可见文案）、死代码（孤儿菜单、死标签、死字典条目、无效的 glue-symbols.scm 登记）与逐页 eager 实例化的性能隐患。
- **How**：
  1. **Scheme**：`pn-read-rules` 双循环合并为单循环（扫到首个缺失 `pn-g<k>` 即止，`pn-next` 仅作存在性标记）；抽出 `pn-all-inits` 供 read/submit 共用；`pn-extract-range` 去掉冗余 disjunct；`pn-qml-meta` 的 `total` 直接传整数；删除死标签 `delRule`/`onlyLastDel`；arabicTip 文案去掉「+ 1000」实现细节。
  2. **C++ bridge**：删除与共用 `closeBridge` 重复的 `cancel()`/`startMove()`；`build_rules_literal` 去掉用不到的 QVariantList 分支；新增 `formatNumber(n, style)`，用排版引擎 number 原语同源的 `lolly::data::to_roman/to_Roman/to_hanzi` 取代 QML 侧 JS 重实现（JS 版汉字数字 n≥100 已错误回退为阿拉伯数字）。
  3. **QML**：`pendingEnd` 改用与规则模型一致的 `"total"` 字符串哨兵，删除全部 `+1000` 魔法数及配套 clamp；`pageDisplay` 复用 `ruleOfPage`；`addRule`/`deleteLastRule` 去掉与 `onRulesChanged` 重复的状态重置；`−`/`+` 按钮改用 `MiniButton` 原子；选中态颜色改用 `Theme.selectBg/selectFg`；页面条由 `Flickable+Repeater`（一次性实例化全部 N 行）改为 `ListView`（仅可见行实例化，`reuseItems`），拖拽坐标改映射 `contentItem`；样式卡 sample 经 `formatNr` 计算而非硬编码。

### 未变更规则时禁用应用按钮并提示

- **What**：
  1. 在「文档 → 页码」设置弹窗中，当页码规则相较打开时没有任何改动时，主按钮「应用」（Apply）置灰禁用；鼠标悬停在「应用」按钮上时显示提示文本「未检测到页码规则的变更」；
  2. 当规则列表发生变更（如新增或删除规则）时，「应用」按钮恢复可用，悬停提示消失；若通过增删使规则重新与打开时一致，按钮重新置灰并显示提示；
  3. `DialogButtons.qml` 支持 `primaryDisabledToolTip` 属性，并在主按钮禁用时依然保持悬停检测，展示主题配色的提示浮层（保持 100% 不透明度）；
  4. 新增自动化 UI 测试脚本 `TeXmacs/tests/python/1310.py`，利用 pynput 打开首页最近文档《中科大少年班数学分析讲义一.stem》，唤起页码设置弹窗，端到端测试规则未改动时的置灰态、hover 提示以及规则变更后的状态恢复。
- **Why**：在用户未作任何规则调整时避免误点击重复提交，并在悬停时明确告知用户当前不可操作的原因，提升用户体验与交互明确性。
- **How**：
  - `DialogButtons.qml`：将 delegate 由 `Rectangle` 包装为独立 `Item`（解耦按钮本体透明度与提示层透明度，防止 QML opacity 向下层级传递导致 tooltip 半透明），添加 `primaryDisabledToolTip` 属性；禁用时 MouseArea 依然保持 `hoverEnabled: true`，在 `containsMouse` 时悬浮展示 1.0 不透明度的深色圆角提示胶囊；
  - `PageNumber.qml`：抽出 `normalizeRules()` 供 `rules` 与 `initialRules` 快照共用，新增计算属性 `hasRulesChanged`，将 `primaryEnabled: root.hasRulesChanged` 与 `primaryDisabledToolTip` 传给 `DialogButtons`，并在 `submit()` 入口增加守卫；
  - `document-widgets.scm` 与 `zh_CN.scm`：新增 `"No changes detected in page numbering rules"` / `"未检测到页码规则的变更"` 词条；
  - `tests/Plugins/Qt/qml_load_test.cpp`：增加 PageNumber 对 `hasRulesChanged` 初始状态及增删规则后变更状态的断言测试；
  - `TeXmacs/tests/python/1310.py`：使用 pynput 模拟键鼠交互，从首页打开数学分析文档并调起页码设置弹窗，验证无改动时的置灰与 hover 提示，以及删除最后一条规则后的启用态变化。
