# 6001: PDF 导出接入现代化通用等待弹窗

## 2026/09/23 PDF 导出接入通用等待弹窗与长文档按页数分流

### What(本次改动做了什么)

1. **移除旧有提示**：
   在 `tm-print.scm` 中移除遗留的粗糙原生矩形提示框调用 `(system-wait "Exporting, " ...)`；
2. **长文档按页数分流**：
   在 C++ `edit_main_rep::print_doc` 中根据排版后计算的实际页数分流：
   - 短文档（`pages <= 10`）：直接导出，不唤起弹窗，避免短耗时下的界面闪烁；
   - 长文档（`pages > 10`）：唤起不可取消的通用等待弹窗 `gui_wait_dialog_open("Exporting, please wait...", false)`；
3. **逐页渲染期间维持动画**：
   在 `print_doc` 的逐页渲染循环中调用 `gui_pump_events()`，以 ~30ms 节流泵 Qt 事件循环，确保 QML 等待弹窗的转圈动画流畅推进，渲染完成后调用 `gui_wait_dialog_close()` 自动关闭弹窗；
4. **多语言翻译**：
   在 `zh_CN.scm` 中补充 `"Exporting, please wait..."` 对应的中文翻译 `"导出中，请稍候..."`。

### Why(为什么这么做)

1. 原提示通过 C++ 底层 `system_wait` 弹出原生 `QLabel` 悬浮框，外观粗糙生硬且无动画，与现代 QML 设计语言格格不入；
2. PDF 导出为同步密集计算，底层无任务中断检查机制，因此采用不可取消等待弹窗（无取消按钮、屏蔽 ESC），避免给用户误导；
3. 短文档（<= 10页）通常在一秒内渲染完毕，弹窗反而会造成明显的视觉白光与闪烁，按页数分流可兼顾短文档的敏捷性与长文档的反馈感。

### How(实现细节与测试)

1. 在 `tm-print.scm` 中清理两处 `system-wait`；
2. 在 `edit_main.cpp` 中通过 `pages > 10` 控制弹窗生命周期并在渲染循环泵事件；
3. 端到端测试：打开长文档（> 10页）点击「文件 -> 导出 -> PDF...」，观察现代化转圈弹窗展示与导出完成后的自动关闭。
