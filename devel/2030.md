## 4 What

### Part A 原子/成品分离
10 个原子板块移入 `qml/atoms/`，4 个成品弹窗留在 `qml/`。新建 `atoms/qmldir` 列原子；
`qml/qmldir` 改为只列成品。`moganqml.qrc` 原子路径加 `atoms/` 前缀；成品 `import "."`
改为 `import "atoms"`（拿原子 + Theme 单例）。原子间互引（TabPanel→TabBar、
EnumComboList→EnumCombo）同目录 `import "."` 不变；`EnumCombo` 靠 `objectName:"DialogShell"`
沿 parent 链找 DialogShell 的运行时机制跨目录不受影响。

### Part B 五项优化
1. **B1 Theme 常量收敛**：`Theme.qml` 加结构尺寸 `rowH`(44) / `btnH`(40) / `itemH`(36)、
   圆角 `radius`(8) / `radiusLg`(16)、字号阶梯 `fontBody`(14) / `fontBtn`(15) / `fontTab`(13)
   / `fontMini`(11) / `fontTiny`(10)。**原子组件内**的这些固定值替换为命名常量；
   成品弹窗的拼接布局数字（列宽、间距）保留字面量。胶囊圆角统一 `radius: height / 2`。
2. **B2 去冗余 / 加滚动兜底**：`ConfirmClose` 注释澄清外层 `Item` 不可省（它承接
   DialogShell 强制的 `anchors.fill`，让内层 Column 自由 `verticalCenter` 居中——同一
   Item 不能既 fill 又 verticalCenter）；`FormDialog` 字段区加 `clip` 兜底（窗口高度已按
   字段数动态算，正常不溢出，clip 防异常多字段撑破视觉）。
3. **B3 统一 id 规则**：原子内部 id 不用 `root`（delegate 内 `root.xxx` 会被原子内部同名 id
   遮蔽——这是 `ParagraphFormat` 被迫用 `id: dialog`、`MiniButton` 用 `id: btn` 的根因）。
   改用组件语义缩写；`ParagraphFormat` 改回 `id: root`，与另三个成品统一。
4. **B4 refreshTick 封装**：`FontSelector` 的 `{ var _ = root.refreshTick; return ... }`
   假读样板出现 4 处，封装进 `SelectableList` 的 `refreshTick` 属性（内部吸收假读依赖），
   调用方 `refreshAll()` 只需递增各 list 的 `refreshTick`。
5. **B5 cancel 语义化入口**：`QmlDialogBridge` 加 `Q_INVOKABLE void cancel()`（内部
   `done(Rejected)`，与 `choose(-1)` 等价但语义明确）；`FormDialog` 的 cancel 按钮改调它，
   消除魔法值 `choose(-1)`。

### Part D 下拉浮层（EnumCombo overlay）边框修复

下拉点开后弹出的选项列表原本无可见边框（与选项底同色，边界糊成一团）。加边框时踩了 Qt 的坑，
最终方案：

- **现象**：浮层 Rectangle 设 `border` + `clip:true`，边框几乎不可见；改 `border.color` /
  `border.width` 都看不出变化（颜色看似「继承」了 EnumCombo，其实是 border 被裁、露出底层）。
- **根因**（Qt 官方文档）：`Rectangle` 的 border 以边缘为中心绘制（半内半外），同一 Rectangle
  既 `border` 又 `clip:true` 时，外侧半像素 border 被自身 bounding box 裁掉；叠加 `radius`
  默认开启的抗锯齿偏移，1px border 进一步被吃掉。
- **修复**：`DialogShell.qml` 浮层拆**双层 Rectangle**——外层只画 border（不 clip），内层
  `clip:true` 容纳选项 ListView；去掉 `radius`（直角）避免抗锯齿偏移。`Theme` 加专用
  `dropdownBorder`（青灰 `#a9c9c6` / `#3d6a66`，呼应选中态青色，比通用 `borderClr` 明显）。
- **顺带修复的几何认知**：浮层几何靠 `EnumCombo.updateGeometry()` 拍快照（toggleOpen 时算一次），
  不能改成 binding 实时算——`dialogShell` 是沿 parent 链查找的命令式 property，parent 变化不
  触发其重算，binding 会在创建瞬间读到 `dialogShell=null` 而永久卡 0（排查时靠 `console.warn`
  打印 comboX/Y/W/overlay.width 定位）。

## 5 Why

- **原子/成品边界模糊**：10 原子与 4 成品混在一个目录、共用单一 qmldir，新增组件难分「可
  复用板块」与「业务弹窗」。子目录分离让物理结构匹配设计意图。
- **逐版演进未回溯收敛**：四弹窗是 2021→2029 分四次加入，早期决策（id 命名、cancel 写法、
  魔法数字）在后期未统一，导致同一件事多种写法。本任务收口。
- **id 遮蔽是真实 bug 源**：原子内部 `id: root` 与调用方 delegate 的 `root.xxx` 碰撞，
  `ParagraphFormat` 不得不改根 id 规避，是症状而非根因。统一原子内部 id 才是正解。
- **refreshTick 假读样板易漏**：每加一个 SelectableList 就要手写一行假读触发依赖，封装进
  原子后调用方只调一个 `refreshTick++`，降低出错面。
- **ESC/Cancel 双路径**：live 弹窗（FontSelector/ParagraphFormat）的 `onCancel` 已 override
  成 `bridge.cancel()`、Cancel 按钮也调 `bridge.cancel()`；exec 弹窗（ConfirmClose/FormDialog）
  未 override、走 DialogShell 默认 onCancel。原默认 `choose(-1)` 与 `cancel()` 等价（均
  `done(Rejected)`），现把默认回调也改成 `closeBridge.cancel()`，四弹窗 ESC 与 Cancel 路径
  统一走语义化入口，消除魔法值。
- **下拉浮层 border 是 Qt 已知坑**：`Rectangle` border 以边缘为中心（半内半外），与
  `clip:true` 同层会把外侧 border 自身裁掉。这是 Qt 文档明确记载的行为，不是 mogan 代码
  bug，故拆双层 Rectangle 规避，并记进 README 编码规矩供后续避坑。

## 6 How

- **执行顺序**：先 B1+B2+B4+B5（QML 语义收敛，不动 id 不动目录）→ B5 C++ 侧 → B3 id 统一
  （单独一步便于回归）→ Part A 目录分离（最后，纯结构性）。每步后 `xmake b stem` 验证。
- **目录分离的解析模型**：组件靠目录 qmldir + `import "."`/`import "subdir"` 解析；Theme 是
  singleton，成品须 `import "atoms"` 才能拿到；`.qrc` 逐文件列举（无 glob），移动须同步改路径。
