## 4 What

### Part A 原子/成品分离
10 个原子板块移入 `qml/atoms/`，4 个成品弹窗留在 `qml/`。新建 `atoms/qmldir` 列原子；
`qml/qmldir` 改为只列成品。`moganqml.qrc` 原子路径加 `atoms/` 前缀；成品 `import "."`
改为 `import "atoms"`（拿原子 + Theme 单例）。原子间互引（TabPanel→TabBar、
EnumComboList→EnumCombo）同目录 `import "."` 不变；`EnumCombo` 靠 `objectName:"DialogShell"`
沿 parent 链找 DialogShell 的运行时机制跨目录不受影响。

### Part B 五项优化
1. **B1 Theme 尺寸常量收敛**：`Theme.qml` 加 `rowH`(44×scale) / `btnH`(40×scale)，
   各原子/成品硬编码的行高/按钮高替换为命名常量，消除魔法数字散落。
2. **B2 去冗余 / 加滚动兜底**：`ConfirmClose` 去掉正文外层无意义 `Item`（与 FormDialog 对齐）；
   `FormDialog` 字段 Repeater 包 `Flickable` + `clip`，字段超 implicitHeight 时滚动。
3. **B3 统一 id 规则**：原子内部 id 不用 `root`（delegate 内 `root.xxx` 会被原子内部同名 id
   遮蔽——这是 `ParagraphFormat` 被迫用 `id: dialog`、`MiniButton` 用 `id: btn` 的根因）。
   改用组件语义缩写；`ParagraphFormat` 改回 `id: root`，与另三个成品统一。
4. **B4 refreshTick 封装**：`FontSelector` 的 `{ var _ = root.refreshTick; return ... }`
   假读样板出现 4 处，封装进 `SelectableList` 的 `refreshTick` 属性（内部吸收假读依赖），
   调用方 `refreshAll()` 只需递增各 list 的 `refreshTick`。
5. **B5 cancel 语义化入口**：`QmlDialogBridge` 加 `Q_INVOKABLE void cancel()`（内部
   `done(Rejected)`，与 `choose(-1)` 等价但语义明确）；`FormDialog` 的 cancel 按钮改调它，
   消除魔法值 `choose(-1)`。

## 5 Why

- **原子/成品边界模糊**：10 原子与 4 成品混在一个目录、共用单一 qmldir，新增组件难分「可
  复用板块」与「业务弹窗」。子目录分离让物理结构匹配设计意图。
- **逐版演进未回溯收敛**：四弹窗是 2021→2029 分四次加入，早期决策（id 命名、cancel 写法、
  魔法数字）在后期未统一，导致同一件事多种写法。本任务收口。
- **id 遮蔽是真实 bug 源**：原子内部 `id: root` 与调用方 delegate 的 `root.xxx` 碰撞，
  `ParagraphFormat` 不得不改根 id 规避，是症状而非根因。统一原子内部 id 才是正解。
- **refreshTick 假读样板易漏**：每加一个 SelectableList 就要手写一行假读触发依赖，封装进
  原子后调用方只调一个 `refreshTick++`，降低出错面。
- **ESC/Cancel 双路径风险经核实当前不存在**：live 弹窗的 `onCancel` 已 override 成
  `bridge.cancel()`、Cancel 按钮也调 `bridge.cancel()`，已一致；exec 弹窗 ESC 与 Cancel 都
  `choose(-1)`，恰好一致。故 B5 降级为「语义清晰度」轻量改动，不改 DialogShell 默认回调、
  不动 live 弹窗与 ConfirmClose。

## 6 How

- **执行顺序**：先 B1+B2+B4+B5（QML 语义收敛，不动 id 不动目录）→ B5 C++ 侧 → B3 id 统一
  （单独一步便于回归）→ Part A 目录分离（最后，纯结构性）。每步后 `xmake b stem` 验证。
- **目录分离的解析模型**：组件靠目录 qmldir + `import "."`/`import "subdir"` 解析；Theme 是
  singleton，成品须 `import "atoms"` 才能拿到；`.qrc` 逐文件列举（无 glob），移动须同步改路径。
