# 0914: 升级内置 Goldfish Scheme 到 v18.11.27

## 任务需求

将 Mogan 内置的 Goldfish Scheme 从 v18.11.26 升级到上游 v18.11.27。

## 现状分析

- 内置 Goldfish 源码位于 `TeXmacs/plugins/goldfish/`：C/C++ 与 s7 源码在
  `src/`，Scheme 库（`scheme/`、`liii/`、`srfi/`、`guenchi/`）在
  `goldfish/`。升级前版本 `GOLDFISH_VERSION` 为 `"18.11.26"`。
- 构建脚本 `xmake/goldfish.lua` 显式枚举编译单元，新增源文件必须手工登记。
- 上游 v18.11.27 相对 v18.11.26 的结构性变化：
  - 新增 `src/liii_json.cpp`：`json->string` 的 C++ 实现（语义与
    `(guenchi json)` 历史 Scheme 实现一致，注册 `glue_liii_json`）；
  - 新增 `src/s7_liii_record.{c,h}`：`define-record-type`（srfi-9）的
    C 实现（注册 `glue_liii_record`）；
  - 新增 `goldfish/liii/http-async.scm`、`goldfish/liii/http-common.scm`；
  - 无源文件/库文件删除。
- `goldfish/goldfish/`、`goldfish/texmacs/`、`goldfish/tm-goldfish.scm`
  为 mogan 本地文件（被 `progs/init-goldfish.scm` 引用，上游不存在），
  覆盖式升级只动 `src/` 与 `goldfish/{scheme,liii,srfi,guenchi}/`，
  这些本地文件自然保留。

## 2026/08/17 升级到 v18.11.27（覆盖式）

### What（本次改动做了什么）

1. 从 GitHub `MoganLab/goldfish` tag `v18.11.27` 克隆到 `/tmp` 临时目录，
   按 `bin/bump_goldfish` 的覆盖式约定（同 v18.11.26 升级，见 devel/0909.md），
   清空并全量拷入：
   - `TeXmacs/plugins/goldfish/src/`（版本号 bump 到 `18.11.27`）；
   - `TeXmacs/plugins/goldfish/goldfish/{scheme,liii,srfi,guenchi}/`
     （vendored 副本保持上游原格式，不按 mogan 的 gf fmt 重排）。
2. `xmake/goldfish.lua` 登记两个新增编译单元：
   - `libgoldfish` 的 s7 `.c` 列表新增 `s7_liii_record.c`；
   - `goldfish` 的 C++ `.cpp` 列表新增 `liii_json.cpp`。

### Why（为什么这么做）

- **覆盖式而非增量**：与 `bin/bump_goldfish` 及历次升级 PR 一致，避免漏带
  新增文件；本次恰好新增 `liii_json.cpp` / `s7_liii_record`，增量式极易
  遗漏。来源用 GitHub 克隆而非本地 goldfish 仓库，保证可复现。
- **登记新源文件到 xmake**：`xmake/goldfish.lua` 不用 glob，新增 `.c/.cpp`
  必须显式登记，否则 `glue_liii_json` / `glue_liii_record` 符号不会被编
  译进库，运行期缺实现。两个新模块的注册已由上游 `goldfish.hpp` 的
  `init_goldfish_scheme` 调用序列接好（goldfish.hpp:715 / :719），无需
  额外接线。
- **无启动兼容适配**：v18.11.26 的 `define-library`/`import` C 实现兼容
  问题已在 0909 解决（boot-s7.scm rootlet 注入 + 3 个插件 init 改回顶层
  风格），本次升级无同类行为变更，headless 启动与测试直接通过。

### How（如何验证）

1. `xmake b stem` 全量构建通过（含新增的 `s7_liii_record.c` 与
   `liii_json.cpp`）。本机需 `xmake f --loro=n`（cargo 未安装，loro 与
   本次升级无关）。
2. headless 启动 `moganstem -headless -d -x ...`：exit 0，无
   `unbound variable` / `cannot export`；`(os-sep)` → `/`，
   `get-preference` 为 procedure。
3. `goldfish-bin --version` → `Goldfish Scheme 18.11.27`；新特性冒烟：
   - `(import (liii json))` 后 `(json->string '((a . 1)))` → `{a:1}`；
   - `(import (srfi srfi-9))` 后 `define-record-type` / 访问器可用。
4. Scheme 纯逻辑测试全绿（与 v18.11.26 基线结果一致）：
   - style-package-load-test：14 correct, 0 failed
   - preferences-widgets-test：409 correct, 0 failed
   - print-widgets-test：23 correct, 0 failed
   - version-test：20 correct, 0 failed
   - tm-collab-test：61 correct, 0 failed

  18.11.27），新增 `liii_json.cpp`、`s7_liii_record.{c,h}`。
- `TeXmacs/plugins/goldfish/goldfish/{scheme,liii,srfi,guenchi}/`：Scheme

  `liii_json.cpp`（goldfish）。
