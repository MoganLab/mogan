# [222_81] 修复 algorithm 环境中 listing 行号缺失问题

## 如何测试

1. **清除缓存并重启 Mogan**：
   - macOS: 删除 `~/Library/Caches/MoganLab`，然后重启 Mogan
   - Windows: 删除 `%appdata%/MoganLab` 和 `%localappdata%/MoganLab`，然后重启 Mogan
   - Linux: 删除 `~/.cache/MoganLab`，然后重启 Mogan
2. 打开 Mogan，新建文档，选择 `generic` 样式
3. 插入 `algorithm` 环境（`插入 -> 程序 -> Algorithm`）
4. 在 algorithm 中插入 `listing` 环境（`插入 -> 程序 -> Listing -> Verbatim`）
5. 在 listing 中插入以下伪代码结构：
   - `algo-if`（`插入 -> 程序 -> Algorithmic -> If`）
   - `algo-while`（`插入 -> 程序 -> Algorithmic -> While`）
   - `algo-for`（`插入 -> 程序 -> Algorithmic -> For`）
   - `algo-if-else-if`（`插入 -> 程序 -> Algorithmic -> If else if`）
6. 预期结果：
   - `algo-while`、`algo-if`、`algo-for` 等结构**内部**的每个语句（`algo-state`、`algo-return` 等）应该有连续的行号
   - `algo-if-else-if` 内部各分支语句行号连续
7. 测试文件参考 `TeXmacs/tests/tmu/222_81.tmu`

## 2026/05/07 修复 listing 中条件结构无行号的问题

### What
修复在 `algorithm` 环境中使用 `listing` 时，`algo-if`、`algo-while`、`algo-for`、`algo-if-else-if` 等条件/循环结构**内部**的语句没有行号的问题。

### Why
`ext-numbered-sub` 在处理多行节点（如 `algo-while`）的子节点时，使用了 `ext-mark` 来标记原始 tree 位置。但在 `extern` 返回的 tree 中，`mark` 节点不会被后续 macro 展开系统处理，导致内部递归生成的 `numbered-line` 全部失效。

另外，`ext-numbered-sub` 原先只处理 `document` 类型的节点，但某些多行节点的子节点可能是 `concat` 类型，`concat` 不会被拆分成独立的 `numbered-line`，导致内部语句缺失行号。

### How
修改 `TeXmacs/progs/utils/misc/markup-funcs.scm`：

1. 修改 `ext-numbered-sub`，去掉 `ext-mark`，直接递归处理子节点。

2. 修改 `ext-numbered-sub`，对 `concat` 节点也做 `document` 处理，确保 `concat` 的 children 被分别包裹 `numbered-line`：
   ```scheme
   (define (ext-numbered-sub t)
     (cond ((tree-is? t 'document)
            `(document ,@(map ext-numbered-line (tm-children t))))
           ((tree-is? t 'concat)
            `(document ,@(map ext-numbered-line (tm-children t))))
           ((tree-multi-line? t)
            (cons (tm-label t) (map ext-numbered-sub (tm-children t))))
           (else t)))
   ```

这样：
- `algo-while`、`algo-if`、`algo-for` 等结构**内部**的每个语句获得连续行号
- 去掉 `ext-mark` 后，内部递归生成的 `numbered-line` 能正确生效
- `concat` 节点被正确处理，children 分别获得行号

- `TeXmacs/progs/utils/misc/markup-funcs.scm`
  - 修改 `ext-numbered-sub`：去掉 `ext-mark`，直接递归处理子节点；对 `concat` 节点做 `document` 处理
