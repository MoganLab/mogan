1. **清除缓存并重启 Mogan**：
   - macOS: 删除 `~/Library/Caches/MoganLab`，然后重启 Mogan
   - Windows: 删除 `%appdata%/MoganLab` 和 `%localappdata%/MoganLab`，然后重启 Mogan
   - Linux: 删除 `~/.cache/MoganLab`，然后重启 Mogan
2. **直接打开测试文件**：`TeXmacs/tests/tmu/222_81.tmu`
3. **算法行号测试**：
   - 所有算法代码行（包括 `algo-while`、`algo-if`、`algo-for`、`algo-if-else-if` 等头部和结束行）都应有连续的行号
   - 无论是 `algorithm` 还是 `specified-algorithm` 环境，行号都应正确显示
4. **Python 代码高亮测试**：
   - 文件末尾有一个 `\listing` 包裹的 `\python-code` 块
   - 确认 `import numpy as np` 有 Python 语法高亮（关键字、字符串等颜色正确）
   - 确认行号正常显示
5. **菜单项验证**：
   - 点击菜单 **Insert → Code → Algorithm** 插入一个算法环境
   - 按 `Ctrl+Backslash` 切换到源码模式（或菜单 **Document → Source → Edit source tree**）

## 2026/05/07 修复 listing 中条件结构无行号的问题

### What
修复在 `algorithm`/`specified-algorithm` 环境中使用 `listing` 时，`algo-if`、`algo-while`、`algo-for`、`algo-if-else-if` 等条件/循环结构的头部行及其内部语句没有行号的问题。

### Why
`listing` 宏通过 `ext-numbered-prog` 为每行包裹 `numbered-line` 来生成行号。但 `algo-while`、`algo-if` 等算法宏内部包含 `document` 节点（用于分隔多行语句），`ext-numbered-prog` 对 `document` 的 direct children 会递归处理，但对算法宏本身（作为 `document` 的一个子元素）直接返回而不包裹 `numbered-line`，导致算法宏的头部行（如 **while**）没有行号。

### How
在 `TeXmacs/progs/utils/misc/markup-funcs.scm` 中：

1. **保留原有的 `ext-numbered-sub`/`ext-numbered-line`**：处理普通多行节点（如 `python-code`、`shell-code`）的高亮和行号，保持结构不变
2. **新增 `is-algo-macro?`**：识别所有算法控制结构宏（`algo-if`、`algo-while`、`algo-for`、`algo-if-else-if` 等）
3. **新增 `wrap-algo-macro`**：将算法宏展开为多个 `numbered-line` 行：
   - 头部行（如 `while N ≠ 0 do`）包裹为 `numbered-line`
   - 内部 body 递归调用 `wrap-algo-body` 处理（对非算法宏的多行节点仍用 `ext-numbered-sub` 保持高亮）
   - 结束行（如 `end while`）包裹为 `numbered-line`
4. **新增 `build-if-else-if`/`build-else-if`**：递归展开 `algo-if-else-if` 的多分支条件结构
5. **修改 `ext-numbered`/`ext-numbered-prog`**：在顶层遍历中判断：如果是算法宏则调用 `wrap-algo-macro` 拆开；否则沿用原来的 `ext-numbered-sub`

这样算法结构中的每一行都能获得连续的行号，同时 Python 等代码块的高亮和结构完全不受影响。

- `TeXmacs/progs/utils/misc/markup-funcs.scm`

  - 修改 `ext-numbered`/`ext-numbered-prog`：对算法宏单独处理，其余沿用原逻辑
- `TeXmacs/progs/prog/prog-menu.scm`
  - 菜单项 "Algorithm" 从 `specified-algorithm` 改为 `algorithm`
