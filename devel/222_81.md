# [222_81] 修复 algorithm 环境中 listing 行号缺失问题

## 如何测试

1. 打开 Mogan，新建文档，选择 `generic` 样式
2. 插入 `algorithm` 环境（`插入 -> 程序 -> Algorithm`）
3. 在 algorithm 中插入 `listing` 环境（`插入 -> 程序 -> Listing -> Verbatim`）
4. 在 listing 中插入以下伪代码结构：
   - `algo-if`（`插入 -> 程序 -> Algorithmic -> If`）
   - `algo-while`（`插入 -> 程序 -> Algorithmic -> While`）
   - `algo-for`（`插入 -> 程序 -> Algorithmic -> For`）
   - `algo-if-else-if`（`插入 -> 程序 -> Algorithmic -> If else if`）
5. 预期结果：
   - `algo-if`、`algo-while`、`algo-for` 的头部行（如 **if**、**while**、**for**）应该有行号
   - 条件结构内部的语句也应有连续的行号
   - `algo-if-else-if` 整体应有一个行号，其内部各分支语句行号连续
6. 测试文件参考 `TeXmacs/tests/tmu/222_81.tmu`

## 2026/05/07 修复 listing 中条件结构无行号的问题

### What
修复在 `algorithm` 环境中使用 `listing` 时，`algo-if`、`algo-while`、`algo-for`、`algo-if-else-if` 等条件/循环结构的头部行及其内部语句没有行号的问题。

### Why
1. `ext-numbered-prog` 在处理 `listing` 的 body 时，对 `document` 的直接子节点：
   - 如果是非多行节点（纯文本），会包裹 `numbered-line`
   - 如果是多行节点（如 `algo-if` 宏调用），只递归处理其子节点，但没有给该节点本身包裹 `numbered-line`
   这导致 `algo-if` 等条件结构的头部行没有被赋予行号。

2. `ext-numbered-sub` 在处理多行节点的子节点时，使用了 `ext-mark` 来标记原始 tree 位置。但在 `extern` 返回的 tree 中，`mark` 节点不会被后续 macro 展开系统处理，导致内部递归生成的 `numbered-line` 全部失效。

### How
修改 `TeXmacs/progs/utils/misc/markup-funcs.scm`：

1. 对 `document` 的直接子节点，如果它是多行节点（`tree-multi-line?`），在递归处理其子节点后，额外包裹一层 `numbered-line`。

2. 修改 `ext-numbered-sub`，去掉 `ext-mark`，直接递归处理子节点：
   ```scheme
   (define (ext-numbered-sub t)
     (cond ((tree-is? t 'document)
            `(document ,@(map ext-numbered-line (tm-children t))))
           ((tree-multi-line? t)
            (cons (tm-label t) (map ext-numbered-sub (tm-children t))))
           (else t)))
   ```

3. 修改 `ext-numbered-line`，对多行节点也包裹 `numbered-line`：
   ```scheme
   (define (ext-numbered-line t)
     (if (tree-multi-line? t)
         `(numbered-line ,(ext-numbered-sub t))
         `(numbered-line ,t)))
   ```

这样：
- `algo-if` 的头部行获得行号
- `algo-if` body 内部的语句通过递归继续获得连续行号
- `algo-while`、`algo-for`、`algo-loop` 等结构同理获得行号
- `algo-if-else-if` 整体获得一个行号，其内部各分支语句行号连续

### 涉及文件
- `TeXmacs/progs/utils/misc/markup-funcs.scm`
  - 修改 `ext-numbered-sub`：去掉 `ext-mark`，直接递归处理子节点
  - 修改 `ext-numbered-line`：对多行节点包裹 `numbered-line`
  - 修改 `ext-numbered` 和 `ext-numbered-prog`：对多行 direct children 包裹 `numbered-line`
- `TeXmacs/tests/tmu/222_81.tmu`
  - 新增测试文件，包含 `algo-if`、`algo-while`、`algo-if-else-if` 的 listing 行号测试用例
