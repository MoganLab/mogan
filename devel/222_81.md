# [222_81] 修复 algorithm 环境中 listing 行号缺失问题

## 如何测试

1. **清除缓存并重启 Mogan**：
   - macOS: 删除 `~/Library/Caches/MoganLab`，然后重启 Mogan
   - Windows: 删除 `%appdata%/MoganLab` 和 `%localappdata%/MoganLab`，然后重启 Mogan
   - Linux: 删除 `~/.cache/MoganLab`，然后重启 Mogan
2. 打开 Mogan，新建文档，选择 `generic` 样式
3. 插入 `algorithm` 环境（`插入 -> 程序 -> Algorithm`）
4. 在 algorithm 中插入 `listing` 环境（`插入 -> 程序 -> Listing -> Verbatim`）
5. 在 listing 中插入以下伪代码结构：
   - `algo-if`（`插入 -> 程序 -> Algorithmic -> If`）
   - `algo-while`（`插入 -> 程序 -> Algorithmic -> While`）
   - `algo-for`（`插入 -> 程序 -> Algorithmic -> For`）
   - `algo-if-else-if`（`插入 -> 程序 -> Algorithmic -> If else if`）
6. 预期结果：
   - `algo-while`、`algo-if`、`algo-for` 等结构**内部**的每个语句（`algo-state`、`algo-return` 等）应该有连续的行号
   - `algo-if-else-if` 内部各分支语句行号连续
7. 测试文件参考 `TeXmacs/tests/tmu/222_81.tmu`

## 2026/05/07 修复 listing 中条件结构无行号的问题

### What
修复在 `algorithm` 环境中使用 `listing` 时，`algo-if`、`algo-while`、`algo-for`、`algo-if-else-if` 等条件/循环结构的头部行及其内部语句没有行号的问题。

### Why
根本原因有两个：

1. **`indent` 宏使用 `surround` 破坏 `document` 段落分隔**：
   `indent` 宏展开为 `(surround "" right-flush (with par-left ... body))`。`surround` 在 typesetting 时通过 `typeset_concat` 处理 body，这会把 `document` 节点当作 `concat` 处理，导致 `document` 内部的段落分隔丢失。`numbered-line` 依赖段落分隔来在每行开头渲染行号，段落分隔丢失后内部语句的行号全部失效。

2. **`ext-numbered-prog` 对多行节点不包裹 `numbered-line`**：
   原始逻辑中，`ext-numbered-prog` 对 `document` 的多行 direct children（如 `algo-while`）直接返回 `ext-numbered-sub` 的结果，不包裹 `numbered-line`。这导致 `algo-while` 的头部行（如 **while**）没有行号。

### How

1. **新增 `algo-indent` 宏替代 `indent`**：
   在 `TeXmacs/packages/environment/env-pseudo-code.ts` 中新增 `algo-indent` 宏：
   ```scheme
   <assign|algo-indent|<\macro|body>
     <\with|par-left|<plus|<value|par-left>|<value|indent-indentation>>>
       <arg|body>
     </with>
   </macro>>
   ```
   `algo-indent` 不使用 `surround`，直接通过 `with` 调整 `par-left`，从而保留 `document` 的段落分隔。

2. **修改所有算法宏使用 `algo-indent`**：
   将 `env-pseudo-code.ts` 中所有算法宏（`algo-procedure`、`algo-function`、`algo-for`、`algo-while`、`algo-if`、`algo-if-else-if` 等）中的 `indent` 替换为 `algo-indent`。

3. **修改 `ext-numbered-prog` 对多行节点包裹 `numbered-line`**：
   ```scheme
   (tm-define (ext-numbered-prog body lang)
     ...
     (if (tree-multi-line? line)
         `(numbered-line ,(ext-numbered-sub line))
         ...))
   ```
   这样 `algo-while`、`algo-if` 等结构的头部行获得行号。

4. **修改 `ext-numbered-line` 对多行节点也包裹 `numbered-line`**：
   ```scheme
   (define (ext-numbered-line t)
     (if (tree-multi-line? t)
         `(numbered-line ,(ext-numbered-sub t))
         `(numbered-line ,t)))
   ```

### 涉及文件
- `TeXmacs/packages/environment/env-pseudo-code.ts`
  - 新增 `algo-indent` 宏
  - 修改所有算法宏，将 `indent` 替换为 `algo-indent`
- `TeXmacs/progs/utils/misc/markup-funcs.scm`
  - 修改 `ext-numbered-line`：对多行节点包裹 `numbered-line`
  - 修改 `ext-numbered-prog`：对多行 direct children 包裹 `numbered-line`
- `TeXmacs/tests/tmu/222_81.tmu`
  - 新增测试文件，包含 `algo-if`、`algo-while`、`algo-if-else-if` 的 listing 行号测试用例
