# 0539 quote-env 引用块与 LLM 会话黑夜/白天配色适配

## 任务描述

1. **黑夜模式适配**：
   - 引用块（`quote-env`）原有的文字颜色（`#9198a1`）偏暗、对比度不足，左侧装饰竖条（`#8b949e`）在暗黑背景下辨识度偏低。需要将 `quote-env` 黑夜模式下的文字颜色调整为偏白色、左侧装饰竖条调整为深色主题专用装饰色；
   - LLM 对话框输入块底色原有浅灰蓝（`#9ba8c2`）导致偏白字与竖线不明显，且输入块正文此前为黑字（`#242938`），与输出部分的白色字不统一，需要将输入块底色调整为深暗底色、正文字体调整为与输出部分相同的白色。
2. **白天模式适配**：
   - 白天模式下引用块文字此前使用 `#5d6065` 整体太灰、不够沉稳黑亮；左侧装饰竖条使用 `#d0d9e0` 过于浅淡，在白底及淡蓝底上几乎看不清。需要将白天模式下的文字调整为深墨黑色、左侧竖条调整为清晰醒目的中度冷灰。
3. **协议头规范化**：
   - 将 `llm.stem` 内嵌入宏树的 `src-license` 节点移除，规范提取为文件顶部的标准版权与 GPL 协议注释块。

## 现状分析与根因

1. **文字与竖条配色**：
   - `quote-env` 的文字颜色由 `quote-text-color` 控制，左侧竖条由 `quote-bar-color` 控制，两者定义于 `std-markup.stem`，并在 `dark.ts` 中针对深色主题覆盖；
   - 之前在 `std-markup.stem` 中默认使用 `#5d6065`（太灰）与 `#d0d9e0`（太浅），在白天白底及 `#f0f4ff` 上对比较弱，公式与竖条模糊不显；
   - 之前在 `dark.ts` 中覆盖为 `#9198a1` 与 `#8b949e`，在暗黑画布下整体发暗，缺乏现代暗色主题的清晰亮白感。
2. **LLM 会话输入块底色与字体**：
   - 之前任务 1067 中黑夜模式下的 `llm-input-bg-color` 设为浅灰蓝 `#9ba8c2`、文字设为黑色 `#242938`，导致与输出部分的深色底白字割裂，且嵌入的偏白引用文字与竖条在浅底上失真。
3. **宏求值机制**：
   - `quote-env` 宏内部使用 `(value "quote-bar-color")` 与 `(value "quote-text-color")` 读取颜色；若赋值为 `(macro ...)` 复合树而非合法字面量颜色字符串，排版引擎解析颜色失败会导致竖线隐形、字体掉色。因此必须在 `std-markup.stem` 与 `dark.ts` 中直接赋予规范字面量色值。

## 解决方案 (How)

1. **`quote-env` 自身配色优化**：
   - `TeXmacs/packages/standard/std-markup.stem`（白天模式）：
     - `quote-text-color`：由 `#5d6065` 改为清晰黑亮的深墨黑 **`#24292f`**，彻底消除“太灰了”的现象；
     - `quote-bar-color`：由 `#d0d9e0` 改为中度冷灰色 **`#828d99`**，对比度显著提升，竖条清晰醒目。
   - `TeXmacs/packages/themes/dark/dark.ts`（黑夜模式）：
     - `quote-text-color`：由 `#9198a1` 改为偏白色 **`#e6edf3`**（高对比度亮白灰，亮度 92.5%）；
     - `quote-bar-color`：由 `#8b949e` 改为深色主题银蓝灰 **`#8fa0b8`**。
2. **LLM 会话输入块配色优化（`llm.stem`）**：
   - `llm-input-bg-color`：黑夜模式由浅灰蓝 `#9ba8c2` 改为深暗底色 **`#2c323c`**，白天模式保持 `#f0f4ff`；
   - `llm-input-color`：黑夜模式由黑字 `#242938` 改为与输出部分一致的白色 **`"white"`**，白天模式保持 `"dark blue"`；
   - 提取协议声明到文件头部注释。
3. **自动化测试**：
   - 新建测试文档 `TeXmacs/tests/tmu/0539.tmu`，覆盖暗黑模式下输入块正文、引文（包含数学公式与中文段落）及输出块结构；
   - 编写自动化测试脚本 `TeXmacs/tests/python/0539.py`（基于 `pynput`），自动设置 `liii-night` 主题、聚焦交互、截屏并基于像素采样精准断言输入块深暗底色（`#2c323c`）、白色文字及装饰竖条，退出后恢复原始偏好。
