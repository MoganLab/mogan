## 3 如何测试

### 3.1 确定性测试（单元测试）
无

### 3.2 非确定性测试（文档验证）
启动 Mogan，进入具有插图或表格的文档，右键或在样式偏好设置菜单中检查以下中文翻译是否正确显示：
- "Caption separator" -> "标题分隔符"
- "Captions above" -> "标题在上方"
- "Style parameters" -> "样式参数"
- "caption left padding" -> "标题左补白"
- "caption right padding" -> "标题右补白"
- "figure caption sep" -> "图标题间距"
- "figure left padding" -> "图左补白"
- "figure right padding" -> "图右补白"
- "figure sep" -> "图分隔符"
- "figure text..." -> "插图文本..."
- "table sep" -> "表分隔符"
- "space" -> "空格"

## 4 如何提交

提交前执行以下最少步骤：

```bash
xmake b stem
```

## 5 What
补全了 Mogan 在插图/表格样式首选项菜单中数个未翻译的英文选项的中文翻译。

具体翻译包括：
1. `Caption separator` 翻译为 `标题分隔符`，其选项中的 `space` 翻译为 `空格`；
2. `Captions above` 翻译为 `标题在上方`；
3. `Style parameters` 翻译为 `样式参数`；
4. `caption left padding` / `caption right padding` 翻译为 `标题左补白` / `标题右补白`；
5. `figure caption sep` 翻译为 `图标题间距`；
6. `figure left padding` / `figure right padding` 翻译为 `图左补白` / `图右补白`；
7. `figure sep` 翻译为 `图分隔符`；
8. `figure text` 翻译为 `插图文本`；
9. `table sep` 翻译为 `表分隔符`。

## 6 Why
部分有关插图与表格样式首选项的菜单项（如标题分隔符、补白等）没有中文翻译，影响了中文用户的操作体验。

## 7 How
在 `TeXmacs/plugins/lang/dic/en_US/zh_CN.scm` 字典中按字母顺序添加了相关的翻译条目。
