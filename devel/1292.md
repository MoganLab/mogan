## 5 What
1. 使用专用 QML 弹窗（`DialogShell` + `InputField` + `DialogButtons` + `run_qml_dialog`）重构「增加宏包 -> 其他宏包...」弹窗，替换旧的 `(interactive add-style-package)` C++ 遗留对话框。
2. 在 Scheme 侧新增 `(open-add-package-dialog)` 统一入口，解构返回值并调用 `(add-style-package pack)`。
3. 替换 `document-menu.scm` 中焦点菜单、焦点图标栏及文档菜单中的调用点。
4. 校验输入的宏包是否存在：若不存在，弹出 QML 确认弹窗提示并不予添加。

## 6 Why
- 原有 `(interactive add-style-package)` 依赖 C++ 遗留的 `qt_inputs_list_widget_rep` 对话框，风格陈旧且无法适配现代 UI 主题。
- 与其他已迁移至 QML 的模态弹窗（如搜索最近打开的文档、打印到文件、页面设置等）保持一致的交互与视觉体验。

## 7 How
- `AddPackage.qml` 基于 `DialogShell` 和 `InputField` 构建，提供宏包名称输入、回车提交及 Esc 取消。
- C++ 层 `cpp_add_package_dialog` 通过 `run_qml_dialog` 启动模态对话框，注入已翻译文案，并提供 `MOGAN_TEST_ADD_PACKAGE` 测试钩子。
- Scheme 侧 `open-add-package-dialog` 接收结果后验证包名非空，先调用 `package-exists?` 检测宏包是否存在；存在则触发 `add-style-package`，不存在则调用 `cpp-confirm-question` 弹窗告知用户。
