# [0537] 美化转到下拉菜单与长文件名宽度限制

| Tester                  | Platform    | Status |
| ----------------------- | ----------- | ------ |
| Mingshen <mingshen@liii.pro> | macOS | Passed |

## 1 任务背景
在 Mogan 标题栏右上角新增的「转到/Go」按钮弹出的 QML 下拉菜单中存在两个体验问题：
1. **长文件名导致整体拉得过宽**：浮层宽度原本采用动态计算 `Math.min(420, contentColumn.implicitWidth + 24)`，当最近文档中存在长文件名时，菜单整体会被拉伸至 420px 甚至更宽，破坏标题栏紧凑协调的视觉比例；
2. **菜单样式较为粗糙**：阴影层次生硬、缺少文件类型图标标识、标题行随列表滚动、滚动指示条覆盖不合理等。

## 2 涉及的代码文件
- `devel/0537.md` — 本任务说明文档
- `src/Plugins/Qt/qml/GoMenu.qml` — Go 菜单 QML 浮层美化及宽度约束实现，补充列表项 hover 浅灰色背景提示
- `tests/Plugins/Qt/qml_load_test.cpp` — 增加 Go 菜单列表项 hover 与浅灰背景色变色单元测试
- `TeXmacs/tests/python/0537.py` — Python 自动化 UI 测试脚本

## 3 改进方案

1. **固定优雅菜单宽度与文件名截断**：
   - 固定菜单卡片宽度为紧凑优雅的 `260 * Theme.scaleFactor`，杜绝长文件名将浮层撑得过宽；
   - 菜单项内部采用精准锚点布局，配合 `Text.ElideMiddle` 中间截断省略，确保即便文件名极长也能优雅显示前缀与扩展名（如 `.stem`/`.tmu`/`.pdf`），且绝对不撑大容器；
2. **美化菜单浮层与交互细节**：
   - **固定顶部标题**：标题行「最近使用」与细分隔线独立固定在卡片顶部，不随下方列表上下滚动；
   - **纯矢量轻量文档图标 (`DocumentIcon`)**：为每一项增加矢量文档图标，根据文件扩展名智能显示专属配色标签（.stem/.tmu 为经典青色、.pdf 为暖红色、.md 为蓝色、其他为灰度），并内嵌排版线条纹理；
   - **多层立体柔和阴影**：增加多层柔和透明弥散阴影，外框圆角调整为 `10 * Theme.scaleFactor`；
   - **列表项 Hover 浅灰背景提示与无闪烁过渡**：MenuItem 采用独立的高亮背景矩形 (`Rectangle`)，通过 `opacity`（透明度 0.0 -> 1.0）进行 100ms 动效过渡。杜绝直接对 `color` 进行向 `transparent` (`#00000000`) 的颜色插值（避免线性插值经过 RGB 低值的深灰色过渡态而引起闪烁），悬停时为纯净柔和的浅灰色 `Theme.fieldBgHover`（亮色 `#e5e7eb`，暗色 `#4e4e4e`），文字高亮显示，按下带有微缩放反馈（0.98）；
   - **列表项右侧文件类型标签**：每个菜单项右侧配备紧凑的文件类型标签（如 `pdf`、`tmu`、`stem`、`md` 等），严格仅截取最后一级后缀（忽略二级以上后缀如 `.tar.gz` 仅识别为 `gz`），无后缀文件自动隐藏标签，文本自动锚定避免遮挡；
   - **极简滚动条**：仅覆盖文档滚动区域，圆角胶囊状，轻盈半透明显示。

## 4 如何测试

### 4.1 Python 自动化 UI 测试
```bash
uv run --with pynput --with pillow --with numpy --with pyobjc-framework-Cocoa python3 TeXmacs/tests/python/0537.py
```
自动注入包含超长文件名的文档记录，定位点击标题栏「转到」按钮，精确测量并断言菜单宽度（<= 290px），验证长文本中间截断与 Esc 关闭退出。

### 4.2 QML 加载单元测试
```bash
xmake b qml_load_test && xmake r qml_load_test
```

### 4.3 Scheme 菜单测试
```bash
xmake b stem && xmake r go-menu-test
```
