## 5 What
把原有基于 tm-widget 的字体选择对话框迁移到 QML（`FontSelector.qml`），三栏
family/style/size + 预览 + Filter/Advanced 选项卡，交互经 C++ bridge 透传到 scheme
facade。selector-set 实时写回（live）；Cancel/重置经打开时快照写回（撤销），OK 补齐
差异落定。

1. 新增 scheme facade `font-selector-*`：原 `selector-*` 状态机经一个内聚 facade 暴露
2. 新增 C++ bridge `FontSelectorBridge`：无状态透传，setter 联动返回依赖（省 QML 二次往返）
3. 新增 `cpp-rasterize-widget`：widget → QImage → base64 PNG data URL，预览复用 impress() 渲染路径
4. 新增 QML 板块 `FontSelector.qml` / `SelectableList.qml` / `PreviewPane.qml`
5. 新增 `cpp-font-selector-dialog` glue 入口，复用 `run_modal_qml_dialog` 非阻塞模态底座
   （`setModal+show`：exec 的嵌套事件循环会让主窗口 live 不重绘，setModal+show 兼得输入
   独占与 live 重绘。详见 ai-docs/qml/README.md）
6. Cancel/重置撤销：register-specs 快照打开时字体（initial-snapshot），Cancel/重置经快照
   写回（selector-get-changes + 一次 setter）——不依赖 mark-cancel（它对 init 块无效、对
   buffer 丢选区）
7. `initial-font-data` 改非精确 `logical-font-search`（原 `-exact` 对 simsun 合成假 style
   名，不在真实列表里导致不高亮）
8. Filter/Advanced 选项 key/value 分离翻译：EnumCombo 加 `optionsTr`，显示翻译、onChanged
   回传英文 key（与老版 tm-widget `make-enum` 的 dec 反查等价）；scheme meta 返回 optionsTr。
   Filter/Advanced 选后经 filterModel/customizeModel 重拉刷新；Import 后重拉 family 列表。
9. cancel/commit 注销 specs-registry（避免每次开关对话框泄漏闭包）。

## 6 Why
- tm-widget 字体选择器与新版 QML 弹窗体系（ConfirmClose / FormDialog）风格割裂，
  迁移后统一无边框透明模态外观与 DPI 缩放。
- 预览需要光栅化为图片喂 QML Image，新增 `cpp-rasterize-widget` 复用 impress()
  渲染路径，hidpi 下清晰。

## 7 How
分层（数据真相源在 scheme，C++ bridge 透传不持字体状态）：

- **specsKey 句柄**：specs 含 getter/setter 过程不能跨 glue 序列化，故维护
  `specs-registry`（int → specs）。对话框打开时 `font-selector-register-specs` 存 specs
  返回 key，key 注入 bridge，facade 按 key 还原 specs。
- **联动 setter**：bridge 每个 `Q_INVOKABLE` 拼 scheme 串经 `eval_scheme` 调 facade；
  setter 直接返回需刷新的依赖（如 `setFamily` 返回 styles + preview），QML 在同一 handler
  更新 model + 预览，省二次往返。
- **Cancel/重置撤销（快照写回）**：`register-specs` 时快照打开瞬间的文档字体
  （`initial-snapshot`，live 改动前——文档字体的 init-multi 会改 init，事后读不到原值）。
  Cancel/重置共用 `font-selector-revert-to-snapshot`：快照填 selector-table，再
  `selector-get-changes` + 一次 setter 写回。不用 mark-cancel——它对 init 块无效、对 buffer
  丢选区（post_notify→selection_cancel）；显式写回两条 setter 路径都适用，单次 setter 避免
  多次 make-multi-with 嵌套吞选区。OK 补齐差异落定。
- **编码**：scheme assoc 的 key 常是 symbol，对 symbol 调 `tmscm_to_string` 会解引用
  垃圾指针，故 `tmscm_to_qstring` 按 string/symbol 分流；mogan string 内部是 Cork 编码，
  统一 `cork_to_utf8` 转 UTF-8 再 to QString，不用启发式的 `to_qstring`。
- **选项翻译 key/value 分离**：Filter/Advanced 的 options（Any/Thin/...）显示要翻译，
  但值回传/过滤查询/DB 用英文，二者不能是同一字符串。EnumCombo 持 `options`（英文 key）
  + `optionsTr`（翻译显示），`displayValue`/`displayOptions` 按 value 的 index 取 optionsTr
  显示，DialogShell 浮层 pick 按 index 回传 `options[index]`。scheme meta 同时返回两者，
  bridge 透传。与老版 tm-widget `make-enum`（menu-widget.scm）的 `dec` 反查表等价。
- **刷新**：右侧 Repeater 的 model 用 QtObject 持可变 list（filterModel/customizeModel），
  setFilter/setCustomize 后重拉触发 Repeater 重建（否则 EnumCombo value 是旧快照不更新）。
  Import 后 QML 重拉 familyModel（font-import 的 refresh-now 只对老 tm-widget 标签生效）。
