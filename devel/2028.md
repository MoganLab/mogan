## 5 What
把原有基于 tm-widget 的字体选择对话框迁移到 QML（`FontSelector.qml`），三栏
family/style/size + 预览 + Filter/Advanced 选项卡，交互经 C++ bridge 透传到 scheme
facade。selector-set 实时写回（live），归入对话框开启的 undo mark 事务；OK 经
`font-selector-commit` 补齐差异并 mark-end 落定，Cancel/重置经 mark-cancel 回滚 live
写回。

1. 新增 scheme facade `font-selector-*`：原 `selector-*` 状态机经一个内聚 facade 暴露
2. 新增 C++ bridge `FontSelectorBridge`：无状态透传，setter 联动返回依赖（省 QML 二次往返）
3. 新增 `cpp-rasterize-widget`：widget → QImage → base64 PNG data URL，预览复用 impress() 渲染路径
4. 新增 QML 板块 `FontSelector.qml` / `SelectableList.qml` / `PreviewPane.qml`
5. 新增 `cpp-font-selector-dialog` glue 入口，复用 `run_qml_dialog` 模态底座
6. 新增 undo mark 事务（`new-marker` glue + `selector-mark`）：包住对话框生命周期，
   Cancel/重置 mark-cancel 回滚 live 写回，OK mark-end 落定

## 6 Why
- tm-widget 字体选择器与新版 QML 弹窗体系（ConfirmClose / FormDialog）风格割裂，
  迁移后统一无边框透明模态外观与 DPI 缩放。
- 预览需要光栅化为图片喂 QML Image，新增 `cpp-rasterize-widget` 复用 impress()
  渲染路径，hidpi 下清晰。

## 7 How
分层（数据真相源在 scheme，C++ bridge 透传不持字体状态）：

- **specsKey 句柄**：specs 含 getter/setter 过程不能跨 glue 序列化，故维护
  `specs-registry`（int → specs）。对话框打开时 `font-selector-register-specs` 存 specs
  返回 key，key 注入 bridge，facade 按 key 还原 specs。
- **联动 setter**：bridge 每个 `Q_INVOKABLE` 拼 scheme 串经 `eval_scheme` 调 facade；
  setter 直接返回需刷新的依赖（如 `setFamily` 返回 styles + preview），QML 在同一 handler
  更新 model + 预览，省二次往返。
- **undo mark 事务（Cancel/重置回滚）**：`register-specs` 时 `mark-start` 开事务，左侧
  selector-set 的 live 写回归入此 mark。Cancel（`font-selector-cancel`）/重置
  （`font-selector-restore`）经 `mark-cancel` 整体回滚 buffer/init 的 live 写回，再
  `selector-clean` 清 selector-table 全部 var（含左侧 family/style/size——live 路径
  selector-set 会写它们），使 selector-get 回退到已回滚的 get-env/get-init。OK
  （`font-selector-commit`）补齐差异后 `mark-end` 落定。重置额外重开新 mark，供后续
  live 归属。mark id 经新增 `new-marker` glue（`edit_modify_rep::new_marker_id` 转调
  moebius `new_marker()`）取得。
- **编码**：scheme assoc 的 key 常是 symbol，对 symbol 调 `tmscm_to_string` 会解引用
  垃圾指针，故 `tmscm_to_qstring` 按 string/symbol 分流；mogan string 内部是 Cork 编码，
  统一 `cork_to_utf8` 转 UTF-8 再 to QString，不用启发式的 `to_qstring`。
