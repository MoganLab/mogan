## 2026/08/04 QML Print-To-File Dialog

### What

Added a QML Print to file dialog for PDF and PostScript output, page selection,
native destination selection, menu integration, and keyboard shortcuts.

### Why

The previous workflow used the legacy file chooser and did not provide a
single QML surface for output format and page selection. The QML bridge also
needs to preserve native Windows paths when sending a selected destination back
to Scheme.

### How

The QML dialog returns named fields through `QmlDialogBridge`. Scheme converts
the selected system path to a Mogan `url` before calling the existing printing
glue. The C++ bridge serializes the file path as UTF-8, matching the existing
Qt file chooser, while ordinary dialog text keeps its normal text conversion.
The dialog validates page bounds and uses a clipped inner field to display long
paths without clipping its border.
