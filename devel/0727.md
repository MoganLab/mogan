# [0727] 修复 ImGui 版本选中区域的显示

## What
ImGui 版本目前选中区域颜色于 Qt 版本不同，原因是在 edit_interface 计算选择区域中采取了与 Qt 不同的计算方法。

因此删去了不一致的条件逻辑，保证两个版本计算选中区域的方法一致

## 如何测试

```
xmake f -p wasm --qt_frontend=no --pdfhummus=no -m debug
或者
xmake f --qt_frontend=no --pdfhummus=no -m debug
```

```
xmake b stem
```

```
xmake r stem
```

在打开的文档中使用鼠标选择内容，观察选中区域的显示（注意 WASM 版本需要先 resize 一下 window (或者缩放到50%)确保鼠标位置计算正确，这个问题将以后解决）
