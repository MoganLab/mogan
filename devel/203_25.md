# [203_25] 支持 \bold 和 \italic

## 如何测试
创建一个 tex 文件，内容如下：
```LaTeX
\documentclass{article}
\begin{document}

这是一个包含 \bold{粗体文本} 和 \italic{斜体文本} 的示例句子。

\end{document}

```
删除缓存：
```bash
rm -rf ~/.local/share/moganlab/
rm -rf ~/.cache/MoganLab/
```
编译并启动 Mogan，文件->导入->LaTeX，选择刚刚创建好的 LaTeX 文件，查看 “粗体文本” 和 “斜体文本” 是否加粗与倾斜。

## 2026/02/25 添加对 \bold 和 \italic 的支持
### What
修改了 /home/mingshen/git/mogan/src/Plugins/Tex/fromtex.cpp，添加了对 \bold 和 \italic 的判断分支，它们将会被转换为 <with|font_series|bold|math_font_series|bold|text> 和 <with|font_series|italic|math_font_series|italic|text>，以实现粗体和斜体。
