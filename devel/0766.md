# [0766] WebSocket 模块
## What
添加了 src/Plugins/WebSocket 客户端模块，在 loro=yes 的时候被编译

tm_websocket 是抽象类，解耦具体实现。

目前有两个版本的具体实现。
- 用 libcurl (版本 >= 7.86.0) 的实现
- 用 emscripten WebSocket API 的实现。用于 WASM。

# 如何测试
目前测试只覆盖了 Qt 客户端的实现
```
xmake f --loro=yes
xmake b tm_websocket_client_test
xmake r tm_websocket_client_test
```
