# [0792] Collab 光标上行节流：位置不改变不触发上行
## What
记录每次上行的光标 payload，如果与上次一致，则不上行，以节流
1. collab_session 增加 last_sent_cursor_payload 缓存：记录最近一次上行的光标 payload。
2. flush_cursor 增加去重判定：
- 非编辑引起的普通节流/轮询调用（force == false）时，若当前 payload 与 last_sent_cursor_payload 一致，直接跳过发送，彻底阻断 0.5s 光标闪烁重绘唤醒 poll 导致的网络上行；
- 本地编辑后（force == true）仍会强制发送，确保编辑与光标顺序对齐。
3. 断开/重连重置缓存：会话断开 disconnect() 时清空 last_sent_cursor_payload，确保新连接成立后首次光标能正常送达。

## 如何测试
```
xmake f --loro=yes
xmake b stem
xmake r stem
```
