# 1286: 升级内置 Goldfish Scheme 到 v18.11.32 并移除 njson

## 任务需求

将 Mogan 内置的 Goldfish Scheme 从 v18.11.31 升级到上游 v18.11.32（本地
`~/git/goldfish`，与 GitHub tag `v18.11.32` 一致），并随上游同步移除
`(liii njson)` 模块。

## 现状分析

- 升级前内置版本为 v18.11.31（`devel/1252.md`）。
- 内置路径：`TeXmacs/plugins/goldfish/`（`src/` + `goldfish/{scheme,liii,srfi}/`）。
  `goldfish/goldfish/`、`goldfish/texmacs/`、`tm-goldfish.scm` 为 mogan 本地文件，
  覆盖式升级不触碰。
- 上游 v18.11.31..v18.11.32 主要改动：
  - `[0160]` 移除 `(liii njson)` 模块及相关代码（#996），JSON 能力统一由
    `(liii json)` + `liii_json.cpp` 提供；
  - 环形结构防御：`list-sorted?` 挂起（0163）、subprocess 命令参数/env 死循环
    （0166/0151）、`set! *load-path*` 死循环（0167）、`json-drop` 回调期造环
    死循环与 `json-set/reduce` 列表截短脏数据（0154）；
  - 边界修复：`substring/cursors` 越界段错误（0152）、`iota_list` 有符号溢出
    UB、`g_http-post` files 参数 multipart 类型检查（0149）、
    `g_listdir` 空字符串防越界（0145）；
  - 类型检查补齐：`hash-table-ref/default` 与 `update!`（0158）、
    `delete-duplicates` 比较器语义（0156）、`s7_internal.h` inline 未定义警告
    （0165）、`gf fmt` 对 `let*` 绑定值位置跨行 vector 的缩进修复（0159）。
- njson 在 mogan 的使用点已由前序任务收尾（1281–1285：tm-dialogue、
  shortcut-edit、chat-list、telemetry 等 progs 迁至 `(liii json)`），本分支
  迁移最后一个使用点 `TeXmacs/tests/0205.scm`（chat 持久化集成测试）。
- `3rdparty/json-schema-validator` 仅被 `liii_njson.cpp` 的 schema 校验使用，
  随 njson 一并移除。
- `xmake/goldfish.lua` 显式枚举源文件，`xmake/vars.lua` 维护 libstem 头文件
  搜索路径，两处均需去掉 njson 相关条目。

## What

1. 从本地 `~/git/goldfish`（v18.11.32）取出 `src/` 与
   `goldfish/{scheme,liii,srfi}/`，覆盖 mogan 对应目录，与上游逐文件一致。
2. 移除 njson：
   - 删除 `TeXmacs/plugins/goldfish/goldfish/liii/njson.scm`、
     `TeXmacs/plugins/goldfish/src/liii_njson.cpp`；
   - 删除整个 `3rdparty/json-schema-validator/`；
   - `xmake/goldfish.lua` 去掉 `liii_njson.cpp` 与 json-schema-validator 的
     源文件及 include 路径；`xmake/vars.lua` 的 `libstem_headers` 去掉对应
     include 目录。
3. `TeXmacs/tests/0205.scm` 从 `(liii njson)` 迁移到 `(liii json)`：
   `file->njson` → `string->json` + `string-load`，`njson-ref` → `json-ref`，
   `njson-array->list` → `vector->list`/`list?` 兼容分支，删除全部
   `njson-free` 手工释放调用。
4. 删除 njson 专属测试：`TeXmacs/tests/0251.scm`、
   `TeXmacs/tests/tmu/200_21_njson.tmu`。
5. vendored 文件保持上游原格式，不按 `gf fmt` 重排。

## Why

与 1252（v18.11.31）相同的覆盖式对齐上游 tag 约定。上游 v18.11.32 已移除
`(liii njson)`，mogan 内置解释器保持与上游一致，避免维护一份上游已废弃的
JSON 双实现及其 schema 校验依赖。

## How（本机验证）

- 与 `~/git/goldfish` v18.11.32 逐文件 `diff -rq` 一致（`src/` 全量、
  `goldfish/{scheme,liii,srfi}/` 除 mogan 本地文件外无差异）。
- 全仓 `grep njson` 无残留引用。
- `xmake b goldfish`、`xmake b stem` 通过。
- 按用户指示跳过测试与 GUI 验证，直接提 PR（GUI 验证按惯例由用户手动做）。

## 涉及文件

- vendored 同步：`TeXmacs/plugins/goldfish/src/`（s7.c、s7_internal.h、
  s7_liii_*.c、s7_module.c、goldfish.hpp、liii_*.cpp）、
  `TeXmacs/plugins/goldfish/goldfish/{scheme,liii,srfi}/`
- 移除 njson：`goldfish/liii/njson.scm`、`src/liii_njson.cpp`、
  `3rdparty/json-schema-validator/`
- 构建：`xmake/goldfish.lua`、`xmake/vars.lua`
- 测试迁移：`TeXmacs/tests/0205.scm`；删除 `TeXmacs/tests/0251.scm`、
  `TeXmacs/tests/tmu/200_21_njson.tmu`
