# [1306] 移除 database 相关的死代码模块

## 1 背景

- Mogan 早已在历史重构中移除了 C++ 端的 `tmdb` 数据库插件实现及其 Glue 绑定，`TeXmacs/progs/database/` 下的模块处于半废弃状态。
- 其中 `(database bib-menu)` 模块（`TeXmacs/progs/database/bib-menu.scm`）在全工程中从未被 `:use`、`load` 或 `lazy-define` / `lazy-menu` 加载，属于孤儿死代码。

## 2 What

- 移除未被加载的死代码文件 `TeXmacs/progs/database/bib-menu.scm`。

## 3 Why

- 减少历史遗留无用代码，为后续进一步清理 `db-*` 数据库相关模块做准备。

## 4 How

- 使用 `git rm TeXmacs/progs/database/bib-menu.scm` 删除该文件。

## 5 涉及文件

- `TeXmacs/progs/database/bib-menu.scm`（删除）
- `devel/1306.md`（新增，任务文档）
