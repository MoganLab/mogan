# [1306] 移除 database 相关的死代码模块

## 1 背景

- Mogan 早已在历史重构中移除了 C++ 端的 `tmdb` 数据库插件实现及其 Glue 绑定，`TeXmacs/progs/database/` 下的模块处于半废弃状态。
- 其中 `(database bib-menu)` 模块（`TeXmacs/progs/database/bib-menu.scm`）在全工程中从未被 `:use`、`load` 或 `lazy-define` / `lazy-menu` 加载，属于孤儿死代码。

## 2 What

- 移除未被加载的死代码文件 `TeXmacs/progs/database/bib-menu.scm`。
- 移除 `TeXmacs/progs/database/bib-local.scm` 及其在 `init-research.scm` 中的 `open-biblio` 惰性定义与属性设置。
- 移除 `document-menu.scm` 中对 `open-biblio` 的菜单项引用，以及 `document-edit.scm` 中未再被使用的辅助函数 `buffer-has-biblio?`。
- 移除 `TeXmacs/progs/database/db-menu.scm` 及与其关联的全局菜单、模式开关、底部工具栏联动代码（`init-research.scm`、`main-menu.scm`、`tm-modes.scm`、`view-menu.scm`、`search-widgets.scm`、`spell-widgets.scm`）。
- 移除 `TeXmacs/progs/database/db-widgets.scm` 与 `TeXmacs/progs/database/db-tmfs.scm`，并在 `init-research.scm` 及 `bib-manage.scm` 中清理其暴露的未使用的符号。
- 移除 `(database db-markup)`（`TeXmacs/progs/database/db-markup.scm`）及废弃测试样式 `TeXmacs/styles/test/database.ts` 与 `TeXmacs/styles/test/database-bib.ts`。
- 移除 `(database bib-manage)`（`TeXmacs/progs/database/bib-manage.scm`），并在 `init-research.scm` 及 `db-convert.scm` 中清理对其的引用。
- 清理 `TeXmacs/progs/init-research.scm` 中剩余的数据库懒加载定义（`db-convert` 与 `bib-db`）。

## 3 Why

- 减少历史遗留无用代码，为后续进一步清理 `db-*` 数据库相关模块做准备。

## 4 How

- 使用 `git rm TeXmacs/progs/database/bib-menu.scm` 删除该文件。
- 使用 `git rm TeXmacs/progs/database/bib-local.scm` 删除该文件，并在 `TeXmacs/progs/init-research.scm` 中删除 `open-biblio` 相关注册。
- 在 `TeXmacs/progs/generic/document-menu.scm` 中删除调用 `open-biblio` 的两处菜单条目，在 `TeXmacs/progs/generic/document-edit.scm` 中删除 `buffer-has-biblio?`。
- 使用 `git rm TeXmacs/progs/database/db-menu.scm` 删除该文件；在 `init-research.scm` 移除 `db-menu` 与 `db-toolbar` 的懒加载；在 `main-menu.scm` 中删除 `Data` 菜单链接；在 `tm-modes.scm` 中移除 `with-database-tool%`；在 `view-menu.scm` 中移除底部工具栏关于 database 的项与分支；在 `search-widgets.scm` 和 `spell-widgets.scm` 中移除对 `db-show-toolbar` 的调用。
- 使用 `git rm` 删除 `TeXmacs/progs/database/db-widgets.scm` 和 `TeXmacs/progs/database/db-tmfs.scm`；在 `init-research.scm` 中清理 `db-widget` 与 `db-tmfs` 相关的懒加载定义；在 `bib-manage.scm` 中清理调用已删除 widget 的 `open-bib-chooser`。
- 使用 `git rm` 删除 `TeXmacs/progs/database/db-markup.scm`、`TeXmacs/styles/test/database.ts` 和 `TeXmacs/styles/test/database-bib.ts`。
- 使用 `git rm` 删除 `TeXmacs/progs/database/bib-manage.scm`；在 `init-research.scm` 移除相关懒加载；在 `db-convert.scm` 中移除动态 `import-from`。
- 清理 `TeXmacs/progs/init-research.scm` 中残留的 `(lazy-define (database db-convert) ...)` 与 `(lazy-define (database bib-db) ...)` 数据库引导块。
