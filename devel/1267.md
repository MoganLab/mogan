# [1267] 隐藏 文件->打印、页面设置以及导出中的 PDF 选项

## 如何测试

1. `xmake b stem && xmake r stem` 启动 Mogan
2. 点开 `文件` 菜单：
   - 预期：不再出现 `打印`（Print）和 `页面设置`（Page setup）入口
   - `预览`（Preview）保留
3. 点开 `文件 -> 导出`（Export）子菜单：
   - 预期：不再出现 `PDF`（Pdf）和 `可编辑PDF`（Pdf with embedded document）选项
4. 工具栏打印图标菜单（`print-menu-inline`）不受影响
5. `文件 -> 预览` 同区新增 `导出为PDF...`（Export as PDF...）：
   - 预期：弹出 QML 对话框「导出为PDF」，仅含一个开关
     `将源文档作为附件嵌入PDF`（默认关）+ `导出`/`取消` 按钮
   - 不勾选点 `导出`：弹文件选择框，默认文件名 `xxx.pdf`，走普通 PDF 导出
   - 勾选后点 `导出`：默认文件名 `xxx.tmu.pdf`，走可编辑 PDF 导出（源文档
     作为附件嵌入）
   - `取消` / ESC / 关闭：不导出
6. `xmake b qml_load_test && xmake r qml_load_test`：ExportPdf.qml 加载通过
7. C++ 测试钩子（不弹窗，验证数据契约）：`MOGAN_TEST_EXPORT_PDF=ok` 时
   `cpp-export-pdf-dialog` 按选项初值返回 `(tuple ("embed" "false"))` 形状；
   `=cancel` 返回空树

## 2026/09/05

### Part 1: 隐藏 文件->打印 和 文件->页面设置

#### What

隐藏 `文件->打印` 和 `文件->页面设置` 两个菜单项。

#### Why

打印/页面设置入口当前不可用（本任务属于 PDF 导出改造，导出统一走
`文件->导出->Pdf`），保留失效入口会误导用户。

#### How

`TeXmacs/progs/texmacs/menus/file-menu.scm` 的 `print-menu`（仅被 `file-menu`
链接，是文件菜单里的打印区块）中，直接移除 `Print`（含打印对话框 / 打印为文件
两种形态）与 `Page setup`（菜单形态 + 弹窗形态）各条目，保留 `Preview`；
打印相关函数与 `print-menu-sub` 定义不动。

不动 `print-menu-sub`：它仍被 `print-menu-inline`（工具栏打印图标）引用；
也不动 `print-menu-inline`：本任务只针对文件菜单。

### Part 2: 隐藏 导出 中的 PDF 和 可编辑PDF

#### What

隐藏 `文件->导出` 菜单中的 `PDF` 和 `可编辑PDF`（`Pdf with embedded document`）两个选项。

#### Why

导出菜单中的旧版 PDF 及可编辑 PDF 导出选项暂不需要显示，清理文件导出入口。

#### How

`TeXmacs/progs/texmacs/menus/file-menu.scm` 的 `file-menu` 的 `Export` 子菜单中，
移除 `"Pdf"` 和 `"Pdf with embedded document"` 两项入口，底层导出实现函数保持不动。

### Part 3: print-menu 新增 导出为PDF...（QML 对话框）

#### What

`print-menu`（`预览` 同区）新增 `导出为PDF...` 菜单项，点击弹出 QML 对话框
`ExportPdf.qml`。对话框只有一个选项：`将源文档作为附件嵌入PDF`（Toggle，默认关），
加 `导出`/`取消` 按钮。确认后走通用文件选择，默认文件名随选项联动：
不嵌入为 `xxx.pdf`，嵌入为 `xxx.tmu.pdf`。

#### Why

导出入口统一收敛到一处（Part 1/2 隐藏了旧入口）。PDF 导出对话框按任务要求
本次只实现「是否嵌入源文档」，后续选项在此对话框上扩展。嵌入源文档时沿用
旧「可编辑PDF」的 `tmu.pdf` 命名约定。

#### How

- `src/Plugins/Qt/qml/ExportPdf.qml`（新增）：DialogShell + 标题 + Toggle +
  DialogButtons，一次性提交（`closeBridge.submit(values)`，布尔用
  `"true"/"false"` 字符串）。字段由 `formFields` 注入，label/value 均在 scm
  侧取好，QML 不碰 i18n。
- `src/Plugins/Qt/QTMQmlDialog.hpp/.cpp`：新增 glue 入口
  `cpp_export_pdf_dialog (tree form)`，与 `cpp_print_to_file_dialog` 同构
  （`run_qml_dialog` exec 阻塞模态 + 测试钩子 `MOGAN_TEST_EXPORT_PDF=
  ok|cancel`）。无 path 型字段，不注入 printBridge。
- `src/Scheme/L5/glue_qt.lua` + `TeXmacs/progs/prog/glue-symbols.scm`：注册
  `cpp-export-pdf-dialog`。
- `TeXmacs/progs/texmacs/texmacs/tm-print.scm`：新增 `export-as-pdf` facade——
  弹对话框读选项，确认后 `choose-file` 选目的地：嵌入走
  `wrapped-print-to-pdf-embeded-with-tmu`，否则 `wrapped-print-to-file`。
  `propose-export-pdf-name` 算默认名（`propose-name-buffer` 去后缀 +
  `.pdf`/`.tmu.pdf`）；`export-pdf-default-dir` 与 `choose-file` 缺省目录逻辑
  同源（scratch 上次目录 / LiiiSTEM，tmfs 下载目录，本地取所在目录）。
- `TeXmacs/progs/texmacs/menus/file-menu.scm`：`print-menu` 增加菜单项
  （仅 Qt GUI 分支链接，ImGui 前端不受影响）。
- `TeXmacs/plugins/lang/dic/en_US/zh_CN.scm`：新增 `Export as PDF...`/
  `Export as PDF`/`Export`/`Embed source document` 的中文翻译。
- `tests/Plugins/Qt/qml_load_test.cpp`：新增 `test_export_pdf_loads` 用例。
