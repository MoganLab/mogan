# 0920 优化 curve_rep::bound 的性能，并撰写其 Doxygen 文档和单元测试

> 基于 0919（PR #4386，curve 迁移至 moebius）分支开发。

## 任务

`curve_rep::bound`（`moebius/Kernel/Types/curve.cpp`）是曲线「位移-参数」
连续性界的默认实现，segment、poly_segment、arc、ellipse、hyperbola、
parabola 等未覆写 bound 的曲线均走此路径，被 `find_closest_points` 等
遍历算法用作参数步长依据。本任务：

1. 优化 `curve_rep::bound` 的性能（消除循环不变量重复求值与临时 `point`
   堆分配）；
2. 为 `bound` 撰写中文 Doxygen 文档；
3. 补充 `bound` 的单元测试。

## What

- `curve_rep::bound` 重写：`evaluate (t)` 提出二分循环（循环不变量），
  距离比较改为 `norm2_diff` 平方距离（免差向量临时 `point`），
  val2 检验失败时短路跳过 val3 的求值；
- `norm2_diff` 由 `point.cpp` 的文件内 static 辅助函数提升为 `point.hpp`
  的内联函数（与 `norm` 同样内联于头文件），补中文 Doxygen 文档，
  二维走无循环快路径；
- `curve.hpp` 中 `bound` 声明补充中文 Doxygen 文档；
- 新增 `moebius/tests/Kernel/Types/curve_test.cpp`（5 个 bound 用例）；
- `point_test.cpp` 新增 norm2_diff 专项用例；
- 新增 `moebius/bench/Kernel/Types/curve_bench.cpp` 基准。

## Why

原实现每轮二分迭代都重新 `evaluate (t)`（val1 是循环不变量），且
`norm (val2 - val1)` 先构造差向量临时 `point`（一次堆分配加 `array`
引用计数的原子加减）再开方。bound 只关心距离是否超过 eps，差向量
本身无需物化；val2 已超限时 val3 的求值也是纯浪费。

## How

1. `evaluate (t)` 提出循环，只算一次；
2. `norm (a - b) <= eps + 1e-6` 等价改写为
   `norm2_diff (a, b) <= (eps + 1e-6)^2`（tol 为负时 lim 取 -1，
   保持与原实现完全一致的真值表）；
3. val2 检验失败时 `continue`，跳过 val3 的 `evaluate`；
4. `norm2_diff` 提升到头文件内联，供跨编译单元复用（curve.cpp 与
   point.cpp 的 dist/seg_dist/collinear 共用同一实现）。

### bench 前后对比（nanobench，release，ns/op，各跑 3 次取中位数）

| 基准 | 优化前 | 优化后 | 加速比 |
|---|---:|---:|---:|
| segment bound | 135.49 | 110.41 | 1.23x |
| poly_segment bound | 142.60 | 117.15 | 1.22x |

`norm2_diff` 与等价的 `norm (a - b)` 对比（point_bench，ns/op，3 次中位数）：

| 基准 | ns/op |
|---|---:|
| norm (a - b)（构造差向量临时 point + 开方） | 7.88 |
| norm2_diff（免临时、免开方） | 0.50 |

单次距离比较相差约 15.8 倍（同版本对照，非前后对比）；bound 整体
加速约 1.2x，因为每轮迭代的开销主要由两次虚函数 `evaluate` 主导，
距离比较只占其中一部分。

另实测 norm2_diff 新旧实现本身（旧：point.cpp 内 static 纯循环；
新：头文件内联 + 二维快路径）均约 0.50 ns/op，无显著差异——二维下
编译器已将两次循环展开。本任务的收益来自调用侧消除临时 point 与
跨编译单元内联复用，而非该函数自身算法变化。

## 测试

```bash
cd moebius
xmake test moebius_tests/curve_test   # bound 专项
xmake test moebius_tests/point_test   # norm2_diff 专项
xmake test "moebius_tests/*"          # 全量 18 个测试
```

覆盖用例：

- 直线段 delta 恰为 eps/|grad|（中点与两端点，端点验证 [0,1] 钳制）；
- 三维点直线段；
- 退化线段（零梯度）返回 tm_infinity；
- poly_segment 拐点处梯度低估位移时二分收缩到精确值；
- 契约性质：对 segment/poly_segment 在 t = 0.1..0.9 采样，返回的 delta
  满足 |c(t±delta) - c(t)| <= eps + 1e-6。
