## 2025/05/27 实现假的 llm 插件

### What
实现一个假的 llm 插件，功能上和 echo 插件一样（简单回显），但样式使用 stem_202602 中 llm 插件的样式。

### Why
用于在墨干仓库开发 llm 插件相关功能，避免依赖真实的 LLM API。

### How
1. 复制 stem_202602 中 llm 插件的样式文件 `packages/session/llm.ts`
2. `init-llm.scm` 参考 echo 插件的初始化逻辑，但注册为 llm 插件
3. `tm-llm.scm` 使用 echo 的 read-eval-print 逻辑，prompt 改为 `llm>`
