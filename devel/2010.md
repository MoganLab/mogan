# [2010] 修复 startup_tab_widget_test 在 macOS 上的退出崩溃

## 如何测试

```bash
xmake b startup_tab_widget_test
xmake r startup_tab_widget_test
```

## What

`startup_tab_widget_test` 在 macOS CI 上所有用例全部 PASS（8 passed），但在进程退出阶段崩溃：

```
qt.core.qobject.connect: QObject::connect(QObject, QThreadPool): invalid nullptr parameter
Received signal 11 (SIGSEGV), code 2, for address 0x00000000000000e0
```

导致 xmake 报 `execv(.../startup_tab_widget_test) failed(-1)`。

## Why

`TemplateManager::initialize()` 会在后台发起真实网络请求（`refreshCategories()` + `refreshRecommendTemplates()`）。`TemplateAPI` 内部的 `QNetworkAccessManager` 维护一个 `QThreadPool` 处理后台任务，并持有仍在飞的网络 reply。

测试用例全部跑完后，进程进入退出阶段，全局对象（`QApplication` 等）的析构顺序不确定。`QNetworkAccessManager` 及其 `QThreadPool`、飞行中的 reply 与其它全局对象发生析构竞争：

- 日志中的 `connect(QObject, QThreadPool): invalid nullptr parameter` 即退出阶段尝试 connect 一个已部分析构的 `QThreadPool`。
- 紧随其后的 SIGSEGV at `0xe0`（小偏移量）是访问该已失效对象成员时的空指针解引用。

macOS 上 Qt 对 `QNetworkAccessManager` 后台线程的清理时序与 Linux 不同，因此该竞争在 macOS CI 上集中暴露，Linux 上往往不出现。

## How

从源头消除问题：让测试**不发真实网络请求**。`TemplateAPI` 已有 `offlineMode_` 机制，各 fetch 入口均有短路（`if (offlineMode_) emit xxxLoadFailed("Offline mode"); return;`），进入离线模式后不会创建网络请求、不启动 `QNetworkAccessManager` 后台线程。

### 1. `TemplateManager` 暴露离线开关

`TemplateManager` 持有的 `api_` 是 private，测试无法直接设置。新增公开入口转发给 `TemplateAPI`：

- `template_manager.hpp`：声明 `void setOffline(bool offline);` / `bool isOffline() const;`
- `template_manager.cpp`：`setOffline()` 调用 `api_->setOfflineMode(offline)`，`isOffline()` 取反 `api_->isOnline()`。

`TemplateAPI::setOfflineMode(true)` 会 `emit networkStateChanged(false)`，`TemplateManager::onNetworkStateChanged(false)` 仅置 `isOnline_=false`（`isOnline` 为 false，不触发重入刷新），后续 `initialize()` 里的 `refreshCategories()` / `refreshRecommendTemplates()` 全部走 offline 短路。

### 2. 测试在 `initialize()` 之前进入离线模式

`startup_tab_widget_test.cpp` 的 `initTestCase()` 中，先 `TemplateManager::instance()->setOffline(true)`，再 `initialize()`。被测的 `QTMTemplatePage` 关心的 `categoriesLoaded` / `templatesLoaded` 信号仍由本地缓存 / Scheme 路径正常发射，测试行为不变；但不再触碰任何网络对象，退出阶段因此没有析构竞争。
