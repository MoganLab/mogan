# [1095] 精简主编辑器右键菜单的文档根分支

任务编号：1095。光标位于文档根（buffer）时，主编辑器右键菜单的 buffer 分支会注入一组文档级项：“Style”（显示当前文档样式名，点开提供样式切换 / Edit style / Add style package 等）以及 `focus-document-menu` / `focus-document-extra-menu` 提供的页面、语言、字体等文档属性项。这些项与主菜单 Document 下的对应入口（Document → Style、页面设置、字体等）重复。本任务清空右键菜单 buffer 分支的这些文档级注入，仅保留 `("Help" (focus-help))`；文档级设置收敛到 Document 菜单。焦点工具栏上对应的图标不受影响（菜单与图标是两套独立定义）。

## 5 What
1. 在 `document-menu.scm` 的 `(tm-menu (standard-focus-menu t) (:require (tree-is-buffer? t)) ...)` 分支中，删除 `(dynamic (focus-style-menu t))`、`(dynamic (focus-document-menu t))`、`(dynamic (focus-document-extra-menu t))`。
2. 一并删除这些注入之间的 `---` 分隔，避免留下悬空分隔线；分支最终仅保留 `("Help" (focus-help))`。

## 6 Why
右键菜单 buffer 分支注入的文档级项与主菜单 Document 重复：“Style” 与 Document → Style（`full-document-menu` 中的 `(-> "Style" (link document-style-menu))`，而 `document-style-menu` 即 `(link style-menu)`）指向同一套 `style-menu`；`focus-document-menu` / `focus-document-extra-menu` 提供的页面、语言、字体等项也与 Document 菜单下的对应入口重叠。右键菜单更适合放编辑上下文相关操作，文档级设置收敛到 Document 菜单单一入口，减少冗余、降低用户在两处看到同名项的认知负担。

## 7 How
- 右键菜单主体为 `focus-menu`（`main-menu.scm` 的 `texmacs-popup-menu`），其内容由 `standard-focus-menu`（`generic-menu.scm`）动态生成。`standard-focus-menu` 是合并式：`generic-menu.scm` 的基础定义提供祖先菜单、tag 菜单、move/insert、hidden、extra、label 等随光标 tag 变化的上下文项；`document-menu.scm` 中带 `:require (tree-is-buffer? t)` 的定义在光标位于文档根时**追加** Style / document 文档级项 + Help。本次只清空这个追加部分的文档级注入，保留 Help；光标进入具体 tag 时基础定义的动态项不受影响。
- 这些文档级菜单项（`focus-style-menu` 等）与焦点工具栏的图标（`focus-style-icons` 等）是两套独立定义：菜单走 `focus-*-menu`，图标走 `focus-*-icons`（在图标栏注入）。删除 buffer 分支的菜单注入只影响右键菜单文本项，不触及图标，故工具栏图标保持不变。
- `focus-style-menu` / `focus-document-menu` / `focus-document-extra-menu` 等定义本身保留不删：它们虽不再被右键菜单引用，但保留可避免误伤未来其他 mode 的引用，且未引用的死定义不影响运行；遵循最小改动原则。
- `focus-style-extra-menu`（theme / package 子项）原本在 `focus-style-menu` 内部被调用，随其一起从右键菜单消失，无需单独处理。
