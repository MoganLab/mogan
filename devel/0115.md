## 任务相关的代码文件
- `3rdparty/tbox/` - tbox 源码目录
- `3rdparty/s7/` - S7 Scheme 源码目录
- `TeXmacs/plugins/goldfish/src/` - goldfish C++ 源码
- `TeXmacs/plugins/goldfish/goldfish/` - goldfish Scheme 库
- `xmake/goldfish.lua` - goldfish 构建配置

## 背景

Goldfish Scheme 的版本号格式为 `x.y.z`，其中 `x` 对应 tbox 的大版本号。
v18.11.4 意味着需要使用 **tbox 1.8.x**。当前 mogan3 中的 tbox 为 v1.7.5，goldfish 为 v17.11.55。

因此本次升级包含两个部分：
1. tbox 从 1.7.5 升级到 1.8.0
2. goldfish 从 17.11.55 升级到 18.11.4

## 升级步骤

### 1. 升级 tbox

使用本地 `~/git/tbox`（v1.8.0）替换 `3rdparty/tbox`：

```bash
rm -rf 3rdparty/tbox
cp -r ~/git/tbox 3rdparty/tbox
```

### 2. 升级 goldfish C++ 源码

从本地 `~/git/goldfish/src/` 复制到 `TeXmacs/plugins/goldfish/src/`：

```bash
cp ~/git/goldfish/src/goldfish.cpp TeXmacs/plugins/goldfish/src/
cp ~/git/goldfish/src/goldfish.hpp TeXmacs/plugins/goldfish/src/
cp ~/git/goldfish/src/goldfish_repl.cpp TeXmacs/plugins/goldfish/src/
```

### 3. 升级 S7 Scheme 源码

从本地 `~/git/goldfish/src/` 复制 s7 相关文件到 `3rdparty/s7/`：

```bash
cp ~/git/goldfish/src/s7.c 3rdparty/s7/
cp ~/git/goldfish/src/s7.h 3rdparty/s7/
cp ~/git/goldfish/src/s7_internal_helpers.h 3rdparty/s7/
cp ~/git/goldfish/src/s7_scheme_base.c 3rdparty/s7/
cp ~/git/goldfish/src/s7_scheme_base.h 3rdparty/s7/
cp ~/git/goldfish/src/s7_scheme_char.c 3rdparty/s7/
cp ~/git/goldfish/src/s7_scheme_char.h 3rdparty/s7/
cp ~/git/goldfish/src/s7_scheme_complex.c 3rdparty/s7/
cp ~/git/goldfish/src/s7_scheme_complex.h 3rdparty/s7/
cp ~/git/goldfish/src/s7_scheme_inexact.c 3rdparty/s7/
cp ~/git/goldfish/src/s7_scheme_inexact.h 3rdparty/s7/
cp ~/git/goldfish/src/s7_scheme_write.c 3rdparty/s7/
cp ~/git/goldfish/src/s7_scheme_write.h 3rdparty/s7/
cp ~/git/goldfish/src/s7_liii_bitwise.c 3rdparty/s7/
cp ~/git/goldfish/src/s7_liii_bitwise.h 3rdparty/s7/
cp ~/git/goldfish/src/s7_liii_string.c 3rdparty/s7/
cp ~/git/goldfish/src/s7_liii_string.h 3rdparty/s7/
cp ~/git/goldfish/src/s7_liii_hash_table.c 3rdparty/s7/
cp ~/git/goldfish/src/s7_liii_hash_table.h 3rdparty/s7/
```

### 4. 更新构建配置 `xmake/goldfish.lua`

新增 `s7_scheme_write.c` 到编译文件列表：

```lua
"$(projectdir)/3rdparty/s7/s7_scheme_write.c",
```

### 5. 升级 goldfish Scheme 库

先清理旧版本 Scheme 文件，再复制新版本：

```bash
rm -rf TeXmacs/plugins/goldfish/goldfish/liii/*
rm -rf TeXmacs/plugins/goldfish/goldfish/scheme/*
rm -rf TeXmacs/plugins/goldfish/goldfish/srfi/*
rm -rf TeXmacs/plugins/goldfish/goldfish/guenchi/*
cp -r ~/git/goldfish/goldfish/* TeXmacs/plugins/goldfish/goldfish/
```

**注意**：mogan3 中以下文件不在 goldfish 仓库中，不会被覆盖，应予以保留：
- `TeXmacs/plugins/goldfish/goldfish/goldfish/repl.scm`
- `TeXmacs/plugins/goldfish/goldfish/texmacs/`
- `TeXmacs/plugins/goldfish/goldfish/tm-goldfish.scm`

## 2026/05/13 升级到 Goldfish Scheme v18.11.4

### What
将 goldfish 从 v17.11.55 升级到 v18.11.4，同步升级 tbox 从 v1.7.5 到 v1.8.0。

### Why
Goldfish Scheme v18.x 基于 tbox 1.8.x，需要使用新版本的 tbox 才能正确构建和运行。

### How
- 不采用 `bin/bump_goldfish` 脚本
- 直接使用本地 `~/git/goldfish` 和 `~/git/tbox` 仓库中的源码
- 手动复制并更新相关文件，同时保留 mogan3 特有的 Scheme 文件

### 实际执行记录

执行了以下命令：

```bash
# 升级 tbox
rm -rf 3rdparty/tbox/*
cp -r ~/git/tbox/* 3rdparty/tbox/

# 升级 goldfish C++ 源码
cp ~/git/goldfish/src/goldfish.cpp TeXmacs/plugins/goldfish/src/
cp ~/git/goldfish/src/goldfish.hpp TeXmacs/plugins/goldfish/src/
cp ~/git/goldfish/src/goldfish_repl.cpp TeXmacs/plugins/goldfish/src/

# 升级 S7 Scheme 源码
for f in s7.c s7.h s7_internal_helpers.h s7_scheme_base.c s7_scheme_base.h s7_scheme_char.c s7_scheme_char.h s7_scheme_complex.c s7_scheme_complex.h s7_scheme_inexact.c s7_scheme_inexact.h s7_scheme_write.c s7_scheme_write.h s7_liii_bitwise.c s7_liii_bitwise.h s7_liii_string.c s7_liii_string.h s7_liii_hash_table.c s7_liii_hash_table.h; do
    cp ~/git/goldfish/src/$f 3rdparty/s7/
done

# 升级 goldfish Scheme 库
rm -rf TeXmacs/plugins/goldfish/goldfish/liii/*
rm -rf TeXmacs/plugins/goldfish/goldfish/scheme/*
rm -rf TeXmacs/plugins/goldfish/goldfish/srfi/*
rm -rf TeXmacs/plugins/goldfish/goldfish/guenchi/*
cp -r ~/git/goldfish/goldfish/guenchi/* TeXmacs/plugins/goldfish/goldfish/guenchi/
cp -r ~/git/goldfish/goldfish/liii/* TeXmacs/plugins/goldfish/goldfish/liii/
cp -r ~/git/goldfish/goldfish/scheme/* TeXmacs/plugins/goldfish/goldfish/scheme/
cp -r ~/git/goldfish/goldfish/srfi/* TeXmacs/plugins/goldfish/goldfish/srfi/

# 构建验证
xmake config --yes
xmake b goldfish
```

构建结果：`build ok`（goldfish 目标编译通过）。
