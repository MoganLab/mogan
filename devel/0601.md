# [0601] 将缩进段落从页面布局菜单移到段落菜单

## 如何测试
1. 打开 Mogan STEM，新建一个空白文档。
2. 确认当前处于默认模式（焦点在文档正文时）。
3. 点击菜单栏 **文档 -> 段落**，应能看到 **缩进段落 (Indent paragraphs)** 选项。
4. 点击 **文档 -> 段落 -> 缩进段落**，文档应应用/取消缩进段落样式。
5. 点击菜单栏 **文档 -> 页面 -> 布局**，确认其中**不再包含**"缩进段落"选项。
6. 反复切换，观察段落缩进状态是否正确变化。

## 2026/05/11
### What
将"缩进段落"(Indent paragraphs) 这一功能入口从 **页面 -> 布局** 菜单中移除，统一迁移到 **文档 -> 段落** 菜单下。

### Why
"缩进段落"属于段落级别的排版设置，放在"页面 -> 布局"中不符合用户的直觉和使用习惯。统一放到"文档 -> 段落"入口下可以让用户更容易找到该功能。

### How
在 `TeXmacs/progs/generic/document-menu.scm` 中：
1. 从 `page-layout-menu` 中移除 `("Indent paragraphs" (toggle-indent-paragraphs))` 项。
2. 在 `document-paragraph-menu` 的 `"Margins"` 子菜单之后， `"Spacing"` 子菜单之前，插入 `("Indent paragraphs" (toggle-indent-paragraphs))` 项。
