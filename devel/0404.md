# [0404] 新增 todoto 交互式待办命令

## 如何测试

### 非确定性测试（文档验证）
```bash
# 编译并运行 Mogan STEM，新建任意风格文档
# 按 \todoto Enter，确认：
# 1. 直接显示 □ + 红色背景，光标定位在内容区（无需输入 false）
# 2. 输入文字后，点击 □ 变 ■，背景变绿色
# 3. 再次点击 ■ 变回 □，背景恢复红色
```

## What

为 Mogan STEM 新增 `\todoto` 命令，提供带 checkbox 的交互式 todo 功能：

1. 在 `std-markup.ts` 中新增 `todoto` 宏定义：
   - 双参数：`state` + `body`
   - `state="true"`：显示 ■ + 绿色背景
   - `state="false"` 或 `state=""`：显示 □ + 红色背景
   - 新增 `render-button` 宏支持点击交互
   - 新增 `button-box-off`（□）、`button-box-on`（■）符号

2. 在 `cpp-wrap.scm` 中新增交互处理函数：
   - `perform-toggle`：状态切换逻辑 `""` → `"true"` → `"false"`
   - `mouse-toggle-button`：鼠标点击事件处理
   - 放在 always-loaded 模块，确保所有风格可用

3. 在 C++ `edit_dynamic.cpp` 的 `activate_hybrid` 中拦截 `todoto`：
   - 直接插入 `(todoto "false" "")` 结构
   - 光标定位到 body 参数（参数 1）
   - 绕过 DRD 和 `make_compound` 的自动参数创建

4. 清理工作：
   - 从 `generic-edit.scm` 移除重复定义
   - 从 `init-research.scm` 懒加载列表中移除相关函数

## Why

原有 `\todo` 命令仅支持静态红色背景，无法标记完成状态。用户需要一种可以交互切换完成状态的 todo 标记，类似 checkbox 的体验。

## How

1. **样式层**：在 `std-markup.ts`（全局加载）定义 `todoto` 宏，用 `action` 包裹 checkbox 符号，绑定 `mouse-toggle-button` 实现点击切换。
2. **脚本层**：在 `cpp-wrap.scm`（`use-modules` 直接加载）定义 `mouse-toggle-button` 和 `perform-toggle`，避免懒加载导致某些风格下函数不可用。
3. **C++ 层**：在 `activate_hybrid` 中检测到 `todoto` 时直接构造 `(todoto "false" "")` 并插入，不依赖 DRD 的 arity 推断，确保所有风格（包括 generic、source、无风格）都能正确插入。

## 注意事项

- 修改了 C++ 代码，必须重新编译
- 样式文件 `.ts` 有缓存，修改后必须复制到 app bundle 并重启
- `todoto` 名称不含连字符，确保命令模式可识别

## 日志输出

终端启动 Mogan STEM 可看到调试日志：
```
[TODOTO] Activating todoto command in style context
```
