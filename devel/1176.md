# 1176 python 插件清理

## 2026-08-07 移除 init-python.scm 中的 menu 引用

### What
- 移除 `init-python.scm` 末尾的 `(when (supports-python?) (import-from (python-menus)))`
- 删除空模块文件 `python-menus.scm`

### Why
`python-menus.scm` 只有模块头（`texmacs-module` + `:use`），没有任何菜单/工具栏定义，属于历史遗留的空壳，import 它没有任何效果。

### How
全库检索确认 `python-menus` 仅被 `init-python.scm` 引用，删除引用后连带删除该空文件。

### 涉及文件
- `TeXmacs/plugins/python/progs/init-python.scm`
- `TeXmacs/plugins/python/progs/python-menus.scm`（删除）
