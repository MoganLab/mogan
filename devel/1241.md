# [1241] 让 scratch url（未命名 buffer）支持自动保存

## 2026/08/24

### What

scratch buffer 加入 autosave 范围，除 Ctrl+S（仍弹另存为）和标签页标题外，
其余行为与普通文档一致。

### Why

scratch buffer 在磁盘上有真实路径（`documents/LiiiSTEM/no_name/no_name_N.tmu`，
见 `src/System/Files/tm_file.cpp` 的 `url_scratch()`），autosave 插件里
「无磁盘路径、保存无意义」的跳过理由已过时（devel/1120）。不自动保存导致
未命名文档的编辑在崩溃/误关后丢失。

### How

- `TeXmacs/plugins/autosave/progs/autosave/plugin.scm`：`autosave-all` /
  `autosave-now` 移除 `(not (url-scratch? name))` 守卫，scratch 走
  `save-buffer-save name (list) "auto"` 原地写 no_name 文件。autosave 不经过
  `save-buffer-check-permissions`（scratch → save-as 弹窗只在该手动保存链路）。
- `TeXmacs/progs/texmacs/texmacs/tm-files.scm` 的 `save-buffer-save-file`：
  对 scratch 跳过 `buffer-notify-recent`（no_name 文件不进 recent 列表）和
  `remember-file-dialog-directory`（不破坏 devel/0912 的 scratch 另存为默认目录约定）。

副作用说明：autosave 成功后 scratch buffer 变为未修改，关闭时不再弹确认框，
no_name 文件保留在磁盘供会话恢复；save-as 时仍按既有逻辑删除旧 scratch 文件。

### 涉及文件

- TeXmacs/plugins/autosave/progs/autosave/plugin.scm
- TeXmacs/progs/texmacs/texmacs/tm-files.scm

### 测试

纯 scheme 改动。GUI 手动验证（用户负责）：新建未命名 buffer，编辑后等
autosave 间隔，确认 no_name .tmu 内容更新、recent 列表无 no_name 条目、
Ctrl+S 仍弹另存为、关闭重开后内容可恢复。
