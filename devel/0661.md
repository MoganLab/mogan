## 5 What

修复设置文本背景色后，行内数学（含下标，如 `a_i`）与相邻文本的背景高亮底部不齐的问题。

1. 将 `concat_box_rep::pre_display` 中背景纵向高度的计算从「按背景色组各自独立计算」改为「整行统一计算」。

## 6 Why

`pre_display` 把同一行内连续相同背景色的子 box 划为一个组，并为每个组独立计算背景的 `y1`/`y2`：
- 文本组（TEXT_BOX）按 "M" 字度量计算，底部较浅；
- 行内数学组（含下标的 concat/side box 等，非 TEXT_BOX）按实际 box 几何计算，底部因下标而更深。

当文本与行内数学之间被无背景的 marker/control box 分隔时，二者被划入不同组，各自独立的高度使同一行内高亮底部参差。将高度计算改为整行统一后，无论是否被分隔，同一行所有背景色组共用一致的纵向高度。

## 7 How

在 `concat_box_rep::pre_display` 中，于分组循环之前先遍历整行所有子 box，计算统一的 `line_y1`/`line_y2`：

```cpp
SI line_y1= MAX_SI;
SI line_y2= -MAX_SI;
for (int k= 0; k < n; k++) {
  if (bs[k]->get_type () == TEXT_BOX) {
    font f= bs[k]->get_leaf_font ();
    if (!is_nil (f)) {
      metric ex_m;
      f->get_extents ("M", ex_m);
      line_y1= min (line_y1, sy (k) + ex_m->y1 - 10 * pixel);
      line_y2= max (line_y2, sy (k) + ex_m->y2 + 10 * pixel);
    }
  }
  else {
    line_y1= min (line_y1, sy1 (k));
    line_y2= max (line_y2, sy2 (k));
  }
}
```

随后每个背景色组直接复用该统一高度：

```cpp
SI bg_y1= line_y1;
SI bg_y2= line_y2;
```

TEXT_BOX 的高度计算方式（"M" 字度量）与原实现保持一致，仅将其计算范围从单个组扩展到整行；非 TEXT_BOX（行内数学等）的实际几何 `sy1(k)`/`sy2(k)` 参与整行统一，使含下标的数学背景与相邻文本背景底部对齐。
