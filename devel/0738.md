# [0738] 修复 WASM 下按住 cmd 切换窗口后按键卡死、文字输入失效

## 1 相关文档
- [dddd.md](dddd.md) - 任务文档模板
- [0836.md](0836.md) - 修复外部拖拽选经过绘图区时的误激活

## 2 任务相关的代码文件
- `src/Plugins/ImGui/im_tm_widget.cpp` — 在 IME 桥接（`im_install_ime_listeners`）中，把页面级 `window` 的 blur/focus 镜像成 canvas 的合成 blur/focus，使 contrib GLFW 端口在失焦时执行 `resetAllKeys()` 释放卡住的修饰键

## 3 如何测试

### 3.1 确定性测试（单元测试）
```
xmake b stem
xmake r stem
```
（该改动位于 `#ifdef __EMSCRIPTEN__`，仅 WASM 构建生效，桌面构建不涉及。）

### 3.2 非确定性测试（交互验证）
1. 在 WASM 构建中，按住 `cmd` 的同时用鼠标点击浏览器外的其他系统窗口（或切换标签页），再切回画布窗口；
2. 切回后 `cmd` 不应停留在“按下”状态，普通字母键应能正常输入文字（修复前 `glfw_char_callback` 会因 `glfwGetKey(SUPER)==PRESS` 持续提前返回，文字输入彻底失效）；
3. 用 `cmd+Tab` 等不经过点击 canvas 的方式切回窗口，键盘焦点也应恢复（修复前仅 canvas `mousedown` 才会重建焦点桥接）。

## 4 What
1. 在 IME 桥接里新增 `window` 的 `blur`/`focus` 监听：失焦时在 canvas 上派发合成 `blur`，获焦时调用既有的 `engageIme`（重新聚焦 textarea 并在 canvas 上派发合成 `focus`）。

## 5 Why
contrib GLFW 端口（pongasoft/emscripten-glfw3）在 `Window::onFocusChange(false)` 中调用 `Keyboard::resetAllKeys()`，释放所有按键状态——这正是丢失 `keyup` 的修饰键被清理的唯一途径。但该回调挂在 canvas（`#main-canvas`）的 `EMSCRIPTEN_EVENT_BLUR` 上，而 DOM 的 `blur` **不冒泡**。

为了接住中文输入法（IME composition），Mogan 用一个隐藏的真实 `<textarea>` 持有 DOM 焦点，canvas 只靠 `engageIme()` 派发的**合成** `focus` 事件维持端口的 `fFocused`。因此 canvas 永远收不到自然的 `blur`：即使整个页面失焦（按住 cmd 点击其他系统窗口），`onFocusChange(false)` → `resetAllKeys()` 也从不执行。

于是页面失焦期间按下、又因失焦而丢失 `keyup` 的 `cmd` 永久卡在端口的 `fKeyStates` 里：`computeModifierBits()` 恒带 `GLFW_MOD_SUPER`，每个按键事件都带 Super 位——`im_from_key_event` 把字母当成 `M-x` 快捷键分发，且 `glfw_char_callback` 因 `glfwGetKey(GLFW_KEY_*_SUPER)==PRESS` 持续提前返回，**文字输入彻底失效**。这同时解释了“cmd 卡住”与“键盘无响应”两个现象（同源）。

## 6 How
真实焦点在 textarea、不在 canvas，但合成事件（`canvas.dispatchEvent(new FocusEvent(...))`）可以直达端口挂在 canvas 上的监听（该监听忽略事件数据，只凭事件触发）。既有代码已用合成 `focus` 维持 `fFocused`，这里补上对称的合成 `blur`，并复用同一桥接：

- `window` `blur` → `canvas` 合成 `blur` → 端口 `onFocusChange(false)` → `resetAllKeys()` 释放卡住的 cmd（并对每个被释放的按键经 `glfwSetKeyCallback` 回灌 `GLFW_RELEASE`，同步清理 ImGui 侧按键状态；同时触发 `glfw_window_focus_callback(focused=0)` → 编辑器 `handle_keyboard_focus(false)` 挂起，与“窗口失焦”语义一致）。
- `window` `focus` → `engageIme()` → canvas 合成 `focus` → `onFocusChange(true)` 恢复 `fFocused`，编辑器 `got_focus` 恢复；覆盖 `cmd+Tab` 等“切回时未点击 canvas”的情形（原先只有 canvas `mousedown` 才会重建焦点）。

`resetAllKeys` 只对确实处于按下态的按键回灌 release，故无副作用；`window` 级 blur/focus 仅在页面真正失焦/获焦时触发，不影响页面内常规的焦点变化。
