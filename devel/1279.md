## 3 如何测试

### 3.1 单元测试
无。`set_type` 开头的 `format_exists` 需调用 scheme（`format?`），未引导 scheme 的
C++ 单测进程在构造 widget 时即崩溃（实测 SIGSEGV）；`perform_dialog` 的
QFileDialog::exec 亦无法在 headless 下运行。符合仓库「GUI 专属路径不走 C++ 单测」
的策略（同 font-selector 的处理），故不设单测。

### 3.2 集成测试
无。`MOGAN_TEST_CHOOSE_FILE` 钩子会整体绕过对话框，集成测试覆盖不到过滤器、
默认选中与文件名规范行为。

### 3.3 端到端测试
- **手动测试**：
  1. 打开 `.ts` 样式文件（如 `TeXmacs/plugins/python/packages/code/python.ts`），
     Ctrl+S 保存：仍写回原 `.ts` 文件，格式不变
  2. 同一文件另存为（Save as / `std S`）：对话框建议文件名为 `*.stem`，文件类型
     下拉**只有 `STEM files (*.stem)` 和 `TS files (*.ts)` 两项**，默认选中
     `STEM files (*.stem)`；直接点保存得到 `*.stem`（S-expression 格式）
  3. 另存为对话框中切到 `TS files (*.ts)` 再保存：得到 `*.ts`
  4. 打开 `.tm` 文档另存为：建议文件名为 `*.tmu`，文件类型下拉只有
     `TMU files (*.tmu)` 和 `TM files (*.tm)`，默认选中 TMU；直接点保存得到
     `*.tmu`，切到 TM 则得到 `*.tm`
  5. 另存为时输入无后缀文件名：按所选过滤器补后缀（样式场景 `.stem`/`.ts`，
     tm 场景 `.tmu`/`.tm`）
  6. `.tmu` 文件与草稿另存为：默认 `TMU files (*.tmu)`，输入无后缀名补 `.tmu`
     （草稿场景为既有缺陷的修复）
  7. 中文界面重复上述步骤，行为一致（默认后缀从过滤器括号内容解析，不依赖
     过滤器英文文本）

## 5 What

1. `.ts`/`.stem` 样式文件另存为：格式下拉仅提供 `STEM files (*.stem)` 与
   `TS files (*.ts)` 两项，默认 `.stem`；建议文件名同步改为 `.stem` 后缀
2. `.tm` 文档另存为：默认 `.tmu`（过滤器保持 tmu/tm 两项），建议文件名同步
   改为 `.tmu` 后缀；直接保存即得 `.tmu`，切到 TM 过滤器则存 `.tm`
3. 两种场景下保存确认后的最终文件名统一规范为所选过滤器的后缀（只改 base
   名也能存成默认格式）
4. `.tmu` 过滤器标签由「STEM files」改名「TMU files」（1131 引入 `.stem` 后，
   STEM 之名归属 `.stem`）；`STEM files (*.stem)` 用于样式另存场景，名实相符
5. 其余另存为情形（`.tmu`/草稿）保持 TMU/TM 过滤器列表与首项默认；初始默认
   后缀设为 `tmu`，修复草稿另存输入无后缀名不补后缀
6. 保存确认后的默认后缀改为从所选过滤器括号内容解析（首个 `*.xxx`），替换
   原先对过滤器英文文本的 `contains ("TMU files")` 硬编码匹配

## 6 Why

- 1131 确立 `.stem` 作为 `.ts` 的继任格式（S-expression 便于 diff/merge，用于
  渐进替换 `.ts`）。样式文件编辑者另存时应被引导到 `.stem`，同时保留 `.ts`
  以便覆盖「就要存回 TeXmacs 专有格式」的场景，故两项之外不再提供其他格式
- `.tmu` 之于 `.tm` 同理：`.tm` 是 TeXmacs 专有文档格式，`.tmu` 是其继任格式，
  另存为默认引导到 `.tmu`，保留 `.tm` 作为兼容选项
- 普通「保存」路径不变，仍写回原文件，避免日常小改动被迫换格式
- 1131 之前 `.tmu` 借用「STEM files」标签，另存时默认格式显示为 STEM files，
  用户误以为存出来是 `.stem`；改名后标签与实际格式一致

## 7 How

- 过滤器与建议名在 `perform_dialog` 里按建议文件名后缀分流（`norm_suffix`/
  `style_save_as`）：`.ts`/`.stem` 走 stem/ts 成对过滤器，`.tm` 保持 tmu/tm
  基础列表；建议名在计算对话框初始路径前完成 `.ts`→`.stem`、`.tm`→`.tmu`
  改写，弹窗即可见默认目标
- 后缀与过滤器的匹配采用完整 token（`*.ts` 须后跟 `)` 或空格），避免 `.tm`
  误配 `*.tmu`；保存确认后的默认后缀从过滤器括号内容解析，与标签翻译解耦
- 最终文件名规范仅作用于继任格式另存场景：先去掉最后一个 `/` 后的旧后缀再接
  所选过滤器的后缀；其余场景沿用既有补后缀逻辑，不改变其行为
- WASM（ImGui）侧另存为是同步保存+浏览器下载，无格式下拉框，不在本次范围
