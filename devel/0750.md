# [2030] ImGui 自动滚动：光标离屏时居中而非贴顶

ImGui 前端的画布自动滚动逻辑与 Qt（及 WASM，二者共用同一份 `im_simple_widget.cpp`）
不一致：当光标因编辑操作离开显示区域（方向键下移到屏外行、插入块体把光标顶出
视口、鼠标点击显示不全的最后一行）时，ImGui 会把画布一直滚到「光标贴在显示区
最顶端」的状态（≈ 整屏跳跃）；而 Qt 只滚动一部分（光标落在视口正中，≈ 半屏跳跃），
既能看到光标又不会太远。回车进新行的滚动原本就与 Qt 一致（它走的滚动量小、视觉
差异不明显）。本任务把 ImGui 的光标离屏滚动改成与 Qt 一致的「居中」。

## 1 相关文档

- [edit_interface.cpp](../src/Edit/Interface/edit_interface.cpp) - `cursor_visible` /
  `make_cursor_visible` / `scroll_to`：所有前端共用的光标可见性逻辑，最终都调
  `scroll_to (cu->ox, cu->oy)`。
- [qt_simple_widget.cpp](../src/Plugins/Qt/qt_simple_widget.cpp) - Qt 的
  `SLOT_SCROLL_POSITION`：`origin = (x,y) - surface/2`，即把传入点当作视口中心。
- [QTMScrollView.hpp](../src/Plugins/Qt/QTMScrollView.hpp) - Qt 的
  `SLOT_VISIBLE_PART = [origin, origin+size]`，配合上面的半尺寸偏移，光标落在中心。

## 2 任务相关的代码文件

- `src/Plugins/ImGui/im_simple_widget.cpp` - `SLOT_SCROLL_POSITION` 由「上对齐」改为
  「居中」（`scroll_y = p.x2 + canvas_h/2`）；新增 `scroll_by()` 供增量滚动专用。
- `src/Plugins/ImGui/im_simple_widget.hpp` - 声明 `scroll_by (SI dx, SI dy)`；更新
  `recenter` 注释说明 editor 绝对定位 vs 增量滚动两条通路。
- `src/Plugins/ImGui/im_tm_widget.cpp` - 滚轮（`glfw_scroll_callback`）与拖选边缘
  自动滚动改走 `scroll_by`，不再发 `SLOT_SCROLL_POSITION`（否则每帧叠加半个画布）。

对照 Qt 版逐项验证光标离屏后的滚动量：

- 方向键下移：光标越过视口下沿 → ImGui 应只滚到「光标大致在视口中段」，而非贴到顶端。
- 插入块体（如 section/方程）：光标被顶出视口 → 同上，居中而非贴顶。
- 鼠标点击显示不全的最后一行：光标进入该行 → 居中显示。
- 文档顶部/底部附近：居中不可行时，钳位到贴顶/贴底（与 Qt 一致，不超出文档范围）。
- 回车进新行：仍与 Qt 一致（原本就一致，确认未被回归）。
- 滚轮 / 拖动选中边缘自动滚动：增量滚动行为不变（不引入半屏漂移）。

## 5 What

1. **`SLOT_SCROLL_POSITION` 改为居中语义**：`scroll_y = p.x2 + (canvas_h >> 1)`。
   editor 的 `scroll_to(x,y)` 下达的点是「希望居于视口中央」的点（与 Qt 一致），
   存储成视口上沿后由 `recenter` 钳位。
2. **新增 `scroll_by(dx, dy)`**：增量滚动（滚轮/拖选）直接累加到 `scroll_y`（上沿），
   不经过居中换算。
3. **滚轮 / 拖选改走 `scroll_by`**：避免增量滚动经过 `SLOT_SCROLL_POSITION` 时每帧
   多加半个画布的偏移。

## 6 Why

- **根因是前后端对 `scroll_to` 语义的理解不一致**：`edit_interface.cpp` 的
  `cursor_visible`/`make_cursor_visible` 是所有前端共用代码，它调
  `scroll_to (cu->ox, cu->oy)` 时，**默认该点会落到视口中央**（这是它最初为 Qt 写的
  契约）。Qt 的 `SLOT_SCROLL_POSITION` 在 `setOrigin` 前 `-= surface/2`
  （注释 "adjust because child is centered"）正好实现「居中」；而 ImGui 旧的
  `scroll_y = p.x2` 把该点直接当成视口**上沿**，于是光标被顶到最上沿、整屏跳跃。
- **居中而非贴顶**：Qt 的「居中」对应用户描述的「滚动一部分、不会太远」（半屏 vs
  ImGui 旧的全屏跳跃）。改 ImGui 对齐 Qt 即可。
- **增量滚动必须绕开居中换算**：滚轮/拖选是「读当前上沿 + delta → 写回」。若它们也走
  `SLOT_SCROLL_POSITION`（现在会 `+canvas_h/2`），每次都会叠加半个画布，光标随滚动
  飞速漂移。故单独走 `scroll_by`，保持 get/set 对称（都是上沿）。
- **`get_scroll_position` 仍返回上沿**：弹出框定位（completion/text/image popup）等依赖
  「上沿」语义的调用方不受影响；这与 Qt 返回 `origin`（上沿）而非传入的中心点同构。

## 7 How

- **坐标推导**：ImGui 的 `SLOT_VISIBLE_PART` 返回 `[scroll_y - canvas_h, scroll_y]`
  （`scroll_y` 为上沿 `vy2`）。旧 `scroll_y = p.x2` 使 `vy2 = 光标` → 光标在上沿。
  要居中只需把可见窗口上移 `canvas_h/2`：`scroll_y = p.x2 + canvas_h/2`，则可见区变为
  `[光标 - canvas_h/2, 光标 + canvas_h/2]`，光标落正中。`recenter` 的钳位范围
  `[−(doc_h−canvas_h), 0]` 天然处理文档顶/底边界（贴顶/贴底时无法居中）。
- **自洽性**：`scroll_y` 同时被渲染（`set_origin(-sx,-sy)`）、鼠标分发（`sy + scroll_y`）、
  `SLOT_VISIBLE_PART` 三处使用；`+canvas_h/2` 后三者同步偏移，光标从上沿移到正中，
  鼠标坐标与渲染仍一致。
- **半尺寸用 `canvas_h >> 1`**：与项目惯用的 SI 位运算风格一致；`canvas_h` 恒正，右移
  安全。
