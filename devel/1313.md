## 2 任务相关的代码文件
- `src/Plugins/Qt/qml/atoms/Toggle.qml` - `Toggle` 组件支持可选 `tooltip` 属性，渲染问号图标与悬停气泡
- `src/Plugins/Qt/qml/ExportPdf.qml` - 导出 PDF 对话框传递 `tooltip` 属性，去除内容列裁剪避免提示框被切
- `src/Plugins/Qt/QTMQmlDialog.cpp` - `print_field_to_qml` 支持解析表单第 4 个子项作为 `tooltip` 透传给 QML
- `TeXmacs/progs/texmacs/texmacs/tm-print.scm` - `export-as-pdf` 表单新增 `expand-slides` 选项（"Expand foldable environments in single slide"），以首选项为默认值，并将用户选择作为参数传递至打印流程
- `TeXmacs/progs/dynamic/fold-edit.scm` - `dynamic-make-slides` 改为由入参 `expand?` 驱动，不再在导出中直接读取首选项（首选项仅用于决定弹窗默认值）
- `TeXmacs/progs/texmacs/menus/preferences-widgets.scm` - 首选项中的选项名称同步更新为 "Expand foldable environments in single slide"
- `TeXmacs/progs/texmacs/menus/preferences-menu.scm` - 偏好菜单中的选项名称同步更新
- `TeXmacs/plugins/lang/dic/en_US/zh_CN.scm` - 新增与更新中英文词典翻译
- `tests/Plugins/Qt/qml_load_test.cpp` - `test_export_pdf_loads` 覆盖新增选项、初始值绑定、切换响应与悬浮提示

## 3 如何测试

### 3.1 自动化测试
运行以下命令构建并执行 QML 单元测试：
```bash
xmake b qml_load_test && xmake r qml_load_test test_export_pdf_loads
```
测试用例覆盖：
1. `ExportPdf` 对话框正常加载包含 `embed`、`expand-slides` 和 `path` 的表单；
2. `expand-slides` 初值正确绑定；
3. `expand-slides` 切换状态响应；
4. `tooltip` 属性正确透传给 `Toggle` 原子；
5. 问号图标与悬停提示气泡结构与显隐行为。

### 3.2 手动测试

#### 测试场景 1：首选项默认值与导出弹窗联动
1. 打开 Mogan STEM：`xmake r stem`；
2. 打开 `首选项 -> 转换 -> PDF`；
3. 勾选 `在单页幻灯片中展开折叠环境`（默认开启）；
4. 打开 `文件 -> 导出为PDF...`；
5. **预期结果**：弹出对话框中包含 `在单页幻灯片中展开折叠环境` 开关，且当前为开启状态；
6. 关闭弹窗，在 `首选项 -> 转换 -> PDF` 中取消勾选该选项；
7. 再次打开 `文件 -> 导出为PDF...`；
8. **预期结果**：弹出对话框中的 `在单页幻灯片中展开折叠环境` 开关默认为关闭状态。

#### 测试场景 2：问号图标悬停提示
1. 打开 `文件 -> 导出为PDF...` 弹窗；
2. 可以看到 `在单页幻灯片中展开折叠环境` 文字右侧有一个小圆圈问号 `?` 图标；
3. 鼠标移动至该问号图标上方悬浮；
4. **预期结果**：弹出提示气泡，显示说明文案：`开启状态下，可折叠对象在单页幻灯片中直接展开。关闭状态下，可折叠对象在多页幻灯片中依次展开。`；
5. 鼠标离开问号图标后，提示气泡自动隐藏。

#### 测试场景 3：幻灯片导出验证
1. 打开包含折叠环境（例如问题与答案）的 Beamer 幻灯片；
2. 点击 `文件 -> 导出为PDF...`，保持 `在单页幻灯片中展开折叠环境` 开启，导出 PDF；
3. **预期结果**：导出的 PDF 中，可折叠对象在单页幻灯片中直接展开；
4. 再次导出，将弹窗中的开关关闭，导出 PDF；
5. **预期结果**：导出的 PDF 中，可折叠对象在多页幻灯片中依次分步展开。
