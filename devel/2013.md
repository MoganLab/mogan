## 3 如何测试

```bash
./bin/test_only 2013
```

被测的路径函数依赖 `get-texmacs-home-path`（运行时），返回绝对路径，故用集成测试验证拼接的相对结构，而非单元测试断言确切字符串。共 9 项断言，预期 `9 correct, 0 failed`。

## 4 What

把 `telemetry-utils.scm` 里 4 处用 `string-append` 拼接 OS 文件路径的代码，改造成使用 `(liii path)`。范围仅限这一个文件。

## 5 Why

- **正确性**：手写 `(string-append path ".tmp")` 拼 tmp 文件名不严谨；`string-append dir "/" name` 在 Windows 上分隔符错误。`path-join` / `path-with-suffix` 跨平台且语义明确。
- **一致性**：`telemetry-utils.scm` 已用了一半 liii-path（`path-exists?`/`path-parent`/`path-unlink`/`path-rename`），却仍用字符串拼接构造路径，混用两套写法。统一收敛到 `(liii path)`。

## 6 How

返回值保持字符串类型（`path->string` 收尾），调用方零改动、零风险。

| 函数 | 改造前 | 改造后 |
|---|---|---|
| `telemetry-dir` | `(string-append home "/system/telemetry")` | `(path->string (path-join home "system" "telemetry"))` |
| `telemetry-main-dir` | `(string-append dir "/main")` | `(path->string (path-join dir "main"))` |
| `telemetry-meta-path` | `(string-append dir "/main-telemetry.json")` | `(path->string (path-join dir "main-telemetry.json"))` |
| `telemetry-full-path` | `(string-append dir "/" filename)` | `(path->string (path-join dir filename))` |
| `telemetry-write-meta` tmp 派生 | `(string-append path ".tmp")` | `(path->string (path-with-suffix path ".json.tmp"))` |

`path-with-suffix` 对 `main-telemetry.json`（suffix=`.json`）应用 `.json.tmp` 得到 `main-telemetry.json.tmp`，与原 `string-append path ".tmp"` 结果一致（已用 goldfish 解释器实测验证）。
