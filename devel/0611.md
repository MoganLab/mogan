## 5 What

将 TikZ 插件从依赖 Python/tmpy 的旧架构迁移到使用 Goldfish Scheme 的新架构，使其能够在 Mogan 中成功加载和运行。

1. 重写 `init-tikz.scm`，使用 `define-library` 和 Goldfish 启动器
2. 新增 `binary/tikz.scm`，用于查找系统中的 LaTeX 编译器（pdflatex/xelatex/lualatex）
3. 新增 `goldfish/tm-tikz.scm`，用 Goldfish Scheme 实现 TikZ 代码的编译和图像返回
4. 新增 `data/tikz.scm`，提供 TikZ 源码格式支持
5. 新增 `code/tikz-lang.scm`，提供基础语法高亮支持
6. 新增 `progs/tikz-test.scm`，提供单元测试
7. 更新 `xmake.lua`，使其能够扫描插件目录中的 scheme 测试

## 6 Why

Mogan 的脚本语言是 Goldfish Scheme，不再依赖 Python 和 tmpy。旧的 TikZ 插件因调用 `python-command` 和引用不存在的 `tm_tikz.py` 而无法加载。需要按照 gnuplot 插件的重写模式，将 TikZ 插件也迁移到 Goldfish Scheme。

## 7 How

参考 `gnuplot` 插件的实现方式：

1. `init-tikz.scm` 使用 `define-library` 定义 `(session tikz)` 库，在 `init-tikz` 函数中调用 `plugin-configure`
2. `tm-tikz.scm` 作为 Goldfish 脚本，读取用户输入的 TikZ 代码，将其包装为最小 LaTeX 文档，调用 pdflatex 编译生成 PDF，然后通过 `flush-file` 将 PDF 图像返回给 Mogan
3. 使用 `standalone` documentclass 自动裁剪内容，避免额外的页面空白
4. 测试覆盖 binary 检测和 language parser feature
