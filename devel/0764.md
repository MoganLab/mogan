# [0764] 实现 Tree 到 LoroDoc 的转换
## What
定义了新的数据类型，loro_ir_node。用于 Rust/C++ 交换
```text
        C++                   Rust
───────────────────┬────────────────────────
tree               │
label              │
generic            │
...                |
loro_ir_node       |
───────────────────┼────────────────────────
               IR Binary
───────────────────┼────────────────────────
                   │ LoroDoc
                   │ Snapshot
                   │ CRDT
```

实现了两个关键的函数
- string tree_to_loro(tree t)
- tree loro_to_tree(string snapshot)

其中 snapshot 为 Rust 中 Loro 库导出，是将来协同编辑时需要传输的数据。

C++ 中 moebius tree 到 snapshot 的路径如下：
```text
                 Mogan (C++)
────────────────────────────────────────────────────────

buffer
   │
   ▼
Moebius Tree
   │
   │ tree_to_loro_ir()
   ▼
loro_ir_node
   │
   │ loro_ir_encode()      (C++ Writer)
   ▼
Binary IR
   │
════════════════ C ABI ════════════════
   │
mogan_loro_encode() / mogan_loro_decode()
   │
────────────────────────────────────────────────────────
                    Rust

Binary IR
   │
   │ Reader::node()
   ▼
IrNode
   │
   │ doc_from_ir()
   ▼
LoroDoc
   │
   ▼
LoroTree
   │
   ▼
LoroMap / LoroText
   │
   ▼
Snapshot
```
