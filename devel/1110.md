# [1110] 升级 pdfhummus 到 v4.9.0

## 1 相关文档
- [dddd.md](dddd.md) - 任务文档模板

## 2 任务相关的代码文件
- `3rdparty/pdfhummus/**` —— pdfhummus 源码目录，整体替换为 PDF-Writer v4.9.0
- `xmake.lua` —— `liii-pdfhummus` 包定义与版本常量
- `xmake/vars.lua` —— 依赖版本汇总

## 3 如何测试

### 3.1 确定性测试（单元测试）
```bash
# 强制重新构建 pdfhummus 包
xmake require -y --force liii-pdfhummus
```

### 3.2 非确定性测试（文档验证）
```bash
# 重新配置并编译主项目
xmake f -y
xmake b stem

# 启动后验证 PDF 相关功能（如导出 PDF）仍可正常工作
xmake r stem
```

## 4 如何提交

提交前执行以下最少步骤：

```bash
gf fmt --changed-since=main
```

## 5 What
1. 将 `3rdparty/pdfhummus` 整体替换为 PDF-Writer v4.9.0 的源码（从本地克隆 `/home/da/git/PDF-Writer` 复制，节省下载时间）。
2. 将 `PDFHUMMUS_VERSION` 从 `4.6.2` 更新为 `4.9.0`。
3. 同步更新 `xmake/vars.lua` 中的版本常量。

## 6 Why
PDF-Writer v4.9.0 包含了上游的若干 bug 修复与改进（如加密、流处理等），
升级到该版本可以让 Mogan 的 PDF 导出/解析功能跟上上游进度。
本地已存在 `/home/da/git/PDF-Writer` 克隆，复用该目录可以显著节省下载与解压时间。

## 7 How
1. 在本地克隆中检出 `v4.9.0` 标签：
   ```bash
   git -C /home/da/git/PDF-Writer checkout v4.9.0
   ```
2. 将本地克隆中的 `PDFWriter` 目录与顶层 `xmake.lua`、`CMakeLists.txt`、`Config.cmake.in`、
   `.gitattributes`、`.gitignore`、`LICENSE`、`LicenseTemplate.txt`、`readme.md`、`cmake/`
   复制到 `3rdparty/pdfhummus/`，覆盖旧版本（不复制捆绑的 `FreeType`、`LibAesgm` 等子模块，
   因为 xmake 使用外部包）。
3. 修改 `xmake.lua` 中的 `PDFHUMMUS_VERSION`。
4. 同步修改 `xmake/vars.lua` 中的 `PDFHUMMUS_VERSION`。
5. 运行 `xmake require -y --force liii-pdfhummus` 或 `xmake f -y` 验证包能正常构建。
