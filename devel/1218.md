# 1218 equations / polynomial 迁移到 moebius

## What

将 `src/Graphics/Types/equations.{hpp,cpp}`、`src/Graphics/Mathematics/polynomial.hpp`
与 `src/Kernel/Types/tab.{hpp,cpp}` 迁移到 `moebius/Kernel/Types/`，
`src/Kernel/Types/space.{hpp,cpp}` 迁移到 `moebius/Kernel/Types/`，
`src/Kernel/Abstractions/player.{hpp,cpp}` 迁移到 `moebius/Kernel/Abstractions/`，
`src/Graphics/Handwriting/poly_line.{hpp,cpp}` 迁移到 `moebius/Kernel/Types/`，
`src/Graphics/Handwriting/` 其余文件（`handwriting.hpp`、
`learn_handwriting.cpp`、`recognize_handwriting.cpp`、`smoothen.cpp`）迁移到
`moebius/Graphics/Handwriting/`。`src/Graphics/Handwriting/`、
`src/Graphics/Mathematics/`、`src/Kernel/` 目录随之清空删除。
搜索过 `tests/`、`moebius/tests/`、`TeXmacs/`，这批文件没有对应的单元测试，无需迁移测试。

## Why

这三份文件只依赖 moebius/lolly 已有的基础类型（`point`、`array`、`vector`、
`tree`、`tm_new_array`、`ASSERT`），不依赖 src 侧任何代码，属于纯数学工具，
应归入 moebius 基础库。迁移后 `src/Graphics/Types/curve.cpp` 等使用方通过
libmoebius 的公共 include 目录继续以 `#include "equations.hpp"` /
`#include "polynomial.hpp"` 引用，无需改动调用方。

## How

- `git mv` 三份文件到 `moebius/Kernel/Types/`，文件内容零改动：
  - `equations.hpp`：依赖 `point.hpp`（moebius 已有）
  - `equations.cpp`：依赖 `math_util.hpp`、`point.hpp`（moebius 已有）、
    `ASSERT`（lolly `basic.hpp`）
  - `polynomial.hpp`：依赖 `vector.hpp → operators.hpp → math_tree.hpp`
    （moebius 已有，提供 `tree`/`as_math_string`/`add/mul/pow`/`moebius::RSUB`）
- moebius 的 xmake 已按 `Kernel/Types/**.cpp` 通配收集源文件，`.cpp` 自动
  纳入构建，无需改 `xmake.lua`
- `src/Graphics/Mathematics/` 目录随之清空删除

## 涉及文件

- `src/Graphics/Types/equations.hpp` → `moebius/Kernel/Types/equations.hpp`
- `src/Graphics/Types/equations.cpp` → `moebius/Kernel/Types/equations.cpp`

- `src/Kernel/Types/tab.cpp` → `moebius/Kernel/Types/tab.cpp`

- `src/Kernel/Types/space.hpp` → `moebius/Kernel/Types/space.hpp`

  `src/Kernel/Types`、`src/Kernel/Abstractions` include 目录项。
  调用方 `src/Graphics/Gui/widget.hpp` 经 libmoebius 公共 include 目录
  继续以 `#include "handwriting.hpp"` 引用，无需改动。
