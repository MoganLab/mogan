# 1144 tm-define 性能基准

## 背景

`tm-define` 展开后经 `(varlet (rootlet) ...)`（`TeXmacs/progs/kernel/texmacs/tm-define.scm`）
把函数放进 rootlet。rootlet 是哈希表，S7 无法为其缓存查找位置，每次调用
都走哈希查找；`define` / `define-public` 把函数放进模块 let 环境，S7 用
槽位向量访问，开销低得多。

## What

新增 `TeXmacs/tests/1144.scm`，用 fib 30 递归调用对比四种定义方式：

- let 内局部 `define`（下限参照）
- 模块顶层 `define`
- `define-public`（= define + export）
- `tm-define`

## 实测结果（Linux，release 构建）

| 定义方式 | 耗时 |
|---|---|
| local define | 19 ms |
| top-level define | 20 ms |
| define-public | 19 ms |
| tm-define | 210 ms |

`tm-define` 约慢 10 倍；`define-public` 与 `define` 无差别。
