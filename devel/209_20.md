# [209_20] 添加 FISH 语言语法高亮

## 如何测试

1. 选择菜单插入-程序-代码块/行内代码，选择`FISH`
2. 输入 FISH 代码，检查关键字、字符串、注释、运算符和常见内建函数高亮
``` FISH
; 定义一个函数：计算数组的平均值
define compute_average(arr)
    local sum = 0.0
    local i = 1
    loop while i <= list.size(arr)
        sum = sum + arr(i)
        i = i + 1
    endloop
    return sum / list.size(arr)
end

; 主程序
define main
    local data = list.create
    list.append(data, 10)
    list.append(data, 20)
    list.append(data, 30)

    local avg = compute_average(data)
    io.out("Average value = " + string.build(avg))

    ; 条件判断
    if avg > 15 then
        io.out("Average is greater than 15")
    else
        io.out("Average is 15 or less")
    endif

    ; 使用 math 内建函数
    local x = -3.5
    local y = math.abs(x)
    io.out("Absolute value = " + string.build(y))

    ; command 块（轻量示例）
    command
        model new
        history list
    endcommand
end
```
3. 打开 `TeXmacs/tests/tmu/209_20.tmu` 查看回归样例
