## 5 What
把 `TeXmacs/progs/database` 纳入现有 Scheme 格式化路径，并对 database 相关文件执行一次统一格式化；同时同步整理一个被同一轮 formatter 命中的键盘 Scheme 文件。

1. 在 `goldformat-path.scm` 中新增 `TeXmacs/progs/database`
2. 对 database 目录下 bib、db、title 相关 Scheme 文件执行批量 format
3. 对 `prefix-kbd.scm` 做同轮样式整理
4. 保持任务范围为“代码样式整理”，不引入预期功能变更

## 6 Why
此前 formatter 路径未覆盖 `TeXmacs/progs/database`，导致数据库和书目管理相关 Scheme 文件的缩进、换行、括号闭合注释风格与仓库其他目录不一致。

把 database 目录纳入统一格式化范围后，可以：

1. 降低后续功能改动时的样式噪音
2. 让 database 相关模块与仓库现有 Scheme 代码保持一致风格
3. 避免该目录继续长期处于“未被 formatter 管理”的状态

`prefix-kbd.scm` 虽不属于 database 目录，但本次暂存改动里它同样体现为纯格式化，因此在任务文档中一并记录，便于后续 review 时理解变更边界。

## 7 How
实现方式与前一批格式化任务一致：

1. 更新 `tools/format/liii/goldformat-path.scm` 的 Scheme 目录列表，把 `TeXmacs/progs/database` 加进去
2. 基于现有格式化工具对 database 目录下命中的 Scheme 文件批量执行 format
3. 对同轮改写的 `prefix-kbd.scm` 保持相同风格整理
4. 产出 diff 时重点约束为样式变化，包括：
   - 多行表达式重新缩进
   - 括号位置与闭合注释整理
   - 长行拆分
   - 少量注释空格和布局统一

本任务不修改算法、控制流或模块接口；如果后续 review 发现行为差异，应按 formatter 误改另行处理，而不是视为本任务目标的一部分。
