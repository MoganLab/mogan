# [1114] 移除 `pretty-time`

## 1 相关文档

- 无

## 2 任务相关的代码文件

- `src/System/Language/tm_locale.hpp` — 已删除
- `src/System/Language/tm_locale.cpp` — 已删除
- `src/Plugins/Qt/qt_utilities.hpp` — 删除 `qt_pretty_time` 声明
- `src/Plugins/Qt/qt_utilities.cpp` — 删除 `qt_pretty_time` 实现
- `src/Scheme/Glue/glue_basic.lua` — 删除 `pretty-time` glue 条目
- `src/Scheme/L5/init_glue_l5.cpp` — 删除 `tm_locale.hpp` include
- `TeXmacs/progs/client/client-chat.scm` — 替换 `pretty-time` 调用
- `TeXmacs/progs/client/client-tmfs.scm` — 替换两处 `pretty-time` 调用

## 3 如何测试

```bash
xmake b stem
xmake b qt_utilities_test && xmake r qt_utilities_test
```

## 4 What

移除 `pretty-time` 相关全部代码：

- C++ 函数 `pretty_time`（`tm_locale.hpp/cpp`）
- C++ 函数 `qt_pretty_time`（`qt_utilities.hpp/cpp`）
- Scheme glue `pretty-time`（`glue_basic.lua`）
- Scheme 调用方（`client-chat.scm`、`client-tmfs.scm`）

## 5 Why

`pretty_time` 在当前代码库中已无实际用途；`TeXmacs/progs/client/` 相关功能后续也将整体移除，因此先把 `pretty-time` 这条无用依赖清理掉。

## 6 How

### 6.1 C++ 层

- 删除 `src/System/Language/tm_locale.hpp` 与 `src/System/Language/tm_locale.cpp`（二者仅用于声明/实现 `pretty_time`）。
- 在 `src/Scheme/L5/init_glue_l5.cpp` 中删除对 `tm_locale.hpp` 的 include。
- 在 `src/Plugins/Qt/qt_utilities.hpp/cpp` 中删除 `qt_pretty_time`，该函数此前仅被 `pretty_time` 调用。

### 6.2 Scheme glue

在 `src/Scheme/Glue/glue_basic.lua` 中删除 `pretty-time` 条目。重新构建时 glue 自动生成，不再导出该符号。

### 6.3 Scheme 调用方

`TeXmacs/progs/client/` 后续会整体移除，但为避免 glue 删除后运行时找不到 `pretty-time`，先把调用替换为等价的简单字符串：

| 文件 | 原代码 | 替换后 |
|---|---|---|
| `client-chat.scm:58` | `(pretty-time (string->number date))` | `date` |
| `client-tmfs.scm:215` | `(pretty-time t)` | `(number->string t)` |
| `client-tmfs.scm:469` | `(pretty-time (string->number date))` | `date` |
