## 3 如何测试

### 3.1 确定性测试（单元测试）
目前该功能主要通过 UI 和后端渲染，无需单元测试。

### 3.2 非确定性测试（文档验证）
1. 编译并运行 Mogan STEM：
   ```bash
   xmake b stem && xmake r stem
   ```
2. 打开「用户首选项」（User Preferences）->「键盘」（Keyboard）标签页。
3. 验证是否有一个名为「快捷键提示类型」（Keyboard shortcut style）的下拉选项。
4. 验证中英文显示。
5. 选择不同的选项（默认、文本、符号），点击后应该会提示重新启动应用以使更改生效。
6. 重新启动后，在菜单项和编辑区提示中验证快捷键显示样式：
   - **默认 (Default)**：macOS 显示原生符号（⌘S 等），Windows/Linux 显示 Ctrl+S。
   - **文本 (Text)**：所有系统显示文本（Mac 下显示 Cmd+S，Windows/Linux 同样是 Ctrl+S）。
   - **符号 (Symbol)**：所有系统显示符号。即使在 Windows/Linux，菜单中也会强制使用 Unicode 符号 `⌃⌥⇧⌘`（如 `⌃S`）。

## 5 What
在用户首选项的「键盘」选项卡中，增加了一个「快捷键提示类型」（Keyboard shortcut style）选项，使用户可以在「默认」、「文本」、「符号」三种快捷键提示形式中自由选择，并且提供了中文翻译。

1. 在 `auto-close.scm` 中注册 `"keyboard shortcut style"` 偏好设置。
2. 在 `preferences-widgets.scm` 中将 `"keyboard shortcut style"` 关联到 pretty names 并添加到 `keyboard-preferences-widget`。
3. 在 `zh_CN.scm` 中为 `"keyboard shortcut style"` 提供中文翻译 `"快捷键提示类型"`。
4. 在 `qt_ui_element.cpp` 中根据该偏好设置，对 Qt Action 菜单快捷键进行平台无关的自定义渲染（支持纯文本和 Unicode 符号渲染）。
5. 在 `tm_config.cpp` 的 `system_kbd_initialize` 中根据该设置，对编辑区和工具栏的提示文本渲染进行适配。

## 6 Why
目前 Mogan 快捷键的显示是根据系统强制绑定的，在 macOS 强制使用符号显示，而在 Windows/Linux 强制使用文字显示。部分 macOS 用户更习惯纯文本式的快捷键显示，而有些 Windows/Linux 用户偏好更加紧凑、直观的 Unicode 符号表示。此任务赋予了用户自由定制快捷键显示样式的能力。

## 7 How
1. 在 Scheme 端声明和渲染选项，并且使用 `set-pretty-preference*` 函数，以便在修改时自动触发保存缓冲区并重启 Mogan。
2. 在 C++ 菜单渲染层（`qt_ui_element.cpp`）：
   - 如果用户选择 `text`，在 macOS 下清除原生 Shortcut 以免 macOS 强制渲染符号，并手动在菜单动作末尾以 `\t` 分隔形式追加自定义的文本表示（如将 `Meta+` 替换为 `Cmd+`，`Alt+` 替换为 `Option+`）。
   - 如果用户选择 `symbol`，在 Windows/Linux 下将 `QKeySequence` 导出的文本（如 `Ctrl+Alt+Shift+S`）通过字符替换映射到 `⌃⌥⇧⌘S` 等直观的 Unicode 符号，并追加到菜单动作末尾。
3. 在 C++ 系统级键盘翻译层（`tm_config.cpp`）：
   - `show_symbols` 条件扩展为：`(style == "symbol") || (style == "default" && use_macos_fonts ())`。
   - `show_text` 条件扩展为：`(style == "text") || (style == "default" && !use_macos_fonts () && gui_is_qt ())`。
