# [0844] 智能标尺对单点不生效

## 1 相关文档
- [0841.md](0841.md) - 折线/多边形绘制中的智能标尺与多点交点吸附

## 2 任务相关的代码文件
- `src/Edit/Interface/edit_graphics.cpp`
  - `snap_ghost_line`：在入口条件中引入 `N(t_prev) >= 2` 的前置检查，并删除内部冗余的 `if (n_points >= 2)` 控制分支以扁平化嵌套结构。

## 3 如何测试

### 3.1 确定性测试（单元测试）
```bash
xmake b curve_test && xmake r curve_test
xmake b stem && xmake r stem
```

### 3.2 非确定性测试（交互验证）
1. 进入绘制状态，在点下第一个控制点时移动鼠标，智能标尺完全静默，不产生绿线或吸附。
2. 当点下第二个点后继续移动鼠标，智能标尺应生效。

## 4 What
- 限制智能标尺和自动吸附的启动边界，仅在折线中至少包含 2 个已绘点（已形成首条参考基准线）时启动检测与吸附。
- 移除分支内部的冗余嵌套控制，精简并规范化 C++ 直线倾角计算流。

## 5 How
- 在 `snap_ghost_line` 顶层，将点数获取前置检查由 `N(t_prev) > 0` 变更为 `N(t_prev) >= 2`。
- 删除内部呈死分支（Dead Branch）状态的 `if (n_points >= 2)` 控制块，将 `pk_1` 和 `pk_2` 基线的获取和 `base_angle` 的解算逻辑直接展平呈现。
