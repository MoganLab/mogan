# 1195 boot 注入 (liii os)

## What

在 `TeXmacs/progs/kernel/boot/boot-s7.scm` 末尾追加 `(import (liii os))`，
将其 22 个导出（`os-arch`/`os-type`/`os-windows?`/`os-linux?`/`os-macos?`/
`os-temp-dir`/`os-sep`/`pathsep`/`os-call`/`mkdir`/`chdir`/`rmdir`/`remove`/
`rename`/`getenv`/`putenv`/`unsetenv`/`getcwd`/`listdir`/`access`/`getlogin`/
`getpid`）注入顶层环境，progs 全局可用。

## Why

此前 progs 中仅 `kernel/texmacs/tm-plugins.scm`（`listdir`/`os-macos?`）和
`dynamic/session-menu.scm`（`access`）两个文件自行 import (liii os)；
guile 遗留代码（如 `link/locus-edit.scm:31` 的 `getpid`）裸用同名函数却无
定义来源。boot 统一注入后，各文件无需重复 import，guile 式裸调用也有了
明确兜底。

## How

`boot-s7.scm` 末尾已把 goldfish 目录加入 `*load-path*` 并 import
`(scheme base)`/`(scheme char)`，`(liii os)` 紧随其后即可解析。
`os-macos?` 与 C++ glue builtin（`glue_lolly.lua`）同名同语义，注入后
顶层绑定覆盖 builtin，行为不变。

验证：`moganstem -headless -x` 顶层直接调用 `(os-type)`/`(getpid)`/
`(listdir "/tmp")` 均正常返回，进程初始化和退出无异常。

## 涉及文件

- `TeXmacs/progs/kernel/boot/boot-s7.scm`

## 任务 2：移除 progs 中冗余的 (liii os) import

### What

- `kernel/texmacs/tm-plugins.scm`：`(import (liii os) (liii vector))`
  改为 `(import (liii vector))`（`vector-filter` 仍在用）。
- `dynamic/session-menu.scm`：整行 `(import (liii os) (liii sys))` 删除——
  `(liii sys)` 导出的 `argv`/`executable`/`which` 在该文件中均无引用。

### Why

boot 顶层注入后 `(liii os)` 全局可用，各文件无需重复 import。

### 涉及文件

- `TeXmacs/progs/kernel/texmacs/tm-plugins.scm`
- `TeXmacs/progs/dynamic/session-menu.scm`

## 任务 3：docx 插件移除 (liii os) import

### What

`plugins/docx/progs/data/docx.scm` 删除 `(import (liii os))`（保留
`(import (liii uuid))`）。该文件用的 `os-temp-dir`/`chdir` 由 boot 顶层
注入提供。

### Why

docx 插件由 mogan 进程内加载，boot 注入对其生效。注意
`plugins/*/goldfish/tm-*.scm`（gnuplot/tikz/quiver/autosave 等）是
goldfish 独立脚本、不经 mogan boot，其 `(liii os)` import 必须保留。

### 涉及文件

- `TeXmacs/plugins/docx/progs/data/docx.scm`

## 任务 4：ocr/account/llm/telemetry 插件移除 (liii os) import

### What

mogan 进程内加载的插件文件统一移除 `(liii os)` import：

- `ocr/progs/liii/ocr.scm`：删整行（`os-temp-dir` 由 boot 注入提供）
- `account/progs/account/liii.scm`：删整行（该 import 本就无符号被引用）
- `llm/progs/llm/chat-list.scm`：`(import (liii njson) (liii os))` 改
  `(import (liii njson))`（`mkdir` 由 boot 注入提供）
- `telemetry/progs/plugin/telemetry-utils.scm`：import 块中删 `(liii os)`
  （`mkdir` 由 boot 注入提供）
- `telemetry/progs/plugin/telemetry-track.scm`：import 块中删 `(liii os)`
  （无符号被引用）

goldfish 独立脚本（`plugins/*/goldfish/tm-*.scm` 及 autosave 库/测试）
由 gf 解释器执行、不经 mogan boot，其 import 保留不动。

### 涉及文件

- `TeXmacs/plugins/ocr/progs/liii/ocr.scm`
- `TeXmacs/plugins/account/progs/account/liii.scm`
- `TeXmacs/plugins/llm/progs/llm/chat-list.scm`
- `TeXmacs/plugins/telemetry/progs/plugin/telemetry-utils.scm`
- `TeXmacs/plugins/telemetry/progs/plugin/telemetry-track.scm`
