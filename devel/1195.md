# 1195 boot 注入 (liii os)

## What

在 `TeXmacs/progs/kernel/boot/boot-s7.scm` 末尾追加 `(import (liii os))`，
将其 22 个导出（`os-arch`/`os-type`/`os-windows?`/`os-linux?`/`os-macos?`/
`os-temp-dir`/`os-sep`/`pathsep`/`os-call`/`mkdir`/`chdir`/`rmdir`/`remove`/
`rename`/`getenv`/`putenv`/`unsetenv`/`getcwd`/`listdir`/`access`/`getlogin`/
`getpid`）注入顶层环境，progs 全局可用。

## Why

此前 progs 中仅 `kernel/texmacs/tm-plugins.scm`（`listdir`/`os-macos?`）和
`dynamic/session-menu.scm`（`access`）两个文件自行 import (liii os)；
guile 遗留代码（如 `link/locus-edit.scm:31` 的 `getpid`）裸用同名函数却无
定义来源。boot 统一注入后，各文件无需重复 import，guile 式裸调用也有了
明确兜底。

## How

`boot-s7.scm` 末尾已把 goldfish 目录加入 `*load-path*` 并 import
`(scheme base)`/`(scheme char)`，`(liii os)` 紧随其后即可解析。
`os-macos?` 与 C++ glue builtin（`glue_lolly.lua`）同名同语义，注入后
顶层绑定覆盖 builtin，行为不变。

验证：`moganstem -headless -x` 顶层直接调用 `(os-type)`/`(getpid)`/
`(listdir "/tmp")` 均正常返回，进程初始化和退出无异常。

## 涉及文件

- `TeXmacs/progs/kernel/boot/boot-s7.scm`

## 任务 5：移除 os-macos? 的 C++ glue 绑定

### What

`src/Scheme/L2/glue_lolly.lua` 删除 `os-macos?` → `os_macos` 的 glue 条目。
scheme 侧 `os-macos?` 由 boot 顶层注入的 `(liii os)` 提供
（`os-type` 是否 `"Darwin"`），语义等价。

### Why

boot 注入后 glue 绑定被顶层同名定义覆盖，属重复绑定。lolly 的 C++
`os_macos()` 本身保留，C++ 内部调用（`tm_sys_utils.cpp`、`tm_config.cpp`
等）不受影响。无 C++ → scheme 反向调用、无测试引用该 scm 名。

### How

xmake glue 规则构建期重新生成 `glue_lolly.cpp`。已验证：`xmake b stem`
通过；headless 顶层 `(os-macos?)`/`(os-windows?)` 均正常返回 `#f`（Linux）。

### 涉及文件

- `src/Scheme/L2/glue_lolly.lua`

## 任务 7：kbd-on-linux? 移除，直接用 os-linux?

### What

`kernel/gui/kbd-define.scm` 删除 `kbd-on-linux?` 定义（原为先前 glue
谓词不全时的反向推断），两处调用点（`(liii logging)` 条件加载、
`kbd-pump-log` 守卫）直接改用 (liii os) 的 `os-linux?`。

### Why

boot 注入后 `os-linux?` 全局可用，反向推断包装失去存在意义。
语义收窄为严格 Linux（原实现对 FreeBSD 等非 win/mac/wasm 平台也返回
#t），与函数名本意一致；两处用途（/tmp 日志、logging 加载）本就以
Linux 为前提。

### 涉及文件

- `TeXmacs/progs/kernel/gui/kbd-define.scm`

## 任务 8：移除 os-mingw?（scheme + glue + C++ 函数）

### What

- `TeXmacs/progs/`（8 处）和 `TeXmacs/plugins/`（1 处）中所有 `os-mingw?`
  调用移除：
  - `(or (os-mingw?) (os-windows?))` → `(os-windows?)`（7 处）
  - 独立 `(os-mingw?)` → `if` 坍缩为 else 分支（2 处，tm-file-system.scm）
- `TeXmacs/progs/prog/glue-symbols.scm` 删除 `"os-mingw?"` 条目
- `src/Scheme/L2/glue_lolly.lua` 删除 `os-mingw?` → `os_mingw` glue 条目
- `lolly/System/Misc/sys_utils.hpp` 删除 `bool os_mingw ();` 声明
- `lolly/System/Misc/sys_utils.cpp` 删除 `os_mingw()` 函数定义
- C++ 调用处清理：`os_mingw ()` 全部移除（3 处 src + 2 处 lolly + 1 处 tests）
- `lolly/System/Classes/url.cpp` 连带删除 `heuristic_is_mingw_default`、
  `url_mingw_default` 两个仅被该死代码引用的函数

对应的代码路径全为死代码。清理后消除误导性的平台分支。
