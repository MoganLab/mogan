# [0745] 阻止 WASM 页面浏览器默认右键菜单和快捷键

## 1 相关文档
- [dddd.md](dddd.md) - 任务文档模板
- [0738.md](0738.md) - 修复 WASM 下按住 cmd 切换窗口后按键卡死、文字输入失效

## 2 任务相关的代码文件
- `bin/wasm_server.py` — 启动 WASM 本地调试服务器时动态生成 `stem.html`，在其中增加浏览器默认行为拦截

## 3 如何测试

### 3.1 构建与启动
```bash
xmake b stem
python bin/wasm_server.py build/wasm/wasm32/debug
```
然后在浏览器中打开 `http://127.0.0.1:8000/stem.html`。

### 3.2 交互验证
1. 在画布区域内点击鼠标右键，应只显示 Mogan 自身的右键菜单，不再同时弹出浏览器的默认右键菜单；
2. 在画布聚焦时按 `cmd+n`（macOS）或 `ctrl+n`（Windows/Linux），浏览器不应打开新窗口；
3. 在画布聚焦时按 `cmd+t`/`ctrl+t`，浏览器不应打开新标签页；
4. 中文输入法（IME）仍应正常工作，不会把 composition 期间的字母直接插入文档（参考 [0738](0738.md) 的 IME 桥接）。

## 4 What
1. 在 `bin/wasm_server.py` 生成的 `stem.html` 中，给 `<canvas id="main-canvas">` 增加 `oncontextmenu="event.preventDefault()"`，阻止浏览器默认右键菜单；
2. 在 `stem.html` 中增加 `window` 级 `keydown` 捕获监听器，对 `Cmd/Ctrl + n/t/w/r/p` 等常见浏览器快捷键调用 `preventDefault()`，避免在应用内触发浏览器默认行为。

## 5 Why
WASM 版本的 Mogan 运行在浏览器 `<canvas>` 上，浏览器默认事件与 Mogan 自身处理的事件是并行的。用户报告：
- 点击右键会同时弹出浏览器的右键菜单和 Mogan 的右键菜单；
- 按下 `cmd+n`/`cmd+t` 等快捷键会触发浏览器的新窗口/新标签页，而不是被 Mogan 拦截或忽略。

这些默认行为需要在 HTML/JS 层面阻止。Qt for WASM 的键盘事件会先经过浏览器 DOM，因此仅靠 Qt 内部处理无法阻止浏览器快捷键。

## 6 How
在 `bin/wasm_server.py` 写入 `stem.html` 的模板字符串中做两处修改：

- 在 `<canvas>` 标签上内联 `oncontextmenu="event.preventDefault()"`，这是 goldfish 插件的 WASM 模板已经在用的做法；
- 在 `Module` 配置之后追加一段脚本：
  ```javascript
  window.addEventListener("keydown", function (e) {
    if (e.metaKey || e.ctrlKey) {
      var key = e.key.toLowerCase();
      if (key === "n" || key === "t" || key === "w" || key === "r" || key === "p") {
        e.preventDefault();
      }
    }
  }, { capture: true });
  ```
  使用 `capture: true` 确保在事件到达浏览器默认处理之前拦截。只拦截浏览器常见快捷键白名单，不影响普通字符输入和 IME composition。

> 注意：某些浏览器/操作系统保留的快捷键（如 macOS 的 `cmd+w` 关闭标签、`cmd+q` 退出应用）无法通过 JavaScript 阻止，这属于浏览器安全限制，不在本任务范围内。
