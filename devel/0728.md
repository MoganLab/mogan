# [0728] WASM 版本适配 Retina HiDPI (ImGui)
## What
- 修改了 im_tm_widget_rep 的构造函数，在 __EMSCRIPTEN__ 条件下 set GLFW_SCALE_TO_MONITOR 为 true，从而开启 Retina 支持
- 修改了 im_gui.cpp 中的 gui_root_extents，在 WASM 情况下屏幕不可用时使用 canvas 的大小作为根部的最大大小

# How to test
使用 mac 或者其他 Retina 显示器
```
xmake f -p wasm --qt_frontend=no --pdfhummus=no
xmake b stem
xmake r stem
```
打开浏览器，查看清晰度是否高清
