# [2029] 段落格式 QML 迁移

「格式 → 段落」(`open-paragraph-format`) 从 tm-widget 迁移到 QML。参考 [2028 字体选择器](2028.md)。

## 0 阶段一：HTML 设计稿（当前）

先在 `ai-docs/qml/qml-dialog.html` 里把段落格式对话框的样式与布局定下来，再写 QML。

### What
- 在现有 QML 组件模拟器的侧边栏新增 `ParagraphFormat.qml` 导航项。
- 新增 `#panel-paragraph`：复用 `form-shell` + `tabs-box` + `option-list`/`option-row` 已有样式，
  分「基础 / 高级」两个 tab，覆盖 `paragraph-parameters` 全部 19 个可配置项。
- 复用 FontSelector 已有 tab 切换 JS 模式，作用域限定在 `#panel-paragraph`（`data-ptab`），
  并把 FontSelector 的 `.tab` 选择器收敛到 `#panel-font` 作用域，避免两组 tab 互相干扰。
- 底部按钮：重置 / 确定 / 取消。确定收集所有 `data-par` 字段，日志输出
  `make-multi-line-with(values)`。

### Why
- 段落格式**需要 live 重绘**：现有 tm-widget 的 `change` 每次下拉改动就立即
  `make-multi-line-with` 写回文档、实时重排段落。QML 版必须保留这一体验——
  用 `run_modal_qml_dialog`(setModal+show) 非阻塞模态（主窗口照常 paint），
  每次 selector-set live 写回；OK 落定，Cancel/重置走快照撤销。
  即与 FontSelector 同一套模态引擎与撤销机制（见 README 的 live 写回/Cancel 章节与
  selector-set/selector-get-changes/initial-snapshot/revert-to-snapshot 通用 facade）。
- exec 的嵌套事件循环不重绘被遮的主窗口，会改了文档树但画面不更新——不能用于本对话框。
- 用 HTML 先定样式，是为了在 QML 实现前就确定布局/控件密度/分组，减少 QML 来回返工。

### How（设计稿要点）
- **可输入下拉 combo**（自建浮层，不用原生 datalist）：每个字段各自独立带 `editable`
  开关，保证组件可变性。交互：**点一下**弹下拉浮层选；**双击**（仅 `editable=on`）进入可编辑
  输入态（Enter/失焦落定、Esc 撤销）。默认：枚举类（对齐/断行/CJK/栏数/边距字距调整）
  `editable=off`（只能下拉选），数值尺寸类（fn/tab/fns）`editable=on`——对应 scheme 末尾
  空串槽位 + `cons-new`。
  - 为何不用 `<input list>`+datalist：Firefox 对 input[list] 悬停时显示的原生箭头无法用 CSS
    隐藏（双箭头），故自建「只读输入框 + 常驻 ▾ 箭头按钮 + 浮层选项列表」，箭头常驻、可控。
  - 取值列表从 `data-options`（JSON）读，与 `format-widgets.scm` 的 `enum` 取值一一对应。
- combo 宽度对齐到能容下「3 个预设按钮 + 间距」（184px）；行间距预设按钮组同宽居中。
- 基础 tab：对齐 `par-mode`、左/右边距 `par-left`/`par-right`、首行缩进 `par-first`、
  行间距 `par-sep`（+ 1.5x/2.0x 预设按钮）、段落间距 `par-par-sep`、栏数 `par-columns`、
  栏间距 `par-columns-sep`。
- 高级 tab：断行 `par-hyphen`、额外行间距 `par-line-sep`、最小行间距 `par-ver-sep`、
  水平折叠 `par-hor-sep`、空间伸展性 `par-flexibility`、CJK 字间距 `par-spacing`、
  字符间拉伸/压缩 `par-kerning-stretch`/`par-kerning-reduce`、字符扩展/收缩
  `par-expansion`/`par-contraction`、边距字距调整开关 `par-kerning-margin`。
- 每个 combo 的取值列表与现有 `format-widgets.scm` 中 `enum` 的取值集合一一对应。
- 控件交互语义按 live 模式：每次下拉/输入改动 → `selector-set` 实时写回文档；确定=落定关闭，
  取消/重置=快照撤销。HTML 设计稿只呈现布局/取值，交互日志见各按钮 `data-log`。

## 1 后续阶段（待做）
