## What
新增 QML 通用 form 引擎，把「文件 → 页面设置」从旧 tm-widget 迁移过去。

### 1. QML form 引擎
- **底座**（`QTMQmlDialog.cpp`）：无边框 `QDialog` + `QQuickWidget` 嵌 QML；`run_qml_dialog` 统一拼装宿主、注入 context property、按 DPI 锁定尺寸。
- **字段转换**（`field_tree_to_qml`）：scheme 字段表 tree → `QVariantMap`，喂给 QML。value 统一 string（scm 侧序列化 number/checkbox/color）。
- **FormDialog.qml**：按 `formFields` 动态渲染。首版实现 enum（自绘下拉，不依赖 QtQuick.Controls）。
- **glue**：`cpp-form-dialog` 接收字段表 tree，OK 返回 `(tuple (key value) ...)`，Cancel 返回空 tuple。

### 2. page-setup 迁移
`open-page-setup-window` 改用 `cpp-form-dialog`：scheme 用 quasiquote 构造字段表（4 个 enum 字段：Preview/Printing command、Paper type、Printer dpi），`stree->tree` 转换后传入，OK 结果解构写回 preference。

### 3. 选项列表整理
- 四个选项列表抽成命名函数（`preview-command-list` 等），集中维护。
- 删掉原版 enum 尾部 `""`（可编辑 combobox 的自定义值占位槽，QML 只读下拉无意义）。
- paper type 列表改小写（`"a4"` 等），对齐全栈规范。

### 4. 下拉浮层修复
- **置顶**：浮层挂 root 顶层（原为 combo 子项，被下方字段行遮挡）。
- **限高 + 滚动**：选项多时按上下可用空间限高，优先向下、不够向上、仍不够 `ListView` 滚动。
- **stree→tree 首项丢失修复**（关键 bug）：mogan 约定下 scheme 列表 `'(a b c)` 经 `stree->tree` 后首项 `a` 变 compound label，原代码只遍历 children 丢首项；改用 `tree_to_scheme_tree` 把 label 拼回首位 + `scm_unquote` 去引号。

## Why
- **迁移动机**：旧 tm-widget 依赖 side-tool（已移除）；QML 弹窗与已有 ConfirmClose 同构，统一实现。
- **设计原则**（详见 `QTMQmlDialog.hpp` @par）：
  - 数据模型由 scm 构造，cpp/QML 不碰 i18n 与业务。
  - key 全部定义在 `pref-keys.scm` 常量 module，cpp 对 key 字符串零硬编码、纯透传 —— 改 key/加字段/调可选项只动 scm，不重编译 cpp。
  - value 统一 string，cpp/QML 全程只搬运。
- **小写而非改源头**：paper type 列表大写 `"A4"` 与系统小写 `"a4"` 不一致，`enum-field` 的 `member` 精确匹配失败导致当前值被防御性重复插入。改大写会破坏 C++ `paper_type` 查表（`supported-sizes` 全小写、无大小写转换），故选择列表对齐小写。

## How
- **字段协议**：`(enum <label> <key> (<option>...) <value> <live?>)`，下标常量 `FIELD_LABEL/KEY/OPTIONS/VALUE/LIVE` 集中在 `QTMQmlDialogInternal.hpp`。
- **浮层定位**：combo `mapToItem(root,0,0)` 把坐标写回 `root.comboX/Y/W`，overlay 据此定位；`openIndex` 控制单展开。
- **限高翻转**：`overlay` 算 `spaceBelow/spaceAbove`，`openBelow` 决定方向，`height = Math.min(optH, 可用空间 - gap)`。
- **stree→tree 还原**：`field_tree_to_qml` 用 `tree_to_scheme_tree` + `scm_unquote`。
- **测试钩子**：`MOGAN_TEST_FORM_DIALOG=ok/cancel` 绕过模态弹窗，供自动化测试。
