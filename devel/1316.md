# 1316 文件 -> 预览 添加说明 tooltip

## 需求

文件 -> 预览 的 tooltip 应该提示，对于幻灯片，只预览当前页。对于普通文档，全文导出PDF之后预览。

## 现状与根因

1. 在幻灯片文档（包含 `<screens>`）中执行「文件 -> 预览」（`preview-buffer`）时，系统直接将当前视图对应的屏幕内容渲染并调用 `preview-file` 预览，因此只预览当前页；
2. 对于普通文档，「预览」会将整篇文档导出为 PDF/PS 临时文件后预览；
3. 目前 `TeXmacs/progs/texmacs/menus/file-menu.scm` 中的 `print-menu` 与 `print-menu-inline` 里，`"Preview"` 仅为普通文本标签，未配置悬停气球提示（balloon），用户无法直观了解幻灯片与普通文档在预览行为上的差异；
4. `menu-widget.scm` 的 `create-text-widget` 中拼接快捷键时先做字符串拼接再调用 `(menu-translate txt)`，导致拼接了快捷键后缀的提示文案无法在字典中匹配翻译。

## 改动方案

1. **菜单项气球提示**：
   - 在 `TeXmacs/progs/texmacs/menus/file-menu.scm` 的 `print-menu` 与 `print-menu-inline` 中，使用 `balloon` 语法为 `"Preview"` 添加提示文案：
     `"For slides, only the current page is previewed. For regular documents, preview after exporting the whole document to PDF."`
2. **函数 synopsis 补充**：
   - 在 `TeXmacs/progs/texmacs/texmacs/tm-print.scm` 的 `preview-buffer` 定义中添加 `:synopsis` 文档属性。
3. **气球提示翻译时序修正**：
   - 在 `TeXmacs/progs/kernel/gui/menu-widget.scm` 的 `create-text-widget` 中，先对提示文案执行 `menu-translate`，再追加快捷键后缀，确保多语言字典正常命中。
4. **多语言字典**：
   - 在 `TeXmacs/plugins/lang/dic/en_US/zh_CN.scm` 中增加中文翻译：
     `"对于幻灯片，只预览当前页。对于普通文档，全文导出PDF之后预览"`。
5. **单元测试**：
   - 在 `TeXmacs/progs/kernel/gui/menu-entry-test.scm` 中补充测试用例，覆盖 `preview-buffer` 的 `:synopsis` 属性导出、提示语中文翻译命中以及带 `balloon` 的菜单项构建。
