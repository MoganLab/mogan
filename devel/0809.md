## 2 任务相关的代码文件

## 3 如何测试

### 3.1 确定性测试（单元测试）
```bash
xmake b stem
xmake r stem
```

### 3.2 非确定性测试（文档验证）
1. 点击 `插入`->`会话`，打开 Python 或 Julia 会话
2. 输入 `using`，颜色应该为蓝色（而不是显示不出来）
3. 插入 `∘` `∉` `∜`，颜色应该为紫色（而不是黑色未渲染）
4. 输入 `struct`，颜色应该也为蓝色
5. 输入 `.`，颜色应该为浅灰色
6. 输入 `:`，颜色应该为橙色
7. 输入 `Any`，颜色应该为稍浅的蓝色（和数字一个颜色）
8. 输入 `?`、`//=`，颜色应该为紫色
9. 输入 `isa`，颜色应该为青色

## 4 What
1. 修复 `using` 等之前颜色配色错误
2. 修复 `∘` `∉` `∜` 等 Unicode 运算符无法高亮的问题
3. 添加更多的语法高亮支持
