# [0320] AI Chat 消息区域的 Markdown 表格自动添加边框

## 如何测试
1. 启动 Mogan STEM，进入含有 AI Chat 的视图并打开 AI Chat 界面。
2. 与大模型进行对话，要求其生成一个 Markdown 格式的表格（例如：“给我生成一个包含学生姓名和分数的 3x2 表格”）。
3. 观察 AI 返回的表格渲染效果。
4. 确认在聊天界面中渲染出的表格自动带有一条线宽的实线边框（外框和内部网格线），而不是默认的无边框样式。
5. 新建空白文档，测试通过“粘贴为 Markdown”或普通的 Markdown 导入方式包含表格，确认此功能不受影响（普通场景的 Markdown 表格依旧遵从系统的默认行为，不会被强制加边框）。

## 2026/06/01
### what
在 AI Chat 面板的会话输出层（`TeXmacs/progs/dynamic/chat-tab-session.scm`）新增了针对模型返回的 Markdown 表格的后处理拦截机制：
- 新增 `chat-tab-add-table-borders-stree` 工具函数，递归扫描大模型输出的 AST（抽象语法树）。
- 当遇到 `tformat` 节点且检查到其不包含 `cell-.*border` 属性设置时，自动向其注入四个边框属性（`cell-tborder`、`cell-bborder`、`cell-lborder`、`cell-rborder`），确保呈现全边框。
- 当遇到 `tabular` 或 `tabular*` 节点时，自动为其外层包裹一个 `big-table` 结构（初始带有空的表注 `(document "")`），这样呈现出来的“大表格”不仅带有完整外框线，而且支持用户后续直接在表格下方或上方输入表注，以获得更好的排版效果。
- 在 `chat-tab-output` 函数中调用该工具，将此处理逻辑限定于 AI Chat 会话气泡的呈现。

### why
在 AI 聊天中，大模型频繁返回 Markdown 格式的表格。原生的 Markdown 表格默认转换为无边框样式，这在聊天界面中可读性较差。为提升用户的对话阅读体验且不污染系统全局的 Markdown 导入和解析行为，将表格加框的策略独立封装到了 AI Chat 专用业务层。
