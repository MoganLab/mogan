# [2027] 通用 QML 板块抽取 + 现有弹窗收敛

## 相关文档
- 完整设计方案（Phase 0–8，含后续 font 弹窗）：[record/qml/font-selector.md](../record/qml/font-selector.md)
- [record/qml/plan.md](../record/qml/plan.md) - QTMQmlDialog 弹窗系统总设计

## 任务范围

本 PR 只做 **Phase 0**：抽取通用 QML 原子板块，并把现有两个 QML 弹窗（`FormDialog` /
`ConfirmClose`）收敛为板块拼装。**行为零变化的纯重构**，不碰字体逻辑。

后续的 font 弹窗实现（光栅化 glue、FontSelector.qml、bridge、入口切换）在
`yuki/2028/font` 分支，详见上面的完整方案。

## What

- 新增 `Theme.qml`（`pragma Singleton`）：统一 `scaleFactor`/`dark`/主题色，取代各
  弹窗各自存一份配色。从 C++ 注入的 `dpScale`/`isDark` context property 取值。
- 新增 `DialogShell.qml`：可复用弹窗外壳——圆角背景、主题、无边框拖动、ESC 取消、
  `content` 正文槽、`onActivate`/`onCancel` 键盘回调。
- 新增 `DialogButtons.qml`：可复用按钮行（自绘胶囊 + hover + 点击缩放）。只发
  `clicked(index)`，不假定按钮语义（submit/cancel 由调用方映射）。
- 新增 `EnumCombo.qml`：自绘下拉，浮层用 `QtQuick.Controls` 的 `Popup` 承载（黑盒，
  不再靠宿主根顶层 overlay，规避 z 序遮挡）。
- 新增 `qmldir`：注册上述组件 + Theme 单例。
- 改造 `ConfirmClose.qml`：收敛为 `DialogShell` + `DialogButtons` 拼装，仅剩「消息
  文案 + 按钮标签注入 + 按钮下标语义」薄逻辑。
- 改造 `FormDialog.qml`：收敛为 `DialogShell` + `EnumCombo` + `DialogButtons` 拼装，
  仅剩「字段 Repeater + values 收集 + submit」薄逻辑。
- 新增 `tests/Plugins/Qt/qml_load_test.cpp`：加载真实 QML 弹窗文档，断言
  `status()==Ready`——改造后的安全网，抓 import 缺失/语法错/context property 误用。

## Why

- `FormDialog.qml` 与 `ConfirmClose.qml` 旧实现各自重复了 主题色定义、圆角背景、
  DragHandler、ESC、下拉 overlay 定位、按钮 Repeater delegate——收敛后这些只在原子
  板块存一份。
- `QTMQmlDialog.hpp` 的 TODO 已标注「第三个 QML 弹窗时抽 DialogBase」——本 PR 即兑现
  该 TODO，为后续 font 弹窗（及所有新弹窗）立样板。
- EnumCombo 改用 Popup：原方案「overlay 挂宿主根」需要调用方协调坐标，组件不自包含；
  Popup 是 Qt 生态标准做法，让 EnumCombo 成彻底黑盒。

## How

- 主题色共享用 QML `pragma Singleton`（`Theme.qml` + `qmldir` 注册），所有组件
  `import "."` 后用 `Theme.bg` 等，不依赖 DialogShell 为 parent。已在 `qml_load_test`
  验证 singleton 在 qrc / QQuickWidget / context property 下可用。
- DialogShell 用 `default property Item content` 作正文槽；键盘逻辑只存一份（ESC 恒为
  取消，Enter/Return 经 `onActivate` 回调由弹窗覆盖），避免跨文件给同一对象的 Keys
  attached 叠加 handler。
- EnumCombo 的 Popup 用 `modal:false`/`dim:false` + `CloseOnPressOutside`，限高滚动
  靠 Popup contentItem 里的 `ListView`。
- `moganqml.qrc` 注册新增 `.qml` + `qmldir`。

## 踩坑记录

- **DialogShell 的 content 不要走 parent 链访问根属性**：`content` 被 DialogShell
  重新 parent 到内部 `contentCol`（再嵌在 Rectangle 里），故 content 子项的 parent 链
  是 `Column → contentCol → Rectangle → root`，中间隔两层。用 `parent.parent.xxx`
  会指向 Rectangle（无该属性），导致取不到值（ConfirmClose 旧改造里按钮 label 取空、
  三按钮不显示就是这个原因）。正解：给 DialogShell 根设 `id: root`，子项用 `root.xxx`
  直接引用。FormDialog 一开始就这么写所以没踩坑。后续 FontSelector 同理。
