## 5 What

1. 新增 4 个原子板块 + Theme 单例 + qmldir：Theme（主题）/ DialogShell（外壳 + 共享下拉
   浮层）/ DialogButtons（按钮行）/ EnumCombo（combo 行样式）。
2. ConfirmClose 收敛为 `DialogShell` + `DialogButtons` 拼装。
3. FormDialog 收敛为 `DialogShell` + `EnumCombo` + `DialogButtons` 拼装。
4. 新增 `qml_load_test.cpp`：加载真实 QML 弹窗文档断言 `status()==Ready`，抓 import 缺失
   /语法错/context property 误用。

**样式改动**（除提取外）：
- FormDialog：零样式改动。所有像素值（圆角/字号/间距/配色/按钮/下拉 overlay）与 main
  旧版逐项核对一致。
- ConfirmClose：提取为主，两处与长文件名相关的有意改动：
  - message 去掉 `lineHeight: 1.6` + `wrapMode: WordWrap`，改为单行 +
    `elide: Text.ElideMiddle`。短文件名视觉与旧版一致；长文件名不再换行撑破弹窗，而是
    中间省略保持单行（修长文件名 bug）。
  - 按钮文字 `letterSpacing: 0.3×sf` 经 DialogButtons 的 `letterSpacing` 属性恢复，与旧版
    一致。

## 6 Why

1. 旧两弹窗各自重复了主题色定义、圆角背景、DragHandler、ESC、下拉 overlay 定位、按钮
   Repeater delegate——收敛后只在原子板块存一份。
2. `QTMQmlDialog.hpp` 的 TODO 已标注「第三个 QML 弹窗时抽 DialogBase」——本 PR 兑现，为
   后续 font 弹窗（及所有新弹窗）立样板。
3. 长文件名文案截断放 QML 侧（`ElideMiddle`）而非 scheme：scheme 的 string 是字节级
   （`string-length "汉"` = 3），按字节截断含中文的文件名会切坏 UTF-8 多字节序列 → 乱码。
   QML/JS 字符串是 UTF-16 码元级（中文字符级），`elide` 中文安全。

## 7 How

**下拉浮层：DialogShell 共享 overlay（关键设计）**
EnumCombo 只负责 combo 行样式，不含浮层。点开后把自己注册为所在 DialogShell 的
`activeCombo`（暴露 comboX/Y/W/options），DialogShell 据此在 root 顶层渲染唯一一个
overlay。限高翻转算法与旧 FormDialog.qml 逐行一致（弹窗逻辑坐标系，不依赖 window/物理
坐标），优先向下、不够向上、仍不够限高滚动。

不采用 QtQuick.Controls 的 Popup：实测 Popup 在 QQuickWidget 嵌入式场景坐标/翻转不稳
（`Window` attached、`mapToItem(null)` 给值导致浮层定位偏）。共享 overlay 用弹窗逻辑
坐标系（`mapToItem(dialogShell)`），与旧实现同源、可靠。组件层回到纯 QtQuick，不依赖
Controls——契合旧两弹窗头注释「纯 QtQuick」原则。

坐标在 EnumCombo 点击瞬间由 `updateGeometry()` 主动算一次（布局已完成），不用 binding
实时算——避免布局未完成时 `mapToItem` 给出 stale 值导致定位偏。

**其他要点**
- 主题色共享用 `pragma Singleton`（`Theme.qml` + `qmldir`），组件 `import "."` 后用
  `Theme.bg` 等，不依赖 DialogShell 为 parent。
- DialogShell 用普通 `property Item content` 作正文槽；挂载时 reparent 到内部 `contentCol`
  并主动设 `content.anchors.fill = contentCol`（调用方不写 anchors.fill，原因见踩坑）。
- 键盘逻辑只在 DialogShell 存一份（ESC 恒取消/浮层展开时先收起，Enter/Return 经
  `onActivate` 回调由弹窗覆盖）。

## 踩坑记录

- **content 不要写 `anchors.fill: parent`**：content 创建初的 parent 是 DialogShell 根，
  `anchors.fill: parent` 的绑定钉死在旧 parent 上，reparent 到 `contentCol` 后不更新，导致
  正文撑满全弹窗、无视 `implicitMargins` 边距。正解：DialogShell 挂载时主动设
  `content.anchors.fill = contentCol`，调用方不写 anchors.fill。
- **content 子项不要走 parent 链访问根属性**：content reparent 到 `contentCol`（再嵌在
  Rectangle 里），parent 链是 `子项 → contentCol → Rectangle → root`，中间隔两层。用
  `parent.parent.xxx` 会指向 Rectangle（无该属性）→ 取不到值（ConfirmClose 按钮曾因此取
  空标签、三按钮不显示）。正解：根设 `id: root`，子项用 `root.xxx`。
- **scheme string 是字节级**：`string-length`/`substring` 按 UTF-8 字节计，截中文切坏多字节
  序列。故文案截断放 QML（字符级），scheme 只传原始字符串。
