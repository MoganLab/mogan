# [0529] OAuth 回调服务器改按需监听与生命周期管理

## 背景

承接 [0525]（回调端口改系统动态分配）与 [0526]（state 校验与 CSRF 防护）。
虽然回调端口已经改为系统动态分配（端口 0），但生命周期与健壮性上仍存在若干问题：

- **常驻监听**：`QOAuthHttpServerReplyHandler` 默认在构造时即绑定端口开始监听。即使用户无需登录或尚未点击登录，本地端口也一直暴露在外部网络/进程扫描面中；
- **静默失败**：原本 `login()` 中若 `!isListening()` 则静默跳过整个流程，用户点击登录毫无反应，日志中亦无法排查；
- **延迟关闭与快速重登的竞态**：浏览器完成授权后重定向回本地，需要留出窗口将包含 `window.location.replace(growth-url)` 的 HTML 写回浏览器。若使用不可取消的匿名定时器，在用户快速重试或换号重登时，上一轮未决的延迟关闭会在几百毫秒后意外掐断新发起的监听；
- **`getRedirectUri()` 关闭后返回空串隐患**：原实现直接调用 `m_reply->callback()`。当回调服务器 close() 后，该接口返回空串 `""`。若令牌交换发生在关闭后或后续有异步重试，会导致向 `/token` 提交的 `redirect_uri` 为空从而被服务端拒绝（RFC 6749 §4.1.3 规定两处必须完全一致）。

## 改动

- `src/Plugins/Qt/QTMOAuth.cpp`
  - **构造即关闭**：构造函数在创建 `m_reply` 后立即调用 `m_reply->close()`，改为 `login()` 时按需监听，消灭无登录需求时的常驻监听；
  - **按需监听与失败报错**：`login()` 发起时调用 `listen(QHostAddress("127.0.0.1"), 0)`，失败时显式输出 `debug_boot << "OAuth callback server failed to listen\n"` 并返回；
  - **延迟关闭竞态保护**：
    - 引入受类生命周期管理的成员单次定时器 `m_callbackCloseTimer`；
    - 在 `login()` 开头检测 `m_callbackCloseTimer->isActive()`：若上一轮登录正处于延迟关闭等待中，立即中止该定时器并关闭旧监听，防止其在新流程中意外触发；
  - **会话级 `redirect_uri` 缓存**：
    - `login()` 中在 `listen()` 成功后固化 `m_redirectUri = m_reply->callback()`；
    - `getRedirectUri()`：监听活跃时优先同步实际监听地址；服务器关闭后回退返回本次登录发起时缓存的有效地址，确保令牌交换时参数绝对一致且非空；
  - **超时与延时释放**：
    - 收到回调信号 `callbackReceived` 时启动 3 秒延迟关闭定时器 `m_callbackCloseTimer`（给系统代理劫持、杀软包过滤与低配设备留足容错窗口），并转调 `handleCallback(values)` 执行 state 校验与令牌交换；
    - `login()` 时启动 5 分钟一次性定时器 `m_loginTimer`，用户长时间未授权则超时关闭；
    - 新增 `closeCallbackServer()`：停止相关定时器并幂等关闭 `m_reply`。
- `src/Plugins/Qt/QTMOAuth.hpp`
  - 新增 `closeCallbackServer()` 私有方法；
  - 新增私有成员变量：`m_loginTimer`、`m_callbackCloseTimer`、`m_redirectUri`。

## 验证

按需监听与生命周期验证：

- **未登录无监听**：应用启动后不点登录，通过 `netstat -ano | findstr <pid>` 确认不存在回调端口监听；
- **按需监听与 3 秒释放**：点击登录后，系统分配临时高位端口，浏览器正常打开授权页；授权通过后 3 秒复查，端口已正常关闭释放；
- **快速重登 / 连击抗竞态**：在收到回调后 3 秒内立即再次点击登录，旧关闭定时器被成功中止，新监听端口正常分配且不会被上一轮延时掐断；
- **5 分钟超时释放**：点击登录后放着不动，5 分钟后端口自动释放；之后再次点击登录能够重新监听；
- **令牌交换参数健全**：服务器关闭后调用 `getRedirectUri()` 依然返回发起授权时的有效地址，令牌交换顺利完成。
