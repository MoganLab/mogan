# [1240] 新文档 no_name 机制改为 draft_ 时间戳命名

## 1 相关文档
- [dddd.md](dddd.md) - 任务文档模板

## 2 任务相关的代码文件
- `src/System/Files/tm_file.{hpp,cpp}` - 移除 `url_scratch` / `url_numbered`
- `src/Texmacs/Data/new_buffer.cpp` - `make_new_buffer` / `propose_title` 委托 scheme
- `TeXmacs/progs/texmacs/texmacs/tm-files.scm` - scratch 命名与标题规则
- `src/Scheme/L3/glue_file.lua` - 删 `url-scratch`,增 `get-documents-path`

- `src/Plugins/Qt/QTMTabPage.cpp` - 标签页最大宽度 150 → 190
- `TeXmacs/plugins/lang/dic/en_US/zh_CN.scm` - 新增 Draft / 周一~周日 词条

## 3 What

新建文档的 scratch buffer 从 `no_name_N.tmu` 改为 `draft_<时间戳>.tmu`:

- 命名:最小精确到分钟(`draft_YYYYMMDDHHMM`),冲突时精确到秒,仍冲突追加 `-N`
- 命名与标题规则全部在 scheme 层实现(`scratch-buffer-name` / `scratch-buffer-title`)
- 标题展示规则:
  - 本周内且当天唯一:`Draft Monday` / 「草稿（周一）」
  - 本周内当天多个:`Draft Monday 21:27` / 「草稿（周一21:27）」
  - 同分钟仍有重复(文件名升到秒级)时展示精确到秒
  - 非本周:`Draft 08/02 22:43` / 「草稿（08/02 22:43）」
- 移除 C++ `url_scratch` / `url_numbered` 及 `url-scratch` glue;新增 `get-documents-path` glue
- `QTMAction::set_text` 改用显式 `utf8_to_qstring (herk_to_utf8 (s))`,不再走 `to_qstring` 编码猜测
- 标签页最大宽度上限 150 → 190,容纳中文标题
- scratch 构建产物加入 `.gitignore`(`3rdparty/curl-*/build-*/`、`3rdparty/curl-*/CMakeLists.txt`)

## 4 Why

`no_name_N` 序号命名无时间信息,标题只能显示「No name [N]」,无法区分多份草稿;
命名与标题逻辑散落 C++(`url_scratch` + `propose_title` 字符串解析),改为 scheme 层
集中实现后规则可读、可测,并支持中文本地化展示(herk 编码链路统一)。

## 5 How

- `make_new_buffer` 调 scheme `(scratch-buffer-name)`(返回系统路径字符串,时间来自
  `(liii time)` 的 `current-date`),scheme 异常或名字被占用时以毫秒时间戳兜底
- `propose_title` 对 `draft_*.tmu` 调 scheme `(scratch-buffer-title u)`,标题在
  scheme 内按 utf8 拼接(translate 结果先 `herk->utf8`)后整体 `utf8->herk` 返回
- 周/日判断用 srfi-19 的 `date->julian-day`(跨月正确)与 `date-week-day`
- `is_scratch`(按目录判断)保持不变,存量关闭清理、另存为等逻辑不受影响
