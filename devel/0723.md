# [0723] 升级 Goldfish 到 18.11.16 (WASM Support)

## What
- goldfish.lua 中给 add_packages("cpr") 添加 not is_plat("wasm") 条件
- 新增 http 模块的条件编译选项，以在 WASM 平台排除 http 模块
- 补充/修正 WASM 相关逻辑
- `TeXmacs/plugins/goldfish/src/goldfish.hpp` - 版本号 `18.11.15` → `18.11.16`

## 如何测试
暂时只能测试非 wasm 平台构建表现不变
```
xmake b goldfish
```
