# [0742] 修复 WASM 下保存 scratch buffer 触发下载的问题
## What
- 新增 `os-wasm?`：在 `src/Scheme/L2/glue_lolly.lua` 绑定 C++ 的 `os_wasm()`，供 scheme 判断是否在 WASM 环境运行。
- 修改 `save-buffer-check-permissions`：scratch buffer 分支原先无条件弹出 `Save as` 对话框。WASM 下将其改为直接调用 `save-buffer-check-faithful`，保存到已有的 scratch 路径，避免普通 `Save` 触发 `choose-file` → `wasm-save-for-download` → 浏览器下载。

# 如何测试
```
xmake f -p wasm -m debug --qt_frontend=no --pdfhummus=no
xmake b stem
xmake r stem
```
浏览器中
```
File-New
File-Save
```
观察：左下角footer提醒已经正常保存，浏览器不触发下载
