# 0905: 数学模式双字母 tab 循环末尾切回两个字母

## 2026/08/13 双字母循环末尾切回两个字母

### What（本次改动做了什么）

数学模式下连按两个相同字母（`a a`、`b b`、…、`z z`、`A A`、…、`Z Z`，
共 52 组）进入符号变体 tab 循环。原来循环到最末档 `<b-up-X>` 后再按
`tab`，会直接回退到首档 `<bbb-X>`；现在在最末档之后**新增一档**，
用字面字符串 `"XX"`（两个该字母，紧凑无空格）切回「连按两次该字母」的
普通斜体双字母形态，构成完整闭环。

以 `a a` 为例，改后循环为：

| 按键 | 符号 |
|------|------|
| `a a` | `<bbb-a>` |
| `a a var` | `<frak-a>` |
| `a a var var` | `<b-a>` |
| `a a var var var` | `<up-a>` |
| `a a var var var var` | `<b-up-a>` |
| **`a a var var var var var`** | **`"aa"`（新增：两个字母）** |

之后再按 `tab` 回到 `<bbb-a>`。

### Why（为什么这么做）

用户期望：双字母循环遍历完所有字体变体后，能切回「连按两次该字母」的
普通斜体双字母形态（如 `aa`），而非从末档直接跳回首档。这使最常用的
普通双字母形态作为循环的一员，可达性更好。

### How（怎么做的）

- `TeXmacs/progs/math/math-kbd.scm`：为 52 组双字母绑定各追加一行末档，
  值用字面字符串 `"XX"`（两个该字母，紧凑无空格）。字面字符串走
  `kbd-insert` → `former` 解析，在数学模式插入紧凑的两个字母（与连按
  两次该字母的结果一致，实测 body 为 `aa`）。
- 小写 `m` 较特殊：0112（commit 23dd4c7e3）移除了 `m m` 基础绑定，
  其变体链整体后移一个 var 层级（从 `m m var` 起）。因此 `m m` 的新增
  末档为 `("m m var var var var var var" "mm")`（比其它字母多一档 var）。

实现用脚本批量定位每组 `<b-up-X>` 末行并替换其值，避免手改 52 处出错。

### 涉及文件

- `TeXmacs/progs/math/math-kbd.scm`：双字母（a-z、A-Z）循环各组追加「两个字母」末档。
- `TeXmacs/tests/0905.scm`：GUI 集成测试，验证 `a a` 连按 tab 到末档后
  底文为紧凑的两个字母 `aa`。

### 测试方法

```bash
xmake b stem && MOGAN_TEST_GUI=1 TEXMACS_PATH=$(pwd)/TeXmacs xmake r 0905
```

测试要点：`a a` 后按 5 次 `tab`，底文应恰好为 `aa`（紧凑两个字母）。
