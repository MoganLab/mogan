# [1317] 修复 PDF 标签页关闭后重开及磁盘变更未重新加载的问题

## What

1. 修复关闭 PDF 标签页后重新打开同一路径的 PDF 时，Mogan 未重新从磁盘加载文件、仍显示此前缓存旧内容的问题。
2. 支持 PDF 标签页在文件于磁盘上被修改（如重新导出或外部程序重新生成）时，自动检测文件修改时间及大小变化并重新加载最新内容。
3. 关闭 PDF 标签页时，通知 Qt 窗口清理关联的 PDF 路径记忆并释放阅读器控件缓存（`pdfViewerWidget->clear()`），确保标签页真正关闭。

## Why

在草稿或文档中导出 PDF 并在 Mogan 中打开后，关闭该 PDF 标签页并继续编辑文档，再次导出 PDF 并打开时，Mogan 显示的仍是第一次导出的 PDF 内容（例如第一次输入 1 导出显示 1，追加 2 再次导出后，磁盘上的 PDF 文件已变为 12，但 Mogan 内打开该 PDF 仍显示 1）。

根因分析：
1. 在 `qt_tm_widget_rep` 中，PDF 阅读器的加载条件为 `!currentPdfPath.isEmpty () && currentPdfPath != lastLoadedPdfPath`。关闭 PDF 标签页时，仅移除了 `tm_view`/`tm_buffer` 并隐藏了阅读器控件，但 `lastLoadedPdfPath` 未被重置，`pdfViewerWidget` 内部的页面缓存与数据也未被清空。
2. 再次打开同一路径的 PDF 时，`currentPdfPath == lastLoadedPdfPath` 为真，`pdfViewerWidget->loadFromFile (currentPdfPath)` 被直接跳过，导致阅读器沿用之前缓存在内存中的旧数据与页面渲染。
3. 当 PDF 文件在磁盘上发生更新（修改时间或文件大小变化）时，原有逻辑仅根据路径字符串是否相等判断，未能感知磁盘文件的更新。

## How

1. **`PDFReaderWidget` (`src/Plugins/Qt/qt_pdf_reader_widget.hpp/.cpp`)**：
   - 提供 `filePath ()` const 获取当前已加载的文件路径。
   - `loadFromFile` 内部记录已加载文件的磁盘指纹（`pdfFileModTime_`/`pdfFileSize_`）：
     路径、修改时间、大小与 dpi 均未变时直接跳过重复加载；任一变化则重新从磁盘读取。
     `clear ()` 一并重置指纹。
2. **`qt_tm_widget_rep` (`src/Plugins/Qt/qt_tm_widget.hpp/.cpp`)**：
   - 新增 `notify_pdf_tab_closed (const QString& closedPath)` 回调：在 PDF 标签页关闭时，
     清空 `currentPdfPath` 并对阅读器控件调用 `clear ()` 真正释放页面与数据缓存。
   - `sync_startup_tab_mode ()`：无条件调用 `loadFromFile`，磁盘变更判定由阅读器内部完成。
   - `send (SLOT_FILE)`：非 PDF 模式下及时清空 `currentPdfPath`，避免残留。
3. **`cpp_kill_tabpage` (`src/Plugins/Qt/QTMTabPage.cpp`)**：
   - 在关闭标签页前检测被关闭视图是否为 PDF 标签页（`is_pdf_tab_file`），若是则调用
     对应窗口的 `notify_pdf_tab_closed`；窗口解析与 `kill_tabpage` 一致
     （`vw->win` 优先，回退 `vw->win_tabpage`）。
4. **测试**：
   - C++ 单元测试：`tests/Plugins/Qt/qt_pdf_reader_widget_test.cpp` 增加对 `filePath ()`、
     `clear ()` 及同路径重复加载的断言。
   - 集成测试：`TeXmacs/tests/1317.scm` 验证 PDF buffer 的加载、关闭以及重新加载流程。
   - UI 自动化测试：`TeXmacs/tests/python/1317.py` 验证导出 PDF 后关闭重开显示最新内容。

## 迭代记录

### 2026-09-18 重构：磁盘变更检测下沉到 PDFReaderWidget

- What：将「文件是否变更」的判定与 mtime/size 状态从 `qt_tm_widget_rep` 下沉到
  `PDFReaderWidget::loadFromFile`，删除 `lastLoadedPdfPath`/`lastLoadedPdfModTime`/
  `lastLoadedPdfSize` 三个影子成员（`lastLoadedPdfPath` 与 `pdfViewerWidget->filePath ()`
  本是重复真相源）。
- Why：路径与指纹描述的是阅读器持有的文件状态，放在窗口层需要在三处手动保持同步；
  下沉后所有 `loadFromFile` 调用方自动获得防陈旧保护，`notify_pdf_tab_closed` 简化为
  两行清理。
- How：`loadFromFile` 开头比对路径+dpi+mtime+size，未变则早退；`sync_startup_tab_mode`
  无条件调用；`cpp_kill_tabpage` 中 `as_string` 去重、窗口解析对齐 `kill_tabpage`、
  裸 C 强转改为 `dynamic_cast`。
- 涉及文件：`src/Plugins/Qt/qt_pdf_reader_widget.hpp/.cpp`、`qt_tm_widget.hpp/.cpp`、
  `QTMTabPage.cpp`，另清理 `TeXmacs/tests/1317.scm`（提取断言 helper）与
  `TeXmacs/tests/python/1317.py`（删除死代码、提取重复块）。
