# [0732] WASM ImGui 输入法支持

## What
- 实现了 exec_pending_commands
- 实现了 WASM 的 IME 支持，使用一个不可见的 textarea 承接 IME 输入（从而避免手搓 GLFW 层的 IME 处理逻辑）

## 如何测试
```
xmake f -m debug -p wasm --qt_frontend=no --pdfhummus=no
xmake b stem
xmake r stem
```
打开浏览器，尝试使用中文输入法输入字符，观察 pre-edit 正常显示，中文字符（空白）被插入。

注意，目前还没有做中文字体的适配，因此中文字符显示为空白
