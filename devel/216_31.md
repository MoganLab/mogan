## 2026/04/23 实现说明

### What

本次修改包含两部分：启动页 File 页面的进一步代码清理，以及 Qt 层 Scheme 字符串转义的统一封装。

#### 修改文件

**src/Plugins/Qt/qt_file_page.cpp** (修改)
- 移除 `StyleCard` 的选中状态相关代码：
  - 删除 `setSelected()` 实现、`isSelected_` 状态、`selectedCard_` 指针。
  - 删除 hover 时自动切换选中的信号连接。
  - 删除默认选中 Generic 卡片的逻辑。
- 简化 `paintEvent`：移除 `QPainter::Antialiasing`，仅保留背景绘制。
- 调整卡片布局：由 `setAlignment(Qt::AlignCenter)` 改为 `addStretch` + 控件 + `addStretch`，实现垂直居中。
- 提取 `populateRecentDocsFromPaths()` 静态函数：消除 `loadRecentDocs()` 中两处重复的 recent paths 填充逻辑。
- `createDocumentWithStyle()` 中 `validStyles` 从 6 项缩减为仅 `{"generic"}`（与 216_30 的 `styles_` 缩减保持一致）。
- 统一 Scheme 字符串转义：所有调用 `eval_scheme` 传入路径的地方，改用 `qt_scheme_quote()`。

**src/Plugins/Qt/qt_file_page.hpp** (修改)
- 移除 `setSelected()`、`isSelected()` 声明。
- 移除 `isSelected_`、`badgeLabel_`、`selectedCard_` 成员。
- 简化注释。

**src/Plugins/Qt/qt_startup_tab_widget.cpp** (修改)
- 删除内联的 `escape_for_scheme_string()` 函数。
- Template 页面打开文档时，改用 `qt_scheme_quote()`。
- `keyPressEvent` 和 `keyReleaseEvent` 中，改用 `qt_scheme_quote()` 构造 Scheme 命令。

**src/Plugins/Qt/qt_utilities.cpp** (修改)
- 新增 `#include <moebius/data/scheme.hpp>`。
- 新增 `qt_scheme_quote()` 实现，封装 `moebius::data::scm_quote()`。
- 将 `qt_scheme_quote()` 的实现位置从文件末尾调整至 `qt_translate()` 附近，与其他字符串转换工具函数归为一组。

**src/Plugins/Qt/qt_utilities.hpp** (修改)
- 新增 `qt_scheme_quote()` 声明。

### Why

1. **消除重复代码**：此前在 `qt_file_page.cpp`（3 处）和 `qt_startup_tab_widget.cpp`（2 处）共有 5 处重复的手动字符串转义逻辑（`replace("\\", "\\\\")` + `replace("\"", "\\\"")`）。抽取为 `qt_scheme_quote()` 后，转义逻辑集中管理，后续修改只需改一处。
2. **利用已验证的基础设施**：`moebius::data::scm_quote()` 在 `moebius` 库中已有单元测试覆盖（`moebius/tests/moebius/data/scheme_test.cpp`），比分散的手动 `replace` 更可靠。
3. **清理冗余交互状态**：216_30 已将 File 页面精简为单一卡片，"选中状态"、"Default 徽标"、"hover 自动选中" 等交互已失去意义。移除这些代码减少维护负担，避免 CSS 和 C++ 双重管理视觉状态。
4. **消除重复代码块**：`loadRecentDocs()` 中两处读取 `recentPaths` 的循环完全相同，提取为 `populateRecentDocsFromPaths()` 后更清晰。
5. **函数位置语义化**：`qt_scheme_quote()` 与 `qt_translate()`、`from_qstring()`、`to_qstring()` 等转换函数属于同一语义组，放在文件末尾的剪贴板函数附近不合理。

### How

1. **统一 Scheme 字符串转义**
   - 在 `qt_utilities` 层新增 `qt_scheme_quote()`，底层调用 `moebius::data::scm_quote()`。
   - 该函数将 `QString` 转为 `string`，并包上双引号、转义其中的 `"` 和 `\`。
   - 所有使用处将旧的 `QString("(cmd \"%1\")").arg(escapedPath)` 模式替换为 `string("(cmd ") * qt_scheme_quote(path) * ")"`。

2. **移除 File 页面冗余状态**
   - 头文件中删除 `isSelected_`、`selectedCard_`、`badgeLabel_`。
   - 删除 `setSelected()` 实现及 `hovered` 信号连接的选中逻辑。
   - `paintEvent` 仅保留 `QStyleOption` 背景绘制，不再手动绘制选中边框。
   - 布局使用 `addStretch` 实现垂直居中，避免硬编码 padding。

3. **提取公共函数**
   - 将 `loadRecentDocs()` 中 `!file.open()` 和 `!doc.isObject()` 两个分支里的相同循环提取为 `populateRecentDocsFromPaths()`。

4. **函数位置调整**
   - 将 `qt_scheme_quote()` 从 `qt_utilities.cpp` 末尾（`qt_clipboard_set_html` 之后）移动到 `qt_translate()` 之后，与字符串转换工具函数归为一组。
