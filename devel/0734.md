# [0734] 精简 ImGui 前端菜单栏

## What?

仅针对 **ImGui 前端**（`qt-gui?` 为 `#f` 时）精简主菜单栏。所有改动用
`(if (qt-gui?) …)` 守卫包裹：**Qt 前端行为完全不变**，仅 ImGui 后端的菜单变窄。
其余菜单项的功能、行为与顺序保持不变。

### 顶级菜单

- 删除整个顶级菜单：**Go**、**Tools**、**Help**。

### File 菜单

- 仅保留：**New**、**Load**、**Save**。
- 删除其余全部：Revert、Recent、Save as、Print、Import、Export、Close window/document、
  Close TeXmacs 等。

### Edit 菜单

- 删除：**Search recent documents**、**Preferences**（含 `use-menus?` / `use-popups?`
  两种形态）。

### Focus 菜单

- 删除：**Help**（`standard-focus-menu` 在 `tree-is-buffer?` 分支末尾的
  `("Help" (focus-help))`）。

### Format 菜单

- 删除：**Font**、**Paragraph**、**Page**、**Cell**、**Table**、**Color**。
- 同时覆盖 `full-text-format-menu`（`use-menus?` 形态）与
  `compressed-text-format-menu`（`use-popups?` 形态）两种布局。

### View 菜单

- 删除：**New window**、**Open in new window**、**Close window**；
  **Main icon bar**、**Mode dependent icons**、**Focus dependent icons**。

## Why?

ImGui 前端目前是精简的（WASM / 即时模式）端口，上述被删除的菜单项对应的弹窗/对话框
（文件选择器、字体选择器、偏好设置、页面设置、多窗口管理等）在 ImGui 后端尚未实现，
或与已实现能力重复。精简菜单可避免向用户暴露无效入口，仅保留当前已实现或必要的功能。

为不影响 Qt 前端（完整产品），改动一律以 `(qt-gui?)` 守卫，即「仅 Qt 显示这些项」，
等价于「ImGui 下移除这些项」。这与仓库已有的 ImGui 专用写法一致（参见
`main-menu.scm` 中既有的 `(if (not (qt-gui?)) …)`）。

## 涉及的主要代码位置及实现方式

实现方式统一为：把「连续的待删条目（含其相邻分隔符 `---`）」整体包进
`(if (qt-gui?) …)`；被保留的条目原样不动，菜单结构与顺序不变。

| 菜单 / 位置 | 文件 | 说明 |
| --- | --- | --- |
| 顶级 Go / Tools / Help | `TeXmacs/progs/texmacs/menus/main-menu.scm`（`texmacs-menu`） | 三个 `(=> …)` 包进 `(if (qt-gui?))` |
| File（仅留 New/Load/Save） | `TeXmacs/progs/texmacs/menus/file-menu.scm`（`file-menu`） | 两段连续删除块各包一层 `(if (qt-gui?))`：Revert/Recent/`---`；Save-as 至 Close TeXmacs |
| Edit（去 Search recent/Preferences） | `TeXmacs/progs/texmacs/menus/edit-menu.scm`（`edit-menu` 末尾） | 末尾含分隔符的 Search recent + Preferences 块包进 `(if (qt-gui?))` |
| Focus（去 Help） | `TeXmacs/progs/generic/document-menu.scm`（`standard-focus-menu` 的 `tree-is-buffer?` 分支） | 末尾 `---` + `("Help" (focus-help))` 包进 `(if (qt-gui?))` |
| Format（去 Font/Paragraph/Page/Cell/Table/Color） | `TeXmacs/progs/text/text-menu.scm` | `full-text-format-menu`：Font/Color 块、Paragraph/Page 块各包一层；`compressed-text-format-menu`：Font..Table 块、Color 块各包一层 |
| View（去 New window 等及三个图标栏开关） | `TeXmacs/progs/texmacs/menus/view-menu.scm`（`view-menu`） | 「New/Open in new/Close window」块、「Main/Mode/Focus 图标栏」块各包一层 `(if (qt-gui?))` |

判断前端用的 `qt-gui?` 由 `src/Scheme/L5/glue_widget.lua` 注册（`scm_name = "qt-gui?"`），
在 Qt 与 ImGui 两种构建下都存在；Qt 构建下为 `#t`，ImGui 构建下为 `#f`。故守卫在两种
前端下都安全可求值。

## 如何测试

1. 构建 ImGui 前端（桌面）：`xmake b stem`，运行 `xmake r stem`（或
   `TEXMACS_PATH=… build/macosx/arm64/debug/MoganSTEM`）。
   - 确认菜单栏仅含：File / Edit / Insert / Focus / Format / Document / View（Go / Tools /
     Help 已消失）。
   - File 仅 New / Load / Save。
   - Edit 无 Search recent documents / Preferences。
   - Focus 末尾无 Help。
   - Format 无 Font / Paragraph / Page / Cell / Table / Color（其余如 Indentation / Break /
     Adjust 等保留）。
   - View 无 New window / Open in new window / Close window，且无 Main / Mode / Focus 图标栏
     开关。
2. 构建 Qt 前端：`xmake f --qt_frontend=y && xmake b stem`，确认菜单与改动前完全一致
   （Go / Tools / Help 等仍在，File/Edit/Format/View 内容不变），即守卫未影响 Qt。
3. 代码风格：已执行 `gf fmt --changed-since=main` 格式化所改 `.scm`；括号配平校验通过。

## 备注

- 本次仅做菜单条目的「删除（前端条件化）」，不改动任何菜单项的功能实现，也未做无关重构。
- 被守卫包裹的 Qt 分支代码原样保留，后续若 ImGui 后端补齐对应功能（如文件选择器、偏好
  设置），只需把相应条目移出 `(if (qt-gui?))` 即可恢复在 ImGui 下的显示。
