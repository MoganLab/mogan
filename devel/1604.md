# 1604 英文界面主题按钮首字母大写

## 任务描述

英文界面下，底部焦点工具栏（样式徽标行）中的主题按钮显示为小写的
`theme`，与左侧同样显示在工具栏上的 `Style` 按钮大小写风格不一致，
应显示为 `Theme`。

## 定位

- 该按钮由 `focus-style-extra-icons`（`TeXmacs/progs/generic/document-menu.scm`）
  渲染：`(balloon (eval (basic-theme-name (current-basic-theme))) "Document theme")`。
- `basic-theme-name` 委托 `basic-theme-button-name`
  （`TeXmacs/progs/various/theme-menu.scm`），后者对默认 plain 主题用
  翻译键 `"theme::theme"` 调 `translate`。
- 英文界面下 `from == to == "english"`，`dictionary_rep::translate`
  （`src/System/Language/dictionary.cpp`）不查词典，直接截掉 `::` 及其
  后缀，返回原文 `theme`（小写），这就是截图中小写的来源。
- 相邻的 `Style` 徽标由 `style-menu-name` 做 `upcase-first` 得到，故首字母
  大写。

## What / How

`TeXmacs/progs/various/theme-menu.scm`：`basic-theme-button-name` 对
翻译结果包一层 `upcase-first`，与工具栏上 `style-menu-name` 的大小写
约定保持一致：

- 英文界面：`theme` → `Theme`（任务要求）；非 plain 主题如 `dark` →
  `Dark`，与 `Style` 并列时大小写一致。
- 中文等其他语言：译文首字符不是 ISO 拉丁小写字母（如「主题」「深色」），
  `upcase_first`（lolly）原样返回，不受影响。

`basic-theme-button-name` 的唯一 UI 消费点即该焦点工具栏按钮（菜单里的
主题名走另一个函数 `basic-theme-menu-name`，不受影响），改动范围最小。

## 涉及文件

- `TeXmacs/progs/various/theme-menu.scm`：`basic-theme-button-name`
  增加 `upcase-first`。

## 测试说明

- headless：`xmake b stem` 后，用构建产物加载临时诊断脚本，在英文界面
  下验证 `(basic-theme-button-name "plain")` 返回 `"Theme"`、
  `(basic-theme-button-name "dark")` 返回 `"Dark"`。
- GUI（人工）：英文界面打开文档，底部焦点工具栏中主题按钮显示 `Theme`；
  切换中文界面确认按钮仍显示「主题」。
