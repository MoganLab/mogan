# 222_64 章节编号自定义（支持汉字、字母、罗马数字、带圈数字）

## 功能描述
在章节标题的首选项（小扳手）中添加编号样式选项，支持：
- 阿拉伯数字 (1, 2, 3) - 默认
- 汉字数字 (一, 二, 三)
- 大写罗马数字 (I, II, III)
- 小写罗马数字 (i, ii, iii)
- 大写字母 (A, B, C)
- 小写字母 (a, b, c)
- 带圈数字 (①, ②, ③)

## 修改的文件
1. `TeXmacs/packages/section/section-base.ts` - 添加 `chapter-number-style` 变量和 `the-chapter-formatted` 宏
2. `TeXmacs/packages/section/section-book.ts` - 使用 `the-chapter-formatted` 替代 `the-chapter`
3. `TeXmacs/packages/section/section-generic.ts` - 使用 `the-chapter-formatted` 替代 `the-chapter`
4. `TeXmacs/packages/customize/language/chinese.ts` - 使用 `the-chapter-formatted` 替代 `the-chapter`
5. `TeXmacs/progs/text/text-menu.scm` - 添加编号样式的菜单选项

## 如何测试
1. 清理缓存
2. 插入一个章环境，点击小扳手，看是否有"Number style"分组和7个选项
3. 测试选择不同的编号样式，章节标题应相应变化
4. 测试目录中的章节编号是否也随之变化
5. 测试页眉中的章节编号是否也随之变化

## 2026/03/26

### Why
原先章节编号只能通过修改宏来更改格式，对普通用户不友好。参考PR3033的章节居中功能，提供一个直观的首选项选项来切换编号样式。
