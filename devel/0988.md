# 0988 LLM 对话思考强度选择

## 需求

1. 模型选择菜单中增加「思考强度」子菜单，含低 / 中 / 高三档单选；
2. 模型清单 JSON（`liii_llm_menu.json`）每个模型条目增加思考强度字段
   `thinking_effort`（默认值均为 `"medium"`）；
3. 思考强度的显示规则：第一次对话（尚无任何会话记录）按 JSON 字段来；
   之后的新对话按上一条记录（最近活跃的已有会话）里的思考强度来——
   因此思考强度随会话持久化到 manifest；
4. 发送给 goldfish 子进程的 chat 协议（`%chat` 行 JSON 的 params）增加
   思考强度字段 `thinkingEffort`；goldfish 侧本任务不改（未知字段自然被
   忽略，向后兼容）；
5. AI 操作栏「翻译」自动发送时使用的模型默认改为 deepseek-v4-pro——
   通过清单 JSON 顶层 `translate_model` 字段配置（字段缺失或指向清单外
   模型时回退清单默认模型）。

## 测试方法

1. `xmake b stem` 构建通过；
2. `xmake b qt_chat_model_test && xmake r qt_chat_model_test`：
   清单解析 `thinking_effort` 字段（显式值 / 缺省回退 medium），
   `chat_normalize_thinking_effort` 非法值回退；
3. `xmake b qt_chat_session_test && xmake r qt_chat_session_test`：
   会话思考强度的设置/获取；
4. `xmake b qt_chat_tab_widget_test && xmake r qt_chat_tab_widget_test`：
   思考强度子菜单结构（三项、互斥、选中态、action data）；
5. `xmake r chat-list-test`：manifest 条目构造 / 增量保存 / 加载恢复 /
   旧 manifest 兼容（缺失字段回退 medium）；
6. 手动 GUI 验证：模型菜单出现「思考强度」子菜单且当前档位勾选；切换
   档位后重启应用仍保持；全新安装的首次对话默认「中」；新建第二个对话
   继承上一个对话的档位；AI 操作栏「翻译」进的新会话模型为 V4-Pro。

## What

- 模型菜单新增「思考强度」子菜单（低/中/高，单选勾选态）；
- `ChatModelInfo` 新增 `thinkingEffort`（JSON 字段 `thinking_effort`，
  缺省 medium）；`ChatSession` 新增 `thinkingEffort` 并随 manifest
  持久化（字段名 `thinkingEffort`）；
- 新会话强度初始化：有历史记录取最近活跃记录的强度，否则取清单模型
  的 `thinking_effort`；
- chat 协议 params 增加 `thinkingEffort`；
- 清单 JSON 顶层新增 `translate_model`，AI 翻译会话模型默认
  deepseek-v4-pro。

## Why

- 不同问题需要不同推理深度，强度需可按会话调整并记忆用户最近一次
  选择，减少重复设置；
- 协议字段先行下发，goldfish 侧后续接入时 mogan 无需再改协议；
- 翻译场景质量优先，默认走 v4-pro。

## How

- 强度取值统一为 `"low" | "medium" | "high"`，归一化收敛在写入边界：
  清单解析（`info_from_entry`）、manifest 恢复
  （`qt_chat_tab_restore_session`）、`ChatSessionManager::setThinkingEffort`
  内部各一处，读取侧不再重复校验；
- 菜单：`chat_effort_menu_populate` 在模型菜单底部追加子菜单，
  QActionGroup 互斥；选择结果经顶层 QMenu::triggered 单一路径捕获，
  以 action 的 actionGroup 归属区分模型项/强度项，点击强度项后调
  `onThinkingEffortSelected`（写回会话 + 落 manifest）；
- 持久化链路：`updateManifest` → `chat-persist-update-manifest`
  （rest 参数透传给 `chat-persist-make-entry`，缺省规则只在一处维护）
  → manifest 条目；加载链路 `chat-persist-load-all` →
  `qt-chat-tab-restore-session`（glue 参数 +1）；
- 「上一条记录」由 `ChatSessionManager::firstTitledSessionId` 给出
  （timeIndex_ 降序中第一个有标题的会话，与 firstActiveSessionId /
  findReusableSession 同一扫描模式）；
- 翻译模型：`chat_model_parse_list` 解析清单顶层 `translate_model`，
  `ChatModelStore::translateKey` 在字段缺失或不在清单内时回退
  defaultKey，AI 翻译动作经 `createNewConversation` 使用该 key。
