# [0716] 重构 xmake.lua && 添加 qt_frontend 选项

## What
1. 
重构了 xmake.lua
现在拆分为

- xmake.lua
- xmake/options.lua   (for options)
- xmake/require.lua   (for requires)
- xmake/targets/*.lua (for build targets)

2. 
添加了 qt_frontend 选项，默认为 true，构建 Qt 版本。
同时添加了 qt_frontend 为 false 时的 ImGui 构建逻辑。

## 如何测试
目前只能测试 Qt 构建表现不变
```
xmake b stem
xmake r stem
```
