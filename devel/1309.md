### 3.3 手动测试
启动 Mogan STEM，在文档中点击顶部菜单「插入 -> 自动 -> 参考文献」：
- 弹出统一现代风格的 QML 对话框，自动跟随浅色/深色主题；
- 未选择文件时，预览区提示「此处预览参考文献的格式」；
- 填入不存在的文件时，输入框下方出现红色「文件不存在」提示，主按钮置灰禁用；
- 点击「浏览」按钮选择 `.bib` 文件，预览区即时清晰呈现排版结果，主按钮点亮；
- 第二行中「样式」、「更新缓冲区」两个功能并排舒展，文字与开关对齐美观；
- 移除原先需要用户手动选择的「使用相对路径」开关，系统策略为「能用相对路径就使用相对路径，不能的时候使用绝对路径」；浏览选择文献后自动转为相对路径（跨盘符或未保存文档时保持绝对路径）；
- 切换样式下拉列表（如 `tm-plain`、`tm-alpha` 等），预览即时刷新；
- 点击「插入」完成文献插入。如果当前文档已有参考文献，再次打开会自动进入「修改参考文献」模式，预填已有文件和样式，主按钮对应为「修改」。

## 5 What
1. 使用项目统一的 QML 弹窗体系（`DialogShell` + `atoms` + `run_qml_dialog`）重新实现「插入 -> 自动 -> 参考文献」功能（同时支持已有文献时的「修改参考文献」）。
2. 移除冗余的手动「使用相对路径」开关选项，贯彻「能用相对路径就使用相对路径，不能的时候使用绝对路径」策略（选择文件自动相对化，无法相对时回退绝对路径），第二行简化为「样式」与「更新缓冲区」两栏并排，比例舒展。
3. 替换旧版生硬文案，未选文件时提示「此处预览参考文献的格式」；当文件路径非法或不存在时，在输入框下方及预览区直接展示明确的错误提示（「文件不存在」/「无效的 BibTeX 文件」），并置灰禁用主按钮防止误插入。
4. 解决旧版预览字号过小、阅读局促的问题，光栅化时使用适度放大倍率（`magnification: "1.05"`）与自适应容器宽，条目字号与标号比例协调。
5. 编写 `TeXmacs/tests/python/1309.py` 端到端 UI 自动化测试脚本，基于 pynput 驱动真实 GUI 完成无死角验证。

## 6 Why
1. 原参考文献对话框采用遗留的 Scheme `dialogue-window` / `tm-widget`，排版引擎自绘且控件简陋，无法适配现代主题。
2. 原预览区域文字字号极小，阅读体验差。
3. 原旧版缺少即时错误反馈，非法文件无法在界面上直观感知。
4. 纳入项目统一的 QML 模态弹窗规范，实现一次性提交、清晰的组件分层、键盘操作与深浅主题自适应。

## 7 How
1. **QML 前端 (`Bibliography.qml`)**：
   - 基于 `DialogShell` 构建，第一行放置标签 + 弹性拉伸输入框 + 右侧「浏览」按钮；文件输入框下方放置动态错误提示文本；
   - 第二行水平放置功能项：左侧「样式」下拉框（`EnumCombo`）、右侧「更新缓冲区」开关（`Toggle`），移除了由系统自动决策的「使用相对路径」开关；
   - 底部放置卡片边框预览区（`PreviewPane`）与操作按钮（`DialogButtons`，`primaryEnabled: root.isValidBib`）。
2. **C++ 桥接与接口 (`BibliographyDialogBridge` / `cpp_bibliography_dialog`)**：
   - `BibliographyDialogBridge` 提供 `browse()`（`QFileDialog::getOpenFileName`）、`toRelativePath()`、`toAbsolutePath()` 与 `requestPreview(file, style)`（返回包含有效性、状态、提示与预览图片 data URL 的 `QVariantMap`）。选定文件后自动调用 `toRelativePath` 贯彻策略。
   - `cpp_bibliography_dialog` 经 `run_qml_dialog` 启动模态弹窗，注入多语言标签，提供 `MOGAN_TEST_BIBLIOGRAPHY` 钩子。
3. **Scheme 逻辑与校验 (`bibtex-bib-widgets.scm`)**：
   - 新增 `(bib-has-entries? st)`，精准检查是否包含有效的 `'bib-entry` 语法树节点。
   - 更新 `(bibliography-preview file-str style-str)`，分流空路径、不存在路径、无有效条目与有效文献四种状态，排版时使用适度放大 `"magnification" "1.05"`，经 `(cpp-rasterize-widget ...)` 生成清晰的预览图片并返回状态元组。
   - 更新 `(bibwid-set-url u)` 与 `(open-bibliography-inserter)`：统一按「能相对则相对，不能则绝对」解析存储路径。
4. **测试覆盖**：
   - `tests/Plugins/Qt/qml_load_test.cpp` 中新增 `test_bibliography_loads`。
   - `TeXmacs/tests/python/1309.py` 完整覆盖真实 GUI 下的初始状态断言、非法路径红色错误反馈、浏览选文件、放大预览检验、样式切换及插入文档全流程。
