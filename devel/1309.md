## 5 What
1. 使用项目统一的 QML 弹窗体系（`DialogShell` + `atoms` + `run_qml_dialog`）重新实现「插入 -> 自动 -> 参考文献」功能（同时支持已有文献时的「修改参考文献」）。
2. 移除冗余的手动「使用相对路径」开关选项，贯彻「能用相对路径就使用相对路径，不能的时候使用绝对路径」策略（选择文件自动相对化，无法相对时回退绝对路径），第二行简化为「样式」与「更新缓冲区」两栏并排，比例舒展。
3. 替换旧版生硬文案，未选文件时提示「此处预览参考文献的格式」；当文件路径非法或不存在时，在输入框下方及预览区直接展示明确的错误提示（「文件不存在」/「无效的 BibTeX 文件」），并置灰禁用主按钮防止误插入。
4. 解决旧版预览字号过小、阅读局促的问题，光栅化时使用适度放大倍率（`magnification: "1.05"`）与自适应容器宽，条目字号与标号比例协调。
5. 编写 `TeXmacs/tests/python/1309.py` 端到端 UI 自动化测试脚本，基于 pynput 驱动真实 GUI 完成无死角验证。

## 6 Why
1. 原参考文献对话框采用遗留的 Scheme `dialogue-window` / `tm-widget`，排版引擎自绘且控件简陋，无法适配现代主题。
2. 原预览区域文字字号极小，阅读体验差。
3. 原旧版缺少即时错误反馈，非法文件无法在界面上直观感知。
4. 纳入项目统一的 QML 模态弹窗规范，实现一次性提交、清晰的组件分层、键盘操作与深浅主题自适应。

## 7 How
1. **QML 前端 (`Bibliography.qml`)**：
   - 基于 `DialogShell` 构建，第一行放置标签 + 弹性拉伸输入框 + 右侧「浏览」按钮；文件输入框下方放置动态错误提示文本；
   - 第二行水平放置功能项：左侧「样式」下拉框（`EnumCombo`）、右侧「更新缓冲区」开关（`Toggle`），移除了由系统自动决策的「使用相对路径」开关；
   - 底部放置卡片边框预览区（`PreviewPane`）与操作按钮（`DialogButtons`，`primaryEnabled: root.previewStatus === "valid"`）。
2. **C++ 桥接与接口 (`BibliographyDialogBridge` / `cpp_bibliography_dialog`)**：
   - `BibliographyDialogBridge` 提供 `browse()`（`QFileDialog::getOpenFileName`）、`toRelativePath()` 与 `requestPreview(file, style)`（返回包含状态、提示与预览图片 data URL 的 `QVariantMap`）。选定文件后自动调用 `toRelativePath` 贯彻策略。
   - `cpp_bibliography_dialog` 经 `run_qml_dialog` 启动模态弹窗，注入多语言标签，提供 `MOGAN_TEST_BIBLIOGRAPHY` 钩子。
3. **Scheme 逻辑与校验 (`bibtex-bib-widgets.scm`)**：
   - 新增 `(bib-has-entries? st)`，精准检查是否包含有效的 `'bib-entry` 语法树节点。
   - 更新 `(bibliography-preview file-str style-str)`，分流空路径、不存在路径、无有效条目与有效文献四种状态，排版时使用适度放大 `"magnification" "1.05"`，经 `(cpp-rasterize-widget ...)` 生成清晰的预览图片并返回状态元组。
   - 更新 `(bibwid-set-url u)` 与 `(open-bibliography-inserter)`：统一按「能相对则相对，不能则绝对」解析存储路径。
4. **测试覆盖**：
   - `tests/Plugins/Qt/qml_load_test.cpp` 中新增 `test_bibliography_loads`。
   - `TeXmacs/tests/python/1309.py` 完整覆盖真实 GUI 下的初始状态断言、非法路径红色错误反馈、浏览选文件、放大预览检验、样式切换及插入文档全流程。

## 9 预览区域从图片改为 tmfs 缓冲区（tmfs://aux/bib-preview）

### 9.1 What
1. 参考文献插入/修改工具的预览区域从静态光栅化图片（PNG base64 data URL）改为真实的 `tmfs` 辅助缓冲区（`tmfs://aux/bib-preview`）。
2. 在 QML 弹窗（`Bibliography.qml`）中移除 `PreviewPane` 位图展示，替换为 QQuickItem 占位容器；宿主在预览区覆盖嵌入原生只读 `tmfs` 编辑器视图。
3. 样式下拉框展开时联动隐藏原生预览视图，收起时恢复，避免原生 QWidget 与 QML 浮层层级冲突。

### 9.2 Why
1. 位图预览为静态栅格图，无法选中文本、无法复制文献内容、放大失真，且不具备原生滚动支持。
2. 改为真实的 tmfs 缓冲区后，复用 Mogan 核心排版引擎的实时渲染、原生矢量文字、字体缩放、文本选中复制与平滑滚动。

### 9.3 How
1. **Scheme 侧 (`bibtex-bib-widgets.scm`)**：
   - 参考 `0ebefefe4` 前的实现，恢复/提炼将 bib 格式化为 TeXmacs 树的函数 `(bib-to-tree file-str style-str)`；
   - 检验文件存在性与 `(bib-has-entries?)`，合法时调用 `(bibwid-output-content ...)` 生成 `(document (bib-list ...))` 排版树并返回状态元组。
2. **C++ 宿主与桥接 (`QTMQmlDialog.cpp` / `BibliographyDialogBridge.*`)**：
   - `cpp_bibliography_dialog` 中创建基于 `tmfs://aux/bib-preview` 的嵌入式视图 `texmacs_input_widget`，取出其原生 `QWidget*`；
   - 安装只读事件过滤器 `BibPreviewReadonlyFilter`，放行方向键与复制/全选快捷键，拦截文字输入；
   - 在 QML 场景就绪后通过 `post_setup` 回调将预览 QWidget 挂接并对齐到 QML 占位区域；
   - `requestPreview` 中经 Scheme 解析获取排版树，调用 `set_buffer_tree` 实时刷新该 tmfs 缓冲区；合法时显示控件，非法/空时隐藏控件由 QML 呈现提示；
   - 对话框关闭时安全销毁控件并清理 `tmfs://aux/bib-preview` 缓冲区；
   - 扩展 `is_aux_bib_buffer`，使菜单更新跳过该辅助缓冲区。
3. **QML 前端 (`Bibliography.qml`)**：
   - 移除 `PreviewPane` 与 `previewDataUrl`，保留边框卡片与非合法状态下的矢量文字提示；
   - 增加 `previewPlaceholder` 占位 Item，并在 `isComboOpen` 变化时调用 `bibBridge.setPreviewVisible` 切换可见性。

## 11 修复 tmfs 预览区滚动条无法拖动及初始居中偏移（2026-09-17）

### 11.1 根因分析
1. **模态弹窗内滚动重绘丢帧**：`QTMWidget::scrollContentsBy` 仅调用 `the_gui->force_update()`。而 QML 弹窗以 `QDialog::exec()` 模态运行，是在主事件循环的某次 `qt_gui_rep::update()` 内部调起，`updating` 标志恒为 `true`。此时 `force_update()` 仅置位 `needing_update = true` 并直接返回，不会执行 `repaint_all()`。由于模态循环不退出，主 `update()` 不会返回，导致拖动滚动条或滚轮时画布从不重绘，视觉上表现为滚动条拖动但内容完全不滚动。
2. **QML 异步布局导致几何初始错位**：弹窗创建初期的 `post_setup` 回调中，QML `Column` 尚未完成首轮布局，`previewPlaceholder` 尺寸为初始负值（-56×192）、坐标在 (28, 28)；第 10 节清理误删了 `width/height/x/yChanged` 信号连接，导致原生嵌入控件未能随 QML 布局完成刷新几何，部分情况下被钉死在左上角狭窄区域。
3. **初始光标居中导致首屏从第 3 条文献显示**：排版引擎在载入嵌入式文档后触发光标居中逻辑（`make-cursor-visible`），将 192px 高度的视口中心对齐到第一条文献中间，导致视口初始偏移量为 433px，文献 [1]、[2] 滚出上方视口，首屏从文献 [3] 开始。
4. **配置树解析健壮性缺陷**：`cpp_bibliography_dialog` 曾误按 `N(item) >= 2` 和 `item[0]` 解析 `stree->tree` 后的键值对；但 Scheme `(list 'file ...)` 经 `stree->tree` 后的 label 为键名（`get_label(item)`）、子节点 0 为值（`item[0]`），导致初值未被正确读取。

### 11.2 修复措施
1. **`QTMWidget.cpp`**：在 `QTMWidget::scrollContentsBy` 中增补 `if (tm_widget ()) tm_widget ()->repaint_invalid_regions();`，在滚动事件到来时立即更新 backing store 并上屏，彻底解决模态子事件循环下 `force_update()` 被 `updating == true` 拦截不重绘的问题。
2. **`QTMQmlDialog.cpp`**：恢复并强化 `placeholder` 及其父级 `parentItem` 的 `x/y/width/heightChanged` 信号连接，确保 QML 列布局就绪及动态错误提示高度伸缩时，原生预览控件几何实时与占位区域精准贴合；按 `get_label` 规范重构 `config` 解析。
3. **`BibliographyDialogBridge.cpp`**：在载入有效 bib 排版树后显式重置 `editor->setOrigin(QPoint(0, 0))` 与 `vsb->setValue(0)`，确保预览无论条目多少，始终从第 [1] 条文献开始从顶端优雅呈现。
4. **测试覆盖**：更新 `TeXmacs/tests/python/1309.py` 端到端测试，改用多条目文献 `204_22.bib`，增加 Step 7.1 自动拖动预览滚动条并对比视口像素差（`diff > 5.0`），确保拖动滚动真实有效、不再回归。

### 12.3 跳过项（附理由）
1. **用光标定位替代 50ms 定时器滚动复位**（altitude 根因方案）：定时器是在与排版引擎异步
   `make-cursor-visible` 竞速，理论上可改为排版后置光标于文首；但涉及编辑器光标语义，
   无 GUI 验证手段，保留现状（e2e 测试 1309.py 已覆盖首屏偏移回归）。
2. **`qt_gui` 嵌套 `update()` 的深层重绘修复**：模态循环下非滚动类重绘（如方向键移动光标）
   仍会饿死，根治需在 `qt_gui_rep::update()` 嵌套分支只跑 `repaint_all()`——跨任务改动，仅报告。
3. **`QTimer::singleShot` 裸指针捕获改 `QPointer`**：bridge 在 `exec()` 返回后同步 `delete`，
   期间无事件处理，定时器不可能在 editor 销毁后触发，当前安全。
4. 跨任务重复（`bib_preview_style` vs `chat_embedded_style`、`BibPreviewReadonlyFilter` vs
   chat 只读过滤、`is_aux_*_buffer` 五份复制）维持第 10.3 节记录，不在本分支修改。
