# [0656] 在普通用户菜单中隐藏 Scheme 会话，开发工具开启时仍可使用

## 测试目标

验证默认情况下，内置的 **Scheme** 会话不会出现在以下两个菜单中：

- `插入 → 会话`（`Insert → Session`）
- `插入 → 折叠 → 可执行`（`Insert → Fold → Executable`）

当开启 `工具 → 开发工具`（`Tools → Developer tool`）后，上述菜单中应能重新看到并插入 Scheme 会话。

## 相关变更

涉及文件：

- `TeXmacs/progs/dynamic/session-menu.scm`
- `TeXmacs/progs/dynamic/fold-menu.scm`

核心逻辑：

- `insert-session-menu` 中的显式 `"Scheme"` 项及其分隔线被包裹在 `(when (with-developer-tool?) ...)` 中。
- `supported-executable-menu` 的循环体中增加了过滤条件：当 `name == "scheme"` 且 `developer tool` 未开启时跳过该项。

## 测试环境

- 操作系统：macOS / Linux / Windows（任意支持 `xmake run stem` 的平台）
- 构建目标：`stem`
- 语言环境：中文或英文界面均可

## 前置条件

1. 代码已构建通过：
   ```bash
   xmake build stem
   ```
2. 启动应用：
   ```bash
   xmake run stem
   ```
3. 确保 `工具 → 开发工具` 默认处于关闭状态（即首次启动或重置配置后）。

## 测试步骤

### 步骤 1：默认隐藏 Scheme

1. 启动 Mogan STEM。
2. 点击顶部菜单 `插入 → 会话`。
3. 观察菜单列表：
   - **预期结果**：列表中**不包含** `Scheme` 项。
4. 点击顶部菜单 `插入 → 折叠 → 可执行`。
5. 观察菜单列表：
   - **预期结果**：列表中**不包含** `Scheme` 项。

### 步骤 2：开启开发工具后显示 Scheme

1. 点击顶部菜单 `工具 → 开发工具`（`Tools → Developer tool`），将其切换为开启状态。
2. 再次点击 `插入 → 会话`。
3. 观察菜单列表：
   - **预期结果**：列表中**包含** `Scheme` 项，且点击后能插入 Scheme 会话。
4. 再次点击 `插入 → 折叠 → 可执行`。
5. 观察菜单列表：
   - **预期结果**：列表中**包含** `Scheme` 项，且点击后能插入 Scheme 可执行折叠。

### 步骤 3：关闭开发工具后再次隐藏

1. 再次点击 `工具 → 开发工具`，将其切换为关闭状态。
2. 检查 `插入 → 会话` 和 `插入 → 折叠 → 可执行`。
3. **预期结果**：`Scheme` 项再次从两个菜单中消失。

### 步骤 4：回归验证

1. 打开或新建一个包含已有 Scheme 会话的文档。
2. **预期结果**：已有 Scheme 会话仍可正常编辑、求值；未受影响。

## 实际结果

- 默认状态下，`插入 → 会话` 和 `插入 → 折叠 → 可执行` 中均不显示 `Scheme`。
- 开启 `工具 → 开发工具` 后，两个菜单中均出现 `Scheme`，且可正常插入。
- 关闭 `工具 → 开发工具` 后，`Scheme` 再次隐藏。
- 已有 Scheme 会话文档可正常编辑。

**测试结论：通过。**
