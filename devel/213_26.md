# GSoC 2026: Julia Plugin with Virtual Environment Support

## Overview

This document outlines the design and implementation plan for the
Julia Plugin with Virtual Environment Support for Mogan STEM,
proposed as part of Google Summer of Code 2026.

The goal is to build a robust Julia plugin that executes Julia code
inside Mogan documents and manages Julia project environments
(Project.toml), similar to Jupyter Notebook but with thesis-level
editing support.

## Motivation

Mogan STEM is a powerful scientific writing platform, but its Julia
integration is currently limited. Scientists and students who use
Julia for computation need:

- Execute Julia code snippets directly inside documents
- Manage Julia package environments per document
- Copy mathematical expressions between Mogan and Julia seamlessly
- Reproduce computations using Project.toml dependencies

## Architecture

### Components

1. **Julia Session Manager**
   - Starts and manages a persistent Julia process
   - Communicates via stdin/stdout or Julia socket server
   - Handles session lifecycle (start, restart, stop)

2. **Package Environment Manager**
   - Detects and activates Project.toml environments
   - Integrates with Julia Pkg manager
   - Resolves and loads dependencies automatically

3. **Mogan-Julia Bridge**
   - Converts Mogan math expressions to Julia syntax
   - Converts Julia output back to Mogan format
   - Supports matrix and formula copy-paste

4. **Scheme Plugin Interface**
   - Integrates with Mogan existing plugin API
   - Handles input/output rendering in documents

## Implementation Plan

### Phase 1: Basic Julia Execution (Weeks 1-4)
- Set up Julia process communication
- Execute basic Julia code snippets in documents
- Display text output and errors in document

### Phase 2: Virtual Environment Support (Weeks 5-8)
- Detect Project.toml in document directory
- Activate Julia environments using Pkg.activate()
- Install and load dependencies from Project.toml
- Show environment status in document toolbar

### Phase 3: Mogan-Julia Math Bridge (Weeks 9-10)
- Parse Mogan math expressions to Julia syntax
- Convert Julia matrix output to Mogan format
- Support copy-paste between math mode and Julia session

### Phase 4: Testing and Documentation (Weeks 11-12)
- Write unit tests for all components
- Write integration tests with sample documents
- Write user documentation and examples

- progs/: Plugin integration with TeXmacs/Mogan API

## Technical Challenges

1. **Process Communication**: Julia startup time is slow.
   Solution: Keep persistent Julia session alive between evaluations.

2. **Environment Isolation**: Different documents may need different
   Julia environments.
   Solution: Activate environments per document using Pkg.activate().

3. **Math Conversion**: Mogan uses TeXmacs tree format internally.
   Solution: Write a converter between TeXmacs trees and Julia syntax.

4. **Error Handling**: Julia errors must be displayed clearly.
   Solution: Capture stderr and format errors in document output.

## Expected Outcomes

1. Functional Julia plugin that executes code in Mogan documents
2. Virtual environment support via Project.toml integration
3. Math copy-paste between Mogan math mode and Julia session
4. Full test coverage and user documentation
