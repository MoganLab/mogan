## 5 What

删除 `liii.css` 与 `liii-night.css` 中 `QLabel#login-membership-title`、`QLabel#login-membership-period` 两个选择器里的 `display: block;` 属性（每文件 2 处，共 4 处），消除运行时 Qt 样式表解析器打印的 `Unknown property display` 警告。

## 6 Why

运行时终端反复出现 `Unknown property display`。该串在 mogan 源码里 grep 不到，说明它来自外部库：

- 这条警告由 **Qt 的 QSS 解析器 `QCss::Parser`** 在解析样式表时发出。Qt 样式表只支持一个很小的 CSS 属性子集，`display` 不在其中，解析器遇到即打印 `Unknown property <name>` 并忽略该属性。
- 这两个主题 css 文件由 `qt_utilities.cpp:init_style_sheet` 在启动时从 `$TEXMACS_THEME_PATH`/`$TEXMACS_PATH` 读出字符串，再 `app->setStyleSheet()` 全局设置——不是硬编码在 C++ 里，所以表现为运行时警告而非编译期问题。
- 作者按标准 CSS 习惯为 `QLabel` 写了 `display: block;`，但 Qt 样式表不支持该属性，故每次解析全局样式表都会报警告。

对 `QLabel` 而言它本就是块级行为，`display: block` 在 Qt 里既无效也无意义，直接删除即可，外观不受影响。

## 7 How

### 7.1 根因定位

1. 先确认告警来源：mogan 源码内 grep `Unknown property` / `display:` 均无 QSS 命中，排除自写代码。
2. 通过 Qt 文档确认 `Unknown property <name>` 是 QSS 解析器对不支持属性的统一告警格式。
3. 定位全局样式表入口：`src/Plugins/Qt/qt_utilities.cpp` 的 `init_style_sheet` 从 `tm_style_sheet` 指定的 css 文件读取并 `app->setStyleSheet`。
4. grep 主题 css 文件，命中 `liii.css:692/701`、`liii-night.css:734/743` 共 4 处 `display: block;`，所在选择器均为 Qt 控件（`QLabel#...`），确认即告警源。

### 7.2 修复

删除这 4 处 `display: block;`。`build/packages/stem/data/misc/themes/` 下是构建期拷贝副本，重新 `xmake b stem` 会从源文件覆盖，无需手动改。
