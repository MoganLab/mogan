# [0756] 协同编辑模块
## What
- 添加了 Plugins/Collab 模块，用于管理协同编辑与服务器的通信
- 在 Editor 模块中添加了与 Collab 通信的代码。在 LORO_ENABLED 时编译。
- 添加了 tm-collab.scm 用于 Scheme 中实现 Collab 功能。
- 在 loro-enabled? 为 #t 时添加了`File` 菜单下的子菜单，用于协同编辑
- 在 tm_debug 中添加了协同编辑相关 debug 通道。

## 如何测试
测试构建
```
xmake f -c --loro=yes
xmake b stem
xmake r stem
```

测试 Editor-Collab-Server 的通信
```
node tools/loro-server/server.js
xmake r 0759_collab
```

测试协同编辑功能
```
终端1: node tools/loro-server/server.js

终端2: xmake r stem
File -> Collaborative -> New shared document
记住 uuid （在 tabpage 处）
进行编辑

终端3: xmake r stem
File -> Collaborative -> Join shared document -> refresh
File -> Collaborative -> Join shared document -> (uuid)

Note: 如果终端2没有编辑操作，那么可能会弹一个 Warning.
```
