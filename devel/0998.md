## 3 如何测试

### 3.1 自动化测试
```bash
xmake b stem && xmake r preferences-widgets-test
```
测试输出应显示所有断言通过，无失败。

### 3.2 手动测试

#### 测试场景 1：思考强度英文首字母大写
1. 启动 Mogan STEM：
   ```bash
   xmake r stem
   ```
2. 将界面语言切换为英文，打开 AI Chat 侧边栏，点击模型选择按钮；
3. **预期结果**：思考强度子菜单标题为 `Thinking effort`，三档选项为 `Low effort` / `Medium effort` / `High effort`（首字母均大写）。

#### 测试场景 2：幽灵文本补全挪入 AI 标签页
1. 打开 `首选项`（Preferences）对话框；
2. **预期结果**：`其他`（Other）标签页下不再有 `幽灵文本补全`（Ghost text）选项；`AI` 标签页下出现该开关，且开关状态与原设置一致、可正常切换并生效。

## 5 What
1. AI Chat 思考强度菜单的英文文案 `thinking effort` / `low effort` / `medium effort` / `high effort` 首字母大写为 `Thinking effort` / `Low effort` / `Medium effort` / `High effort`；
2. 首选项 `其他`（Other）标签页下的 `幽灵文本补全`（Ghost text）开关挪到 `AI` 标签页下。

## 6 Why
1. 思考强度菜单英文文案未首字母大写，与界面其他菜单项的书写习惯不一致；
2. 幽灵文本补全是 AI 能力，放在 `其他` 标签页的实验特性里不易发现，归入 `AI` 标签页更符合用户心智。

## 7 How
1. 修改 `src/Plugins/Qt/qt_chat_tab_widget.cpp`：`chat_effort_menu_populate` 中子菜单标题与三档 label 的英文源串首字母大写（存储值 `low`/`medium`/`high` 不变，仅展示文案变化）；
2. 修改 `TeXmacs/plugins/lang/dic/en_US/zh_CN.scm`：四条 effort 词条的英文键同步大写，保证翻译查找命中（词典按大小写不敏感字母序排列，原位修改即可）；
3. 修改 `TeXmacs/progs/texmacs/menus/preferences-widgets.scm`：
   - 在 `preferences-qml-ai-fields` 末尾追加 `(pref-ai-ghost-text) "Ghost text"` 字段；AI 主 tab 整体已在 `community-stem?` 下隐藏，故不再需要字段级的社区版判断；
   - 从 `preferences-qml-other-experimental-fields` 中删除 ghost text 条件分支，并把不再需要的 `append` 简化回普通 `list`；
4. 修改 `TeXmacs/progs/kernel/texmacs/pref-keys.scm`：访问器 `pref-experimental-ghost-text` 更名 `pref-ai-ghost-text` 并移入 AI tab 小节（存储键 `"ghost text"` 不变，无首选项迁移）；同步更新 `ghost-text.scm` 中「实验选项」的过时注释；
4. 修改 `TeXmacs/progs/texmacs/menus/tests/preferences-widgets-test.scm`：
   - `test-meta-field-counts`：AI tab 字段数 3 → 4，Other tab 去掉 ghost text 的社区版条件计数；
   - `test-ai-tab-fields`：字段数断言 3 → 4，新增 Ghost text toggle 的存在性、kind 与 label 断言。
