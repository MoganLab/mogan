# [203_27] Fix LaTeX export crash on empty macros (#1621)

## 2026/03/31 Prevent LaTeX export crash on empty macros in preamble

### What
Fixed a bug where exporting a document with an empty macro definition (e.g., `<assign||<macro|>>`) in the preamble causes a silent export failure.

### Why
The `collect-user-defs-sub` function in `tmtex.scm` was blindly passing the macro name to `string->symbol`. When the macro name is empty (`""`), it causes a fatal memory/parsing error in stricter Scheme environments (such as macOS).

### How
Added a string length validation check `(> (string-length (cadr t)) 0)` inside the `cond` block of `collect-user-defs-sub`. This ensures the parser safely ignores blank macro definitions before attempting to convert them to symbols.
