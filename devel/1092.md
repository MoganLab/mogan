# [1092] 修复 Windows 上 autosave 插件无法触发本地备份

任务编号：1092。PR #3734 合入后，Linux/macOS 上 autosave 插件能正常生成 `$TEXMACS_HOME_PATH/system/backup/<doc-id>/<yyyymmdd>_<hhmmss>.tmu`，但 Windows 上不产生任何备份文件。本期共发现三层独立 bug，全部修完后端到端打通：

1. **goldfish `(liii path)` 在 Windows 上只识别 `\`**：`parse-windows-path` 与 `path-parent` 不识别 `/`，对 `(port-filename)` 返回的正斜杠绝对路径解析错误，`tm-autosave.scm` 顶部扩展 `*load-path*` 失败、`(import (liii autosave))` 找不到模块，插件进程握手前即崩溃
2. **主进程 `auto-backup-buffer-path` 自行拼路径产出畸形串**：原实现走 `url->stree` → `auto-backup-url-stree->path` → `path-from-string` → `path->string`，在 Windows 上把 `file:/C:/...` 风格的 url 拼成 `\\C\Users\...\foo.tmu`（前导双反斜杠、盘符丢冒号），插件端 `file-exists?` 找不到源文件，日志记录 `autosave copy skipped: source missing`
3. **`autosave-log` 写日志路径硬编码 `/tmp/debug.log`**：Windows 上 `/tmp` 不存在，`tb_file_init` 用 `CREAT` 模式不创建父目录，所有日志写入失败，前两层 bug 期间完全看不到原因

## 5 What
1. 内嵌 `TeXmacs/plugins/goldfish/goldfish/liii/path.scm` 两处函数修复（与 goldfish 上游 1004 完全一致）：
   - `parse-windows-path`：进入 split 前先把 `/` 替换为 `\`，使带正斜杠的 Windows 绝对路径（如 `C:/Users/.../foo.scm`）能正确切分为 parts
   - `path-parent`：string 输入分支同样在 Windows 上做 `/` → `\` 归一化
2. `tm-files.scm` 的 `auto-backup-buffer-path` 改为 `(url->system name)`，删除三个 stree→path 辅助函数。这是修第 2 层 bug 的核心改动，单独修 goldfish path 不能解决——主进程送进 payload 的 `path` 字段在源头就是错的
3. `tm-autosave.scm` 的 `autosave-log` 改为用 `path-temp-dir` 取跨平台日志目录。这层不影响功能（写日志失败本来就被吞掉），但调试时看不到任何错误信息会让人误以为「插件没启动」

## 6 Why

### 6.1 为什么 Linux/macOS 上一直没暴露
- goldfish 默认 `*load-path*`、cwd、`(port-filename)` 在 POSIX 平台恰好凑出正确目录，第 1 层 bug 不会触发
- POSIX 路径 root 是 `/`、`path-root` 也是 `/`，第 2 层 bug 走 `auto-backup-url-stree->path` 拼出来的就是合法 POSIX 绝对路径，`file-exists?` 能找到
- `/tmp` 在 Linux/macOS 上存在，第 3 层 bug 不存在
- 三层 bug 全部只在 Windows 上同时暴露，是一个典型的「跨平台脚本只在 Linux 上验证」的案例

### 6.2 为什么用 `url->system` 而不是修 stree→path
`url->system` 是 mogan url 系统的官方 API，已在 `tm-files.scm` 中被多处使用（行 85、95、326、374、426、485、568、623、814 等），直接返回当前平台的系统路径。原 `auto-backup-buffer-path` 自己又写了一套 `url->stree` → path 拼接是过度设计，且：
- 跨平台行为不一致（POSIX 路径 root 是 `/`、Windows 上 url 的 root 语义不同）
- 绕过了 url 系统已有的转义/盘符处理逻辑
- 实现复杂度高（三个辅助函数），出错点更多

删掉自造的转换链，统一走 `url->system`，代码净减约 40 行，行为更可预测。

## 7 How

### 7.1 goldfish path 模块修复（详见 goldfish 1004）
mogan 内嵌一份 goldfish 源码（`TeXmacs/plugins/goldfish/goldfish/liii/path.scm`），运行时加载自己这份 .scm，所以需要把 goldfish 上游的修复同步过来。两边代码字节级一致。

### 7.2 `auto-backup-buffer-path` 简化
```scheme
;; Before:
(define (auto-backup-buffer-path name)
  (catch #t
    (lambda ()
      (path->string (path-from-string (auto-backup-url-stree->path (url->stree name))))
    ) ;lambda
    (lambda args "untitled")
  ) ;catch
) ;define

;; After:
(define (auto-backup-buffer-path name)
  (catch #t
    (lambda ()
      (url->system name)
    ) ;lambda
    (lambda args "untitled")
  ) ;catch
) ;define
```

`auto-backup-url-stree-tag`、`auto-backup-url-stree-ref`、`auto-backup-url-stree->path` 三个函数仅被原 `auto-backup-buffer-path` 调用，一并删除。

### 7.3 `autosave-log` 跨平台日志路径
```scheme
;; Before:
(define (autosave-log message)
  (path-append-text "/tmp/debug.log" (string-append message "\n"))
) ;define

;; After:
(define (autosave-log-path)
  (path->string (path-join (path-temp-dir) "mogan-autosave-debug.log"))
) ;define

(define (autosave-log message)
  (path-append-text (autosave-log-path) (string-append message "\n"))
) ;define
```

`path-temp-dir` 在 Windows 上返回 `%TEMP%`、POSIX 上返回 `/tmp`，跨平台一致。
