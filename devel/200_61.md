# 200_61 魔法粘贴埋点与调试日志

## 如何测试

1. 编译：`xmake b stem`
2. 启动 Mogan，打开任意文档。
3. 分别在以下场景触发魔法粘贴（`Ctrl+Shift+V` / `编辑 -> 智能粘贴`）：
   - 剪贴板为图像时触发 OCR 粘贴
   - 代码模式（`prog`）下粘贴代码
   - 数学模式（`math`）下粘贴公式
   - 文本模式下粘贴普通内容
4. 查看终端/控制台输出，确认出现 `[telemetry] track: MAGIC_PASTE props=...` 的 `qDebug` 日志，且 `mode` 分别为 `image` / `prog` / `math` / `text`。
5. 非社区版（`!IS_COMMUNITY`）编译时，确认日志正常输出；社区版编译时，确认无日志输出且无编译错误。

## 2026/05/06 实现说明

### What

为魔法粘贴（Magic Paste）功能增加统一埋点，并在 C++ 底层增加 `qDebug` 调试日志，同时去除 Scheme 层的重复日志。

#### 修改文件

**TeXmacs/progs/generic/generic-edit.scm**
- 模块 `:use` 中新增 `(telemetry telemetry-track)`，引入 `track-event`。
- `kbd-magic-paste` 四个分支（image / prog / math / text）分别调用 `(track-event "MAGIC_PASTE" '(("mode" . "xxx")))` 上报事件。

**src/Mogan/Telemetry/telemetry.hpp**
- 新增 `#include <QDebug>`。
- `telemetry_track` 两个重载内增加 `qDebug() << "[telemetry] track:" << ...` 输出事件名和属性，便于开发调试。

**TeXmacs/progs/telemetry/telemetry-track.scm**
- 移除 `track-event` 内先前添加的 `(display ...)` 日志，避免与 C++ 层重复输出。

### Why

1. **数据需求**：魔法粘贴是 Mogan 的核心卖点之一，需要追踪用户实际使用频率和模式分布（image/prog/math/text）。
2. **统一日志入口**：C++ 的 `telemetry_track` 是所有埋点的最终 C++ 入口，在此加 `qDebug` 可覆盖 Scheme 和 C++ 两端的调用，无需在每个调用点重复加日志。
3. **避免重复输出**：`telemetry_track` 底层会调用 Scheme 的 `track-event`，若两边都加 `display`/`qDebug`，同一事件会打印两次。

### How

- 在 `generic-edit.scm` 的 `kbd-magic-paste` 主分支处埋点，根据实际进入的粘贴模式带上不同的 `mode` 属性。
- C++ 层统一在 `telemetry_track` 内输出 `qDebug`，利用 `string.begin()` 适配 `qDebug` 的 `char*` 重载。
- Scheme 层 `track-event` 保持精简，仅负责事件入队与阈值刷新，不再负责日志输出。
