## What
将 `utf8_to_herk` 与 `herk_to_utf8` 从依赖 `load_converter("...", "Hex-Cork")` 的实现，改为基于硬编码映射表的直接实现：

1. **移除 Hex-Cork 转换器加载路径**：`converter_rep::load()` 中不再加载 `herktounicode.scm`。
2. **硬编码映射表**：
   - `herk_to_utf8_code[256]`：Herk 字节到 Unicode 码点。
   - `utf8_to_herk_byte[256]`：Unicode 码点 0x00..0xFF 到 Herk 字节。
   - `utf8_to_herk_high[88][2]`：Unicode 码点 0x0100 及以上到 Herk 字节，按码点排序以便二分查找。
3. **优化实现**：
   - `herk_to_utf8` 直接按字节查表并内联输出 UTF-8 编码，避免每次调用 `encode_as_utf8` 构造临时字符串。
   - `utf8_to_herk` 解码 UTF-8 后查表，无映射时生成 `<#XXXX>` 转义。

## Why
Herk 编码是 TMU 序列化的核心编码，其转换正确性直接影响文档的读写一致性。
此前实现依赖 `TeXmacs/langs/encoding/herktounicode.scm` 文件，在打包、分发或最小化安装场景下可能缺失，导致转换器加载失败。
将映射表硬编码到 C++ 后，函数自包含、不依赖外部文件，同时消除了加载和构建 hashtree 的开销。

## How
1. 在 `src/Data/String/converter.cpp` 顶部添加三个静态映射表和一个二分查找辅助函数。
2. 重写 `utf8_to_herk` 与 `herk_to_utf8`，仅使用静态表完成转换。
3. 从 `converter_rep::load()` 中删除 `Hex-Cork` 相关分支。
4. 保留 `tests/Data/String/converter_test.cpp` 中已有的完整单元测试作为回归验证。
5. 将 `utf8_to_herk` 与 `herk_to_utf8` 的实现迁移到 `lolly/lolly/data/herk.cpp`，
   在 `lolly::data` 命名空间中提供相同签名的函数；`src/Data/String/converter.cpp`
   保留为对 `lolly::data` 的薄封装，保持现有 C++ 调用点不变。
6. 将对应的 Scheme glue（`utf8->herk`、`herk->utf8`）从 `glue_moebius.lua`
   迁移到 `glue_lolly.lua`，使其绑定到 `lolly::data::utf8_to_herk` 与
   `lolly::data::herk_to_utf8`。
7. 在 `lolly/tests/lolly/data/herk_test.cpp` 中添加针对 lolly 实现的单元测试。

## releasedbg 模式自动启用 enable_tests

### What
让 lolly 在 `-m releasedbg` 下自动启用测试,无需 CI 显式传 `--enable_tests=true`。

### Why
此前 3 个 CI(`ci-debian13`、`ci-xmake-windows`、`ci-macos-arm64`)的 lolly config 步骤
都要手写 `--enable_tests=true`,而 mogan config 步骤又不带该 flag——
两条路径 config 命令不一致。releasedbg 本就是带符号的优化构建(CI/开发主用模式),
默认开测试合理,统一默认值后 config 命令可以一致。

### How
- 不用 `set_default(is_mode(...))`:option 的 default 求值早于 mode 确定,
  实测 `is_mode("releasedbg")` 在该点恒返回 false。
- 改为在两处使用点(`add_requires` 段、`lolly_test_dynamic_library` 等 target 段)
  把 `has_config("enable_tests")` 改成 `has_config("enable_tests") or is_mode("releasedbg")`。
  这两处在文件作用域求值,mode 已确定。
- 同步删除 3 个 CI 中冗余的 `--enable_tests=true`。
- 验证:releasedbg(无 flag)拉入 `liii-doctest`/`nanobench`;release 不拉。
