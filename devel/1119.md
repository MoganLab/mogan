### 转换约定

- `(import (liii check))` + `(check-set-mode! 'report-failed)`
- 每个 `(test "desc" input expected)` 改写为 `(check (result-cmd input) => expected)`
- `(test-fails "desc" input expected)` 转为对 `(not (equal? ...))` 的 `check` 断言
- 入口 `regtest-*`/`test_*` 移除计数返回值与 `Total: N tests.` 输出，统一在末尾调用 `(check-report)`

## 2 2026/06/28 移除 regression-test-group 框架

1119 迁移全部完成后，`regression-test-group` 宏及其辅助函数已无任何调用方
（grep 全仓零引用）。从 `TeXmacs/progs/kernel/boot/debug.scm` 移除：

- `regression-test-equal`、`regression-test-nequal`：仅在宏内部使用的断言辅助
- `regression-test-group`：测试分组宏本身
- `regtest-table-library`：表格简写宏，其导出的 `cell`/`row`/`table`/`tformat`/
  `colwith`/`rowwith`/`allwith` 也无人使用

### Why
框架已被 `(liii check)` 替代，留着只会让维护者误以为仍是推荐入口。

### How to apply
后续新测试一律用 `(import (liii check))` + `check-set-mode!` + `check`/`check-report`。
若看到旧代码里残留 `regression-test-group` 或 `regtest-*`，按本文档「转换约定」改写。
