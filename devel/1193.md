## 任务 4：bash 插件

### What

bash 插件的三个模块一级模块名从 `code` 改为 `bash`：
`(code bash-edit|bash-lang|bash-mode)` → `(bash bash-edit|bash-lang|bash-mode)`。

### Why

插件内模块的一级命名空间从共享的 `code` 改为插件专属的 `bash`，缩小
`use-modules` 查找模块时的搜索范围——`(bash bash-edit)` 只需在 load path
上查找 `bash/bash-edit.scm`，只有 bash 插件有该目录，而非 `(code bash-edit)`
需要在每个插件（18+）的 `progs/code/` 子目录下逐一查找。

### How

- 模块文件迁移：`TeXmacs/plugins/bash/progs/code/` → `TeXmacs/plugins/bash/progs/bash/`
- `texmacs-module` 声明及模块间 `:use` 同步改一级名
- `bash.ts` 的 `<use-module>` 更新
- C++ 侧双路径兼容：
  - `prog_lang_exists` 新增 `plugins/<s>/progs/<s>/<s>-lang.scm` 路径检查
  - `prog_language_rep` 构造器先用 `(catch ...)` 尝试 `<name> <name>-lang>`，
    回退到 `(code <name>-lang)`，保证其他未迁移语言不受影响

### 涉及文件

- `TeXmacs/plugins/bash/progs/bash/bash-edit.scm`（rename + edit）
- `TeXmacs/plugins/bash/progs/bash/bash-lang.scm`（rename + edit）
- `TeXmacs/plugins/bash/progs/bash/bash-mode.scm`（rename + edit）
- `TeXmacs/plugins/bash/packages/code/bash.ts`
- `src/System/Language/prog_language.cpp`

## 任务 3：comment 插件

### What

comment 插件的四个模块一级模块名从 `various` 改为 `comment`：
`(various comment-drd|comment-edit|comment-menu|comment-widgets)`
→ `(comment comment-drd|comment-edit|comment-menu|comment-widgets)`。

### Why

插件内模块命名规范：必须以插件名开头。`(various comment-*)` 占据 various
命名空间，违反规范。

### How

- 模块文件迁移：`TeXmacs/plugins/comment/progs/various/`
  → `TeXmacs/plugins/comment/progs/comment/`，
  `texmacs-module` 声明及模块间 `:use` 同步改一级名
- 更新全部引用：
  - `TeXmacs/plugins/comment/packages/utilities/comment.ts` 的 `<use-module>`
  - `TeXmacs/progs/text/text-menu.scm` 的 `:use`
  - `TeXmacs/plugins/keyboard/progs/keyboard/text-kbd-utf8.scm` 的 `:use`
  - `TeXmacs/progs/kernel/texmacs/tm-secure.scm` 的 `lazy-define`

## 任务 2：autosave 插件

### What

autosave 插件的模块从 `(plugin autosave)` / `(plugin autosave-impl)` 合并改名为
`(autosave plugin)`。

### Why

插件内模块命名规范：必须以插件名开头。`(plugin autosave)` 占据 plugin 命名空间，
违反规范。原 entry/impl 双模块拆分是为规避 use-modules 直载模块含 `(import ...)`
的问题，account 插件（任务 1）已验证单模块内直接用 import 可行，故合并为单模块。

### How

- 模块文件迁移合并：`progs/plugin/autosave.scm` + `progs/plugin/autosave-impl.scm`
  → `TeXmacs/plugins/autosave/progs/autosave/plugin.scm`，
  `texmacs-module` 声明改为 `(autosave plugin)`，删除 `progs/plugin/` 目录
- 更新全部引用：
  - `TeXmacs/plugins/autosave/progs/init-autosave.scm`
  - `TeXmacs/progs/texmacs/menus/preferences-tools.scm`
  - `TeXmacs/progs/texmacs/menus/preferences-menu.scm`
  - `TeXmacs/progs/texmacs/menus/preferences-widgets.scm`
  - `TeXmacs/progs/texmacs/texmacs/tm-server.scm`
  - `TeXmacs/progs/texmacs/texmacs/tm-files-test.scm`
