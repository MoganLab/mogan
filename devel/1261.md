# [1261] 头像按钮悬浮即显示个人页

## 1 任务背景（What/Why）

商业版主窗口标题栏右上角的头像按钮（`QWK::LoginButton`，User Center）原来需要
**点击**才弹出个人页（登录/账户信息弹窗 `QWK::LoginDialog`）。本次改为**鼠标悬浮
即显示**，点击行为保留（悬浮已弹出时点击等效于原来的切换关闭），社区版不受影响
（无个人页，仍为点击跳转官网）。

## 2 实现方式（How）

- 新增 `LoginDialogHoverWatcher`（定义于 `qt_tm_widget.cpp`，仿照
  `InviteBtnResizeWatcher` 的看护对象模式）：监听头像按钮的 `QEvent::Enter`，
  触发 `qt_tm_widget_rep::showLoginDialogOnHover ()`。
- 新增 `showLoginDialogOnHover ()`：与点击路径（`checkLocalTokenAndLogin`）的差异是
  不切换显隐、不隐藏小红点；悬浮要求即时响应，有缓存 token 时先按已有内容**立即**
  显示（启动时 `refreshMembershipInfoInBackground` 已预取过用户信息），同时
  `fetchUserInfo (token, false)` 后台拉取，数据到位后经 `updateDialogContent`
  原位更新。
- **隐藏判定用光标轮询而非 Leave 事件**：弹窗是 `Qt::Popup`，显示后会抓取鼠标，
  按钮与弹窗的 Enter/Leave 事件此后不可靠。看护对象以 200ms 轮询
  `QCursor::pos ()`，连续两轮（400ms）都不在按钮与弹窗范围内才隐藏，避免鼠标
  穿过两者之间空隙时被误关。
- 点击打开的弹窗不启动轮询，维持原有「外部点击关闭」行为不变。

## 3 涉及文件

- `src/Plugins/Qt/qt_tm_widget.hpp` — 前置声明、成员 `loginHoverWatcher`、
  方法声明 `showLoginDialogOnHover ()`、`friend class LoginDialogHoverWatcher`
  （看护对象定义在成员函数外，需 friend 访问私有方法）。
- `src/Plugins/Qt/qt_tm_widget.cpp` — 看护对象类、构造函数接线（仅商业版）、
  `ensureLoginDialog` 登记 `setDialog`、`showLoginDialogOnHover` 实现。

## 4 如何测试

### 4.1 单元测试
暂无（纯 GUI 交互路径）。

### 4.2 手动测试（商业版）

1. 启动后等数秒（后台预取用户信息完成），鼠标悬浮右上角头像按钮 → 个人页
   立即弹出，内容为已缓存的账户信息，随后自动刷新为最新数据。
2. 鼠标从按钮移入弹窗 → 弹窗保持显示，可正常点击续费/登出等按钮。
3. 鼠标离开按钮与弹窗范围 → 约 400ms 后弹窗自动关闭。
4. 未登录（无 token）时悬浮 → 立即显示未登录态弹窗（Login 按钮）。
5. 点击头像按钮 → 行为同前（切换显隐）；点击弹窗外部 → 关闭。
6. 社区版：悬浮无反应，点击仍跳转官网。

## 5 已知取舍

- `LoginDialog::showAtRect` 显示时会 `activateWindow ()`（原有行为未改）。理论上
  编辑器正在输入时鼠标扫过标题栏头像会抢一次焦点；发生频率低，如实际感到打扰，
  后续可给 `showAtRect` 增加 `activate` 参数，悬浮路径传 `false`。
