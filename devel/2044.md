## 5 What

把首选项对话框（现有 `preferences-widget` 一套 texmacs `tm-widget`，1249 行）重写为 QML 弹窗 `Preferences.qml`，纳入现有 QML 模态对话框体系。五个主 tab（General / Keyboard / Mathematics / Convert / Other），其中 Convert 下再有六个子 tab（Html / LaTeX / BibTeX / Verbatim / Pdf / Image）。约 40 个 combo（下拉）+ 35 个 toggle（开关）+ 若干 info row（只读，如 updater 最后检查时间）。

1. 新增 `Toggle` 原子（现有 atoms 无 toggle）。
2. 新增 `Preferences.qml` 弹窗：`DialogShell` 外壳，顶部主 `TabBar`，正文按 tab 渲染字段（`Repeater`，delegate 按 `kind` 分支 → `EnumCombo` / `Toggle` / info Text），分组标题、双栏（Math / experimental Other）、条件可见性（semantic editing / latex source-tracking 开关联动）、radio 互斥（mathjax/mathml/images）纯 QML 本地处理。
3. 新增 `PreferencesBridge`（C++↔QML 桥，无状态 `eval_scheme` 透传）。
4. 新增 glue 入口 `cpp_preferences_dialog`（exec 阻塞模态，复用 `run_qml_dialog` + `inject_common_context`）。
5. scheme facade `preferences-qml-meta`（一次性拉全树）/ `-submit`（应用 diff，按需重启字段「先确认再 apply」）/ `-set-field`（统一 setter 按 key 路由副作用）。
6. 改 `open-preferences`：非 side-tools 模式调 `cpp-preferences-dialog`，side-tools 模式仍走旧 `open-preferences-window`（旧 tm-widget body 保留）。
7. QML 加载测试 + scheme 契约测试（`MOGAN_TEST_PREFERENCES` + `MOGAN_TEST_CONFIRM_RESTART`）。

## 6 Why

现有首选项弹窗是 texmacs `tm-widget`（minibuffer 内 widget DSL），与 Qt 主界面的视觉/交互割裂：

- 不能用 Qt 原生下拉/combo，靠 minibuffer 字段输入体验差。
- 分组、联动可见性、radio 互斥依赖 `refreshable` + `refresh-now` 脏刷新，逻辑分散且难调试。
- `assuming` 在 refreshable 内有 FIXME（`refreshable` widget 内 `assuming` 失效，字段可见性不能正确联动——见 `preferences-widgets.scm:345` 注释）。

把弹窗迁到 QML 体系后，所有模态弹窗（确认关闭、表单、字体选择、段落格式、首选项）共享同一套外壳（`DialogShell`）、主题（`Theme`）、下拉浮层、拖动/Esc/Enter 行为，视觉与交互一致；条件可见性/radio 改为 QML 本地 binding，消除 refreshable 机制。

## 7 How

### 提交模型：本地暂存 + OK 一次性提交

仿 `FormDialog.qml`：打开时 `prefBridge.meta()` 一次性拉全部 tab/字段树到 `initialValues`（打开快照），用户改动只改本地 `values` map；OK 时 `changedFields()` 算 diff（仅与打开快照不同的键），`prefBridge.submit(diff)` 一次性应用到 scheme，Cancel 丢弃本地改动。

`run_qml_dialog`（exec 阻塞模态），同 FormDialog——首选项是一次性提交，无需 live 重绘文档，故不用 `run_modal_qml_dialog`。

### 副作用字段：facade 统一封装

部分偏好改动有副作用：

| 字段 | 副作用 |
|------|--------|
| look and feel / gui theme / language / keyboard shortcut style | 需重启才生效（现有走 `set-pretty-preference*` + `confirm-restart-and-act`） |
| buffer management | 联动 `tab bar` boolean 偏好 + `show-icon-bar 4` |
| texmacs->html:mathjax / mathml / images | 三选一互斥（radio） |
| latex source-tracking / conservative / transparent-source-tracking | 双向（import + export 各一） |
| autosave | On/Off 显示 ↔ 120/0 内部值映射 |

scheme facade 提供**统一 setter** `preferences-qml-set-field(key, val)`，按 key 路由到正确的 setter（普通 / silent / on-buffer-management-changed / formula radio / latex 双向 / autosave）。bridge/QML 只传 `(key, val)`，不感知副作用差异。

### 重启确认：「先确认再 apply」

提交时若 diff 含需重启字段：

1. facade 把 diff 分为**非重启** / **重启**两组（固定重启键集合）。
2. **先调 `cpp-confirm-restart`**（合成标题用首个改动重启字段的 `restart-preference-title`）：
   - `restart` → 全部 apply（重启键走普通 setter），`save-all-buffers`，`restart-TeXmacs`。
   - `later` → 非重启键走普通 setter，重启键走 `set-pretty-preference-silent`（下次启动生效）。
   - `cancel` → **什么都不 apply**。
3. 无需重启字段改动时直接全部 apply。

「先确认再 apply」消除了回滚问题（已核对：所有非重启 setter 不读任何重启键的值，故此顺序安全）。

### 条件可见性 / radio 互斥：纯 QML 本地

所有值都在 QML `values` map 里——条件可见性是纯 JS binding（`values["semantic editing"] === "on"` 才显示 semantic-focus/semantic-selections；`values["latex:source-tracking"] === "on"` 才显示 transparent-source-tracking/attach-tracking-info），radio 互斥在 QML `setField` helper 里改同组其它 peer 为 false。无 facade 往返、无 refreshable 脏刷新。

### wire 类型统一为字符串

toggle 在 QML 内用 bool，但提交到 scheme 统一序列化为 `"on"`/`"off"` 串（与 `get/set-preference` 直通，避免类型分派）；meta 里 toggle 的 `value` 也用 `"on"`/`"off"` 串，QML 读时 `value === "on"`。

### 统一键映射

设计稿把 LaTeX 双向偏好合并成一个展示字段（如 `"latex:source-tracking"` 读用 OR、写时双向）；`"latex:conservative"`、`"latex:transparent-source-tracking"` 同理。由 `preferences-qml-set-field` 路由处理。

### CJK 标签编码

scheme 侧 `(translate "key")` 到 Cork，bridge 必须用 `cork_to_utf8` + `utf8_to_qstring`（**勿用 `to_qstring`**——其 `looks_utf8/looks_ascii` 启发式对纯 Cork 中文不稳定，见 `FontSelectorBridge.cpp:42-48`）。

### 数据契约（meta，scheme → QVariantMap）

bridge 的 `meta()` 一次性返回全部 5 主 tab（Convert 下 6 子 tab）的树。每字段为 QVariantMap，含 `kind`（`"combo"` / `"toggle"` / `"info"`）、`key`、`label`（已 translate）、`value`（combo 存内部键，对齐 `EnumCombo` 契约；toggle 存 `"on"`/`"off"`）、`options` / `optionsTr`（combo 的内部键列表 + 翻译显示）、`editable`（combo）、`hint`（toggle/info 副说明）、`group`（分组标题，组首字段）、`restart`（重启确认标记）、`radioGroup`（组内互斥）、`visibleWhenKey` / `visibleWhenVal`（条件可见性）、`column`（双栏列号 0/1）。

### 平台差异

meta 构建时按平台谓词过滤字段与裁剪 options（look and feel 选项 / keyboard shortcut style 仅 macOS / magic-paste Cmd 显示 / native menubar/unified toolbar 仅 macOS / pdf 需 `supports-native-pdf?` / print dialogue 需 `qt-gui?` / updater 需 `use-plugin-updater?`），QML 只渲染收到的。

## 8 后续修复（2026-07）

### 8.1 切 language 崩溃（SIGSEGV）

**现象**：在 Preferences.qml 改 language（如 British / Chinese）→ 点 OK，完全没弹 ConfirmRestart 就 `attempt to evaluate ("language" . "chinese")` → SIGSEGV（Qt 输入法重建）。

**根因**：`PreferencesBridge::eval_submit` 拼 `(preferences-qml-submit (...))` 时**没给 assoc 字面量加 quote**。dotted-pair `("language" . "chinese")` 出现在函数实参位置（求值位置），被当函数应用（car `"language"` 当函数）→ 报 `attempt to evaluate` 并 SIGSEGV，submit 函数体根本没进，故没弹窗。

**修复**：`eval_submit` 改拼 `(preferences-qml-submit '(...))`（quote 整个 assoc 字面量）。涉及 `src/Plugins/Qt/PreferencesBridge.cpp`。

### 8.2 restart 分支实时切 language 的潜在崩溃

`preferences-qml-submit` 的 restart 分支（用户在 ConfirmRestart 选「重启」）原对所有 changed-keys 调 `preferences-qml-set-field`（实时切）再 `restart-TeXmacs`。实时切 language 会立即触发 Qt 输入法/菜单重建，在重启真正执行前 SIGSEGV。

**修复**：restart 分支改为非重启键实时 apply、重启键走 `preferences-qml-set-field-silent`（不实时切，重启后加载新值，效果等价）。与 later 分支写法对齐。涉及 `TeXmacs/progs/texmacs/menus/preferences-widgets.scm`。

### 8.3 Toggle/combo 双栏布局

Math / Other experimental 字段定义里已标 `column 0/1`（经 `preferences-qml-flags->assoc` 进 descriptor），但 `Preferences.qml` 没用，单列平铺。改为 `Preferences.qml` 的 `fieldCol` 按 `hasColumns` 分流：带 column 的 tab（Math / Other experimental）渲染成 Row + 左右两个 Column（各 filter `column === 0/1`），无 column 的 tab 维持单列满宽。delegate 提成 `fieldDelegate` Component 供单/双栏复用。Toggle/EnumCombo 内部按 parent.width 缩放，半宽容器下自动等比缩小，未改原子。涉及 `src/Plugins/Qt/qml/Preferences.qml`。

### 8.4 submit 数据契约 bug（早期）

`build_assoc_literal` 原产出二元组 `("k" "v")`，scheme `(cdr (assoc ...))` 得单元素 list `(v)` 而非字符串，下游 setter 全误判。改为 dotted-pair `("k" . "v")`（与 ParagraphFormat / FontSelector sibling bridge 一致），配合 8.1 的 quote。

### 测试

`TeXmacs/tests/2044.scm` 扩展：submit 各分支（非重启 toggle/combo、buffer-management 联动、restart+cancel、restart+later）+ bridge quote 路径回归（模拟 `eval_submit` 拼的带 quote 串，钉死 8.1 的修复）。链首抓偏好快照、链尾还原，不污染全局配置。`MOGAN_TEST_GUI=1 xmake r 2044`：32 correct, 0 failed。

## 9 字段/布局对齐原 tm-widget（2026-07）

对照原 texmacs `tm-widget`（`*-preferences-widget` 一套）逐 tab 核对，补齐 QML facade 漏掉的字段与布局，并删除已废弃的原 widget 实现。

### 9.1 删除原 tm-widget 一套

`preferences-widgets.scm` 前 1200 余行的所有 `*-preferences-widget` 定义（general/keyboard/math\*/html/latex/bibtex/verbatim/pdf/image/conversion/misc/experimental/other/preferences）+ `open-preferences-window` + `export-formulas-as-*` helper 全删。`open-preferences` 简化为永远 `(cpp-preferences-dialog)`，删 side-tools 回退分支（原分支引用的 `preferences-tool` 全项目无定义、本就半残）。保留 `set-pretty-preference*`、`on-buffer-management-changed`、各 `define-preference-names` decode 表、latex/bibtex 双向偏好 helper、image-format-list-pair 等 facade 仍在用的基础设施。外部无 `(dynamic (xxx-preferences-widget))` 引用，删除安全。

### 9.2 Keyboard shortcut style 归位

原 widget 该字段在 Keyboard tab（`(assuming (os-macos?) ...)`），新 facade 误放进 General tab。从 `preferences-qml-general-fields` 移到 `preferences-qml-keyboard-fields`（cyrillic 之后、IR 之前），保留 `'platform-filter 'macos-only` + `'restart? #t`。

### 9.3 分组标题渲染

原 `fieldDelegate` 没读 `modelData.group`，导致「Remote controllers...」「Keyboard behavior」等分组标题不显示。改为 delegate 内：组首字段（带 group 字符串）在字段上方渲染加粗标题 + 分隔线（非段首才显示线，仿原 `======`）。`hasGroup` 用 `typeof === "string"` 判定，避免 undefined→bool 的 QWARN。

### 9.4 layout 区段双列

原 widget Keyboard tab 是「5 combo 单列 + 8 IR 左右双列」混排，新 facade 全单列。新增 `'layout` flag（`'two-col`）：`flags->assoc` 加 `'layout` 解析，字段标 `'layout 'two-col` + `column 0/1`。`Preferences.qml` 新增 `activeSections()` 把当前 tab 字段按连续 layout 切段，single 段单列满宽、two-col 段拆左右两列（filter column 0/1）。IR 8 个标 two-col（Left/Right/Up/Down col 0、Center/Play/Pause/Menu col 1）；Math / Other experimental 原有双栏字段补 `'layout 'two-col`。

### 9.5 Math 列号对齐原 widget

原 Math widget「左列=Keyboard+Contextual hints，右列=Semantics+Correction」，新 facade 列号相反。互换：Correction 组 column 0→1、Contextual hints/Semantics 组 column 1→0。

### 9.6 双栏 EnumCombo label 比例

半宽列下 EnumCombo 原用单栏 `comboLabelRatio`（0.6）会把下拉挤窄。新增 `Theme.comboLabelRatioNarrow`，fieldDelegate 在半宽列（parent.width < twoColHalfWidth）时切 narrow 比例。
