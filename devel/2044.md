## 5 What

把首选项对话框（现有 `preferences-widget` 一套 texmacs `tm-widget`，1249 行）重写为 QML 弹窗 `Preferences.qml`，纳入现有 QML 模态对话框体系。五个主 tab（General / Keyboard / Mathematics / Convert / Other），其中 Convert 下再有六个子 tab（Html / LaTeX / BibTeX / Verbatim / Pdf / Image）。约 40 个 combo（下拉）+ 35 个 toggle（开关）+ 若干 info row（只读，如 updater 最后检查时间）。

1. 新增 `Toggle` 原子（现有 atoms 无 toggle）。
2. 新增 `Preferences.qml` 弹窗：`DialogShell` 外壳，顶部主 `TabBar`，正文按 tab 渲染字段（`Repeater`，delegate 按 `kind` 分支 → `EnumCombo` / `Toggle` / info Text），分组标题、双栏（Math / experimental Other）、条件可见性（semantic editing / latex source-tracking 开关联动）、radio 互斥（mathjax/mathml/images）纯 QML 本地处理。
3. 新增 `PreferencesBridge`（C++↔QML 桥，无状态 `eval_scheme` 透传）。
4. 新增 glue 入口 `cpp_preferences_dialog`（exec 阻塞模态，复用 `run_qml_dialog` + `inject_common_context`）。
5. scheme facade `preferences-qml-meta`（一次性拉全树）/ `-submit`（应用 diff，按需重启字段「先确认再 apply」）/ `-set-field`（统一 setter 按 key 路由副作用）。
6. 改 `open-preferences`：非 side-tools 模式调 `cpp-preferences-dialog`，side-tools 模式仍走旧 `open-preferences-window`（旧 tm-widget body 保留）。
7. QML 加载测试 + scheme 契约测试（`MOGAN_TEST_PREFERENCES` + `MOGAN_TEST_CONFIRM_RESTART`）。

## 6 Why

现有首选项弹窗是 texmacs `tm-widget`（minibuffer 内 widget DSL），与 Qt 主界面的视觉/交互割裂：

- 不能用 Qt 原生下拉/combo，靠 minibuffer 字段输入体验差。
- 分组、联动可见性、radio 互斥依赖 `refreshable` + `refresh-now` 脏刷新，逻辑分散且难调试。
- `assuming` 在 refreshable 内有 FIXME（`refreshable` widget 内 `assuming` 失效，字段可见性不能正确联动——见 `preferences-widgets.scm:345` 注释）。

把弹窗迁到 QML 体系后，所有模态弹窗（确认关闭、表单、字体选择、段落格式、首选项）共享同一套外壳（`DialogShell`）、主题（`Theme`）、下拉浮层、拖动/Esc/Enter 行为，视觉与交互一致；条件可见性/radio 改为 QML 本地 binding，消除 refreshable 机制。

## 7 How

### 提交模型：本地暂存 + OK 一次性提交

仿 `FormDialog.qml`：打开时 `prefBridge.meta()` 一次性拉全部 tab/字段树到 `initialValues`（打开快照），用户改动只改本地 `values` map；OK 时 `changedFields()` 算 diff（仅与打开快照不同的键），`prefBridge.submit(diff)` 一次性应用到 scheme，Cancel 丢弃本地改动。

`run_qml_dialog`（exec 阻塞模态），同 FormDialog——首选项是一次性提交，无需 live 重绘文档，故不用 `run_modal_qml_dialog`。

### 副作用字段：facade 统一封装

部分偏好改动有副作用：

| 字段 | 副作用 |
|------|--------|
| look and feel / gui theme / language / keyboard shortcut style | 需重启才生效（现有走 `set-pretty-preference*` + `confirm-restart-and-act`） |
| buffer management | 联动 `tab bar` boolean 偏好 + `show-icon-bar 4` |
| texmacs->html:mathjax / mathml / images | 三选一互斥（radio） |
| latex source-tracking / conservative / transparent-source-tracking | 双向（import + export 各一） |
| autosave | On/Off 显示 ↔ 120/0 内部值映射 |

scheme facade 提供**统一 setter** `preferences-qml-set-field(key, val)`，按 key 路由到正确的 setter（普通 / silent / on-buffer-management-changed / formula radio / latex 双向 / autosave）。bridge/QML 只传 `(key, val)`，不感知副作用差异。

### 重启确认：「先确认再 apply」

提交时若 diff 含需重启字段：

1. facade 把 diff 分为**非重启** / **重启**两组（固定重启键集合）。
2. **先调 `cpp-confirm-restart`**（合成标题用首个改动重启字段的 `restart-preference-title`）：
   - `restart` → 全部 apply（重启键走普通 setter），`save-all-buffers`，`restart-TeXmacs`。
   - `later` → 非重启键走普通 setter，重启键走 `set-pretty-preference-silent`（下次启动生效）。
   - `cancel` → **什么都不 apply**。
3. 无需重启字段改动时直接全部 apply。

「先确认再 apply」消除了回滚问题（已核对：所有非重启 setter 不读任何重启键的值，故此顺序安全）。

### 条件可见性 / radio 互斥：纯 QML 本地

所有值都在 QML `values` map 里——条件可见性是纯 JS binding（`values["semantic editing"] === "on"` 才显示 semantic-focus/semantic-selections；`values["latex:source-tracking"] === "on"` 才显示 transparent-source-tracking/attach-tracking-info），radio 互斥在 QML `setField` helper 里改同组其它 peer 为 false。无 facade 往返、无 refreshable 脏刷新。

### wire 类型统一为字符串

toggle 在 QML 内用 bool，但提交到 scheme 统一序列化为 `"on"`/`"off"` 串（与 `get/set-preference` 直通，避免类型分派）；meta 里 toggle 的 `value` 也用 `"on"`/`"off"` 串，QML 读时 `value === "on"`。

### 统一键映射

设计稿把 LaTeX 双向偏好合并成一个展示字段（如 `"latex:source-tracking"` 读用 OR、写时双向）；`"latex:conservative"`、`"latex:transparent-source-tracking"` 同理。由 `preferences-qml-set-field` 路由处理。

### CJK 标签编码

scheme 侧 `(translate "key")` 到 Cork，bridge 必须用 `cork_to_utf8` + `utf8_to_qstring`（**勿用 `to_qstring`**——其 `looks_utf8/looks_ascii` 启发式对纯 Cork 中文不稳定，见 `FontSelectorBridge.cpp:42-48`）。

### 数据契约（meta，scheme → QVariantMap）

bridge 的 `meta()` 一次性返回全部 5 主 tab（Convert 下 6 子 tab）的树。每字段为 QVariantMap，含 `kind`（`"combo"` / `"toggle"` / `"info"`）、`key`、`label`（已 translate）、`value`（combo 存内部键，对齐 `EnumCombo` 契约；toggle 存 `"on"`/`"off"`）、`options` / `optionsTr`（combo 的内部键列表 + 翻译显示）、`editable`（combo）、`hint`（toggle/info 副说明）、`group`（分组标题，组首字段）、`groupSpan`（group 标题横跨整行，统领下方左右两列）、`restart?`（重启确认标记）、`radioGroup`（组内互斥）、`enabledWhenKey` / `enabledWhenVal`（条件锁定——字段始终显示，仅当依赖键取此值时可勾，否则灰显）、`layout`（`"two-col"` 双栏区段）、`column`（双栏列号 0/1）、`buttonLabel` / `buttonAction`（combo 旁行内按钮，如 Auto backup 打开目录）。

### 编码表一致性

全部 22 个 `define-preference-names` 编码表的 pretty 名必须与字段 `optionsTr` 严格一致（`current-value` 通过 `get-pretty-preference` 输出在 `options-pretty` 中查表，大小写不匹配则反查失败、combo 显示空白）。已核对全部对齐（如 `pdf:version` 统一小写、`verbatim:encoding` 统一大写 ISO）。

### 模块拆分

preference key 常量集中在 `pref-keys.scm`（`pref-general-look-and-feel` 等 proc，单一可信源）；QML facade 纯函数族（`field->descriptor`、`flags->assoc`、`current-value`、`resolve-options`、`build-tab` 等）和 LaTeX/BibTeX 双向偏好 helper 放在 `preferences-tools.scm`；编解码表、字段定义、facade 入口（`meta`/`submit`/`set-field`）放在 `preferences-widgets.scm`。依赖方向 widgets → tools（单向，无循环）。

## 8 第二轮修复（review）

### What

1. **combo 字段 `"on"/"off"` 误判为 boolean**：`preferences-qml-set-field` 原来按 value 字符串 `"on"/"off"` 分流 toggle/combo，导致 combo 选项值恰好为 `"on"`/`"off"` 的字段（如 Auto backup、Automatic brackets）被错误存为 boolean 而非字符串。修复：新增 key→kind 表，在 `preferences-qml-meta` 构建时填入（`preferences-qml-collect-field-kinds`），`set-field`/`set-field-silent` 按 kind 分流——combo 始终走 `set-pretty-preference`，toggle 才走 `set-boolean-preference`。

2. **scripting language 存显示名而非插件 key**：`preferences-qml-resolve-options` 原来用 `(map scripts-name (scripts-list))` 同时填充 options 和 optionsTr，导致偏好值存为 `"Python"` 而不是 `"python"`。修复：options 用 `(scripts-list)`（插件 key），optionsTr 用 `(map scripts-name ...)`（显示名）。

3. **submit() 取消后仍关闭对话框**：`Preferences.qml` 原来不检查 `prefBridge.submit(diff)` 返回值、无条件 `closeBridge.cancel()`。修复：只在返回值非 `"cancel"` 时关窗，cancel 时保持对话框打开。

4. **禁用 Toggle 仍可点击**：`Toggle.qml` 的 pill `MouseArea` 未绑定 `enabled`。修复：`enabled: toggleRow.enabled`。

5. **look-and-feel 当前值非英文环境无法匹配**：`preferences-qml-general-look-and-feel-pretty` 返回翻译后的显示名，而 `preferences-qml-current-value` 用 `get-pretty-preference` 的英文 pretty 去比对。修复：combo fallback 链改为 pretty → internal key → 兜底，按 internal key 在 options 里查找。

6. **非 ASCII label 编码不一致**：所有文案翻译统一走 `preferences-qml-translate-label`（`utf8->cork` + `translate`），替换原来分散的 `(translate (utf8->cork val))` 和 `(translate label)` 等不一致写法。

7. **HTML formula-export 互斥未下沉到 scheme**：原来仅在 QML 层做 radio 互斥，脚本/命令行直接设值可同时开启多项。修复：在 `preferences-qml-set-field`/`-silent` 里增加互斥分支，调用 `preferences-qml-set-html-formula-export`（任意一个开则关另外两个）。

8. **跨模块函数需 `tm-define`**：Mogan 模块系统里 `define` 的函数跨模块不可见。新增的 `preferences-qml-html-formula-export-keys`、`preferences-qml-set-html-formula-export`、`preferences-qml-collect-field-kinds` 均使用 `tm-define`。

9. **其他**：`ahash-ref` 在 Goldfish 中不支持三参数默认值，改用 `(or (ahash-ref ...) default)`；`with` 在某些上下文不稳定，改用 `let`；Other tab 字段数测试 macOS 适配。
