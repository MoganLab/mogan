## 5 What

移除 `TeXmacs/progs/client/` 目录及其在启动流程、菜单系统中的全部挂载点：

1. 删除 `TeXmacs/progs/client/` 下全部 9 个 `.scm` 文件
2. 在 `init-research.scm` 中删除 client 相关的三处 lazy 注册（`remote-home-directory`、`start-client-menu`/`client-menu`/`remote-menu`/`remote-icons`、`remote-file` tmfs handler），保留 `(server server-menu)` 注册
3. 删除 `with-remote-tool%` 模式定义以及菜单中 4 处 `(if (with-remote-tool?) ... "Remote" ...)` 入口，同时清理 `tools-menu` / `preferences-menu` 中的 `Remote tool` 偏好开关和 `tm-server.scm` 中的默认值，UI 不再出现 `Remote` 菜单

## 6 Why

`TeXmacs/progs/client/` 是远程 TeXmacs 服务的客户端实现（远程登录、远程文件 tmfs、共享文档、live 协作、聊天、db 同步等），依赖大量遗留的 socket/glue 基础设施。该功能在当前代码库中已无实际维护与使用，[1114](1114.md) 已先行清理掉 `pretty-time` 这条仅为 `client/` 服务的依赖。本任务将其整体移除，避免无关代码继续拖累启动流程、菜单结构和后续重构。

## 7 How

### 7.1 删除模块目录

`git rm -r TeXmacs/progs/client/` 删除整个目录。该目录对外只暴露 4 个符号：`remote-home-directory`、`remote-menu`/`remote-icons`（菜单）、`remote-file`（tmfs handler）、`start-client-menu`/`client-menu`。

### 7.2 解除启动注册

`init-research.scm` 中删除三行 client 相关的 `lazy-*` 注册。`(lazy-menu (server server-menu) ...)` 一行保留——server 侧暂不移除。

### 7.3 清理 Remote 菜单入口

`remote-menu` / `remote-icons` 由 `client-menu.scm` 提供，没有 server 侧替代。client 删除后这两个菜单变成空壳，因此把所有 `(if (with-remote-tool?) ... Remote ...)` 入口连同模式开关 `with-remote-tool%` 一并删除。涉及：

| 文件 | 位置 | 删除内容 |
|---|---|---|
| `tm-modes.scm:322` | 模式定义 | `(with-remote-tool% ...)` |
| `main-menu.scm:74` | 主菜单（compact） | `(if (with-remote-tool?) (=> "Remote" ...))` |
| `main-menu.scm:174` | 主菜单（detailed） | `(if (with-remote-tool?) (-> "Remote" ...))` |
| `main-menu.scm:243` | 工具栏图标 | `(if (with-remote-tool?) / (link remote-icons))` |
| `scheme-menu.scm:58` | scheme 菜单 | `(if (with-remote-tool?) (-> "Remote" ...))` |
| `tools-menu.scm:78` | 工具菜单 | `("Remote tool" (toggle-preference "remote tool"))` |
| `preferences-menu.scm:275` | 偏好设置 | `(toggle ("Remote tool" "remote tool"))` |
| `tm-server.scm:141` | 默认偏好 | `("remote tool" "off" notify-tool)` |

### 7.4 C++ 端残留一并清理

`src/System/Link/texmacs_client.cpp` 整个文件都是远程 TeXmacs 服务的 client 侧实现，无任何外部调用方（C++ 端无调用，scheme 端的 glue 注册随 client 模块删除后也不再使用），整体删除：

1. `src/System/Link/texmacs_client.cpp` — 删除整个文件（构建脚本按 `src/System/Link` 目录通配，无需改 xmake.lua）
2. `src/System/Link/client_server.hpp` — 删除 `client_start`/`client_stop`/`client_read`/`client_write` 4 个声明，server 部分保留
3. `src/Scheme/Glue/glue_basic.lua` — 删除 `client-start`/`client-stop`/`client-read`/`client-write` 4 个 glue 条目

server 侧 `texmacs_server.cpp` / `client_server.hpp` 的 server 声明 / `init-research.scm` 中的 `(server server-menu)` 注册保持不变。
