# [2039] 将 `tools->Statistics` 更换为 QML 实现

## 1 What

将文档统计信息对话框从旧 `tm-widget` / `dialogue-window` 替换为 QML 模态对话框（`Statistics.qml`），使用 `run_qml_dialog`（exec 阻塞模态）。统计项由 scm 侧 `get-statistics-data` 计算后经 `stree->tree` 打包传入 C++，QML 纯展示、无 live 写回。

## 2 Why

旧实现使用 TeXmacs 遗留的 `tm-widget` 体系（`show-counts-widget`），与项目 QML 弹窗体系（ConfirmClose / FormDialog / FontSelector / ParagraphFormat）不统一。迁移到 QML 后：
- UI 风格与其他 QML 对话框一致（DialogShell + DialogButtons + Theme）
- 统计项 label/value 分离，支持未来扩展差异化样式
- 移除 `tm-widget` 依赖，简化代码

## 3 How

1. **数据层**：从 `show-counts` 中抽取纯数据函数 `get-statistics-data`（返回 `((label value) ...)`），并增加可传 doc 参数的 `get-statistics-data-from-doc` 供测试使用。
2. **QML 层**：新建 `Statistics.qml`（DialogShell + Column Repeater + DialogButtons），context property 为 `statsTitle` / `statsItems` / `dialogButtons`。
3. **C++ glue**：新增 `cpp_statistics_dialog(string title, tree items)`，解析 tree 为 QVariantList 注入 QML，走 `run_qml_dialog` 引擎。
4. **注册**：`qmldir` / `moganqml.qrc` 加 `Statistics.qml`；`glue_qt.lua` 加 glue 声明。
5. **设计稿**：`ai-docs/qml/qml-dialog.html` 加 Statistics 面板。

## 4 测试

- **SCM 数据测试** (`202_53.scm`)：扩展原有计数函数测试，新增 `get-statistics-data-from-doc` 的 label/value 格式验证（9 项 check）。
- **QML 加载测试** (`qml_load_test.cpp`)：新增 `test_statistics_loads`，注入 `statsItems` / `statsTitle` / `dialogButtons` 桩，断言 `status()==Ready`。
