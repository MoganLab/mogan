## 5 What

将文档统计信息对话框从旧 `tm-widget` / `dialogue-window` 体系迁移到项目 QML 弹窗体系。

1. 新建 `Statistics.qml`（DialogShell + Column Repeater + DialogButtons），纯展示、一次性提交
2. 新增 C++ glue 入口 `cpp_statistics_dialog`，走 `run_qml_dialog`（exec 阻塞模态）
3. 抽取 `get-statistics-data` / `get-statistics-data-from-doc` 数据层，`show-counts` 改用 QML
4. 扩展 SCM 测试覆盖数据组装层，新增 QML 加载测试
5. 设计稿 `qml-dialog.html` 补 Statistics 面板，README 补三条开发规则

## 6 Why

旧实现用 TeXmacs 遗留的 `tm-widget`（`show-counts-widget`），与项目已有 QML 弹窗体系（ConfirmClose / FormDialog / FontSelector / ParagraphFormat）不统一。迁移后：
- UI 风格统一（DialogShell + DialogButtons + Theme）
- 统计项 label/value 分离，支持差异化样式
- 移除 `tm-widget` 依赖，简化代码

## 7 How

### 7.1 数据层（scm）
- `compute-stats-data doc page-str`：共享实现，返回 `((label value) ...)`
- `get-statistics-data`：`show-counts` 调用，从 editor 取文档树和页数
- `get-statistics-data-from-doc doc`：测试调用，无 editor，页数写死 `"0"`
- `statistics-data->stree data`：转 `(stats (item <label> <value>) ...)`，label/value 作 compound 子节点（原子 string），避免 `get_label(compound)` 对中文加引号

### 7.2 C++ glue
- `cpp_statistics_dialog(title, items)`：遍历 tree children 解析 `(item label value)`，组装 `QVariantList` 注入 QML context property `statsItems`
- 走 `run_qml_dialog`（exec 阻塞模态），无需 live 写回
- 用户可见文本（label、标题）在 scm 侧用 `(translate ...)` 翻译，cpp/QML 纯透传

### 7.3 QML 界面
- `Statistics.qml`：`DialogShell` 根，Column 内含标题 + Repeater（统计行）+ DialogButtons（Close）
- context property：`statsTitle` / `statsItems` / `dialogButtons` / `dpScale` / `isDark` / `closeBridge`
- 布局尺寸全引用 Theme 常量（`Theme.margin` / `titleH` / `textRowH` / `btnH` / `padS` / `pad` / `gapS` / `inlineGap` / `fontBody`），只保留本弹窗专属的 `labelW`（列宽比 0.62）
- 按钮区高度 = `Theme.btnH + Theme.padS * 2`（按钮高 + 上下小留白）

### 7.4 新增 Theme 常量
- `textRowH: 24` — 纯文本行高（区别于 `rowH: 44` EnumCombo 行）
- `titleH: 28` — 弹窗标题区高度
- `inlineGap: 12` — 行内 label↔value 间隙
