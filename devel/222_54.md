# [222_54] 添加附录子目录 (appendix-toc) 宏包

## 如何测试

### 测试场景 1：基本附录子目录功能
1. 创建新文档，使用 `article` 或 `book` 样式
2. 添加 `<use-package|custom|appendix-toc>`
3. 添加正文章节：
   ```
   <section|Introduction>
   <section|Methods>
   ```
4. 插入主目录：`<table-of-contents|toc|<document|>>`
5. 添加附录：`<appendix|Additional Material>`
6. 在附录内添加子章节：`<appendix-section|Proofs>`
7. 插入附录子目录：`<appendix-table-of-contents>`

### 测试场景 2：多个附录章节
1. 创建包含多个附录的文档
2. 验证每个附录章节都出现在附录子目录中
3. 验证正文章节不出现在附录子目录中

### 测试场景 3：使用 with-subtoc 宏
1. 在文档中使用：
   ```
   <with-subtoc|custom-toc|
     <section|Special Section>
     <subsection|Subsection>
   >
   <table-of-contents|custom-toc|<document|>>
   ```
2. 验证特殊范围内的章节只出现在对应的子目录中

## 2025/03/11 实现附录子目录宏包

### What
创建了 `appendix-toc.ts` 宏包，位于 `TeXmacs/packages/custom/`，提供以下功能：
- `<appendix|title>` - 重定义的附录命令，使用 "appendix-toc" 前缀
- `<appendix-section|title>` - 附录内的 section，使用 "appendix-toc" 前缀
- `<appendix-subsection|title>` - 附录内的 subsection，使用 "appendix-toc" 前缀
- `<appendix-subsubsection|title>` - 附录内的 subsubsection，使用 "appendix-toc" 前缀
- `<appendix-table-of-contents>` - 显示只包含附录章节的子目录
- `<with-subtoc|prefix|body>` - 通用宏，用于创建任意范围的子目录

### Why
- 原系统所有章节标题都写入同一个 `local_aux["toc"]`，无法实现范围限定的子目录
- 用户需要在附录范围内有一个独立的目录，只包含附录章节
- 通过切换 `toc-prefix` 参数，可以实现任意范围的子目录

### How
1. 利用现有的 `with-toc` 宏切换 `toc-prefix`：
   ```ts
   <assign|with-toc|<macro|toc|body|<with|toc-prefix|<arg|toc>|<arg|body>>>>
   ```

2. 重定义 `appendix` 宏，包装在 `with|toc-prefix|appendix-toc` 中：
   ```ts
   <assign|appendix|<macro|title|
     <with|toc-prefix|appendix-toc|
       ...原有逻辑...
       <with|toc-prefix|appendix-toc|<appendix-toc>|<arg|title>>>
     >
   >>
   ```

3. 附录内的 section/subsection 同样使用 `with|toc-prefix|appendix-toc` 包装

4. 核心原理：
   - `toc-entry` 宏使用 `<write|<value|toc-prefix>|...>` 写入 aux 数据
   - 通过 `with|toc-prefix|<arg|prefix>` 临时改变前缀
   - 不同前缀的数据存储在独立的 `local_aux` 键中
   - `<table-of-contents|appendix-toc|...>` 只读取 "appendix-toc" 键的数据

## 使用示例

### 示例 1：基本用法
```ts
<use-package|custom|appendix-toc>

;; 正文部分 - 写入默认 "toc"
<section|Introduction>
<section|Methods>

;; 显示主目录
<table-of-contents|toc|<document|>>

;; 附录部分 - 自动使用 "appendix-toc" 前缀
<appendix|Additional Material>
<appendix-section|Detailed Proofs>
<appendix-subsection|Proof of Theorem 1>

;; 显示附录子目录（只包含附录章节）
<appendix-table-of-contents>
```

### 示例 2：使用 with-subtoc 创建自定义范围
```ts
<use-package|custom|appendix-toc>

;; 第一部分 - 使用 "part1-toc" 前缀
<with-subtoc|part1-toc|
  <part|Part I: Background>
  <chapter|Introduction>
  <chapter|Related Work>
>
<table-of-contents|part1-toc|<document|>>

;; 第二部分 - 使用 "part2-toc" 前缀
<with-subtoc|part2-toc|
  <part|Part II: Methodology>
  <chapter|Approach>
  <chapter|Implementation>
>
<table-of-contents|part2-toc|<document|>>
```
