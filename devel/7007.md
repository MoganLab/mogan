# [7007] 修复 WASM 端 Collaborative 菜单不可用

## What

WASM（ImGui 前端）端 File → Collaborative 子菜单恢复可用：

- 三个主入口（Set/Change server address...、New shared document、
  New shared document from file）重新出现在菜单中；
- WASM 下这些命令的输入交互（服务器地址、文档显示名）改走浏览器原生
  `window.prompt`（同步、阻塞式，与现有 WASM 文件选择器/下载的 JS 桥接同套思路）；
- Qt 端行为零改动；桌面 ImGui（非 Qt 非 WASM）兜底给出「不支持」提示，
  不再出现「点了没反应」。

## Why

[0736]（#3956）在 `make-menu-items` 对所有非 Qt 前端过滤带 `:interactive`
属性的菜单叶子项（仅 `:imgui-supported` 白名单豁免，当时只有 choose-file/Save as）。
Collaborative 子菜单的三个主入口命令（`collab-configure-server`、
`collab-new-document`、`collab-new-document-from-file`）均为 `:interactive #t`，
在 WASM 上被全部过滤——未配置服务器时子菜单唯一项被滤掉，菜单变空，完全不可用。

但只加白名单不够：ImGui/WASM 端并未实现 interactive 弹窗与 footer minibuffer
（web shell types.ts 标注 "not yet rendered"），命令显示出来也无法完成输入。
因此需要给这三条命令一个 WASM 可用的输入路径。

## How

### 1. C++ glue：`wasm-prompt`（浏览器原生 prompt）

- `src/Scheme/Plugins/glue_plugin_extra.hpp`：新增
  `wasm_prompt(title, default)`——`#ifdef __EMSCRIPTEN__` 下用 `EM_ASM_PTR`
  调 `window.prompt`；取消（JS 返回 null）时置全局 `s_wasm_prompt_cancelled`，
  区分「取消」（不应触发任何改动）与「确认空串」（如清除服务器偏好 = 合法操作）。
  非 WASM 为 stub（返回空串、cancelled=true）。配套 `wasm_prompt_cancelled()`。
- `src/Scheme/Plugins/glue_plugin.lua`：注册 `wasm-prompt`（string string → string）
  与 `wasm-prompt-cancelled?`（→ bool）。

### 2. Scheme：三个命令加 WASM 分支 + 白名单标记

`TeXmacs/progs/texmacs/texmacs/tm-collab.scm`：

- `collab-configure-server`：WASM 下单框 prompt（预填当前生效 URL，接受完整
  `ws(s)://` 地址；空串 = 清除偏好，与 Qt 两框版语义一致）；标记
  `(:imgui-supported #t)`。
- `collab-new-document`：WASM 下 prompt 文档名（空 = 无名文档，取消 = 不创建），
  确认后走现有 `collab-new-document-named`；标记白名单。
- `collab-share-file-prompt-name`（from file 链路的命名框）：WASM 下 prompt
  预填文件名，走现有 `collab-new-document-from-file-named`；
  `collab-new-document-from-file` 标记白名单（choose-file 在 WASM 已由
  im_chooser_widget 的文件选择器实现）。
- 非 Qt 非 WASM 兜底：`set-message` 提示前端不支持。

平台谓词复用已有 glue：`os-wasm?`（glue_lolly.lua）、`qt-gui?`。

### 涉及文件

- `src/Scheme/Plugins/glue_plugin_extra.hpp`（wasm_prompt 实现）
- `src/Scheme/Plugins/glue_plugin.lua`（glue 注册）
- `TeXmacs/progs/texmacs/texmacs/tm-collab.scm`（WASM 分支 + 白名单标记）
