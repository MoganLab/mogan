# [0976] 联网搜索和深度思考按钮改为纯图标样式

## 1 任务描述

AI 聊天输入区的「深度思考」「联网搜索」两个开关按钮，样式改为：没有按钮边框，
也没有文字显示，只有图标。

## 2 任务相关的代码文件

- `src/Plugins/Qt/qt_chat_tab_widget.cpp` — `make_toggle_btn`：按钮样式改为
  `Qt::ToolButtonIconOnly`，文字改作 tooltip；内边距改为对称（原左大右小是
  为图标+文字布局预留）。
- `TeXmacs/misc/themes/liii.css` — 浅色主题：去掉两个按钮的 `border` 声明。
- `TeXmacs/misc/themes/liii-night.css` — 深色主题：去掉两个按钮（含 checked
  态）的 `border` 声明。

按钮图标本身由主题 CSS 的 `qproperty-iconNormal/iconChecked` 提供
（`QTMStateToolButton`），勾选态仍通过背景色/图标切换表达，不受影响。

## 3 如何测试

### 3.1 格式化与基础校验

```bash
gf fmt --changed-since=main

```

### 3.2 手动测试（GUI）

1. 编译并启动 Mogan STEM：
   ```bash
   xmake b stem
   xmake r stem
   ```
2. 打开 AI 聊天侧边栏（菜单「插入 → 会话 → LLM」）。
3. 验证「深度思考」「联网搜索」按钮：
   - 按钮无边框、无文字，只显示图标；
   - 鼠标悬停显示对应文字 tooltip；
   - 点击切换勾选态后，图标/背景变化仍正常（可区分开/关）；
   - 分别切换浅色（liii）与深色（liii-night）主题，两种主题下均无边框。

## 4 What / Why / How

- **What**：深度思考、联网搜索按钮由「边框 + 图标 + 文字」改为「仅图标」。
- **Why**：输入区按钮更紧凑简洁，与发送按钮等纯图标控件风格一致。
- **How**：C++ 侧把 `QToolButton` 样式设为 `Qt::ToolButtonIconOnly` 并把文字
  移到 tooltip；两套主题 CSS 删除相关 `border` 声明。
