# [0976] 侧边栏的联网搜索和深度思考按钮改为纯图标样式

## 1 任务描述

AI 聊天**侧边栏（dock）**中的「深度思考」「联网搜索」两个开关按钮，样式改为：
没有按钮边框，也没有文字显示，只有图标。**Chat 标签页（全屏）中的按钮保持
原样**（主题边框 + 图标 + 文字）。

## 2 任务相关的代码文件

- `src/Plugins/Qt/qt_chat_tab_widget.hpp/.cpp`
  - `toggle_btn_qss (iconOnly, btnH)`：开关按钮内联样式助手。纯图标模式显式
    `border: none`（内联样式优先级高于主题 CSS，覆盖主题边框）；文字模式
    不声明 border，沿用主题 CSS。
  - `ChatConversationPanel::setToggleButtonsIconOnly`：切换两个按钮的
    `ToolButtonStyle`（IconOnly / TextBesideIcon）与内联样式。
  - `QTChatTabWidget::setDockMode` + `dockMode_`：对已有面板立即生效，
    `createPanel` 对新建面板沿用当前模式。
  - `make_toggle_btn`：默认仍为文字模式；文字同时设为 tooltip（纯图标模式
    下供悬停辨认）。
- `src/Plugins/Qt/qt_tm_widget.cpp`：`sync_chat_sidebar_mode` 进入侧边栏时
  `setDockMode (true)`；`sync_chat_tab_mode` 及侧边栏隐藏路径把控件移出
  dock 时 `setDockMode (false)`。

按钮图标本身由主题 CSS 的 `qproperty-iconNormal/iconChecked` 提供
（`QTMStateToolButton`），勾选态仍通过背景色/图标切换表达，不受影响。

## 4 What / Why / How

- **What**：仅侧边栏的深度思考、联网搜索按钮改为纯图标；标签页保持原样。
- **Why**：侧边栏宽度有限，纯图标按钮更紧凑；标签页空间充裕，保留文字更易读。
- **How**：同一 `QTChatTabWidget` 在两种模式间复用并被 reparent，故在
  模式切换点（`sync_chat_sidebar_mode` / `sync_chat_tab_mode`）调用
  `setDockMode`，由 View 层统一切换按钮样式；`border` 用按钮内联样式
  覆盖主题 CSS，不改动主题文件。
