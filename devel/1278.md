## 3 如何测试

### 3.1 端到端测试（手动）

```bash
xmake b stem
TEXMACS_PATH=$(pwd)/TeXmacs ./build/linux/x86_64/release/moganstem 某文件.tm -c /tmp/out.tex
```

转换应自动以 headless 运行（不弹 GUI 窗口），完成后进程自动退出
（无需显式传 `-q`），且 `/tmp/out.tex` 已生成。

显式传 `-q` 行为不变，不重复追加退出命令：

```bash
TEXMACS_PATH=$(pwd)/TeXmacs ./build/linux/x86_64/release/moganstem 某文件.tm -c /tmp/out.tex -q
```

不带 `-c` 的普通启动仍然弹 GUI 并保持运行，不受影响：

```bash
TEXMACS_PATH=$(pwd)/TeXmacs ./build/linux/x86_64/release/moganstem
```

## 5 What

`moganstem 输入 -c 输出` 转换完成后自动退出，等价于默认加上了 `-q`，
并自动开启 headless（不弹 GUI 窗口）；帮助信息中 `-c` 一行同步标注。

## 6 Why

`-c` 面向命令行脚本化转换，转换完成就该退出。此前必须手动补 `-q`，
否则随转换启动的 GUI 会一直挂着，批量转换时每个文件都残留一个进程；
转换本身也不需要 GUI，弹窗纯属干扰。

## 7 How

- `immediate_options`（research.cpp）：参数预扫描中遇到 `-c`/`-convert`
  置 `headless_mode= true`。必须在 `main` 里 Qt 应用初始化
  （`QTMApplication`/`QTMCoreApplication` 的选择）之前生效，因此放在
  `immediate_options` 而非 `TeXmacs_main`。
- `TeXmacs_main`（init_texmacs.cpp）：`-c`/`-convert` 分支中，转换命令
  （tex→tmu 特殊路径与默认 load-buffer/export-buffer 路径）追加到
  `my_init_cmds` 之后，紧跟着追加 `(quit-TeXmacs)`，保证 quit 位于
  `(begin ...)` 末尾、转换先于退出执行；显式传入 `-q` 时行为不变。
