## 5 What

为 Mogan STEM 的 PDF 阅读器添加 macOS 触控板捏合（Pinch）缩放支持：

1. 在 viewport 上注册 `Qt::PinchGesture` 手势识别
2. 在 `eventFilter` 中处理 `QEvent::Gesture`，提取 `QPinchGesture` 的 `totalScaleFactor()` 计算实时缩放比例
3. 捏合过程中仅更新 UI 显示（zoom factor 和 combo box），不触发页面重渲染，避免卡顿
4. 手势结束后（`GestureFinished` / `GestureCanceled`）统一触发一次防抖重渲染
5. 添加 `1%` 阈值，避免微小手势抖动导致 UI 反复刷新
6. 缩放比例仍受 `MIN_ZOOM = 0.12` 和 `MAX_ZOOM = 8.0` 约束

## 6 Why

此前 PDF 阅读器在 macOS 上仅支持：
- 工具栏按钮点击缩放
- `Ctrl + 滚轮` 缩放（对应鼠标）
- 快捷键 `Ctrl + +/-` 缩放

缺少对触控板原生捏合手势的支持，这与 macOS 用户的直觉操作习惯不符。直接实现时，若在每次 `ScaleFactorChanged` 都调用 `setZoomFactor()`（内部会启动 200ms 防抖定时器并排队 `rebuildPages()`），会导致捏合过程中页面反复重渲染，造成明显卡顿。

## 7 How

实现思路：

1. 在构造函数中为 `scrollArea_->viewport()` 调用 `grabGesture(Qt::PinchGesture)`，让 Qt 识别并分发捏合手势事件到 viewport。
2. 在 `eventFilter()` 的 viewport 分支中新增对 `QEvent::Gesture` 的处理：
   - 通过 `gestureEvent->gesture(Qt::PinchGesture)` 获取 `QPinchGesture`
   - 当 `changeFlags() & QPinchGesture::ScaleFactorChanged` 时，说明手势正在更新
3. 捏合过程中采用"轻量更新"策略：
   - 记录 `pinchStartZoom_` 作为手势开始时的基准缩放比例
   - 使用 `zoomFactor_ = pinchStartZoom_ * pinch->totalScaleFactor()` 计算新值
   - 仅当变化超过 `1%`（`|newZoom - zoomFactor_| > 0.01`）时才更新 `zoomFactor_` 和 `updateZoomDisplay()`
   - **不调用 `setZoomFactor()`**，因为该方法内部会启动 `zoomDebounceTimer_` 并最终触发 `rebuildPages()` 重渲染所有可见页面
4. 手势结束时统一重渲染：
   - 监听 `Qt::GestureFinished` 和 `Qt::GestureCanceled`
   - 将 `inPinchGesture_` 置为 `false`
   - 此时才启动 `zoomDebounceTimer_->start()`，由防抖机制在 200ms 后统一调用 `rebuildPages()`
5. 缩放边界仍由 `qBound(MIN_ZOOM, ..., MAX_ZOOM)` 保证，与原有滚轮缩放逻辑一致
6. 状态变量 `pinchStartZoom_` 和 `inPinchGesture_` 加入类头文件，初始化均在构造函数中完成
