# [203_29] 新增快捷键 Ctrl Shift L 用于复制到 LaTeX


## 2026/04/28 如何测试

1. 在文档中选中一段普通文本或数学公式。
2. 按 `Ctrl+Shift+L`。
3. 粘贴到纯文本编辑器，确认剪贴板内容为 LaTeX。
4. 在 Scheme/headless 环境中确认 `C-L` 绑定到：

```scheme
(clipboard-copy-export "latex" "primary")
```
## 新增快捷键 Ctrl Shift L 用于复制到 LaTeX

### What

新增全局快捷键 `Ctrl+Shift+L`，用于将当前选中的内容复制为 LaTeX。

本次涉及：

- `TeXmacs/progs/generic/generic-kbd.scm`

### Why

此前用户需要通过菜单 `Edit -> Copy to -> LaTeX` 才能把选区复制为 LaTeX，键盘操作不够直接。

### How

在通用键盘映射中加入：

```scheme
("C-L" (clipboard-copy-export "latex" "primary"))
```

其中 `C-L` 表示 `Ctrl+Shift+L`。该命令复用已有的 `clipboard-copy-export` 逻辑，与菜单中的 `Copy to -> LaTeX` 走同一条导出路径。

同时引入 `(utils edit selections)`，保证键盘模块可以直接使用 selection 导出工具。

原先 `std L` 绑定到 `(open-document*)`，会与该快捷键冲突；本次移除了这个绑定，保留 `std o` 作为打开文档入口。
