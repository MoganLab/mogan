# Loro 协作服务器

## 做了什么（What）
新增了一个 Node.js 服务器（`tools/loro-server`），作为基于 Loro CRDT 的 Mogan 协同编辑后端。

## 为什么（Why）
协同编辑需要一个中心化服务来管理文档生命周期、处理 WebSocket 连接、持久化 CRDT 快照与增量更新，并将编辑操作实时广播给所有已连接的客户端。

## 如何实现（How）
- 使用 `ws`（WebSocket）和 HTTP（提供 `/docs` 接口及健康检查）开发了 `server.js`。
- `store.js` 负责持久化存储，保存 `snapshot.bin` 快照文件，并将增量更新追加到 `updates.log` 日志中。
- `registry.js` 维护内存中的文档状态，并管理活跃客户端的订阅关系。
- 提供了集成测试（`test/server.test.js`），验证完整的协议生命周期、CRDT 同步、客户端重连以及服务器重启后的恢复能力。
