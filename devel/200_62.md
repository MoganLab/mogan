# 200_62 Telemetry（埋点）系统

## 如何测试

### 1. 编译与启动
```bash
xmake config --is_community=false
xmake b stem
xmake r stem
```

### 2. Telemetry 开关
```scheme
(set-preference "telemetry" "0")  ; 关闭
(set-preference "telemetry" "1")  ; 开启（默认）
```

### 3. 数据落盘
触发 10 次以上埋点事件（或等待 60 秒），查看终端输出：
```
[telemetry] flush: N events -> /Users/.../.TeXmacs/system/telemetry/telemetry-pending.jsonl
```

检查 `~/.TeXmacs/system/telemetry/telemetry-pending.jsonl`，每行为一个 JSON 对象。

### 4. 环境变量配置
```bash
export MOGAN_TELEMETRY_BUFFER_SIZE=5
export MOGAN_TELEMETRY_FLUSH_INTERVAL=30000
xmake r stem
```
非法值会输出警告并回退到默认值。`BUFFER_SIZE` 超过队列上限（1000）会自动 clamp。

### 5. 社区版兼容性
```bash
xmake config --is_community=true
xmake b stem
```
确认编译通过，无埋点日志输出，`telemetry_track` 为空操作。

### 6. 自动化测试
```bash
./bin/test_only 200_62
```

## 设计概要

### 新增文件

| 文件 | 职责 |
|---|---|
| `src/Mogan/Telemetry/telemetry.hpp` | C++ 胶水层。非社区版调用 Scheme `track-event`；社区版为空操作。 |
| `TeXmacs/progs/telemetry/telemetry-utils.scm` | 路径、配置、设备信息、事件构造。 |
| `TeXmacs/progs/telemetry/telemetry-track.scm` | 事件入队、内存队列、flush（锁 + 追加写 JSON Lines）。复杂清理逻辑（大小限制、过期过滤）由 liii 子进程负责。 |
| `TeXmacs/progs/telemetry/init-telemetry.scm` | 启动时加载配置、注册周期性 flush 与退出 flush 钩子。 |
| `TeXmacs/tests/200_62.scm` | 自动化测试：事件构造、开关、配置 clamp。 |

### 核心机制

- **事件格式**：`telemetry-make-event` 统一生成包含 `event_type`、`timestamp_ms`、`distinct_id`、`session_id`、`event_id`、`app_version`、`device_id`、`platform`、`language`、`timezone`、`properties` 的标准结构。
- **内存缓冲**：`track-event` 将事件写入内存队列，达到 `telemetry-buffer-size`（默认 10）后自动 flush。
- **周期性刷新**：每 60 秒 delayed 任务检查并 flush。
- **退出 flush**：`on-exit` 钩子确保关闭前落盘。
- **多进程安全**：目录锁（`mkdir` 原子性）防止并发写入损坏。
- **主进程轻量**：`telemetry-write-pending` 只做追加写（`string-append-to-file`），不读取旧文件、不解析 JSON、不过滤、不检查大小。复杂清理由 liii 子进程异步处理。
- **兜底措施**：
  - 内存队列上限 1000，超出丢弃最旧事件
  - 写入失败保留内存队列，下次重试
  - `telemetry-buffer-size` 环境变量自动 clamp 到队列上限
  - `on-exit` flush 包裹 `catch`，防止异常中断退出链
  - 锁 owner 不匹配时输出 warn 日志便于排查
- **时区修复**：`telemetry-timezone` 使用 `date-zone-offset` 计算偏移量并格式化为 `+08:00`（之前 `date-zone` 不存在导致始终回退到 `"UTC"`）。
- **社区版隔离**：`IS_COMMUNITY` 宏在编译期完全剔除埋点逻辑。
