## 3 如何测试

### 3.1 确定性测试
```
xmake b qml_load_test
xmake r qml_load_test
xmake b stem
xmake r 4160
```
`MOGAN_TEST_PRINT_TO_FILE=ok|cancel` 不弹窗。ok 返回字段初值；cancel 返回空树、不打印。

### 3.2 非确定性测试
Windows：`xmake b stem` 后 `xmake install stem`。偏好里关闭系统打印对话框（`gui:print dialogue` 非 on）。

文件 → 打印 → 选择打印为文件：应出现 QML 窗（路径、首页、末页、浏览、OK/Cancel），不是旧的逐步 `interactive` + `choose-file`。Esc/Cancel 不写文件。OK 按页码打印到所选路径。

## 4 如何提交
```
gf fmt --changed-since=main
```

## 5 What
1. 「选择打印为文件」改为专用 QML（不套 FormDialog、不抄错误 PR 的快捷键/自定义超大 diff）。
2. 页码与路径一次提交，Browse 走原生保存框。
3. 仍调用原有 `print-pages-to-file`。

## 6 Why
旧交互是先问页码再选文件，且 FormDialog 只有下拉、不好填路径/页码。

## 7 How
scheme 组 `(path …) (number …)` 字段树 → `cpp-print-to-file-dialog` → `run_qml_dialog`。OK 的 kv 树交给 `print-pages-to-file`。
