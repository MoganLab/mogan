# 1130: 将 tree_observer 迁移到 moebius

## 目标
将 `src/Data/Tree/tree_observer.hpp` 与 `tree_observer.cpp` 迁移到 `moebius/Data/Tree`，使其作为 moebius 库的一部分编译。

## 背景
moebius 是 Mogan 的基础 C++ 库，已包含 `tree`、`modification`、`observer` 等核心抽象。
`tree_observer` 直接依赖 `modification` 与 `observer`，天然适合放入 moebius。
迁移后上层代码仍通过同样的公开头文件使用这些接口。

## 完成记录
1. 将 `tree_observer.hpp`/`tree_observer.cpp` 从 `src/Data/Tree` 移动到 `moebius/Data/Tree`。
2. 由于 `tree_observer.cpp` 包含 `observers.hpp`，而该头文件原位于 `src/Data/Observers`，
   为保持 moebius 不自依赖 src，将 `observers.hpp` 移动到 `moebius/Kernel/Abstractions`。
   其实现文件（`ip_observer.cpp`、`list_observer.cpp` 等）仍保留在 src，通过 libmoebius 的公开 include 路径引用新头文件。
3. 在 `tree_observer.cpp` 中替换对 `src/Texmacs/tm_debug.hpp` 的依赖：
   - `failed_error` 改为 `cerr`；
   - 显式包含 `basic.hpp` 以获得 `TM_FAILED`。
4. `src/Scheme/L4/glue_tree.lua` 中仍通过 `"tree_observer.hpp"` / `"observers.hpp"` 包含头文件，
   由于 moebius 的 include 路径已公开给 libmogan，无需修改该文件。
5. 运行 `gf fmt` 格式化迁移后的 C++ 文件。
6. 构建验证：
   - `xmake b libmoebius` 成功
   - `xmake b libmogan` 成功
   - `xmake b stem` 成功
7. 测试验证：
   - `xmake test`：moebius 单元测试全部通过
   - `xmake run 0138`：headless 启动测试正常完成并自动退出，3 checks passed, 0 failed
