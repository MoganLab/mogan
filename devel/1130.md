# 1130: 将 tree_observer / tree_patch / tree_modify 迁移到 moebius

## 目标
将 `src/Data/Tree` 下的 `tree_observer`、`tree_patch`、`tree_modify` 三对头文件/实现文件
迁移到 `moebius/Data/Tree`，使其作为 moebius 库的一部分编译。

## 背景
moebius 是 Mogan 的基础 C++ 库，已包含 `tree`、`modification`、`observer`、`patch`、`drd` 等核心抽象。
`tree_observer`、`tree_patch`、`tree_modify` 均直接依赖这些基础类型，天然适合放入 moebius。
迁移后上层代码仍通过同样的公开头文件使用这些接口。

## 完成记录
1. 将 `tree_observer.hpp`/`tree_observer.cpp` 从 `src/Data/Tree` 移动到 `moebius/Data/Tree`。
2. 将 `tree_patch.hpp`/`tree_patch.cpp` 从 `src/Data/Tree` 移动到 `moebius/Data/Tree`。
3. 将 `tree_modify.hpp`/`tree_modify.cpp` 从 `src/Data/Tree` 移动到 `moebius/Data/Tree`。
4. 由于 `tree_observer.cpp`/`tree_modify.cpp` 包含 `observers.hpp`，而该头文件原位于 `src/Data/Observers`，
   为保持 moebius 不自依赖 src，将 `observers.hpp` 移动到 `moebius/Kernel/Abstractions`。
   其实现文件（`ip_observer.cpp`、`list_observer.cpp` 等）仍保留在 src，通过 libmoebius 的公开 include 路径引用新头文件。
5. 在 `tree_observer.cpp` 中替换对 `src/Texmacs/tm_debug.hpp` 的依赖：
   - `failed_error` 改为 `cerr`；
   - 显式包含 `basic.hpp` 以获得 `TM_FAILED`。
6. `src/Scheme/L4/glue_tree.lua` / `src/Scheme/L3/glue_patch.lua` 中仍通过头文件名包含，
   由于 moebius 的 include 路径已公开给 libmogan，无需修改这些文件。
7. 运行 `gf fmt` 格式化迁移后的 C++ 文件。
8. 构建验证：
   - `xmake b libmoebius` 成功
   - `xmake b libmogan` 成功
   - `xmake b stem` 成功
9. 测试验证：
   - `xmake test`：moebius 单元测试全部通过
   - `xmake run 0138`：headless 启动测试正常完成并自动退出，3 checks passed, 0 failed
