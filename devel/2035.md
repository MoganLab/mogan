## 5 What
消除打开/操作 AI Chat 侧边栏时反复出现的 Qt 警告
`setMinimumSize: (chatSideDock) Negative sizes (N,-1)`。

## 6 Why
`chatSideDock` 用一个空 `QWidget` 替换原生标题栏以禁用它
（`setTitleBarWidget(new QWidget())`）。`QDockWidget` 在**没有内容 widget**
（空 dock 刚 show、尚未 `setWidget`）时，其布局项 `QDockWidgetItem::
minimumSizeHint()` 取自 **titlebar widget 的 `minimumSizeHint()`**。而空
`QWidget` 的 `minimumSizeHint()` 默认返回 `QSize(-1, -1)`（Qt「无约束」惯例，
非 `setFixedHeight` 能改变 —— 那只影响 min/max size，不影响 minHint）。
`QMainWindowLayout` 据此对 dock 调 `setMinimumSize(已有 min 宽度, -1)`
（宽度是 `DpiUtils::scaled(320)`，不同 DPI 下为 320/328），触发警告。

这条警告本身无害（Qt 内部 clamp 成 0），但每次排版/菜单重建都会重复刷屏，
干扰日志。Qt 文档亦明确：自定义 titleBarWidget 必须提供有效的 sizeHint 与
minimumSizeHint。

## 7 How
子类化空 titleBar，override `sizeHint()`/`minimumSizeHint()` 均返回
`QSize(0, 0)`，给 Qt 一个有效约束而非 `(-1, -1)`：
```cpp
class EmptyTitleBar : public QWidget {
public:
  QSize sizeHint () const override { return QSize (0, 0); }
  QSize minimumSizeHint () const override { return QSize (0, 0); }
};
chatSideDock->setTitleBarWidget (new EmptyTitleBar ());
```
视觉效果不变（标题栏依旧零高度、不显示）。
