# [1145] 升级 Goldfish 到 18.11.17

## What
同步上游 goldfish v18.11.17（commit 171ad160）到 `TeXmacs/plugins/goldfish/`：

- `src/goldfish.hpp`：版本号 `18.11.16` → `18.11.17`，新增 `glue_scheme_char` 声明与注册
- `src/scheme_char.cpp`：新增，(scheme char) 的 `char-upcase`/`char-downcase` 改用 C++ 实现（上游 #886）
- `goldfish/scheme/char.scm`：删除超长 Scheme 表驱动初始化，`char-upcase`/`char-downcase` 直接绑定 `g_char-upcase`/`g_char-downcase`
- `src/s7.c`：未绑定变量建议扫描跳过 `main_names` 的 NULL 槽，修复解引用 NULL 导致的 SIGSEGV（上游 #885）
- `xmake/goldfish.lua`：goldfish target 新增 `scheme_char.cpp`

## Why
- (scheme char) 的 import 与函数调用性能改善（超长 hash-table 初始化改为 C++ 查表）
- 修复未绑定变量触发建议时的崩溃

## 如何测试
```
xmake b stem
gf eval '(import (scheme char)) (display (char-upcase #\a)) (newline)'
```
