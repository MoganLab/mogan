### 3.3 端到端测试
端到端测试既可以手动测试，也可以采用 Python 的 pynput 框架来自动化测试：

- **自动化测试**：
```bash
python3 TeXmacs/tests/python/1260.py
```

依赖 `pynput`、`rapidocr_onnxruntime`、`Pillow`、`numpy`，仅支持 Windows
（真实 GUI，测试期间不要锁屏）。流程：

1. 启动 Mogan，等待窗口出现后**先最大化**再聚焦（几何稳定，且点击不会切走窗口）；
2. `Ctrl + T` 新建标签页，截图作为基线，测量页面上下边缘位置；
3. 通过 OCR（只在 Mogan 窗口截图范围内识别，避免误点其他窗口的文字）依次点击
   **帮助 -> 欢迎**、**帮助 -> 用户手册 -> 开始使用**；
4. 再次截图，对比页面上下边缘：顶部空隙 = 页顶下移量，底部空隙 = 页底上移量；
5. 任一空隙超过阈值（4×缩放系数物理像素，200% 缩放下为 8px）则失败。

截图与放大图输出到系统临时目录（`1260_*.png`），便于人工复核。

- **手动测试**：
1. 启动 Mogan STEM：`xmake r stem`；
2. 等待 3 秒启动完成，切换到 Mogan STEM 窗口；
3. 按 `Ctrl + T` 新建标签页（进入可编辑文档视图）；
4. 点击顶部菜单栏 **帮助 -> 欢迎**，打开欢迎页面；
5. 点击顶部菜单栏 **帮助 -> 用户手册 -> 开始使用**，打开开始使用手册文档；
6. 观察文档编辑区域与上方工具栏（模式/焦点工具栏）、下方状态栏之间是否紧密贴合、无多余空隙或灰色间隙。

## 5 What
问题已复现（2026-09-02，Windows 11，200% 缩放，窗口最大化，物理像素）：

| 状态 | 页顶 y | 页底 y |
|------|--------|--------|
| `Ctrl + T` 新建标签页（基线） | 355 | 1658 |
| 打开「欢迎」+「开始使用」后 | 387 | 1646 |

- 顶部：焦点工具栏（背景浅灰 243）与文档画布之间多出约 **32 物理px（16 逻辑px）**、
  颜色 (160,160,160) 的深灰空隙带；
- 底部：文档画布与状态栏之间多出约 **12 物理px（6 逻辑px）** 的同色空隙带；
- 画布视口上下共被压掉约 44 物理px，影响编辑面积与界面美观。

## 6 Why
在通过标签页和菜单依次打开「欢迎」和「开始使用」文档后，工具栏与文档渲染画布之间、
画布与状态栏之间出现了多余的空隙，影响界面美观和有效编辑面积。

## 7 How
**测量方法**（`TeXmacs/tests/python/1260.py`）：工具栏/状态栏背景为浅灰 (243)，
空隙带为深灰 (160)，页面为纯白 (≥250)；取窗口中央竖条（35%～65% 宽）内首个/最后一个
纯白行作为页顶/页底，与 `Ctrl + T` 基线比较，超过阈值即判定失败。与主题无关，按
DPI 缩放自适应。

**根因**：待分析。两处空隙透出的都是画布背景色 (160)，推测打开文档后画布的
布局高度/位置与工具栏、状态栏的计算不同步（Qt 布局或 typeset 高度通知路径），
待定位后补充。
