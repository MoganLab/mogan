# 1185 Chat 标签页初始化性能热点定位

## What

在 `chat_init`（见 `devel/1182.md`）的 bench_start/bench_end 之间插入
`chat_init: xxx` 子阶段计时日志，定位 Chat 标签页初始化热点。

## Why

点击 Chat 标签页到渲染完成的总耗时已知（`chat_init`），需要拆分到各初始化
阶段才能定位瓶颈。

## How

子阶段日志全部由 `QTChatTabWidget::isInitBenchPending ()` 门控——只有点击
Chat 标签页触发的初始化窗口内才打印，避免新建会话、dock 模式等非点击路径
误报。命名计时器相互独立，可嵌套。

- `src/Plugins/Qt/qt_tm_widget.cpp`（`sync_chat_tab_mode`）：
  - `chat_init: sync_chat_tab_mode`：整个显示分支（隐藏编辑器、
    update_visibility、show + focus）
  - `chat_init: createView`：首次创建 chatContentWidget
- `src/Plugins/Qt/qt_chat_controller.cpp`（`createView`）：
  - `chat_init: load chat modules`：`use-modules (llm chat-loader)` +
    `chat-persist-load-all`
  - `chat_init: buildDisplayInfos`：会话显示数据构建
  - `chat_init: new QTChatTabWidget`：View 构造
  - `chat_init: activate session`：激活初始会话（`activateSession` /
    `ensureNewConversation`）
- `src/Plugins/Qt/qt_chat_tab_widget.cpp`：
  - `chat_init: setup_left_sidebar` / `chat_init: setup_right_content`：
    `QTChatTabWidget` 构造的左右两区
  - `chat_init: new ChatSidebar`：侧边栏构造（按会话数创建 item）
  - `chat_init: message widget` / `chat_init: input widget`：
    `ChatConversationPanel::setup_ui` 中两个内嵌 TeXmacs 编辑控件的创建

`chat_init` 总耗时减去各子阶段之和，即为点击后的 scheme 命令分发与 Qt
布局/绘制等未插桩部分的开销。
