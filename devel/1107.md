## 3 如何测试

### 3.1 确定性测试（单元测试）

顶层构建并运行全部测试：

```bash
xmake config --yes -vD
xmake build libmoebius
xmake build libmogan
xmake build stem
xmake test
```

moebius 独立构建并运行测试：

```bash
xmake build libmoebius
xmake test "moebius_tests/*"
```

仅运行 moebius 测试时，不需要构建 `stem`。

### 3.2 非确定性测试（文档验证）

1. 确认 `xmake show --targets` 中 `libmoebius`、`moebius_tests` 等 target 无重名冲突。
2. 确认 `libmogan` 和 `stem` 能正常编译，说明 moebius 头文件路径已通过 `{public = true}` 正确传递。
3. 确认 moebius 的 CI 工作流在迁移到 `.github/workflows/` 后路径和命令正确。

## 4 如何提交

提交前执行以下最少步骤：

```bash
gf fmt --changed-since=main

xmake build libmoebius
xmake build libmogan

```

## 5 What

将 moebius 从顶层 `xmake.lua` 的内联定义重构为独立的 xmake 子模块，使用 `includes("moebius")` 引入。

1. 修改 `moebius/xmake.lua`，使其既能独立构建，也能作为子模块被顶层包含。
2. 顶层 `xmake.lua` 使用 `includes("moebius")` 替代内联 `libmoebius` target。
3. 在 `libmoebius` target 上设置 `add_includedirs(..., {public = true})`，使 `libmogan` 和 `stem` 自动继承 moebius 头文件搜索路径。
4. 将 moebius 内部 target `tests` 重命名为 `moebius_tests`，`bench_base` 重命名为 `moebius_bench_base`，避免与顶层潜在 target 名称冲突。
5. 清理 `xmake/vars.lua` 中不再需要的 `moe_files` / `moe_includedirs` 全局变量，以及 `xmake/tests.lua` 中冗余的 `add_packages("moebius")` 和 `add_includedirs(moe_includedirs)`。
6. 将 `moebius/.github/workflows/` 下的 CI 工作流迁移到顶层 `.github/workflows/`，并更新路径与命名。
7. 更新 `Develop_on_Linux.md` 和 `Develop_on_Linux_ZH.md`，补充 moebius 子模块的构建说明。
8. 将 `src/Data/History/commute.cpp` 迁移到 `moebius/Data/History/commute.cpp`，使 `libmoebius` 完整包含 patch/modification 相关实现，测试可独立链接。

## 6 Why

- 当前顶层 `xmake.lua` 内联定义了 `libmoebius`，并通过 `xmake/vars.lua` 的全局变量管理 moebius 源码和头文件路径，造成构建配置重复且耦合紧密。
- `moebius/xmake.lua` 已经存在但未被顶层使用，无法发挥 xmake 子模块的优势。
- 参考 `xmake-multi-cpp-modules` 的多模块实践，将 moebius 作为子模块引入，可以统一构建机制、降低顶层复杂度，并保留 moebius 独立开发/测试的能力。

## 7 How

- 在 `moebius/xmake.lua` 中使用 `os.scriptdir()` 定位 moebius 根目录，确保独立构建（`cd moebius && xmake`）和子模块包含（`includes("moebius")`）两种模式下路径都正确。
- `libmoebius` 使用 `add_includedirs(moe_includedirs, {public = true})`，让依赖方无需再显式声明 moebius 头文件路径。
- 顶层 `xmake.lua` 删除内联 `libmoebius` 定义，并删除 `libmogan`/`stem` 中显式的 `add_includedirs(moe_includedirs)`。
- `xmake/tests.lua` 中测试目标已经通过 `add_deps("libmoebius")` 依赖 moebius，因此可直接移除 `add_packages("moebius")` 和 `add_includedirs(moe_includedirs)`。
- CI 迁移到顶层后直接使用顶层命令（如 `xmake build libmoebius`、`xmake test "moebius_tests/*"`），无需再设置 `working-directory: moebius`。
- 将 `src/Data/History/commute.cpp` 移动（`git mv`）到 `moebius/Data/History/commute.cpp`，内容保持不变，使 `libmoebius` 自包含 modification 交换/合并/逆运算实现。
